Are Hyperbolic Functions Supported in GPU.js?

Hyperbolic functions such as Math.sinh, Math.cosh, and Math.tanh are not natively supported inside GPU.js kernels. While standard trigonometric methods like Math.sin and Math.cos translate directly to WebGL shading language (GLSL), GPU.js lacks built-in native mappings for hyperbolic math methods. However, developers can easily compute hyperbolic operations within kernels by defining custom mathematical equivalents using the natively supported Math.exp() function.

Native Support Status in GPU.js

When GPU.js compiles a JavaScript function to run on the GPU, it translates JavaScript syntax into GLSL. GPU.js includes built-in support for standard arithmetic, exponential, logarithmic, and trigonometric functions:

  • Math.sin(x)
  • Math.cos(x)
  • Math.tan(x)
  • Math.asin(x)
  • Math.acos(x)
  • Math.atan(x)
  • Math.exp(x)
  • Math.log(x)

Hyperbolic functions (Math.sinh, Math.cosh, and Math.tanh) are omitted from this native transpilation layer. Attempting to call Math.sinh(x) directly inside a GPU.js kernel will result in a compilation error or runtime failure because the compiler cannot resolve the corresponding GLSL instruction.

Mathematical Workaround

Because WebGL shaders inherently support exponential calculation via exp(), you can replicate hyperbolic functions inside your kernel using their standard mathematical definitions:

  • Hyperbolic Sine (\(\sinh\)): \[\sinh(x) = \frac{e^x - e^{-x}}{2}\]
  • Hyperbolic Cosine (\(\cosh\)): \[\cosh(x) = \frac{e^x + e^{-x}}{2}\]
  • Hyperbolic Tangent (\(\tanh\)): \[\tanh(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}} = \frac{e^{2x} - 1}{e^{2x} + 1}\]

Implementing Hyperbolic Functions in GPU.js

You can define custom functions and register them using gpu.addFunction(), or write the calculations directly inside the kernel body.

Method 1: Using gpu.addFunction

Defining modular functions allows you to reuse hyperbolic calculations cleanly across multiple kernels:

const { GPU } = require('gpu.js');
const gpu = new GPU();

// Register hyperbolic functions
gpu.addFunction(function sinh(x) {
  return (Math.exp(x) - Math.exp(-x)) / 2.0;
});

gpu.addFunction(function cosh(x) {
  return (Math.exp(x) + Math.exp(-x)) / 2.0;
});

gpu.addFunction(function tanh(x) {
  const e2x = Math.exp(2.0 * x);
  return (e2x - 1.0) / (e2x + 1.0);
});

// Create kernel
const kernel = gpu.createKernel(function (data) {
  const val = data[this.thread.x];
  return tanh(val);
}).setOutput([512]);

Method 2: Inlining Calculations

If you only need a single calculation, inlining the exponential formula avoids creating external functions:

const kernel = gpu.createKernel(function (data) {
  const x = data[this.thread.x];
  
  // Inlined tanh implementation
  const expVal = Math.exp(2.0 * x);
  const tanhVal = (expVal - 1.0) / (expVal + 1.0);

  return tanhVal;
}).setOutput([512]);

Precision and Overflow Considerations

When using exponential-based implementations on the GPU, extreme input values (\(x > 88.0\) or \(x < -88.0\) in 32-bit floating-point precision) can cause Math.exp() to overflow to infinity or underflow to zero.

For stable performance with large values:

  • For large positive \(x\), \(\tanh(x)\) approaches 1.0.
  • For large negative \(x\), \(\tanh(x)\) approaches -1.0.

Clamping the input or checking boundary conditions in your custom function prevents NaN and infinity propagation during high-performance compute tasks.
