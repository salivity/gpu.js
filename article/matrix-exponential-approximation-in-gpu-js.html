Matrix Exponential Approximation in gpu.js

This article explains how to compute matrix exponential approximations using Taylor series expansions accelerated on the GPU with gpu.js. You will learn the mathematical foundation behind the Taylor series for matrix exponentials, how to implement parallel matrix multiplication and addition kernels, and how to structure the iterative accumulation process for maximum numerical stability and performance in JavaScript.

Mathematical Formulation

The matrix exponential \(e^A\) for a square matrix \(A \in \mathbb{R}^{n \times n}\) is defined by the convergent power series:

\[e^A = \sum_{k=0}^{\infty} \frac{A^k}{k!} = I + A + \frac{A^2}{2!} + \frac{A^3}{3!} + \dots\]

To approximate \(e^A\) computationally, the series is truncated to a finite order \(m\):

\[e^A \approx \sum_{k=0}^{m} T_k\]

where each term \(T_k\) can be defined iteratively to avoid overflow from large factorials:

\[T_0 = I\] \[T_k = T_{k-1} \cdot \frac{A}{k} = \frac{1}{k} (T_{k-1} A)\]

This recurrence relation minimizes the total number of operations to \(m\) matrix multiplications and \(m\) matrix additions.

Setting Up gpu.js Kernels

Computing matrix powers is an \(O(n^3)\) operation on the CPU. By using gpu.js, computations are compiled into WebGL shaders and executed concurrently across GPU threads.

Two primary GPU kernels are required:

  1. Matrix Multiplication (matMul): Multiplies two \(n \times n\) matrices.
  2. Matrix Add and Scale (matAddScaled): Adds a scaled term directly to the running sum accumulator.
const { GPU } = require('gpu.js');
const gpu = new GPU();

// Kernel: Parallel Matrix Multiplication (C = A * B)
function createMatMulKernel(n) {
  return gpu.createKernel(function (a, b, size) {
    let sum = 0;
    for (let i = 0; i < size; i++) {
      sum += a[this.thread.y][i] * b[i][this.thread.x];
    }
    return sum;
  })
  .setOutput([n, n])
  .setPipeline(true); // Keeps data in GPU memory as textures
}

// Kernel: Linear Combination / Element-wise Accumulation (Sum = Sum + Term * scalar)
function createAccumulateKernel(n) {
  return gpu.createKernel(function (sum, term, scalar) {
    return sum[this.thread.y][this.thread.x] + (term[this.thread.y][this.thread.x] * scalar);
  })
  .setOutput([n, n])
  .setPipeline(true);
}

Note: Enabling .setPipeline(true) avoids expensive CPU-GPU memory transfers between iterations by keeping intermediate matrices on the GPU as textures.

Implementing the Taylor Series Approximation

With the kernels initialized, the evaluation loop runs through the series up to degree \(m\).

function matrixExponential(A, n, terms = 20) {
  const matMul = createMatMulKernel(n);
  const accumulate = createAccumulateKernel(n);

  // Initialize Identity Matrix (I)
  const identity = [];
  for (let i = 0; i < n; i++) {
    identity[i] = new Float32Array(n);
    identity[i][i] = 1.0;
  }

  // T_0 = I, Accumulator = I
  let currentTerm = identity;
  let result = identity;

  for (let k = 1; k <= terms; k++) {
    // Compute currentTerm = currentTerm * A
    currentTerm = matMul(currentTerm, A, n);

    // Compute result = result + currentTerm * (1 / k!)
    // Note: Since currentTerm = A^k, the scalar is 1 / k!
    // Alternatively, update incrementally using scalar: 1 / k
    const scalar = 1 / factorial(k);
    result = accumulate(result, currentTerm, scalar);
  }

  // Extract final matrix from GPU texture back to JavaScript array
  return result.toArray();
}

function factorial(num) {
  let rval = 1;
  for (let i = 2; i <= num; i++) {
    rval *= i;
  }
  return rval;
}

Optimizing Numerical Stability: Scaling and Squaring

A naive truncated Taylor series diverges or produces severe floating-point round-off errors if the norm of \(A\) (\(\|A\|\)) is large. To solve this, pair the Taylor expansion with the scaling and squaring method, based on the identity:

\[e^A = \left(e^{A / 2^s}\right)^{2^s}\]

  1. Compute an integer \(s \ge 0\) such that \(\|A / 2^s\|_\infty \le 1\).
  2. Compute the matrix exponential approximation \(B \approx e^{A / 2^s}\) using the Taylor expansion.
  3. Square the resulting matrix \(s\) times: \(B \leftarrow B^2\).
function matrixExpScalingSquaring(A, n, terms = 16) {
  const matMul = createMatMulKernel(n);

  // Calculate matrix infinity norm
  let maxRowSum = 0;
  for (let i = 0; i < n; i++) {
    let rowSum = 0;
    for (let j = 0; j < n; j++) {
      rowSum += Math.abs(A[i][j]);
    }
    if (rowSum > maxRowSum) maxRowSum = rowSum;
  }

  // Determine scaling factor s
  const s = Math.max(0, Math.ceil(Math.log2(maxRowSum)));
  const scaleDivisor = Math.pow(2, s);

  // Scale input matrix A / (2^s)
  const scaledA = A.map(row => row.map(val => val / scaleDivisor));

  // Compute e^(A / 2^s) via Taylor series
  let expScaled = matrixExponential(scaledA, n, terms);

  // Repeated squaring: (e^(A / 2^s))^(2^s)
  for (let i = 0; i < s; i++) {
    expScaled = matMul(expScaled, expScaled, n);
  }

  return expScaled.toArray ? expScaled.toArray() : expScaled;
}

This hybrid approach guarantees rapid Taylor series convergence on the GPU while maintaining numerical stability across a wide range of input matrices.
