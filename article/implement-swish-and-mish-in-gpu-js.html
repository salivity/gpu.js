Implement Swish and Mish in gpu.js

This article provides a concise guide to implementing the forward pass of the Swish and Mish activation functions using gpu.js. You will learn the mathematical formulations for both non-linearities, how to translate their equations into compiled GPU kernels, and how to handle numerical stability to achieve fast, hardware-accelerated tensor operations directly in JavaScript.

Prerequisites and Setup

To run compute kernels on the GPU using JavaScript, install gpu.js:

npm install gpu.js

Initialize the main GPU instance in your script:

const { GPU } = require('gpu.js');
const gpu = new GPU();

1. Implementing the Swish Forward Pass

The Swish activation function is defined mathematically as:

\[\text{Swish}(x) = x \cdot \sigma(\beta x) = \frac{x}{1 + e^{-\beta x}}\]

When \(\beta = 1\), it simplifies to \(x \cdot \text{sigmoid}(x)\).

gpu.js Swish Kernel

const createSwishKernel = (length, beta = 1.0) => {
  return gpu.createKernel(function (input, betaVal) {
    const x = input[this.thread.x];
    return x / (1.0 + Math.exp(-betaVal * x));
  })
  .setOutput([length]);
};

// Usage
const dataSize = 5;
const swish = createSwishKernel(dataSize);
const inputData = [-2.0, -1.0, 0.0, 1.0, 2.0];
const swishOutput = swish(inputData, 1.0);

console.log(Array.from(swishOutput));
// Output: [-0.2384, -0.2689, 0, 0.7311, 1.7616]

2. Implementing the Mish Forward Pass

The Mish activation function is self-regularized and smooth, defined as:

\[\text{Mish}(x) = x \cdot \tanh(\text{softplus}(x)) = x \cdot \tanh(\ln(1 + e^x))\]

Because \(e^x\) can cause floating-point overflow for large values of \(x\), a threshold is typically applied: when \(x > 20\), \(\text{softplus}(x) \approx x\), so \(\tanh(x) \approx 1\), and \(\text{Mish}(x) \approx x\).

gpu.js Mish Kernel

const createMishKernel = (length) => {
  return gpu.createKernel(function (input) {
    const x = input[this.thread.x];

    // Numerical stability check for large positive values
    if (x > 20.0) {
      return x;
    }

    // Softplus: ln(1 + e^x)
    const softplus = Math.log(1.0 + Math.exp(x));
    
    // Mish: x * tanh(softplus)
    return x * Math.tanh(softplus);
  })
  .setOutput([length]);
};

// Usage
const mish = createMishKernel(dataSize);
const mishOutput = mish(inputData);

console.log(Array.from(mishOutput));
// Output: [-0.2525, -0.3034, 0, 0.8651, 1.9440]

2D Tensor (Matrix) Processing

In practical deep learning pipelines, activations process 2D matrices (batch size \(\times\) feature dimension). Below is an example applying Mish across a 2D tensor:

const createMish2DKernel = (width, height) => {
  return gpu.createKernel(function (matrix) {
    const x = matrix[this.thread.y][this.thread.x];

    if (x > 20.0) {
      return x;
    }

    const softplus = Math.log(1.0 + Math.exp(x));
    return x * Math.tanh(softplus);
  })
  .setOutput([width, height]);
};

// Example usage on a 2x3 matrix
const matrixInput = [
  [-1.0, 0.0, 1.0],
  [-2.0, 0.5, 2.0]
];

const mish2D = createMish2DKernel(3, 2);
const outputMatrix = mish2D(matrixInput);

console.log(outputMatrix.map(row => Array.from(row)));

Summary of Performance Considerations

  1. Precision: Standard WebGL targets typically compute using single-precision 32-bit floats (Math.exp and Math.log will run as 32-bit operations).
  2. Branching: The threshold check (x > 20.0) in the Mish kernel prevents standard float overflow (Infinity) while keeping branching divergence minimal across parallel thread warps.
  3. Pipelining: If these activations are part of a larger network, set pipeline: true on the kernel configuration to keep the results directly in GPU texture memory without transferring back to the CPU.
