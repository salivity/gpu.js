Implement FXAA Post-Processing in GPU.js

This article explains how to implement Fast Approximate Anti-Aliasing (FXAA) as a screen-space post-processing pass using gpu.js. You will learn the core algorithm behind FXAA, how to set up an image-processing pipeline using gpu.js graphical kernels, and how to write the edge detection and directional blur logic directly within a JavaScript-defined GPU kernel.

The FXAA Algorithm Overview

FXAA operates entirely in screen space after a scene has rendered, eliminating the memory and performance overhead of hardware Multi-Sample Anti-Aliasing (MSAA). The post-processing pass executes the following steps per pixel:

  1. Luminance Calculation: Convert the RGB values of the current pixel and its immediate neighbors (North, South, East, West) into perceptual luminance.
  2. Contrast Detection: Compute the local contrast range (maximum luminance minus minimum luminance). If the contrast is below a specified threshold, the pixel is on a flat surface and remains unblurred.
  3. Edge Direction Analysis: Compare horizontal and vertical luminance gradients to identify whether the detected edge runs horizontally or vertically.
  4. Sub-pixel Blending: Sample along the detected edge direction and blend neighboring pixels based on the local gradient magnitude to smooth the jagged edge.

Step 1: Initializing the GPU Instance

To run FXAA on an existing canvas render, configure a GPU instance capable of graphical output. Enable graphical mode using .setGraphical(true) to render directly to a WebGL canvas target.

const gpu = new GPU();

const width = 800;
const height = 600;

Step 2: Creating the FXAA Kernel

GPU.js allows you to write the shading logic using JavaScript syntax, which compiles to GLSL. The following kernel accepts an input texture or HTML Canvas element, performs neighborhood luminance sampling, and computes the anti-aliased output color.

const fxaaKernel = gpu.createKernel(function(src) {
    const x = this.thread.x;
    const y = this.thread.y;
    const w = this.constants.width;
    const h = this.constants.height;

    // Luminance weights based on human perception
    const lumaR = 0.299;
    const lumaG = 0.587;
    const lumaB = 0.114;

    // Center pixel
    const rgbM = src[y][x];
    const lumaM = rgbM[0] * lumaR + rgbM[1] * lumaG + rgbM[2] * lumaB;

    // Safe clamped neighbor coordinates
    const xL = Math.max(0, x - 1);
    const xR = Math.min(w - 1, x + 1);
    const yD = Math.max(0, y - 1);
    const yU = Math.min(h - 1, y + 1);

    // Cardinal neighbor samples
    const rgbN = src[yU][x];
    const rgbS = src[yD][x];
    const rgbW = src[y][xL];
    const rgbE = src[y][xR];

    const lumaN = rgbN[0] * lumaR + rgbN[1] * lumaG + rgbN[2] * lumaB;
    const lumaS = rgbS[0] * lumaR + rgbS[1] * lumaG + rgbS[2] * lumaB;
    const lumaW = rgbW[0] * lumaR + rgbW[1] * lumaG + rgbW[2] * lumaB;
    const lumaE = rgbE[0] * lumaR + rgbE[1] * lumaG + rgbE[2] * lumaB;

    // Local contrast detection
    const rangeMin = Math.min(lumaM, Math.min(Math.min(lumaN, lumaS), Math.min(lumaW, lumaE)));
    const rangeMax = Math.max(lumaM, Math.max(Math.max(lumaN, lumaS), Math.max(lumaW, lumaE)));
    const range = rangeMax - rangeMin;

    // Early exit if contrast is below edge detection thresholds
    const edgeThresholdMin = 0.0312;
    const edgeThresholdMax = 0.125;
    if (range < Math.max(edgeThresholdMin, rangeMax * edgeThresholdMax)) {
        this.color(rgbM[0], rgbM[1], rgbM[2], 1.0);
        return;
    }

    // Diagonal neighbor samples
    const rgbNW = src[yU][xL];
    const rgbNE = src[yU][xR];
    const rgbSW = src[yD][xL];
    const rgbSE = src[yD][xR];

    const lumaNW = rgbNW[0] * lumaR + rgbNW[1] * lumaG + rgbNW[2] * lumaB;
    const lumaNE = rgbNE[0] * lumaR + rgbNE[1] * lumaG + rgbNE[2] * lumaB;
    const lumaSW = rgbSW[0] * lumaR + rgbSW[1] * lumaG + rgbSW[2] * lumaB;
    const lumaSE = rgbSE[0] * lumaR + rgbSE[1] * lumaG + rgbSE[2] * lumaB;

    // Direction calculation
    const edgeHorz = Math.abs((lumaNW + 2.0 * lumaN + lumaNE) - (lumaSW + 2.0 * lumaS + lumaSE));
    const edgeVert = Math.abs((lumaNW + 2.0 * lumaW + lumaSW) - (lumaNE + 2.0 * lumaE + lumaSE));
    const isHorizontal = edgeHorz >= edgeVert;

    // Normal gradient computation
    const luma1 = isHorizontal ? lumaS : lumaW;
    const luma2 = isHorizontal ? lumaN : lumaE;
    const gradient1 = Math.abs(luma1 - lumaM);
    const gradient2 = Math.abs(luma2 - lumaM);

    const stepLength = gradient1 >= gradient2 ? -1.0 : 1.0;

    // Sample along the determined edge
    let sampleX = x;
    let sampleY = y;

    if (isHorizontal) {
        sampleY = Math.max(0, Math.min(h - 1, y + stepLength * 0.5));
    } else {
        sampleX = Math.max(0, Math.min(w - 1, x + stepLength * 0.5));
    }

    // Low-pass filter blend across the edge
    const rgbSubA = 0.5 * (src[Math.floor(sampleY)][Math.floor(sampleX)][0] + rgbM[0]);
    const rgbSubB = 0.5 * (src[Math.floor(sampleY)][Math.floor(sampleX)][1] + rgbM[1]);
    const rgbSubC = 0.5 * (src[Math.floor(sampleY)][Math.floor(sampleX)][2] + rgbM[2]);

    this.color(rgbSubA, rgbSubB, rgbSubC, 1.0);
})
.setConstants({ width, height })
.setOutput([width, height])
.setGraphical(true);

Step 3: Executing the Post-Processing Pipeline

To process a frame:

  1. Render your primary scene to an offscreen canvas or frame buffer.
  2. Pass the rendered canvas or texture data to the fxaaKernel.
  3. Display or swap the resulting fxaaKernel.canvas into the DOM.
function applyAntiAliasing(sourceCanvas) {
    // Execute kernel pass
    fxaaKernel(sourceCanvas);

    // fxaaKernel.canvas contains the final anti-aliased frame
    const finalCanvas = fxaaKernel.canvas;
    return finalCanvas;
}

Tuning and Performance Considerations

  • Edge Thresholds: Adjusting edgeThresholdMin (clamp threshold) and edgeThresholdMax (relative contrast) controls edge sensitivity. Lower values capture subtle edges at the cost of slight blurring in textured areas.
  • Performance: In gpu.js, sampling 9 distinct coordinates produces uniform texture lookups. Keep the input and output resolutions identical to maintain a 1:1 pixel mapping. Ensure input canvases are passed as direct references without manual array conversions to leverage WebGL textures.
