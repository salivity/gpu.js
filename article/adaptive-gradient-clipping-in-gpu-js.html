Adaptive Gradient Clipping in GPU.js

Adaptive gradient clipping (AGC) stabilizes neural network training by dynamically scaling gradient updates relative to parameter magnitudes, eliminating the instability of fixed-threshold global clipping. This article provides a direct implementation guide for executing layer-wise adaptive gradient clipping across multi-layer parameter buffers using gpu.js. It details the mathematical formulation, kernel structure for computing tensor norms, and execution pipelines that maintain tensor data on the GPU to maximize performance.

Understanding Adaptive Gradient Clipping

Standard gradient clipping scales gradients based on a static global threshold. In contrast, Adaptive Gradient Clipping scales the gradient of layer \(l\) based on the ratio of the Frobenius norm of its weights \(\|W_l\|_F\) to the Frobenius norm of its gradients \(\|G_l\|_F\):

\[G_l \leftarrow G_l \cdot \min\left(1, \frac{\lambda \cdot \max(\|W_l\|_F, \epsilon)}{\|G_l\|_F + \epsilon}\right)\]

Here, \(\lambda\) is a user-defined clipping threshold (typically \(0.01\) to \(0.1\)), and \(\epsilon\) is a small constant (e.g., \(10^{-3}\)) to prevent division by zero and handle zero-initialized parameters.

Architectural Pipeline in GPU.js

In gpu.js, memory transfers between the CPU and GPU introduce significant latency. To make AGC efficient, the pipeline must execute fully on the GPU:

  1. Squared Sum Map: Parallel calculation of element-wise squares for weights and gradients.
  2. Norm Reduction: Summing the squared elements into single scalar values representing \(\|W_l\|^2\) and \(\|G_l\|^2\).
  3. Adaptive Scale and Clip: Evaluating the scaling factor and multiplying the gradient buffer in parallel.

Step 1: Norm Computation Kernels

Because WebGL shaders lack atomic operations for single-step reductions across arbitrary buffer sizes, computing the Frobenius norm requires a mapping kernel followed by a reduction step.

const { GPU } = require('gpu.js');
const gpu = new GPU();

// Map kernel to compute element-wise squares
const computeSquaredElements = gpu.createKernel(function(tensor) {
    const val = tensor[this.thread.x];
    return val * val;
}, {
    output: [1], // Configured dynamically based on buffer length
    pipeline: true
});

// Sum reduction kernel (chunks of power-of-two or flat reduction)
function calculateNorm(gpuInstance, buffer, length) {
    const squareKernel = gpuInstance.createKernel(function(data) {
        return data[this.thread.x] * data[this.thread.x];
    }).setOutput([length]);

    const squaredData = squareKernel(buffer);
    
    // Summing elements (efficiently executed on CPU if buffer fits, or via tree-reduction on GPU)
    let sum = 0;
    for (let i = 0; i < length; i++) {
        sum += squaredData[i];
    }
    return Math.sqrt(sum);
}

For large layers, perform a hierarchical tree reduction inside gpu.js by iteratively halving buffer dimensions.

Step 2: Adaptive Gradient Clipping Kernel

Once norms are extracted, use a vector kernel to scale gradients element-wise.

const applyAdaptiveClipping = gpu.createKernel(function(
    gradients, 
    weights, 
    gradNorm, 
    weightNorm, 
    lambda, 
    epsilon
) {
    const g = gradients[this.thread.x];
    const wNorm = Math.max(weightNorm, epsilon);
    const maxNorm = lambda * wNorm;
    const triggerNorm = gradNorm + epsilon;

    if (triggerNorm > maxNorm) {
        return g * (maxNorm / triggerNorm);
    }
    return g;
}, {
    output: [1], // Set dynamically to layer buffer length
    pipeline: true
});

Step 3: Managing Multi-Layer Buffers

Multi-layer architectures store weights and gradients as arrays of buffers. To avoid compile overhead, compile kernels once to the maximum layer buffer size, or allocate kernels tailored to each layer's specific dimension.

class MultiLayerAGC {
    constructor(layerSizes, lambda = 0.01, epsilon = 1e-3) {
        this.gpu = new GPU();
        this.lambda = lambda;
        this.epsilon = epsilon;
        this.layerSizes = layerSizes;

        // Pre-compile kernels per layer geometry
        this.clipKernels = layerSizes.map(size => {
            return this.gpu.createKernel(function(G, W, gNorm, wNorm, lambda, eps) {
                const g = G[this.thread.x];
                const maxG = lambda * Math.max(wNorm, eps);
                const denom = gNorm + eps;
                const factor = maxG / denom;
                
                if (factor < 1.0) {
                    return g * factor;
                }
                return g;
            })
            .setOutput([size])
            .setPipeline(true);
        });
    }

    clipGradients(weightBuffers, gradientBuffers) {
        const clippedGradients = [];

        for (let i = 0; i < this.layerSizes.length; i++) {
            const size = this.layerSizes[i];
            const W = weightBuffers[i];
            const G = gradientBuffers[i];

            // 1. Calculate Frobenius Norms
            const wNorm = calculateNorm(this.gpu, W, size);
            const gNorm = calculateNorm(this.gpu, G, size);

            // 2. Dispatch adaptive clipping kernel
            const clippedG = this.clipKernels[i](
                G, 
                W, 
                gNorm, 
                wNorm, 
                this.lambda, 
                this.epsilon
            );

            clippedGradients.push(clippedG);
        }

        return clippedGradients;
    }
}

Execution Considerations

  • Pipeline Mode: Set pipeline: true on gpu.js kernels to output GPU textures instead of round-tripping Float32Array objects back to the CPU between network layers.
  • Granularity: Adaptive clipping should be applied independently per parameter tensor (e.g., separating weights from biases) because biases typically have much smaller norms and different scale dynamics.
  • Epsilon Tuning: If training with 16-bit precision textures, increase \(\epsilon\) to 1e-4 or 1e-3 to prevent numerical underflow during norm calculations.
