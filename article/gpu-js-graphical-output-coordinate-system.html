GPU.js Graphical Output Coordinate System

When rendering graphical output to an HTML canvas, GPU.js uses a Cartesian coordinate system rooted at the bottom-left corner of the canvas, adhering to standard WebGL conventions rather than traditional HTML5 2D canvas coordinates. In this system, coordinate (0, 0) represents the bottom-left pixel, with values along the X-axis increasing to the right and values along the Y-axis increasing upward. Understanding this layout is essential for properly orienting shapes, textures, and rendered effects when using GPU.js in graphical mode.

The WebGL Origin (Bottom-Left)

Because GPU.js compiles JavaScript functions into WebGL fragment shaders, it inherits WebGL's native screen-space coordinates. When you initialize a kernel with { graphical: true }, GPU.js maps your kernel threads directly to canvas pixels:

  • this.thread.x: Represents the horizontal pixel index, starting at 0 on the far-left edge and increasing to width - 1 on the far-right edge.
  • this.thread.y: Represents the vertical pixel index, starting at 0 on the bottom edge and increasing to height - 1 on the top edge.

Contrast with the HTML5 Canvas 2D API

Developers familiar with the standard HTML5 Canvas 2D context (CanvasRenderingContext2D) often expect the origin (0, 0) to reside in the top-left corner, with the Y-axis increasing downward.

If you port algorithms directly from Canvas 2D to a GPU.js graphical kernel without accounting for this difference, your output will appear vertically inverted (flipped upside down).

Inverting the Y-Axis

If your project requires a top-left origin to match external image data or typical web canvas conventions, you can easily invert the vertical axis inside your kernel using the output height:

const render = gpu.createKernel(function() {
    // Invert the Y-axis to match top-left origin conventions
    const invertedY = this.constants.height - 1 - this.thread.y;
    const x = this.thread.x;

    // Set pixel color: this.color(r, g, b, a)
    this.color(x / this.constants.width, invertedY / this.constants.height, 0, 1);
}, {
    constants: { width: 512, height: 512 },
    output: [512, 512],
    graphical: true
});

By explicitly mapping this.thread.y to an inverted variable, you can write rendering logic matching whichever coordinate orientation best suits your application.
