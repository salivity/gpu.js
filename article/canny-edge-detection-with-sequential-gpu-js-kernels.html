Canny Edge Detection with Sequential gpu.js Kernels

This article details the implementation of a multi-stage Canny edge detection pipeline in the browser using gpu.js. By breaking down the algorithm into discrete stages—noise reduction, gradient calculation, non-maximum suppression, and hysteresis thresholding—developers can leverage WebGL acceleration through sequential compute passes. Utilizing the gpu.js texture pipelining feature enables passing intermediate output buffers directly between execution stages in GPU memory, avoiding costly CPU-GPU data transfers until the final processed image is retrieved.

Pipeline Architecture and Kernel Chaining

Executing multi-pass image processing algorithms in gpu.js requires enabling texture output via setPipeline(true). Instead of returning an array of numbers to the CPU after each step, each kernel outputs a WebGL texture that is fed directly as a parameter into the next kernel.

const gpu = new GPU();

Stage 1: Gaussian Blur Kernel

The Canny algorithm begins with noise reduction, as edge detection is highly sensitive to high-frequency pixel noise. A 5x5 Gaussian kernel convolves the input grayscale image to produce a smoothed image.

const gaussianBlur = gpu.createKernel(function(image) {
    const kernel = [
        [2,  4,  5,  4, 2],
        [4,  9, 12,  9, 4],
        [5, 12, 15, 12, 5],
        [4,  9, 12,  9, 4],
        [2,  4,  5,  4, 2]
    ];
    let sum = 0.0;
    for (let i = -2; i <= 2; i++) {
        for (let j = -2; j <= 2; j++) {
            sum += image[this.thread.y + i][this.thread.x + j] * kernel[i + 2][j + 2];
        }
    }
    return sum / 159.0;
})
.setOutput([width, height])
.setPipeline(true);

Stage 2: Gradient Intensity and Direction Kernel

The smoothed image is processed using horizontal and vertical Sobel operators to determine the gradient magnitude and edge direction at each pixel. Because gpu.js kernels typically return scalar values or RGB vectors, the gradient magnitude can be stored in one channel and the quantized angle (0°, 45°, 90°, or 135°) in another.

const sobelFilter = gpu.createKernel(function(blurredImage) {
    const x = this.thread.x;
    const y = this.thread.y;

    // Sobel Gx
    const gx = (
        -1.0 * blurredImage[y - 1][x - 1] + 1.0 * blurredImage[y - 1][x + 1] +
        -2.0 * blurredImage[y][x - 1]     + 2.0 * blurredImage[y][x + 1] +
        -1.0 * blurredImage[y + 1][x - 1] + 1.0 * blurredImage[y + 1][x + 1]
    );

    // Sobel Gy
    const gy = (
        -1.0 * blurredImage[y - 1][x - 1] - 2.0 * blurredImage[y - 1][x] - 1.0 * blurredImage[y - 1][x + 1] +
         1.0 * blurredImage[y + 1][x - 1] + 2.0 * blurredImage[y + 1][x] + 1.0 * blurredImage[y + 1][x + 1]
    );

    const magnitude = Math.sqrt(gx * gx + gy * gy);
    let angle = Math.atan2(gy, gx) * (180.0 / Math.PI);
    if (angle < 0.0) angle += 180.0;

    // Quantize direction: 0 (0°), 1 (45°), 2 (90°), 3 (135°)
    let direction = 0.0;
    if ((angle >= 0.0 && angle < 22.5) || (angle >= 157.5 && angle <= 180.0)) {
        direction = 0.0;
    } else if (angle >= 22.5 && angle < 67.5) {
        direction = 1.0;
    } else if (angle >= 67.5 && angle < 112.5) {
        direction = 2.0;
    } else if (angle >= 112.5 && angle < 157.5) {
        direction = 3.0;
    }

    this.color(magnitude, direction, 0.0, 1.0);
})
.setOutput([width, height])
.setPipeline(true);

Stage 3: Non-Maximum Suppression (NMS) Kernel

Non-maximum suppression thins the edges by preserving only the local maxima along the gradient direction. For each pixel, the kernel compares the magnitude to its two neighbors along the quantized gradient angle. If the current pixel is not greater than both neighbors, its magnitude is set to zero.

const nonMaxSuppression = gpu.createKernel(function(sobelTexture) {
    const x = this.thread.x;
    const y = this.thread.y;

    const currentPixel = sobelTexture[y][x];
    const mag = currentPixel[0];
    const dir = currentPixel[1];

    let neighborA = 0.0;
    let neighborB = 0.0;

    if (dir === 0.0) { // 0 degrees (East - West)
        neighborA = sobelTexture[y][x + 1][0];
        neighborB = sobelTexture[y][x - 1][0];
    } else if (dir === 1.0) { // 45 degrees (North-East - South-West)
        neighborA = sobelTexture[y - 1][x + 1][0];
        neighborB = sobelTexture[y + 1][x - 1][0];
    } else if (dir === 2.0) { // 90 degrees (North - South)
        neighborA = sobelTexture[y - 1][x][0];
        neighborB = sobelTexture[y + 1][x][0];
    } else if (dir === 3.0) { // 135 degrees (North-West - South-East)
        neighborA = sobelTexture[y - 1][x - 1][0];
        neighborB = sobelTexture[y + 1][x + 1][0];
    }

    if (mag >= neighborA && mag >= neighborB) {
        return mag;
    } else {
        return 0.0;
    }
})
.setOutput([width, height])
.setPipeline(true);

Stage 4: Double Thresholding and Hysteresis Kernel

The final stage classifies pixels into strong, weak, and non-edges based on high and low thresholds. Hysteresis edge tracking is implemented by promoting weak edge pixels to strong edges if they are adjacent to at least one strong edge pixel within an 8-connected neighborhood.

const hysteresisThreshold = gpu.createKernel(function(nmsTexture, lowThreshold, highThreshold) {
    const x = this.thread.x;
    const y = this.thread.y;
    const mag = nmsTexture[y][x];

    if (mag >= highThreshold) {
        return 1.0; // Strong edge
    } else if (mag < lowThreshold) {
        return 0.0; // Non-edge
    } else {
        // Weak edge: check 8-connected neighbors for strong edges
        let hasStrongNeighbor = 0.0;
        for (let i = -1; i <= 1; i++) {
            for (let j = -1; j <= 1; j++) {
                if (nmsTexture[y + i][x + j] >= highThreshold) {
                    hasStrongNeighbor = 1.0;
                }
            }
        }
        return hasStrongNeighbor;
    }
})
.setOutput([width, height]);

Orchestrating Sequential Execution

The complete pipeline is invoked sequentially. The intermediate outputs remain in VRAM as GPU textures, avoiding memory bottlenecks until the final hysteresis pass returns the detected edges.

function runCannyPipeline(inputImageMatrix, lowThresh, highThresh) {
    const blurred = gaussianBlur(inputImageMatrix);
    const sobel = sobelFilter(blurred);
    const nms = nonMaxSuppression(sobel);
    const finalEdges = hysteresisThreshold(nms, lowThresh, highThresh);

    // Clean up pipeline textures to free GPU memory
    blurred.delete();
    sobel.delete();
    nms.delete();

    return finalEdges;
}
