Measure Frame Rate Stability and P99 Latency in GPU.js

This article explains how to accurately benchmark continuous rendering workloads in gpu.js by tracking execution times, determining frame rate stability, and calculating 99th percentile (p99) latency. By leveraging the browser's performance.now() API alongside requestAnimationFrame, you can capture precise frame intervals, account for GPU pipeline stalls, and statistically analyze frame consistency to detect micro-stuttering in compute-heavy or graphical pipelines.

The Measurement Strategy

gpu.js compiles JavaScript functions into WebGL shaders. In continuous rendering loops, workloads run inside a requestAnimationFrame (rAF) loop, rendering either directly to a canvas using kernel.setGraphical(true) or reading data back to the CPU.

To measure performance reliably:

  1. Track Frame Intervals (Delta Time): Record the exact elapsed time between consecutive render loops to measure frame rate and its variance.
  2. Track Kernel Execution Time: Record the wall-clock time required for the kernel call itself (including CPU-GPU dispatch overhead).
  3. Sort and Percentile: Store rolling window data, sort the recorded durations, and extract the p99 value.

Because WebGL calls are asynchronous, if your kernel outputs directly to a graphical canvas, measuring with performance.now() strictly around the kernel call measures CPU dispatch time, not complete GPU rasterization. Measuring the time delta between successive requestAnimationFrame callbacks provides the true end-to-end frame latency experienced by the display.

Implementing the Benchmarking Harness

Below is a complete implementation showing how to execute a continuous rendering kernel and record both frame rate stability metrics (via Standard Deviation) and p99 latency.

const gpu = new GPU();

// Create a graphical kernel outputting to canvas
const renderKernel = gpu.createKernel(function() {
    this.color(Math.sin(this.thread.x), Math.cos(this.thread.y), 0.5, 1);
})
.setOutput([800, 600])
.setGraphical(true);

document.body.appendChild(renderKernel.canvas);

// Metrics collection buffer
const FRAME_BUFFER_SIZE = 1000;
const frameDeltas = [];
let lastTimestamp = performance.now();

function renderLoop() {
    const currentTimestamp = performance.now();
    const delta = currentTimestamp - lastTimestamp;
    lastTimestamp = currentTimestamp;

    // Execute the kernel
    renderKernel();

    // Store frame time delta (skip the first frame initialization)
    if (frameDeltas.length < FRAME_BUFFER_SIZE) {
        frameDeltas.push(delta);
    } else {
        frameDeltas.shift();
        frameDeltas.push(delta);
    }

    requestAnimationFrame(renderLoop);
}

// Start loop
requestAnimationFrame(renderLoop);

Calculating P99 Latency

P99 latency represents the frame time below which 99% of all frames fall. It highlights worst-case micro-stutters that average frame rates conceal.

function getP99Latency(times) {
    if (times.length === 0) return 0;

    // Create a sorted copy of the times
    const sorted = [...times].sort((a, b) => a - b);
    
    // Find the 99th percentile index
    const p99Index = Math.floor(sorted.length * 0.99);
    
    return sorted[p99Index];
}

Calculating Frame Rate Stability

Frame rate stability is quantified by evaluating the variability of frame times. High variability indicates jitter and dropped frames. Two primary metrics define this stability:

  1. Standard Deviation (\(\sigma\)): A lower standard deviation indicates higher frame time consistency.
  2. 1% Low FPS: Indicates the average of the worst 1% of frames, offering a tangible frame rate minimum.
function calculateStabilityMetrics(times) {
    if (times.length === 0) return { mean: 0, stdDev: 0, fps: 0, onePercentLowFPS: 0 };

    const count = times.length;
    const mean = times.reduce((acc, val) => acc + val, 0) / count;

    // Calculate Standard Deviation
    const variance = times.reduce((acc, val) => acc + Math.pow(val - mean, 2), 0) / count;
    const stdDev = Math.sqrt(variance);

    // Calculate 1% Lows
    const sorted = [...times].sort((a, b) => a - b);
    const worstOnePercentCount = Math.max(1, Math.floor(count * 0.01));
    const worstFrames = sorted.slice(-worstOnePercentCount);
    const worstMean = worstFrames.reduce((acc, val) => acc + val, 0) / worstOnePercentCount;

    return {
        averageFrameTimeMs: mean.toFixed(2),
        fps: (1000 / mean).toFixed(1),
        stdDevMs: stdDev.toFixed(2),
        p99LatencyMs: getP99Latency(times).toFixed(2),
        onePercentLowFPS: (1000 / worstMean).toFixed(1)
    };
}

Accurate GPU Timing with Disjoint Timer Queries

When you must measure purely the GPU compute time of the kernel—isolated from the browser compositor and JavaScript overhead—use the EXT_disjoint_timer_query_webgl2 extension.

  1. Acquire the underlying WebGL context via renderKernel.context.
  2. Wrap renderKernel() between gl.beginQuery(ext.TIME_ELAPSED_EXT, query) and gl.endQuery(ext.TIME_ELAPSED_EXT).
  3. Check asynchronously with gl.getQueryParameter(query, gl.QUERY_RESULT_AVAILABLE) to retrieve the nanosecond-accurate GPU execution time once complete.
  4. Pass these query results through the same P99 and standard deviation algorithms to isolate GPU-bound stability from main-thread CPU interference.
