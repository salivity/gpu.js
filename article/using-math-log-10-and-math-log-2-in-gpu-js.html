Using Math.log10 and Math.log2 in gpu.js

This article explains whether gpu.js can parse JavaScript's native Math.log10 and Math.log2 functions and how to correctly implement base-10 and base-2 logarithmic operations inside GPU kernels. While gpu.js translates JavaScript into WebGL/GLSL shader code, it does not provide native support for every standard JavaScript Math method. Understanding these parser limitations allows you to compute non-natural logarithms efficiently using supported alternatives.

Parser Support for Math.log10 and Math.log2

The short answer is no. The gpu.js transpiler cannot directly parse Math.log10 or Math.log2.

gpu.js operates by parsing the JavaScript Abstract Syntax Tree (AST) of a kernel function and converting supported nodes into corresponding GLSL (OpenGL Shading Language) primitives. The parser only whitelists a specific subset of the standard JavaScript Math library.

When you attempt to use Math.log10(x) or Math.log2(x) inside a kernel function, gpu.js fails during compilation and throws an error indicating that the function or method is unsupported.

The Supported Method: Math.log

In gpu.js, the only logarithmic function recognized by the AST parser is Math.log(), which maps directly to the native GLSL log() function. In both GLSL and JavaScript, Math.log() computes the natural logarithm (base e).

// This works natively in gpu.js
const kernel = gpu.createKernel(function(x) {
    return Math.log(x[this.thread.x]);
}).setOutput([100]);

How to Implement Base-10 and Base-2 Logarithms

To compute base-10 or base-2 logarithms inside a gpu.js kernel, you must apply the mathematical change-of-base formula:

\[\log_b(x) = \frac{\ln(x)}{\ln(b)}\]

Because Math.log() is fully supported, divide the natural logarithm of your value by the natural logarithm of the desired base.

Implementing Base-10 Logarithm

To compute \(\log_{10}(x)\), divide Math.log(x) by the natural log of 10 (\(\ln(10) \approx 2.302585092994046\)):

const gpu = new GPU();

const log10Kernel = gpu.createKernel(function(arr) {
    // Math.log(10) evaluates to ~2.302585093
    return Math.log(arr[this.thread.x]) / 2.302585093;
}).setOutput([100]);

Implementing Base-2 Logarithm

To compute \(\log_2(x)\), divide Math.log(x) by the natural log of 2 (\(\ln(2) \approx 0.6931471805599453\)):

const gpu = new GPU();

const log2Kernel = gpu.createKernel(function(arr) {
    // Math.log(2) evaluates to ~0.69314718
    return Math.log(arr[this.thread.x]) / 0.69314718;
}).setOutput([100]);

Optimization Tip: Multiplication vs. Division

On GPU architectures, floating-point multiplication is generally faster than division. You can optimize base conversion by multiplying by the precomputed reciprocal rather than dividing:

  • Base-10 Multiplier (\(1 / \ln(10)\)): 0.4342944819
  • Base-2 Multiplier (\(1 / \ln(2)\)): 1.44269504089
const fastLogKernels = gpu.createKernel(function(arr) {
    let val = arr[this.thread.x];
    
    let base10 = Math.log(val) * 0.4342944819;
    let base2  = Math.log(val) * 1.4426950409;
    
    return base10;
}).setOutput([100]);

Using precomputed literal constants ensures maximum compatibility with the gpu.js AST parser and provides the highest execution throughput on the underlying GPU hardware.
