Using Arrow Functions with gpu.addFunction in GPU.js

Modern versions of GPU.js (v2 and later) support arrow functions when using gpu.addFunction, but they must satisfy specific syntax and declaration requirements. Because GPU.js translates JavaScript functions into GLSL shaders at runtime, an arrow function must have an identifiable name, explicit block structure, and compatible return statements to compile correctly into the GPU pipeline.

How GPU.js Handles Arrow Functions

GPU.js relies on an internal Abstract Syntax Tree (AST) parser to analyze JavaScript source code and transpile it into WebGL-compatible GLSL code. While older versions struggled with modern ES6 syntax, current versions parse arrow functions reliably.

However, GLSL requires every function to have a formal name, argument types, and a return type. A standard function declaration (function add(a, b) { ... }) provides the identifier automatically, whereas arrow functions are inherently anonymous expressions unless explicitly assigned.

Requirements for Passing Arrow Functions

To successfully register an arrow function via gpu.addFunction, you must adhere to the following rules:

  1. Named Assignment or Explicit Identifier: The arrow function must be assigned to a variable before registration so that JavaScript sets its .name property, or you must specify the function name manually in the configuration object.

    // Recommended: Named constant
const square = (x) => {
  return x * x;
};
gpu.addFunction(square);

    Passing an anonymous arrow function directly without an identifier (e.g., gpu.addFunction((x) => x * x)) will fail because the compiler cannot generate the corresponding GLSL function signature.

  2. Explicit Block and Return Statements: Avoid concise body syntax (omitting braces). GPU.js parses the block for a ReturnStatement node. Always write full function bodies using curly braces {} and an explicit return keyword.

    // Avoid:
const double = (x) => x * 2.0;

// Use:
const double = (x) => {
  return x * 2.0;
};

  3. Type Definitions: GLSL is strictly typed. If GPU.js cannot infer the argument or return types from the arrow function's implementation, pass the optional settings object to declare them explicitly:

    const multiply = (a, b) => {
  return a * b;
};

gpu.addFunction(multiply, {
  argumentTypes: { a: 'Float', b: 'Float' },
  returnType: 'Float'
});

Summary

Arrow functions can be used with gpu.addFunction in modern GPU.js setups as long as they are assigned to a variable (providing a name), utilize standard block syntax with explicit return statements, and supply proper type declarations when type inference is not possible.
