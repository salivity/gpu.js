Bark Scale Energy Bands from FFT in gpu.js

Calculating psychoacoustic Bark scale energy bands from Fast Fourier Transform (FFT) bins models human auditory perception by grouping linear frequencies into critical bandwidths. By executing this transformation in gpu.js, web applications can process audio frames in parallel on the GPU to reduce main-thread latency. This guide covers how to precompute frequency-to-bin boundaries and execute a GPU kernel that aggregates FFT bin magnitudes into 24 Bark scale energy values.

Understanding the Bark Scale and FFT Bins

The Bark scale spans from 1 to 24, corresponding to the 24 critical bands of human hearing. Each band reflects the ear's frequency resolution, which is roughly linear below 500 Hz and logarithmic above.

An FFT breaks audio into \(N/2\) discrete linear bins. The center frequency \(f\) of any bin index \(k\) is calculated as:

\[f(k) = k \cdot \frac{F_s}{N}\]

where \(F_s\) is the sampling rate and \(N\) is the FFT size. To convert these linear bins into Bark energy bands, you must sum the spectral power (magnitude squared) of all bins that fall within each Bark band's boundary frequencies.

The standard lower/upper frequency edges (in Hz) for the 24 Bark critical bands are:

[0, 100, 200, 300, 400, 510, 630, 770, 920, 1080, 1270, 1480, 1720, 2000, 2320, 2700, 3150, 3700, 4400, 5300, 6400, 7700, 9500, 12000, 15500]

Step 1: Precomputing Bin Boundaries on the CPU

Because GPU threads operate independently, computing frequency-to-bin lookups dynamically inside a shader can introduce branching overhead. Instead, precalculate the start and end bin indices on the CPU once during initialization.

const BARK_EDGES = [
  0, 100, 200, 300, 400, 510, 630, 770, 920, 1080, 1270, 1480,
  1720, 2000, 2320, 2700, 3150, 3700, 4400, 5300, 6400, 7700,
  9500, 12000, 15500
];

function computeBarkBinRanges(sampleRate, fftSize) {
  const numBands = 24;
  const binResolution = sampleRate / fftSize;
  const maxBin = fftSize / 2;

  const starts = new Int32Array(numBands);
  const ends = new Int32Array(numBands);

  for (let i = 0; i < numBands; i++) {
    const startFreq = BARK_EDGES[i];
    const endFreq = BARK_EDGES[i + 1];

    starts[i] = Math.min(Math.floor(startFreq / binResolution), maxBin);
    ends[i] = Math.min(Math.floor(endFreq / binResolution), maxBin);

    // Ensure at least one bin per band to avoid empty loops
    if (ends[i] <= starts[i]) {
      ends[i] = starts[i] + 1;
    }
  }

  return { starts, ends };
}

Step 2: Creating the gpu.js Kernel

The gpu.js kernel runs across 24 parallel threads, where each thread index (this.thread.x) computes the total energy for one Bark band.

Inside the kernel, the thread reads its corresponding start and end bin indices, iterates over the FFT magnitudes, squares each value to obtain energy, and returns the accumulated sum.

import { GPU } from 'gpu.js';

const gpu = new GPU();

function createBarkEnergyKernel() {
  return gpu.createKernel(function (fftMagnitudes, bandStarts, bandEnds) {
    const bandIndex = this.thread.x;
    const startBin = bandStarts[bandIndex];
    const endBin = bandEnds[bandIndex];

    let energy = 0.0;

    for (let i = startBin; i < endBin; i++) {
      const mag = fftMagnitudes[i];
      energy += mag * mag;
    }

    return energy;
  })
  .setOutput([24])
  .setPipeline(true); // Optional: keeps output as a WebGL texture for downstream GPU kernels
}

Step 3: Executing the Kernel with Audio Data

Pass the linear FFT magnitude array along with the precomputed bin boundary arrays into the compiled kernel.

// Setup parameters
const sampleRate = 44100;
const fftSize = 2048; // Results in 1024 magnitude bins
const { starts, ends } = computeBarkBinRanges(sampleRate, fftSize);
const barkKernel = createBarkEnergyKernel();

// Process an incoming FFT frame
function processFFTFrame(fftMagnitudes) {
  // fftMagnitudes must be a Float32Array of length fftSize / 2
  const barkEnergies = barkKernel(fftMagnitudes, starts, ends);
  
  // If pipeline mode is false or .toArray() is called:
  return barkEnergies.toArray ? barkEnergies.toArray() : barkEnergies;
}

Considerations for Real-Time Pipelines

  • Band Overlap and Weighting: The standard box-filter approach assigns each FFT bin exclusively to one Bark band. For higher psychoacoustic fidelity, you can replace the range loop with a sparse critical-band weighting matrix that incorporates triangular or trapezoidal filters.
  • Pipeline Mode: If the Bark energies are passed directly into subsequent GPU operations (such as Mel-frequency cepstral coefficients or spectral flateness routines), leave .setPipeline(true) enabled to avoid expensive GPU-to-CPU memory readbacks.
