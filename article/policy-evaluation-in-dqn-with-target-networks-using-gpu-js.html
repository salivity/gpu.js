Policy Evaluation in DQN with Target Networks Using GPU.js

This article explains how to implement policy evaluation within a Deep Q-Network (DQN) framework utilizing target networks and hardware acceleration via gpu.js. You will learn the mechanics of formulating Bellman updates on the GPU, structuring neural network forward passes as parallel compute kernels, computing Temporal Difference (TD) targets using an isolated target network, and synchronizing network parameters to maintain training stability.

Policy Evaluation and Target Networks

In standard Q-learning, policy evaluation iteratively computes the action-value function \(Q(s, a)\) to approximate the expected return of taking action \(a\) in state \(s\). In Deep Q-Networks (DQN), parameterized function approximators (neural networks) estimate these values.

The standard update relies on the Bellman equation:

\[Y_t = R_{t+1} + \gamma \max_{a} Q(S_{t+1}, a; \theta_t)\]

Using the same parameter set \(\theta_t\) to compute both the current estimate \(Q(S_t, A_t; \theta_t)\) and the target \(Y_t\) leads to non-stationary targets and training instability. To resolve this, a target network parameterized by \(\theta^-\) is introduced:

\[Y_t = R_{t+1} + \gamma \max_{a} Q(S_{t+1}, a; \theta^-)\]

The target weights \(\theta^-\) remain fixed for a predetermined number of steps before being synchronized with the active training weights \(\theta\).

Structuring DQN with gpu.js

gpu.js compiles specialized JavaScript functions into WebGL or OpenCL shaders, allowing matrix operations and array manipulations to execute in parallel across GPU threads. To implement DQN policy evaluation, two functional components are required on the GPU:

  1. Forward Pass Kernel: Computes \(Q(s, \cdot)\) across all discrete actions for a given state batch.
  2. Bellman Target Kernel: Evaluates transitions \((s, a, r, s', d)\) and constructs target values using the target network outputs.

1. Initializing gpu.js

const { GPU } = require('gpu.js');
const gpu = new GPU();

2. Dense Layer Kernel (Matrix Multiplication and ReLU)

A simple feedforward pass computes \(Z = \text{ReLU}(W \cdot X + B)\). In gpu.js, this is defined as a kernel outputting a 2D tensor:

const forwardDenseRelu = gpu.createKernel(function(weights, inputs, biases, inputSize) {
    let sum = 0;
    for (let i = 0; i < inputSize; i++) {
        sum += weights[this.thread.y][i] * inputs[i][this.thread.x];
    }
    sum += biases[this.thread.y];
    return sum > 0 ? sum : 0; // ReLU activation
}).setOutput([batchSize, outputSize]);

For the output layer representing discrete Q-values, a linear activation (without the ReLU conditional) is used to permit negative Q-values.

3. Implementing the Target Network Evaluation Kernel

Once the target network performs a forward pass on the next states \(S'\), the evaluation kernel identifies \(\max_{a'} Q(S', a'; \theta^-)\) and computes the Bellman target.

const computeTDTargets = gpu.createKernel(function(rewards, nextQValues, terminals, gamma, numActions) {
    const sampleIdx = this.thread.x;
    
    // Find the maximum Q-value for the next state S'
    let maxNextQ = -9999999.0;
    for (let a = 0; a < numActions; a++) {
        const qVal = nextQValues[a][sampleIdx];
        if (qVal > maxNextQ) {
            maxNextQ = qVal;
        }
    }

    // If terminal, target is simply the reward; otherwise include discounted future reward
    const isTerminal = terminals[sampleIdx];
    if (isTerminal === 1) {
        return rewards[sampleIdx];
    } else {
        return rewards[sampleIdx] + (gamma * maxNextQ);
    }
}).setOutput([batchSize]);

4. Computing the Temporal Difference Loss

The policy evaluation step measures the error between the current online predictions \(Q(S, A; \theta)\) and the computed targets \(Y\).

const computeTDErrors = gpu.createKernel(function(currentQValues, actions, targets) {
    const sampleIdx = this.thread.x;
    const actionTaken = actions[sampleIdx];
    const predictedQ = currentQValues[actionTaken][sampleIdx];
    const targetQ = targets[sampleIdx];
    
    // Returns TD error: (Q(s,a) - Target)
    return predictedQ - targetQ;
}).setOutput([batchSize]);

Synchronizing the Target Network

The target network must track the active network parameters to ensure steady policy convergence. Parameter updates are handled using either periodic hard copying or continuous soft updates.

Hard Update

In a hard update scheme, online weights are directly assigned to the target network every \(C\) updates:

function hardUpdateTargetNetwork(onlineWeights, targetWeights) {
    for (let layer = 0; layer < onlineWeights.length; layer++) {
        // Deep copy matrices
        targetWeights[layer] = onlineWeights[layer].map(row => [...row]);
    }
}

Soft Update (Polyak Averaging)

Alternatively, a soft update gradually blends active weights into the target weights at every training iteration:

\[\theta^- \leftarrow \tau \theta + (1 - \tau) \theta^-\]

This operation can be vectorized using an element-wise gpu.js kernel:

const softUpdateKernel = gpu.createKernel(function(onlineWeights, targetWeights, tau) {
    const wTarget = targetWeights[this.thread.y][this.thread.x];
    const wOnline = onlineWeights[this.thread.y][this.thread.x];
    return (tau * wOnline) + ((1.0 - tau) * wTarget);
}).setOutput([numCols, numRows]);

Execution Flow for Policy Evaluation

  1. Sample Batch: Retrieve a mini-batch of tuples \((S, A, R, S', D)\) from the replay memory.
  2. Predict Next State Values: Pass \(S'\) through the target network layers using the forward pass kernels with target parameters \(\theta^-\).
  3. Calculate TD Targets: Execute computeTDTargets on the GPU with the retrieved rewards, terminal flags, and calculated target Q-values.
  4. Predict Current Values: Pass \(S\) through the active network kernels with parameters \(\theta\).
  5. Compute Error and Gradients: Execute computeTDErrors to derive sample-specific gradients.
  6. Update Parameters: Apply backpropagation to update \(\theta\) via standard gradient descent.
  7. Sync Targets: Execute softUpdateKernel or periodically invoke hardUpdateTargetNetwork to refresh \(\theta^-\).
