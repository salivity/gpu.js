Genetic Variant Frequency Matrices Using GPU.js

Processing population-scale genomic datasets requires calculating allele and genotype frequencies across millions of variants and hundreds of thousands of individuals. This guide explains how to accelerate the generation of genetic variant frequency matrices across stratified population cohorts using GPU.js, compiling JavaScript functions into WebGL/WebGPU compute shaders for massively parallel calculations.

Conceptual Architecture and Data Layout

A population-scale variant dataset typically consists of:

  1. Genotype Matrix (\(M \times N\)): \(M\) variants across \(N\) individual samples.
  2. Cohort Annotation Vector (\(N\)): A population identifier for each individual (e.g., EUR=0, AFR=1, EAS=2, SAS=3, AMR=4).

Genotype calls from VCF files are encoded numerically:

  • 0: Homozygous reference (0/0)
  • 1: Heterozygous (0/1 or 1/0)
  • 2: Homozygous alternate (1/1)
  • -1: Missing call (./.)

The objective is to compute an output matrix of dimensions [M, K, 2], where \(M\) is the number of variants, \(K\) is the number of distinct populations, and the third dimension tracks total alternate allele count (\(AC\)) and total non-missing allele count (\(AN\)). The Alternate Allele Frequency is:

\[AF = \frac{AC}{AN}\]

Prerequisites and Setup

Install gpu.js in your Node.js environment or include it in a browser context:

npm install gpu.js

Step 1: Prepare the Input Buffers

GPU shaders execute most efficiently on flattened, typed 1D or structured 2D arrays. Ensure genotype matrices are numeric arrays or flat typed arrays before transferring them to GPU memory.

import { GPU } from 'gpu.js';

const gpu = new GPU();

// Configuration
const numVariants = 10000;
const numSamples = 2500;
const numPopulations = 5;

// Mock data generation: Flat/2D genotype array [variants][samples]
const genotypeData = [];
for (let v = 0; v < numVariants; v++) {
  const row = [];
  for (let s = 0; s < numSamples; s++) {
    // Random genotype: 0, 1, 2, or -1 (missing)
    const rand = Math.random();
    row.push(rand > 0.05 ? Math.floor(Math.random() * 3) : -1);
  }
  genotypeData.push(row);
}

// Sample population mappings: [sampleIndex] -> populationId (0 to numPopulations - 1)
const samplePopulations = [];
for (let s = 0; s < numSamples; s++) {
  samplePopulations.push(s % numPopulations);
}

Step 2: Implement the GPU.js Kernel

To calculate counts across both variants and populations, create a 3D kernel that outputs:

  • Index 0: Alternate Allele Count (\(AC\))
  • Index 1: Total Chromosome Count (\(AN\))

The kernel threads are mapped across [2, numPopulations, numVariants].

const calculateAlleleFrequencies = gpu.createKernel(function(genotypes, populations, numSamples) {
  const variantIdx = this.thread.z;
  const targetPop = this.thread.y;
  const metricType = this.thread.x; // 0 for AC (alternate alleles), 1 for AN (total alleles)

  let altCount = 0;
  let totalAlleles = 0;

  for (let s = 0; s < numSamples; s++) {
    if (populations[s] === targetPop) {
      const gt = genotypes[variantIdx][s];

      if (gt >= 0) {
        totalAlleles += 2;
        if (gt === 1) {
          altCount += 1;
        } else if (gt === 2) {
          altCount += 2;
        }
      }
    }
  }

  if (metricType === 0) {
    return altCount;
  } else {
    return totalAlleles;
  }
})
.setOutput([2, numPopulations, numVariants])
.setPipeline(false); // Set to true if chaining kernels

Step 3: Run the Kernel and Extract Allele Frequencies

Execute the kernel by passing the input matrices. Compute the final Allele Frequency (\(AF = \frac{AC}{AN}\)) either directly on the CPU or via a secondary normalization kernel.

console.time('GPU Matrix Computation');
const frequencyMatrix = calculateAlleleFrequencies(genotypeData, samplePopulations, numSamples);
console.timeEnd('GPU Matrix Computation');

// Function to safely extract AF for Variant v in Population p
function getAlleleFrequency(matrix, variantIdx, popIdx) {
  const ac = matrix[variantIdx][popIdx][0];
  const an = matrix[variantIdx][popIdx][1];
  return an === 0 ? 0.0 : ac / an;
}

// Example: Retrieve AF of Variant 0 for Population 0
const afVar0Pop0 = getAlleleFrequency(frequencyMatrix, 0, 0);
console.log(`Variant 0, Population 0 - AF: ${afVar0Pop0.toFixed(4)}`);

Performance Optimization Guidelines

  1. Chunking Large Datasets: WebGL texture dimensions often cap at \(4096 \times 4096\) or \(16384 \times 16384\) pixels depending on hardware. For millions of variants, slice the input array into variant chunks (e.g., 5,000 variants per dispatch) to avoid hardware texture limit allocation errors.
  2. Bit-Packing Genotypes: Genotypes (-1, 0, 1, 2) fit in a 2-bit integer representation. Packing 16 genotypes into a single 32-bit unsigned integer reduces memory transfer overhead across the PCI bus to the GPU by 93.75%.
  3. Pipeline Mode: When chaining steps (such as calculating Hardy-Weinberg equilibrium or linkage disequilibrium directly after frequency matrix construction), set .setPipeline(true) to keep texture allocations in GPU VRAM without reading back to host memory.
