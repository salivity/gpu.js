GPU.js Empty Array Compile Error Explained

Passing an empty array into a GPU.js kernel causes a compilation and execution failure because the underlying compiler cannot infer data types or allocate valid WebGL texture dimensions from zero-length inputs. This article details the specific errors generated when an empty array is provided to a compiled GPU.js kernel, explains why the compiler fails at the architectural level, and outlines how to handle empty data inputs safely.

The Generated Error

When passing an empty array ([]) into a GPU.js kernel, GPU.js throws an error during argument parsing and shader compilation. The exact error typically surfaces as:

Error: Argument array cannot be empty

or, depending on the GPU.js version and internal pipeline stage:

Error: Cannot compile kernel: Unknown argument type

If the kernel was pre-compiled and attempts to allocate a WebGL texture directly for the input argument, the process can also fail at the WebGL texture initialization layer with:

Error: Texture width and height must be greater than zero

Why the Compile Error Occurs

GPU.js relies on Just-In-Time (JIT) shader compilation and strict WebGL pipeline specifications. When an argument is supplied to a kernel, several validation steps occur:

  1. Type and Dimensionality Inference: GPU.js inspects the elements inside an array (starting at index 0) to determine whether the argument is a 1D, 2D, or 3D array, as well as the primitive data type (integers, floats, or vectors). An empty array has no index 0, making it impossible for the type reflection system to determine the GLSL variable type.
  2. Texture Memory Allocation: In WebGL mode, GPU.js packages array arguments into textures to stream data onto the graphics hardware. A zero-length array evaluates to a dimension of zero, which violates WebGL texture constraints requiring positive dimensions (width > 0 and height > 0).
  3. GLSL Uniform Declarations: Because the compiler cannot establish the data shape, it cannot generate the corresponding uniform declarations or texture samplers in the resulting GLSL fragment shader source code, immediately terminating compilation.

How to Resolve the Error

Because GPU kernels cannot process empty buffers, input handling must be managed on the CPU before invoking the kernel:

  • Short-Circuit Empty Inputs: Check array lengths prior to kernel invocation. If an array is empty, bypass the kernel call entirely and return an empty array or default value immediately via standard JavaScript.
  • Use Padding/Placeholders: If the kernel must run unconditionally, provide a single-element placeholder array (e.g., [0]) and pass a separate uniform variable representing the actual active element count (0) to prevent out-of-bounds calculations inside the kernel loop.
