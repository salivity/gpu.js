GPU.js Undeclared Global Variable Error Explained

When developing GPU-accelerated applications using GPU.js, referencing an undeclared global variable inside a kernel function causes the compilation pipeline to fail before execution begins. This article explains the exact internal exception thrown by GPU.js, why this compilation failure occurs during AST translation, and how to correctly provide external values to your kernels.

The Internal Exception

When a kernel function references an undeclared global variable, GPU.js throws a standard JavaScript Error generated by its internal AST parser with the message:

Error: Unknown identifier [variableName]

Depending on the backend in use (such as WebGL or HeadlessGL), the error string is formatted via the internal astError() method, which prefixes the Unknown identifier message with positional context, including the line number and column where the unresolved variable appears in the kernel source code.

Why the Exception Occurs

GPU.js executes kernel functions on the GPU by compiling JavaScript functions into WebGL GLSL (OpenGL Shading Language) shaders or OpenCL code. Because the kernel executes entirely inside the GPU pipeline rather than the JavaScript runtime engine (such as V8), it does not have access to the JavaScript lexical scope, closure variables, or global objects like window or globalThis.

During compilation, GPU.js parses the kernel function into an Abstract Syntax Tree (AST) using Acorn and iterates through each node using backend translators (such as GLKernel or WebGLKernel). When the compiler encounters an Identifier node (handled by astIdentifier), it checks the identifier against known symbol registries:

  1. Declared Arguments: Parameters passed into the kernel function.
  2. Local Variables: Variables declared inside the kernel using var, let, or const.
  3. GPU.js Built-ins: Internal variables and methods such as this.thread.x, this.thread.y, or supported Math operations.
  4. Kernel Constants: Values provided explicitly through the kernel configuration.

If the identifier is not found in any of these registries, the compiler cannot generate the corresponding GLSL type, uniform, or variable declaration. It halts transpilation immediately and throws this.astError(ast, 'Unknown identifier ' + ast.name).

How to Fix the Error

To make outside values accessible inside a GPU.js kernel without triggering the Unknown identifier exception, you must pass them through one of the supported channels:

1. Pass the Value as a Kernel Parameter

Dynamic values should be passed as arguments during kernel invocation:

const compute = gpu.createKernel(function(myValue) {
  return this.thread.x + myValue;
}).setOutput([100]);

compute(42);

2. Declare the Value as a Constant

Static or configuration values can be injected into the kernel's compile-time scope using the constants configuration object:

const compute = gpu.createKernel(function() {
  return this.thread.x + this.constants.myGlobal;
}, {
  constants: { myGlobal: 42 },
  output: [100]
});

compute();
