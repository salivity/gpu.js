Ray-Sphere Intersection in a GPU.js Kernel

This article explains how to implement an analytic ray-sphere intersection algorithm inside a hardware-accelerated GPU.js graphical kernel. By offloading primary ray generation, vector mathematics, and quadratic intersection tests to the GPU using WebGL, you can render smooth 3D spheres directly to an HTML5 canvas in real time. The following sections break down the underlying mathematical equations, address GPU.js specific constraints, and provide a functional code implementation.

The Ray-Sphere Mathematics

A ray is defined parametrically by an origin point \(\mathbf{O}\) and a normalized direction vector \(\mathbf{D}\):

\[\mathbf{P}(t) = \mathbf{O} + t\mathbf{D}\]

A sphere is defined by a center point \(\mathbf{C}\) and a radius \(r\):

\[\|\mathbf{P} - \mathbf{C}\|^2 = r^2\]

Substituting the ray equation into the sphere equation yields a standard quadratic equation in terms of \(t\):

\[a t^2 + b t + c = 0\]

Where:

  • \(a = \mathbf{D} \cdot \mathbf{D} = 1\) (assuming \(\mathbf{D}\) is normalized)
  • \(\mathbf{oc} = \mathbf{O} - \mathbf{C}\)
  • \(b = 2(\mathbf{oc} \cdot \mathbf{D})\)
  • \(c = (\mathbf{oc} \cdot \mathbf{oc}) - r^2\)

The discriminant determines whether the ray hits the sphere:

\[\Delta = b^2 - 4ac\]

If \(\Delta < 0\), the ray misses the sphere entirely. If \(\Delta \ge 0\), the ray intersects the sphere, and the distance to the nearest intersection point is:

\[t = \frac{-b - \sqrt{\Delta}}{2a}\]

Implementing in GPU.js

GPU.js compiles JavaScript functions into GLSL shaders. Because GPU.js operates on scalar primitives and fixed-size arrays within kernel functions, vector operations such as dot products and vector subtraction must be written using component-wise arithmetic.

To write directly to an HTML5 canvas, the kernel must be configured with { graphical: true }. Instead of returning data, a graphical kernel writes pixel values using this.color(r, g, b, a), where each channel is normalized between 0.0 and 1.0.

Complete Implementation

const { GPU } = require('gpu.js'); // Or use window.GPU in a browser
const gpu = new GPU();

const width = 800;
const height = 600;

const renderKernel = gpu.createKernel(function(sphereX, sphereY, sphereZ, radius) {
    // Normalize pixel coordinates to NDC space [-1, 1]
    const u = (this.thread.x / this.output.x) * 2.0 - 1.0;
    const v = (this.thread.y / this.output.y) * 2.0 - 1.0;
    const aspectRatio = this.output.x / this.output.y;

    // Ray setup
    const rayOriginX = 0.0;
    const rayOriginY = 0.0;
    const rayOriginZ = -2.0;

    // Direct ray forward through the virtual camera plane
    let rayDirX = u * aspectRatio;
    let rayDirY = v;
    let rayDirZ = 1.0;

    // Normalize ray direction
    const length = Math.sqrt(rayDirX * rayDirX + rayDirY * rayDirY + rayDirZ * rayDirZ);
    rayDirX /= length;
    rayDirY /= length;
    rayDirZ /= length;

    // Vector from sphere center to ray origin: oc = origin - center
    const ocX = rayOriginX - sphereX;
    const ocY = rayOriginY - sphereY;
    const ocZ = rayOriginZ - sphereZ;

    // Quadratic coefficients
    const a = rayDirX * rayDirX + rayDirY * rayDirY + rayDirZ * rayDirZ;
    const b = 2.0 * (ocX * rayDirX + ocY * rayDirY + ocZ * rayDirZ);
    const c = (ocX * ocX + ocY * ocY + ocZ * ocZ) - (radius * radius);

    const discriminant = (b * b) - (4.0 * a * c);

    if (discriminant > 0.0) {
        const t = (-b - Math.sqrt(discriminant)) / (2.0 * a);

        if (t > 0.0) {
            // Compute hit point
            const hitX = rayOriginX + t * rayDirX;
            const hitY = rayOriginY + t * rayDirY;
            const hitZ = rayOriginZ + t * rayDirZ;

            // Compute surface normal: (hitPoint - center) / radius
            const normalX = (hitX - sphereX) / radius;
            const normalY = (hitY - sphereY) / radius;
            const normalZ = (hitZ - sphereZ) / radius;

            // Simple diffuse directional light
            const lightDirX = 0.577;
            const lightDirY = 0.577;
            const lightDirZ = -0.577;

            // Dot product between normal and light direction
            let diffuse = normalX * lightDirX + normalY * lightDirY + normalZ * lightDirZ;
            if (diffuse < 0.1) {
                diffuse = 0.1; // Ambient floor
            }

            // Render shaded sphere (red)
            this.color(diffuse * 0.9, diffuse * 0.2, diffuse * 0.2, 1.0);
            return;
        }
    }

    // Background color
    this.color(0.05, 0.05, 0.08, 1.0);
})
.setOutput([width, height])
.setGraphical(true);

// Run the kernel
renderKernel(0.0, 0.0, 2.0, 1.0);

// Append the generated WebGL canvas to the document
document.body.appendChild(renderKernel.canvas);

Execution Details

  1. Coordinate Alignment: WebGL places thread coordinate (0, 0) at the bottom-left corner of the canvas. Adjusting the horizontal component by aspectRatio prevents horizontal stretching on non-square viewports.
  2. Surface Normals: When the discriminant yields a valid hit distance \(t > 0\), the surface normal vector at the intersection point is derived by subtracting the center from the hit point and dividing by the radius.
  3. Lighting: A simple Lambertian diffuse term is computed via the dot product of the surface normal and a fixed light vector, creating 3D depth directly on the GPU without intermediate CPU round-trips.
