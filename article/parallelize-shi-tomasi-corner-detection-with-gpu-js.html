Parallelize Shi-Tomasi Corner Detection with GPU.js

This article explains how to accelerate the Shi-Tomasi corner detection algorithm using GPU.js by parallelizing the computation of image gradients, the structure tensor, and the minimum eigenvalue scoring function. By translating pixel-level matrix operations into a WebGL kernel, thousands of image coordinates can be evaluated simultaneously on the GPU, significantly reducing latency compared to pure JavaScript implementations.

Mathematical Foundation

The Shi-Tomasi corner detector evaluates the second moment matrix (or structure tensor) \(M\) over a local window \(W\) around each pixel \((x, y)\):

\[M = \sum_{(u,v) \in W} \begin{bmatrix} I_x^2 & I_x I_y \\ I_x I_y & I_y^2 \end{bmatrix} = \begin{bmatrix} a & b \\ b & c \end{bmatrix}\]

Where:

  • \(I_x\) and \(I_y\) are horizontal and vertical image gradients.
  • \(a = \sum I_x^2\), \(c = \sum I_y^2\), and \(b = \sum I_x I_y\).

The corner response score \(R\) is the smaller of the two eigenvalues (\(\lambda_1, \lambda_2\)) of \(M\):

\[R = \lambda_{\min} = \frac{(a + c) - \sqrt{(a - c)^2 + 4b^2}}{2}\]

Pixels with a score exceeding a chosen threshold are identified as corners.

Implementing the Kernel in GPU.js

In GPU.js, calculations are parallelized by mapping kernel execution directly to the dimensions of the input image. Each thread processes a single coordinate (this.thread.x, this.thread.y).

Below is a complete implementation that samples a grayscale 2D array, calculates local central differences to approximate gradients, accumulates the structure tensor across a \(3 \times 3\) window, and outputs the minimum eigenvalue score.

const { GPU } = require('gpu.js');
const gpu = new GPU();

const createShiTomasiKernel = (width, height) => {
  return gpu.createKernel(function (image) {
    const x = this.thread.x;
    const y = this.thread.y;

    // Boundary check to avoid out-of-bounds access
    if (x < 2 || x >= this.constants.width - 2 || y < 2 || y >= this.constants.height - 2) {
      return 0.0;
    }

    let a = 0.0; // Sum of Ix^2
    let b = 0.0; // Sum of Ix * Iy
    let c = 0.0; // Sum of Iy^2

    // Accumulate tensor over a 3x3 local window
    for (let wy = -1; wy <= 1; wy++) {
      for (let wx = -1; wx <= 1; wx++) {
        const sampleX = x + wx;
        const sampleY = y + wy;

        // Central difference gradients
        const Ix = (image[sampleY][sampleX + 1] - image[sampleY][sampleX - 1]) * 0.5;
        const Iy = (image[sampleY + 1][sampleX] - image[sampleY - 1][sampleX]) * 0.5;

        a += Ix * Ix;
        b += Ix * Iy;
        c += Iy * Iy;
      }
    }

    // Minimum eigenvalue calculation: lambda_min
    const trace = a + c;
    const determinant = (a * c) - (b * b);
    const discriminant = Math.sqrt(Math.max(0.0, (trace * trace) - (4.0 * determinant)));
    const minEigenvalue = (trace - discriminant) * 0.5;

    return minEigenvalue;
  })
  .setConstants({ width, height })
  .setOutput([width, height]);
};

Executing the Kernel

To run the kernel, supply the image data as a normalized two-dimensional array of pixel values ranging from 0.0 to 1.0:

const width = 640;
const height = 480;

// Initialize a dummy 640x480 grayscale matrix
const grayscaleImage = [];
for (let y = 0; y < height; y++) {
  const row = [];
  for (let x = 0; x < width; x++) {
    row.push(Math.random());
  }
  grayscaleImage.push(row);
}

const shiTomasiKernel = createShiTomasiKernel(width, height);
const cornerScores = shiTomasiKernel(grayscaleImage);

// Retrieve corner score at a specific pixel (x: 100, y: 150)
const score = cornerScores[150][100];

Optimization Considerations

  1. Memory Pipeline Mode: When passing results to subsequent processes (e.g., non-maximum suppression), enable .setPipeline(true). This keeps output data as a WebGL texture directly in GPU VRAM, removing CPU-GPU transfer overhead.
  2. Separable Gradients: For larger window sizes (\(5 \times 5\) or \(7 \times 7\)), separate the gradient computation into an initial pass, store \(I_x^2\), \(I_y^2\), and \(I_x I_y\) textures, and perform a separable box blur before calculating eigenvalues to lower arithmetic cost per thread.
