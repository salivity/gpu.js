How to Implement 2D Wave Equation with GPU.js

This article explains how to simulate 2D wave propagation across a discrete heightfield grid using the finite difference method accelerated by the WebGL wrapper library gpu.js. It details the underlying mathematical discretization of the wave equation, setting up a compute kernel, handling boundary conditions, and managing state across time steps using ping-pong buffering.

The Mathematical Foundation

The standard 2D wave equation with damping is defined as:

\[\frac{\partial^2 u}{\partial t^2} = c^2 \nabla^2 u - \gamma \frac{\partial u}{\partial t}\]

Where:

  • \(u(x, y, t)\) represents the height of the wave at coordinate \((x, y)\) at time \(t\).
  • \(c\) is the wave propagation speed.
  • \(\gamma\) is the damping factor that simulates energy loss.
  • \(\nabla^2 u = \frac{\partial^2 u}{\partial x^2} + \frac{\partial^2 u}{\partial y^2}\) is the spatial Laplacian.

Using the central finite difference method on a regular grid with spacing \(\Delta x = \Delta y = 1\) and time step \(\Delta t = 1\), the discrete Laplacian around grid cell \((x, y)\) is calculated from its four orthogonal neighbors:

\[\nabla^2 u_{x,y}^t \approx u_{x+1,y}^t + u_{x-1,y}^t + u_{x,y+1}^t + u_{x,y-1}^t - 4u_{x,y}^t\]

Incorporating damping (\(d \in [0, 1)\)), the height at the next time step (\(u^{t+1}\)) is derived from the current height (\(u^t\)) and the previous height (\(u^{t-1}\)):

\[u_{x,y}^{t+1} = (1 - d) \left[ 2u_{x,y}^t - u_{x,y}^{t-1} + c^2 \nabla^2 u_{x,y}^t \right]\]

Environment Setup

Include gpu.js in your project via npm or CDN:

<script src="https://cdnjs.cloudflare.com/ajax/libs/gpu.js/5.14.0/gpu-browser.min.js"></script>

Initialize the GPU instance:

const gpu = new GPU();
const WIDTH = 512;
const HEIGHT = 512;

Creating the Wave Propagation Kernel

The computation kernel evaluates the wave equation for every cell in parallel. To achieve high performance, output textures directly back to the GPU using pipeline mode (setPipeline(true)), which prevents copying data between the GPU and CPU each frame.

const waveKernel = gpu.createKernel(function(current, previous, cSquared, damping) {
    const x = this.thread.x;
    const y = this.thread.y;
    const w = this.constants.width;
    const h = this.constants.height;

    // Dirichlet boundary conditions (edges remain fixed at zero)
    if (x === 0 || x === w - 1 || y === 0 || y === h - 1) {
        return 0;
    }

    const uCurr = current[y][x];
    const uPrev = previous[y][x];

    // Sample adjacent neighboring cells
    const left   = current[y][x - 1];
    const right  = current[y][x + 1];
    const bottom = current[y - 1][x];
    const top    = current[y + 1][x];

    // Discrete 2D Laplacian
    const laplacian = left + right + bottom + top - 4.0 * uCurr;

    // Time-integration step
    const uNext = (2.0 - damping) * uCurr - (1.0 - damping) * uPrev + cSquared * laplacian;

    return uNext;
})
.setConstants({ width: WIDTH, height: HEIGHT })
.setOutput([WIDTH, HEIGHT])
.setPipeline(true)
.setImmutable(true);

Adding Disturbances to the Grid

To create waves, modify height values at specific points. A secondary kernel injects impulses (such as raindrops or user clicks):

const disturbanceKernel = gpu.createKernel(function(grid, dropX, dropY, radius, strength) {
    const x = this.thread.x;
    const y = this.thread.y;
    const dx = x - dropX;
    const dy = y - dropY;
    const distSq = dx * dx + dy * dy;

    const currentVal = grid[y][x];

    if (distSq < radius * radius) {
        return currentVal + strength * (1.0 - distSq / (radius * radius));
    }
    return currentVal;
})
.setOutput([WIDTH, HEIGHT])
.setPipeline(true)
.setImmutable(true);

State Management and Simulation Loop

Simulating the wave equation requires tracking states across three time levels: \(t-1\), \(t\), and \(t+1\). Using pipeline textures, these states rotate sequentially in memory.

// Initialize empty state grids
let previous = gpu.createKernel(function() { return 0; }).setOutput([WIDTH, HEIGHT]).setPipeline(true)();
let current = gpu.createKernel(function() { return 0; }).setOutput([WIDTH, HEIGHT]).setPipeline(true)();

// Simulation parameters
const cSquared = 0.2; // Must satisfy Courant-Friedrichs-Lewy condition: c^2 * dt^2 / dx^2 <= 0.5
const damping = 0.005;

function addDrop(x, y, radius = 5, strength = 1.0) {
    const disturbed = disturbanceKernel(current, x, y, radius, strength);
    current.delete(); // Free previous GPU texture memory
    current = disturbed;
}

function stepSimulation() {
    // Compute next step t+1
    const next = waveKernel(current, previous, cSquared, damping);

    // Free memory of the oldest texture
    previous.delete();

    // Rotate buffers: t-1 becomes t, t becomes t+1
    previous = current;
    current = next;
}

Rendering the Heightfield

To visualize the simulation, create a render kernel that outputs RGBA values to an HTML canvas:

const renderKernel = gpu.createKernel(function(heightfield) {
    const val = heightfield[this.thread.y][this.thread.x];
    
    // Normalize wave amplitude around mid-gray (0.5)
    const normalized = 0.5 + val * 0.5;

    this.color(normalized, normalized, normalized, 1.0);
})
.setOutput([WIDTH, HEIGHT])
.setGraphical(true);

document.body.appendChild(renderKernel.canvas);

function animate() {
    stepSimulation();
    renderKernel(current);
    requestAnimationFrame(animate);
}

// Trigger initial ripples
addDrop(Math.floor(WIDTH / 2), Math.floor(HEIGHT / 2), 8, 2.0);

animate();

Stability Considerations

When tuning simulation variables, respect the Courant-Friedrichs-Lewy (CFL) stability condition:

\[c \frac{\Delta t}{\Delta x} \le \frac{1}{\sqrt{2}} \approx 0.7071\]

With \(\Delta x = 1\) and \(\Delta t = 1\), setting \(c^2 > 0.5\) results in numerical instability, causing the grid values to diverge rapidly to infinity. Maintain \(c^2\) between \(0.1\) and \(0.4\) for realistic, stable wave propagation.
