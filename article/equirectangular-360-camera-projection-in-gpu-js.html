Equirectangular 360 Camera Projection in GPU.js

This article explains how to implement an equirectangular 360-degree camera projection using GPU.js. By mapping 2D canvas coordinates to spherical angles and converting those angles into 3D unit direction vectors, you can cast panoramic rays directly on the GPU in the browser. Below, you will find the mathematical derivation for equirectangular mapping alongside a complete, functional GPU.js implementation for rendering a 360-degree spherical environment.

Mathematical Principles of Equirectangular Mapping

An equirectangular projection maps the surface of a sphere to a flat rectangular plane with a 2:1 aspect ratio (representing \(360^\circ\) horizontally and \(180^\circ\) vertically).

  1. Normalized Coordinates (\(u, v\)):
    Convert the pixel coordinates \((x, y)\) from the canvas dimensions \((W, H)\) to normalized texture coordinates ranging from \(0.0\) to \(1.0\): \[u = \frac{x}{W}, \quad v = \frac{y}{H}\]

  2. Spherical Coordinates (\(\theta, \phi\)):
    Map \(u\) to longitude (\(\theta \in [-\pi, \pi]\)) and \(v\) to latitude (\(\phi \in [-\frac{\pi}{2}, \frac{\pi}{2}]\)): \[\theta = (u - 0.5) \times 2\pi\] \[\phi = (0.5 - v) \times \pi\]

  3. Cartesian Ray Vector (\(D_x, D_y, D_z\)):
    Convert spherical coordinates into a normalized 3D ray direction vector: \[D_x = \cos(\phi) \times \sin(\theta)\] \[D_y = \sin(\phi)\] \[D_z = \cos(\phi) \times \cos(\theta)\]

These directional components can then be used inside a GPU.js kernel to sample environment cubemaps, evaluate procedural sky models, or perform ray tracing.

Setting Up the GPU.js Kernel

GPU.js allows JavaScript functions to be compiled into WebGL shaders. To render graphics directly to a canvas, configure the kernel with .setGraphical(true) and define an output size with a 2:1 aspect ratio.

Complete Implementation

const canvas = document.getElementById('renderCanvas');
const width = 1024;
const height = 512;

const gpu = new GPU({
  canvas: canvas,
  mode: 'webgl2'
});

// Construct the equirectangular projection kernel
const renderPanoramicCamera = gpu.createKernel(function(yaw, pitch) {
  const PI = 3.141592653589793;
  const width = this.constants.width;
  const height = this.constants.height;

  // 1. Normalize pixel coordinates to [0, 1]
  const u = this.thread.x / width;
  const v = this.thread.y / height;

  // 2. Map coordinates to spherical angles (theta: longitude, phi: latitude)
  const theta = (u - 0.5) * 2.0 * PI + yaw;
  const phi = (v - 0.5) * PI + pitch;

  // 3. Generate the 3D ray direction vector
  const cosPhi = Math.cos(phi);
  const rx = cosPhi * Math.sin(theta);
  const ry = Math.sin(phi);
  const rz = cosPhi * Math.cos(theta);

  // 4. Procedural Scene / Skybox Visualization
  // Creates a grid pattern across spherical coordinates to verify projection
  const gridTheta = Math.abs(Math.sin(theta * 6.0));
  const gridPhi = Math.abs(Math.sin(phi * 6.0));
  const isGrid = (gridTheta > 0.98 || gridPhi > 0.98) ? 1.0 : 0.0;

  // Calculate horizon gradient
  const horizon = 0.5 + 0.5 * ry;

  // Color assignments based on 3D ray direction
  const r = horizon * 0.4 + isGrid * 0.6;
  const g = horizon * 0.6 + isGrid * 0.6;
  const b = 0.8 + 0.2 * ry;

  this.color(r, g, b, 1.0);
})
.setConstants({ width: width, height: height })
.setOutput([width, height])
.setGraphical(true);

// Render initial view (yaw = 0, pitch = 0)
renderPanoramicCamera(0.0, 0.0);

Handling Orientation and Sampling

To rotate the equirectangular camera, modify the yaw and pitch parameters passed into the kernel. The ray components rx, ry, and rz represent an origin-centered ray that intersects scene geometry or spherical textures.

If sampling from an existing 2D environment texture within the kernel, pass the texture as an input array and sample it using the spherical angles rather than direct pixel lookups to avoid polar distortion artifacts.
