How to Build a useGPUKernel Hook with GPU.js

Accelerating complex browser calculations often requires offloading data-intensive operations to the device's graphics processor. This article demonstrates how to build a custom React hook, useGPUKernel, to manage the lifecycle, compilation, execution, and state handling of GPU.js operations directly within functional React components.

The Challenge with GPU.js in React

GPU.js compiles a subset of JavaScript into GLSL shaders, running them via WebGL. In a declarative environment like React, creating a new GPU() instance or recompiling a kernel function on every render degrades performance. A proper custom hook must:

  1. Maintain a single GPU instance across renders.
  2. Compile and cache the kernel only when its logic or settings change.
  3. Handle execution states (loading, error, output).
  4. Release WebGL resources on unmount to prevent memory leaks.

Building the useGPUKernel Hook

Below is the complete implementation of the useGPUKernel hook. It accepts a computation function and standard GPU.js kernel settings, returning an execution function alongside status states.

import { useState, useRef, useEffect, useCallback } from 'react';
import { GPU } from 'gpu.js';

export function useGPUKernel(kernelFunction, options = {}) {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(false);
  const [error, setError] = useState(null);

  const gpuRef = useRef(null);
  const kernelRef = useRef(null);

  // Initialize GPU instance once
  useEffect(() => {
    gpuRef.current = new GPU();

    return () => {
      if (gpuRef.current) {
        gpuRef.current.destroy();
      }
    };
  }, []);

  // Compile kernel when logic or options change
  useEffect(() => {
    if (!gpuRef.current) return;

    try {
      if (kernelRef.current) {
        kernelRef.current.destroy();
      }

      kernelRef.current = gpuRef.current.createKernel(kernelFunction, options);
    } catch (err) {
      setError(err);
    }

    return () => {
      if (kernelRef.current) {
        kernelRef.current.destroy();
      }
    };
  }, [kernelFunction, JSON.stringify(options)]);

  // Execution wrapper
  const run = useCallback(
    (...args) => {
      if (!kernelRef.current) {
        setError(new Error('Kernel is not initialized.'));
        return null;
      }

      setLoading(true);
      setError(null);

      try {
        const result = kernelRef.current(...args);
        setData(result);
        setLoading(false);
        return result;
      } catch (err) {
        setError(err);
        setLoading(false);
        return null;
      }
    },
    []
  );

  return { run, data, loading, error };
}

Implementing the Hook in a Component

To use the hook, pass a kernel function and configure the target dimensions via the output property. Use useCallback on the kernel function to prevent unnecessary recompilations.

import React, { useCallback } from 'react';
import { useGPUKernel } from './useGPUKernel';

export default function MatrixMultiplier() {
  const matrixSize = 512;

  // Define kernel function
  const multiplyMatrixKernel = useCallback(function (a, b) {
    let sum = 0;
    for (let i = 0; i < 512; i++) {
      sum += a[this.thread.y][i] * b[i][this.thread.x];
    }
    return sum;
  }, []);

  const { run, data, loading, error } = useGPUKernel(multiplyMatrixKernel, {
    output: [matrixSize, matrixSize],
    pipeline: false,
  });

  const handleCompute = () => {
    // Generate dummy square matrices
    const a = Array.from({ length: matrixSize }, () =>
      Array.from({ length: matrixSize }, () => Math.random())
    );
    const b = Array.from({ length: matrixSize }, () =>
      Array.from({ length: matrixSize }, () => Math.random())
    );

    run(a, b);
  };

  return (
    <div>
      <button onClick={handleCompute} disabled={loading}>
        {loading ? 'Computing on GPU...' : 'Run GPU Calculation'}
      </button>

      {error && <p style={{ color: 'red' }}>Error: {error.message}</p>}
      {data && <p>Computation completed successfully.</p>}
    </div>
  );
}

Key Considerations

  • Pipeline Mode: If chaining calculations, set pipeline: true in the options. This keeps textures in GPU VRAM instead of copying them back to the CPU, significantly improving sequential operations.
  • Fallback Behavior: GPU.js falls back to CPU execution if WebGL is unavailable. The hook requires no modifications to support this, but verify execution mode in sensitive environments using the gpuRef.current.mode property.
  • Cleanup: Invoking kernel.destroy() and gpu.destroy() inside cleanup effects is essential. Failure to do so can quickly trigger WebGL context loss errors when components mount and unmount repeatedly.
