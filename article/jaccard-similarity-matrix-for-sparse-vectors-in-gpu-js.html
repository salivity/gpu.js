Jaccard Similarity Matrix for Sparse Vectors in GPU.js

This article details how to compute a pairwise Jaccard similarity matrix for sparse binary feature vectors using GPU acceleration with gpu.js. Because GPU threads operate best on structured data without dynamic memory allocations, handling sparse vectors requires converting variable-length sparse indices into padded 2D arrays or flat buffers. The following sections walk through data structuring, kernel construction, and parallel execution to efficiently compute intersections, unions, and similarity scores on the GPU.

Understanding Pairwise Jaccard Similarity

The Jaccard similarity coefficient between two binary sets \(A\) and \(B\) is defined as:

\[J(A, B) = \frac{|A \cap B|}{|A \cup B|} = \frac{|A \cap B|}{|A| + |B| - |A \cap B|}\]

In sparse representation, a binary vector is stored only as the indices of its non-zero (active) features. Computing Jaccard similarity between two sparse vectors requires:

  1. Finding the size of the intersection \(|A \cap B|\) by matching active indices.
  2. Summing their non-zero counts and subtracting the intersection size to obtain \(|A \cup B|\).
  3. Dividing the intersection by the union.

Data Representation for the GPU

GPU.js executes WebGL or WebGPU shaders under the hood. Shaders do not natively support jagged arrays (arrays of variable lengths). To feed sparse data to the kernel:

  1. Active Indices Matrix (indices): Store the non-zero feature indices of each vector in a 2D array of dimensions [N, MaxNonZeros], where N is the number of vectors, and MaxNonZeros is the maximum number of active features across any vector. Empty slots are padded with -1.
  2. Lengths Array (lengths): A 1D array of size N containing the true number of non-zero elements for each vector.

Sorting the indices in ascending order for each vector allows for efficient traversal.

Implementing the GPU.js Kernel

Ensure gpu.js is installed in your project:

npm install gpu.js

Below is the complete implementation that structures the input, defines the pairwise kernel, and evaluates the similarity matrix.

const { GPU } = require('gpu.js');

// Initialize GPU.js instance
const gpu = new GPU();

/**
 * Creates a GPU kernel to compute an N x N pairwise Jaccard matrix.
 * @param {number} numVectors Total number of vectors (N).
 * @param {number} maxFeatures Maximum active features in any vector.
 */
function createJaccardKernel(numVectors, maxFeatures) {
  return gpu.createKernel(
    function (indices, lengths, maxLen) {
      const i = this.thread.y;
      const j = this.thread.x;

      const lenA = lengths[i];
      const lenB = lengths[j];

      // Handle identical vectors or self-comparison
      if (i === j) {
        return 1.0;
      }

      // Handle empty sets
      if (lenA === 0 && lenB === 0) {
        return 1.0;
      }
      if (lenA === 0 || lenB === 0) {
        return 0.0;
      }

      // Compute intersection count using two-pointer search on sorted indices
      let intersection = 0;
      let ptrA = 0;
      let ptrB = 0;

      for (let step = 0; step < maxLen * 2; step++) {
        if (ptrA >= lenA || ptrB >= lenB) {
          break;
        }

        const valA = indices[i][ptrA];
        const valB = indices[j][ptrB];

        if (valA === valB) {
          intersection++;
          ptrA++;
          ptrB++;
        } else if (valA < valB) {
          ptrA++;
        } else {
          ptrB++;
        }
      }

      const unionSize = lenA + lenB - intersection;

      if (unionSize === 0) {
        return 0.0;
      }

      return intersection / unionSize;
    },
    {
      output: [numVectors, numVectors],
      precision: 'single',
    }
  );
}

Preparing the Data and Executing the Kernel

Sparse binary vectors must be normalized and formatted into uniform-sized arrays prior to passing them into the kernel.

// Example sparse binary vectors (lists of active column indices)
const rawSparseVectors = [
  [1, 5, 8, 12],
  [2, 5, 8, 14, 20],
  [1, 5, 8, 12], // Duplicate of vector 0
  [0, 3, 9],
];

const numVectors = rawSparseVectors.length;

// Find maximum active elements to define 2D array width
const maxFeatures = Math.max(...rawSparseVectors.map((vec) => vec.length));

// Allocate uniform arrays
const paddedIndices = [];
const vectorLengths = [];

for (let i = 0; i < numVectors; i++) {
  const sorted = rawSparseVectors[i].slice().sort((a, b) => a - b);
  vectorLengths.push(sorted.length);

  const row = new Float32Array(maxFeatures).fill(-1);
  for (let k = 0; k < sorted.length; k++) {
    row[k] = sorted[k];
  }
  paddedIndices.push(Array.from(row));
}

// Instantiate and run kernel
const jaccardKernel = createJaccardKernel(numVectors, maxFeatures);
const similarityMatrix = jaccardKernel(paddedIndices, vectorLengths, maxFeatures);

console.log(similarityMatrix);

Performance Considerations

  1. Loop Unrolling Constraints: Shaders require static bounds for loops. The loop condition uses step < maxLen * 2 rather than variable condition expressions, ensuring compatibility across all WebGL/WebGPU compilation targets.
  2. Memory Alignment: For large-scale datasets, pass flat 1D arrays (Float32Array) and unpack coordinates manually in the shader, or chunk the execution if output dimensions exceed maximum WebGL texture limits (gl.MAX_TEXTURE_SIZE).
