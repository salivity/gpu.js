Rayleigh Quotient Iteration in gpu.js

Evaluating Rayleigh quotient iteration (RQI) for dominant eigenvalue finding in gpu.js requires a hybrid iterative strategy combining a warm-started shift with a GPU-native linear system solver. Because gpu.js translates JavaScript functions into WebGL fragment shaders, standard CPU-based direct matrix factorizations like LU or QR decomposition perform poorly due to memory layout and branching constraints. The most effective strategy involves chaining custom pipeline kernels to run an inner iterative solver—such as the Conjugate Gradient or BiCGSTAB method—to solve the shifted system \((A - \mu_k I)x = v_k\), paired with parallel reduction kernels to compute vector norms and Rayleigh quotients directly on the GPU.

Hybrid Warm-Start Initialization

Rayleigh quotient iteration converges cubically, but it converges locally to the eigenvalue nearest to the initial guess rather than guaranteeing convergence to the dominant (largest magnitude) eigenvalue. To target the dominant eigenpair, the strategy begins with several steps of standard Power Iteration. In gpu.js, this involves repeatedly executing a matrix-vector multiplication kernel followed by a normalization kernel. Once the iteration vector aligns sufficiently with the dominant subspace, the algorithm transitions to RQI, setting the initial Rayleigh quotient shift \(\mu_0 = \frac{v_0^T A v_0}{v_0^T v_0}\).

Inner Iterative Shifted Solver

Each RQI step requires solving the linear system:

\[(A - \mu_k I) y = v_k\]

Because direct inversion is computationally prohibitive on WebGL hardware, the recommended approach implements an iterative solver within gpu.js:

  1. Symmetric Matrices: Use the Conjugate Gradient (CG) algorithm.
  2. Non-Symmetric Matrices: Use the Biconjugate Gradient Stabilized (BiCGSTAB) or Generalized Minimal Residual (GMRES) method.

The shifted matrix-vector product \((A - \mu_k I)p\) is evaluated procedurally inside a single kernel to avoid explicitly allocating the shifted matrix \(A - \mu_k I\) in memory, reducing texture memory bandwidth.

GPU Pipeline and Texture Ping-Ponging

Transferring large matrices and intermediate vectors between the CPU and GPU introduces major bus bottlenecks that destroy performance. To evaluate RQI efficiently:

  • Set pipeline: true on all gpu.js kernels so that intermediate vectors remain on the GPU as WebGL textures.
  • Use double-buffering (texture ping-ponging) for state vectors (such as search directions and residual vectors in the inner solver) so that the output of kernel \(n\) becomes the input for kernel \(n+1\) without triggering toArray() readbacks.
  • Keep the main matrix \(A\) immutable in GPU memory, dynamically passing the scalar shift \(\mu_k\) into the kernel as a uniform variable.

Parallel Reductions for Dot Products and Norms

Computing the Rayleigh quotient \(\mu_k = \frac{v_k^T A v_k}{v_k^T v_k}\) and the vector norm \(\|y\|_2\) requires fast vector dot products. Serial accumulation in WebGL results in \(O(N)\) shader passes. The strategy applies a multi-pass tree reduction kernel:

  1. Multiply elements pairwise into a 1D texture.
  2. Recursively sum neighboring elements using a downsampling kernel of stride \(2^m\) until a single scalar remains.
  3. Read back only the scalar quotient to the CPU to evaluate termination criteria: \(\|A v_k - \mu_k v_k\| < \epsilon\).

Convergence and Deflation Safeguards

As \(\mu_k\) nears the true eigenvalue, the shifted matrix \((A - \mu_k I)\) becomes ill-conditioned. In finite-precision WebGL shaders (typically 32-bit floats), standard solvers can produce NaN or diverge if the residual threshold is set too low. The iteration strategy must include an inner iteration ceiling (e.g., 20 to 50 iterations per RQI step) and a step-length guard that clamps the maximum update to maintain stability during near-singular conditions. Once converged, the dominant vector and eigenvalue are extracted, allowing for Hotelling deflation if subsequent eigenvalues are required.
