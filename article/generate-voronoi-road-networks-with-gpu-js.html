Generate Voronoi Road Networks with GPU.js

This article explains how to procedurally generate city road networks using Voronoi diagrams accelerated by GPU.js. By delegating distance calculations and edge detection to the GPU via WebGL shaders, you can synthesize high-resolution, complex urban layouts in real time. Below, you will find the architectural principles, a complete GPU.js implementation, and techniques for refining procedural road hierarchies.

1. Understanding Voronoi Road Networks

In procedural city generation, Voronoi diagrams divide space into regions based on distances to a specified set of seed points. The boundaries between these regions naturally mimic road networks, forming organic, cell-like city blocks.

To determine where a road lies on a 2D grid, a shader computes the distance from each pixel to the closest seed point (\(d_1\)) and the second-closest seed point (\(d_2\)). An edge (or road) exists wherever the difference between these two distances falls below a specified threshold:

\[\Delta d = d_2 - d_1 < \text{road\_thickness}\]

Because this check requires measuring distances to dozens or hundreds of seeds for millions of pixels, executing it on the CPU is slow. GPU.js compiles JavaScript functions into WebGL shaders, running this process in parallel across GPU threads.

2. Setting Up GPU.js

First, include the GPU.js library in your project via npm or a CDN:

<script src="https://cdnjs.cloudflare.com/ajax/libs/gpu.js/2.15.2/gpu-browser.min.js"></script>

Initialize a new GPU instance and configure a canvas element where the result will be rendered.

3. Seed Point Generation

Generate a set of 2D coordinates representing city block centers. These can be uniformly random, jittered grid points for organized districts, or distributed via Poisson disc sampling for balanced neighborhoods.

function generateSeeds(count, width, height) {
    const seeds = [];
    for (let i = 0; i < count; i++) {
        seeds.push([
            Math.random() * width,
            Math.random() * height
        ]);
    }
    return seeds;
}

4. Writing the GPU.js Kernel

Create a GPU.js kernel that computes the distance to the two nearest seeds for each pixel and outputs the road network directly to a canvas.

const width = 800;
const height = 800;
const seedCount = 64;

const gpu = new GPU();
const seeds = generateSeeds(seedCount, width, height);

const renderRoads = gpu.createKernel(function(seeds, seedCount, roadWidth) {
    const x = this.thread.x;
    const y = this.thread.y;

    let d1 = 100000.0;
    let d2 = 100000.0;

    // Find the two nearest seed points
    for (let i = 0; i < seedCount; i++) {
        const sx = seeds[i][0];
        const sy = seeds[i][1];
        
        // Euclidean distance squared
        const dx = x - sx;
        const dy = y - sy;
        const dist = Math.sqrt(dx * dx + dy * dy);

        if (dist < d1) {
            d2 = d1;
            d1 = dist;
        } else if (dist < d2) {
            d2 = dist;
        }
    }

    // Edge detection threshold
    if ((d2 - d1) < roadWidth) {
        // Road color (e.g., light gray)
        this.color(0.85, 0.85, 0.85, 1.0);
    } else {
        // Block / terrain color (e.g., dark slate)
        this.color(0.12, 0.14, 0.18, 1.0);
    }
})
.setOutput([width, height])
.setGraphical(true);

renderRoads(seeds, seedCount, 3.0);

// Append the resulting WebGL canvas to the document
document.body.appendChild(renderRoads.canvas);

5. Refining Road Networks

To transform raw Voronoi boundaries into believable urban layouts, apply the following adjustments:

  • Manhattan Distance: Replace Euclidean distance with Manhattan distance (\(|dx| + |dy|\)) or Minkowski distance (\((|dx|^p + |dy|^p)^{1/p}\)) to produce orthogonal, rectangular city blocks instead of hexagonal shapes.
  • Hierarchical Road Widths: Assign weights or hierarchical tiers to seeds. Seed boundaries separating major regional centers can evaluate against a larger threshold to form highways, while internal subdivisions use a narrower threshold for local streets.
  • Coordinate Warping: Add simplex or Perlin noise to the pixel coordinates before distance calculation (x + noise(x, y)). This perturbs straight Voronoi boundaries into meandering, natural paths suited for rural roads or coastline routes.
