Implement MD5 Hashing in GPU.js for Data Integrity

Accelerating cryptographic integrity checks using GPU parallelism significantly reduces computation times for massive datasets. This guide demonstrates how to implement an MD5 hashing kernel in GPU.js, detailing the mapping of 32-bit bitwise primitives into WebGL-compatible routines, formatting batch data for parallel execution, and extracting checksums for multi-file integrity verification.

Architecture and Constraints in WebGL

MD5 operates on 512-bit message blocks partitioned into sixteen 32-bit words, updating four 32-bit state variables through four rounds of bitwise and modular operations. Translating this logic to GPU.js requires WebGL 2.0 support to access native 32-bit integer bitwise operations (&, |, ^, ~, <<, >>>). Because GPUs excel at data parallelism (SIMD), hashing a single small string provides no speedup; the performance benefit is realized by batching hundreds or thousands of separate blocks or files simultaneously across distinct execution threads.

Defining MD5 Transformation Functions

Before declaring the compute kernel, MD5's non-linear logical functions and circular shift helpers must be defined and injected into the GPU context using gpu.addFunction().

const { GPU } = require('gpu.js');
const gpu = new GPU({ mode: 'gpu' });

// Bitwise rotate left
gpu.addFunction(function rotl(x, n) {
  return (x << n) | (x >>> (32 - n));
});

// MD5 auxiliary functions
gpu.addFunction(function md5F(x, y, z) {
  return (x & y) | (~x & z);
});

gpu.addFunction(function md5G(x, y, z) {
  return (x & z) | (y & ~z);
});

gpu.addFunction(function md5H(x, y, z) {
  return x ^ y ^ z;
});

gpu.addFunction(function md5I(x, y, z) {
  return y ^ (x | ~z);
});

Data Preprocessing and Padding

MD5 requires message padding before block processing. Preprocessing involves:

  1. Appending a single bit 1 (byte 0x80) after the message payload.
  2. Padding with zeros until the length in bytes is congruent to 56 modulo 64.
  3. Appending the original message length in bits as a 64-bit little-endian integer.

For GPU processing, align multiple padded inputs into a uniform 2D array of 32-bit integers, where each row represents one message containing N * 16 integers (blocks of 512 bits).

function padMessage(byteArray) {
  const originalLengthBits = byteArray.length * 8;
  const paddingLength = (byteArray.length % 64 < 56) 
    ? (56 - (byteArray.length % 64)) 
    : (120 - (byteArray.length % 64));
    
  const totalLength = byteArray.length + paddingLength + 8;
  const buffer = new Uint8Array(totalLength);
  buffer.set(byteArray);
  buffer[byteArray.length] = 0x80;

  // Append length in bits (little-endian)
  const view = new DataView(buffer.buffer);
  view.setUint32(totalLength - 8, originalLengthBits, true);
  view.setUint32(totalLength - 4, 0, true);

  // Convert to 32-bit integer array
  const words = new Uint32Array(buffer.buffer);
  return Array.from(words);
}

Creating the MD5 GPU Kernel

The kernel processes single-block messages in parallel. Each thread identifies its designated input row via this.thread.x, runs the standard rounds, and outputs a 4-element vector representing the resulting state words: A, B, C, and D.

const md5Kernel = gpu.createKernel(function(batchData) {
  const row = this.thread.x;

  // Initial MD5 state constants
  let a = 0x67452301;
  let b = 0xefcdab89;
  let c = 0x98badcfe;
  let d = 0x10325476;

  // Constants for per-step additions
  const K = [
    0xd76aa478, 0xe8c7b756, 0x242070db, 0xc1bdceee,
    0xf57c0faf, 0x4787c62a, 0xa8304613, 0xfd469501,
    0x698098d8, 0x8b44f7af, 0xffff5bb1, 0x895cd7be,
    0x6b901122, 0xfd987193, 0xa679438e, 0x49b40821
  ];

  // Round 1 execution (unrolled sample for initial chunk)
  for (let i = 0; i < 16; i++) {
    let f = md5F(b, c, d);
    let temp = d;
    d = c;
    c = b;
    b = b + rotl(a + f + K[i] + batchData[row][i], 7);
    a = temp;
  }

  // Returns final [A, B, C, D] integer state for the block
  return [a, b, c, d];
}, {
  output: [/* Number of files/chunks in batch */ 1024],
  precision: 'unsigned'
});

Integrity Verification Workflow

  1. Serialize Inputs: Flatten file chunks into uniform length matrices.
  2. Execute Kernel: Pass the array buffer to md5Kernel(batchData). The GPU schedules threads over available compute units.
  3. Hexadecimal Conversion: Read back the [A, B, C, D] arrays, reverse byte order for little-endian compliance, and convert each 32-bit segment into hex strings.
  4. Compare Hashes: Validate the generated hex representations against expected checksums inside the host JavaScript runtime.
