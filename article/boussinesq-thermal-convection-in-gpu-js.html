Boussinesq Thermal Convection in GPU.js

This article provides a guide to implementing a real-time thermal fluid convection simulation in the browser using GPU.js and the Boussinesq approximation. You will learn the underlying mathematical formulation of buoyancy-driven flows, the split-operator numerical method on an Eulerian grid, and how to structure parallel WebGL compute kernels to solve for advection, thermal buoyancy, viscous diffusion, and incompressibility.

The Boussinesq Governing Equations

Thermal convection occurs when temperature variations create density differences, producing buoyant forces. The Boussinesq approximation assumes density variations are negligible except where they generate gravitational body forces.

For an incompressible fluid, the dynamics are governed by:

  1. Mass Conservation (Incompressibility): \[\nabla \cdot \mathbf{u} = 0\]

  2. Momentum Conservation (Navier-Stokes with Buoyancy): \[\frac{\partial \mathbf{u}}{\partial t} + (\mathbf{u} \cdot \nabla)\mathbf{u} = -\frac{1}{\rho_0}\nabla p + \nu \nabla^2 \mathbf{u} + g \beta (T - T_0)\hat{\mathbf{j}}\]

  3. Thermal Energy Conservation: \[\frac{\partial T}{\partial t} + (\mathbf{u} \cdot \nabla)T = \alpha \nabla^2 T\]

Where:

  • \(\mathbf{u} = (u, v)\) is the velocity vector.
  • \(p\) is pressure, and \(\rho_0\) is the reference density.
  • \(\nu\) is the kinematic viscosity.
  • \(\alpha\) is thermal diffusivity.
  • \(g\) is gravitational acceleration.
  • \(\beta\) is the thermal expansion coefficient.
  • \(T\) is temperature, and \(T_0\) is the reference temperature.
  • \(\hat{\mathbf{j}}\) is the unit vector pointing in the vertical direction.

Simulation Pipeline

Using an operator splitting approach on a staggered or collocated 2D grid, each time step \(\Delta t\) progresses through five distinct stages:

  1. Advection: Advect velocity \(\mathbf{u}\) and temperature \(T\) using the current velocity field (Semi-Lagrangian advection).
  2. Buoyancy Forcing: Add vertical acceleration proportional to \((T - T_0)\) to the vertical velocity \(v\).
  3. Diffusion: Disperse momentum and temperature using explicit finite differences or Jacobi relaxation.
  4. Pressure Solve: Compute the velocity field's divergence and solve the Poisson equation \(\nabla^2 p = \frac{\rho_0}{\Delta t} \nabla \cdot \mathbf{u}^*\) using an iterative Jacobi solver.
  5. Projection: Subtract the pressure gradient \(\nabla p\) from the intermediate velocity field to enforce mass conservation (\(\nabla \cdot \mathbf{u} = 0\)).

Implementing the GPU Kernels

GPU.js compiles JavaScript functions into WebGL fragment shaders, operating over 2D textures representing grid data. Textures are ping-ponged (read from one, written to another) between update steps.

1. Initialization

Initialize the GPU context and configure float-precision rendering:

const gpu = new GPU({ mode: 'webgl2' });

const WIDTH = 256;
const HEIGHT = 256;
const DT = 0.01;
const DX = 1.0;
const BUOYANCY = 5.0;
const T_BASE = 0.0;

// Textures storing values as [u, v] or scalar T

2. Advection Kernel

The Semi-Lagrangian scheme traces particles backward in time to sample the advected quantity with bilinear interpolation:

const advectField = gpu.createKernel(function(field, velocity, dt, dx, width, height) {
    const x = this.thread.x;
    const y = this.thread.y;

    // Sample current velocity
    const u = velocity[y][x][0];
    const v = velocity[y][x][1];

    // Trace back coordinate
    let prevX = x - u * (dt / dx);
    let prevY = y - v * (dt / dx);

    // Clamp to boundary
    prevX = Math.max(0.5, Math.min(width - 1.5, prevX));
    prevY = Math.max(0.5, Math.min(height - 1.5, prevY));

    // Bilinear interpolation indices
    const i0 = Math.floor(prevX);
    const i1 = i0 + 1;
    const j0 = Math.floor(prevY);
    const j1 = j0 + 1;

    const s1 = prevX - i0;
    const s0 = 1.0 - s1;
    const t1 = prevY - j0;
    const t0 = 1.0 - t1;

    return s0 * (t0 * field[j0][i0] + t1 * field[j1][i0]) +
           s1 * (t0 * field[j0][i1] + t1 * field[j1][i1]);
}).setOutput([WIDTH, HEIGHT]).setPipeline(true);

3. Buoyancy Kernel

Add the Boussinesq buoyant term to the vertical velocity channel based on the current temperature field:

const applyBuoyancy = gpu.createKernel(function(velocity, temperature, dt, buoyancyCoeff, t0) {
    const x = this.thread.x;
    const y = this.thread.y;

    const u = velocity[y][x][0];
    let v = velocity[y][x][1];
    const t = temperature[y][x];

    // Boussinesq upward acceleration: dv/dt += beta * g * (T - T0)
    v += (t - t0) * buoyancyCoeff * dt;

    return [u, v];
}).setOutput([WIDTH, HEIGHT]).setPipeline(true);

4. Divergence Kernel

Calculate the divergence of the intermediate velocity field:

const computeDivergence = gpu.createKernel(function(velocity, dx, width, height) {
    const x = this.thread.x;
    const y = this.thread.y;

    // Zero divergence at borders
    if (x === 0 || x === width - 1 || y === 0 || y === height - 1) {
        return 0.0;
    }

    const uRight = velocity[y][x + 1][0];
    const uLeft  = velocity[y][x - 1][0];
    const vTop   = velocity[y + 1][x][1];
    const vBot   = velocity[y - 1][x][1];

    return 0.5 * ((uRight - uLeft) + (vTop - vBot)) / dx;
}).setOutput([WIDTH, HEIGHT]).setPipeline(true);

5. Pressure Poisson Solver (Jacobi Iterations)

Iterate over the pressure grid to satisfy \(\nabla^2 p = \frac{1}{\Delta t} \nabla \cdot \mathbf{u}\):

const jacobiPressure = gpu.createKernel(function(pressure, divergence, dx, dt, width, height) {
    const x = this.thread.x;
    const y = this.thread.y;

    // Neumann boundary conditions (zero pressure gradient)
    const pLeft  = (x > 0) ? pressure[y][x - 1] : pressure[y][x];
    const pRight = (x < width - 1) ? pressure[y][x + 1] : pressure[y][x];
    const pBot   = (y > 0) ? pressure[y - 1][x] : pressure[y][x];
    const pTop   = (y < height - 1) ? pressure[y + 1][x] : pressure[y][x];

    const div = divergence[y][x];

    return 0.25 * (pLeft + pRight + pBot + pTop - (dx * dx * div / dt));
}).setOutput([WIDTH, HEIGHT]).setPipeline(true);

Run this kernel sequentially 20 to 40 times per frame, alternating input and output textures to ensure proper convergence.

6. Velocity Projection Kernel

Enforce incompressibility by subtracting the computed pressure gradient from the intermediate velocity:

const projectVelocity = gpu.createKernel(function(velocity, pressure, dx, dt, width, height) {
    const x = this.thread.x;
    const y = this.thread.y;

    if (x === 0 || x === width - 1 || y === 0 || y === height - 1) {
        return [0.0, 0.0]; // No-slip boundary
    }

    const pLeft  = pressure[y][x - 1];
    const pRight = pressure[y][x + 1];
    const pBot   = pressure[y - 1][x];
    const pTop   = pressure[y + 1][x];

    const gradPx = 0.5 * (pRight - pLeft) / dx;
    const gradPy = 0.5 * (pTop - pBot) / dx;

    const u = velocity[y][x][0] - dt * gradPx;
    const v = velocity[y][x][1] - dt * gradPy;

    return [u, v];
}).setOutput([WIDTH, HEIGHT]).setPipeline(true);

Thermal Boundary Conditions and Rayleigh-Bénard Convection

To establish classic Rayleigh-Bénard thermal convection cells, apply fixed-temperature Dirichlet boundary conditions to the temperature field:

  • Bottom boundary (\(y = 0\)): Set to a constant hot temperature (\(T_{\text{hot}} = 1.0\)).
  • Top boundary (\(y = H\)): Set to a constant cold temperature (\(T_{\text{cold}} = 0.0\)).
  • Left and right boundaries: Set to insulated Neumann conditions (\(\frac{\partial T}{\partial x} = 0\)).

Add small, randomized temperature perturbations across the domain during setup. Without perturbations, a pure conduction state will persist until numerical noise breaks the symmetry. Once perturbed, the buoyant force amplifies vertical fluid movement, forming counter-rotating convection rolls.

Stability Considerations

  • Courant-Friedrichs-Lewy (CFL) Condition: While Semi-Lagrangian advection is unconditionally stable, high velocities with large \(\Delta t\) lead to severe numerical dissipation. Maintain \(\Delta t \le \frac{\Delta x}{||\mathbf{u}||_{\max}}\) for sharp convective structures.
  • Floating-Point Precision: GPU.js requires WebGL float textures to avoid clamping intermediate pressure values. Ensure that gpu.setPipeline(true) is enabled to keep computations stored on the GPU without costly roundtrips to the CPU.
