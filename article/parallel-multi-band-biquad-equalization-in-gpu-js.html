Parallel Multi-Band Biquad Equalization in GPU.js

This article explains how to implement a parallel multi-band equalizer using second-order biquad filters with GPU.js. By utilizing WebGL compute kernels, audio processing can offload independent frequency band calculations to the GPU. You will learn the mathematical foundation of biquad filtering, how to structure recursive filters within GPU compute limitations, and how to write the kernels to compute and sum multiple equalizer bands concurrently.

Biquad Filter Fundamentals

A second-order Infinite Impulse Response (IIR) biquad filter processes an input signal \(x[n]\) to generate an output \(y[n]\) based on the Direct Form I difference equation:

\[y[n] = b_0 x[n] + b_1 x[n-1] + b_2 x[n-2] - a_1 y[n-1] - a_2 y[n-2]\]

Here, \(b_0, b_1, b_2\) are feedforward coefficients, and \(a_1, a_2\) are feedback coefficients (normalized where \(a_0 = 1\)).

In a multi-band equalizer, an input signal is split across \(M\) distinct frequency bands (e.g., low shelf, peak filters, high shelf), each defined by its own coefficient set. In a parallel topology, the original signal is fed into all \(M\) filters simultaneously, and their outputs are summed:

\[y_{\text{total}}[n] = \sum_{k=1}^{M} y_k[n]\]

Handling IIR Recursion in GPU.js

GPUs excel at data-parallel execution across independent data points. However, IIR biquad filters are inherently recursive along the time dimension: \(y[n]\) strictly depends on \(y[n-1]\) and \(y[n-2]\).

To overcome this constraint without complex parallel prefix scans, parallelism is mapped across bands and channels rather than time. Each GPU thread evaluates one specific band across time or updates the state of all bands synchronously per sample block.

Using GPU.js, we can maintain the filter states (\(x_1, x_2, y_1, y_2\)) across bands and compute sample frames using GPU textures or loop through samples per thread allocated to a band.

Step-by-Step Implementation

1. Coefficient Generation

Calculate standard Audio EQ Cookbook coefficients on the CPU for each band:

function getPeakBiquadCoefficients(gainDb, centerFreq, sampleRate, Q = 1.0) {
  const w0 = (2 * Math.PI * centerFreq) / sampleRate;
  const alpha = Math.sin(w0) / (2 * Q);
  const A = Math.pow(10, gainDb / 40);

  const b0 = 1 + alpha * A;
  const b1 = -2 * Math.cos(w0);
  const b2 = 1 - alpha * A;
  const a0 = 1 + alpha / A;
  const a1 = -2 * Math.cos(w0);
  const a2 = 1 - alpha / A;

  // Normalize by a0
  return [b0 / a0, b1 / a0, b2 / a0, a1 / a0, a2 / a0];
}

2. Multi-Band Filtering Kernel

We initialize a GPU kernel where each thread corresponds to a specific equalization band. The kernel receives the shared audio buffer, iterates through time sequentially for its assigned filter coefficients, and writes out the filtered samples for that band.

const { GPU } = require('gpu.js');
const gpu = new GPU();

// Kernel outputs a 2D array: [sampleCount, numBands]
const multiBandBiquadKernel = gpu.createKernel(function(audio, coeffs, numSamples) {
  const bandIndex = this.thread.y;
  const sampleIndex = this.thread.x;

  // Coefficients for this band
  const b0 = coeffs[bandIndex][0];
  const b1 = coeffs[bandIndex][1];
  const b2 = coeffs[bandIndex][2];
  const a1 = coeffs[bandIndex][3];
  const a2 = coeffs[bandIndex][4];

  // Direct Form I state registers
  let x1 = 0.0;
  let x2 = 0.0;
  let y1 = 0.0;
  let y2 = 0.0;
  let currentY = 0.0;

  // Sequentially process up to the required sample index
  for (let n = 0; n <= sampleIndex; n++) {
    const x0 = audio[n];
    currentY = (b0 * x0) + (b1 * x1) + (b2 * x2) - (a1 * y1) - (a2 * y2);

    // Shift state delays
    x2 = x1;
    x1 = x0;
    y2 = y1;
    y1 = currentY;
  }

  return currentY;
})
.setDynamicOutput(true)
.setPrecision('single');

Note: For large audio buffers, recomputing from index 0 inside a single kernel call becomes computationally redundant (\(O(N^2)\)). For long-form audio buffers, process data in segmented blocks or unroll the sequence inside a 1D thread layout where each thread processes an entire audio stream for one band:

// Optimized: Thread per band, processing the entire buffer
const processBandsSequentialTime = gpu.createKernel(function(audio, coeffs, numSamples) {
  const band = this.thread.x;
  
  const b0 = coeffs[band][0];
  const b1 = coeffs[band][1];
  const b2 = coeffs[band][2];
  const a1 = coeffs[band][3];
  const a2 = coeffs[band][4];

  let x1 = 0.0, x2 = 0.0;
  let y1 = 0.0, y2 = 0.0;

  for (let n = 0; n < numSamples; n++) {
    const x0 = audio[n];
    const y0 = (b0 * x0) + (b1 * x1) + (b2 * x2) - (a1 * y1) - (a2 * y2);

    x2 = x1;
    x1 = x0;
    y2 = y1;
    y1 = y0;
    
    // Store back into an internal buffer if supported by output format
  }
  return y1;
}).setOutput([numBands]);

3. Summation Kernel

Once the parallel bands are generated, sum each band together to form the output signal. The summation kernel parallelizes across all audio sample indices:

const sumBandsKernel = gpu.createKernel(function(bandOutputs, numBands) {
  const sampleIndex = this.thread.x;
  let sum = 0.0;

  for (let band = 0; band < numBands; band++) {
    sum += bandOutputs[band][sampleIndex];
  }

  return sum;
}).setDynamicOutput(true);

Execution Pipeline

To execute the entire multi-band chain:

  1. Calculate Parameters: Determine sample rate, center frequencies (e.g., 60Hz, 250Hz, 1kHz, 4kHz, 12kHz), and user gain values.
  2. Compile Coefficients: Construct an array of shape [numBands, 5].
  3. Execute Band Kernel: Pass the input PCM audio array, coefficient matrix, and sample count into multiBandBiquadKernel.
  4. Sum Output: Feed the resulting multi-band matrix into sumBandsKernel.
  5. Output Handling: Retrieve the single-channel equalized audio array from the GPU context.
