Check for NaN and Overflow in GPU.js

Verifying whether a mathematical calculation in gpu.js has produced NaN (Not-a-Number) or resulted in an overflow requires combining GPU-side constraints with CPU-side array validation. Because gpu.js translates JavaScript into WebGL shaders, traditional JavaScript runtime exceptions do not occur during execution. Instead, operations that exceed 32-bit floating-point limits result in Infinity or clamp to maximum float thresholds, while invalid operations yield NaN. You can detect these conditions either by using specific shader logic inside the kernel or by inspecting the output buffer in JavaScript after execution.

1. Post-Execution Buffer Inspection on the CPU

The simplest and most reliable method to verify calculation integrity is inspecting the output data on the CPU after the kernel finishes running.

When gpu.js returns a calculation, the result is typically a multidimensional array or a typed array (Float32Array). You can scan the output using native JavaScript methods:

const gpu = new GPU();
const myKernel = gpu.createKernel(function() {
  return 1.0 / 0.0; // Produces Infinity
}).setOutput([100]);

const result = myKernel();

// Check for NaN or Infinite values
let hasError = false;
for (let i = 0; i < result.length; i++) {
  const value = result[i];
  if (Number.isNaN(value)) {
    console.error(`NaN detected at index ${i}`);
    hasError = true;
    break;
  }
  if (!Number.isFinite(value)) {
    console.error(`Overflow/Infinity detected at index ${i}`);
    hasError = true;
    break;
  }
}

If you set the kernel mode to { output: [n], pipeline: false }, gpu.js will automatically return CPU-readable arrays, making this check straightforward.

2. In-Kernel Sentinel Value Tagging

If your architecture uses pipeline mode (where textures stay in GPU memory) or you want immediate tagging inside the kernel, you can encode overflow and NaN states into sentinel values.

WebGL 1.0 (GLSL ES 1.0) lacks built-in isnan() or isinf() functions, but WebGL 2.0 provides them. To maintain compatibility across hardware, use mathematical properties:

  • NaN Check: In IEEE 754 arithmetic, NaN is the only value that is never equal to itself (x != x).
  • Overflow/Infinity Check: If a number exceeds standard single-precision float bounds (\(\approx 3.402823 \times 10^{38}\)), multiplying it by 0.0 will result in NaN rather than 0.0.
const kernel = gpu.createKernel(function(a, b) {
  let val = a[this.thread.x] * b[this.thread.x];

  // NaN Detection: A NaN value is not equal to itself
  if (val != val) {
    return -999999.0; // Custom NaN sentinel
  }

  // Overflow Detection: Check against safe 32-bit float limits
  // or test if multiplication by zero fails
  if (val > 3.4e38 || val < -3.4e38 || (val * 0.0 != 0.0)) {
    return -888888.0; // Custom Overflow sentinel
  }

  return val;
}).setOutput([512]);

Note: Some aggressive GPU driver optimizations may optimize away val != val. If you encounter this, verify using the CPU-side method.

3. WebGL2 Built-In Functions

If your target environment supports WebGL 2, gpu.js allows direct mathematical operations that comply with GLSL ES 3.0. You can enforce WebGL2 when instantiating gpu.js:

const gpu = new GPU({ mode: 'webgl2' });

Under WebGL2, standard math checks become more resilient:

  • Compare against extremely high thresholds to catch overflows before standard hardware clamping converts them into unrecoverable values.
  • Use explicit threshold branches to reset, flag, or handle values that exceed standard float capacity.

4. Multi-Channel Status Flags

For complex pipelines where calculation output must not be replaced with sentinel numbers, configure the kernel to return an extra channel (e.g., using setOutput([width, 2]) or 4-channel vector mode).

  • Channel 0: The actual calculated value.
  • Channel 1: Status code (0.0 for Normal, 1.0 for Overflow, 2.0 for NaN).

This separates numeric evaluation from calculation results, allowing downstream kernels or CPU processes to skip or correct faulty threads without losing the raw float state.
