Grass Blade Wind Simulation in GPU.js

Simulating realistic grass blade bending and wind interaction across expansive terrain fields requires offloading physics calculations to the GPU. By leveraging GPU.js, developers can execute massively parallel displacement algorithms directly in the browser using JavaScript syntax compiled to WebGL shaders. This article details the mathematical models and step-by-step implementation for calculating procedural wind fields, blade stiffness, and terrain height adjustments using GPU.js kernels to drive real-time vegetation animations.

Core Concepts of the Simulation Pipeline

Simulating thousands or millions of individual grass blades on the CPU introduces severe performance bottlenecks. Using GPU.js, the simulation evaluates each grass blade's state concurrently:

  1. Terrain Integration: Sampling terrain elevation data so blade roots anchor correctly to uneven surfaces.
  2. Procedural Wind Function: Applying spatial and temporal trigonometric waves or noise algorithms to compute directional wind vectors.
  3. Blade Elasticity and Bending: Calculating the physical displacement of blade tips relative to blade stiffness and wind force.
  4. Buffer Output: Writing displaced tip coordinates into a 1D or 2D array that can be read directly by rendering frameworks like Three.js or raw WebGL.

Defining the Wind and Physics Model

To make the wind appear natural, a composite sine-wave approach provides directional turbulence without the high computational cost of full 3D fluid dynamics. The wind force \(\vec{W}(x, z, t)\) at any coordinate \((x, z)\) and time \(t\) is calculated as:

\[\vec{W}(x, z, t) = \text{direction} \times \left( \sin(x \cdot f_1 + t \cdot s_1) + \cos(z \cdot f_2 + t \cdot s_2) \right) \cdot \text{strength}\]

The displacement of the blade tip depends on the blade's height and stiffness. A stiffer blade resists wind force, while taller blades experience greater torque:

\[\text{Displacement} = \frac{\vec{W}(x, z, t)}{\text{Stiffness}} \times \text{Height}\]

Implementing the GPU.js Kernel

To set up the computation, initialize GPU.js and create a kernel configured to output coordinate vectors for the blade tips.

1. Initialize GPU and Input Data Structures

The simulation requires flat arrays containing grass instance attributes: root positions \((x, y, z)\), blade heights, blade stiffness constants, and current scene parameters.

const { GPU } = require('gpu.js');
const gpu = new GPU();

const bladeCount = 100000;

// Example populated flat Float32Arrays
const rootPositions = new Float32Array(bladeCount * 3); // x, y, z
const bladeProperties = new Float32Array(bladeCount * 2); // [0]: height, [1]: stiffness

2. The Simulation Kernel

The kernel computes the \((x, y, z)\) position of each blade's tip. The vertical position drops slightly as the blade bends to conserve blade length (the Pythagorean approximation).

const simulateGrass = gpu.createKernel(function(roots, properties, time, windDirX, windDirZ, windSpeed, windStrength) {
    const index = this.thread.x;
    const rootIndex = index * 3;
    const propIndex = index * 2;

    const rootX = roots[rootIndex];
    const rootY = roots[rootIndex + 1];
    const rootZ = roots[rootIndex + 2];

    const height = properties[propIndex];
    const stiffness = properties[propIndex + 1];

    // Procedural wave equation for wind gusting
    const wave1 = Math.sin((rootX * 0.1) + (rootZ * 0.1) + (time * windSpeed));
    const wave2 = Math.cos((rootX * 0.05) - (rootZ * 0.05) + (time * windSpeed * 0.7));
    const gust = (wave1 + wave2) * 0.5;

    // Apply directional force
    const force = gust * windStrength;
    const bendAmount = (force / stiffness) * height;

    // Displace tip along wind vector
    const tipX = rootX + (windDirX * bendAmount);
    const tipZ = rootZ + (windDirZ * bendAmount);

    // Approximate vertical sag due to bending
    const horizontalDisplacement = Math.sqrt(
        (tipX - rootX) * (tipX - rootX) + 
        (tipZ - rootZ) * (tipZ - rootZ)
    );
    const verticalSag = Math.sqrt(Math.max(0.001, (height * height) - (horizontalDisplacement * horizontalDisplacement)));
    const tipY = rootY + verticalSag;

    // Return the new tip position based on internal component index
    if (this.thread.y === 0) return tipX;
    if (this.thread.y === 1) return tipY;
    return tipZ;
})
.setOutput([bladeCount, 3])
.setPipeline(true); // Keeps output on the GPU for direct rendering interoperability

Terrain Conformance

If the terrain uses a heightmap or mathematical surface function, root heights must be computed prior to running the displacement kernel. For dynamic deformation (such as vehicles driving across the terrain), pass an updated heightmap texture into the GPU.js kernel:

// Texture sampling logic inside a GPU.js kernel:
function getTerrainHeight(heightmap, mapSize, worldX, worldZ) {
    const u = (worldX / mapSize) + 0.5;
    const v = (worldZ / mapSize) + 0.5;
    return heightmap[Math.floor(v * mapSize)][Math.floor(u * mapSize)];
}

Updating rootY with the sampled height maintains proper blade contact with the ground plane dynamically.

Rendering Loop Integration

Execute the kernel inside the rendering loop, passing the elapsed time to propagate the wind waves:

function animate(currentTimeMs) {
    const time = currentTimeMs * 0.001;

    // Execute kernel
    const tipPositionsTexture = simulateGrass(
        rootPositions,
        bladeProperties,
        time,
        1.0, // windDirX
        0.5, // windDirZ
        2.5, // windSpeed
        1.2  // windStrength
    );

    // Bind tipPositionsTexture directly to instanced vertex attributes
    // or retrieve values using tipPositionsTexture.toArray() if not using pipeline mode

    requestAnimationFrame(animate);
}
requestAnimationFrame(animate);

By keeping the simulation output bound as a WebGL texture via GPU.js pipeline mode, the calculated tip positions can be consumed directly by a vertex shader on instanced grass blade geometries, achieving real-time performance across dense fields.
