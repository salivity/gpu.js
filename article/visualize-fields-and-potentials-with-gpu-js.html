Visualize Fields and Potentials with GPU.js

Visualizing electrostatic potentials and magnetic field lines in real time requires significant parallel computational power, making browser-based execution slow when relying strictly on the CPU. By leveraging gpu.js, you can offload intense mathematical evaluations—such as Coulomb's law, the Biot-Savart law, and numerical line integration—directly to the GPU via WebGL shaders compiled from standard JavaScript. This article explains how to set up gpu.js, compute continuous scalar potential maps, and generate vector field lines efficiently on an HTML5 canvas.

1. Setting Up the Environment

gpu.js compiles JavaScript functions into GLSL shaders that run concurrently on the graphics card. Start by installing or importing the library:

<script src="https://cdnjs.cloudflare.com/ajax/libs/gpu.js/2.16.0/gpu-browser.min.js"></script>
<canvas id="fieldCanvas" width="800" height="600"></canvas>

Initialize the GPU instance and bind it to your target canvas:

const canvas = document.getElementById('fieldCanvas');
const gpu = new GPU({
  canvas: canvas,
  mode: 'gpu' // Falls back to CPU if WebGL is unavailable
});

2. Visualizing Electrostatic Potential (Scalar Fields)

The electrostatic potential \(V\) at any coordinate \((x, y)\) due to \(N\) point charges is calculated by summing the contributions from each charge:

\[V(x, y) = \sum_{i=1}^{N} \frac{k \cdot q_i}{r_i}\]

Where \(k\) is Coulomb's constant, \(q_i\) is the charge value, and \(r_i = \sqrt{(x - x_i)^2 + (y - y_i)^2}\).

Constructing the Potential Kernel

To create a color-coded potential map with equipotential lines, write a kernel that computes the potential per pixel and applies a color mapping function:

const renderPotential = gpu.createKernel(function(chargesX, chargesY, chargesQ, numCharges) {
  const x = this.thread.x;
  const y = this.thread.y;
  let totalPotential = 0.0;
  const k = 8987.55; // Scaled constant for visual balance

  for (let i = 0; i < numCharges; i++) {
    const dx = x - chargesX[i];
    const dy = y - chargesY[i];
    const dist = Math.sqrt(dx * dx + dy * dy) + 1.0; // Avoid division by zero
    totalPotential += (k * chargesQ[i]) / dist;
  }

  // Generate equipotential contour lines using sinusoidal modulation
  const contour = Math.sin(totalPotential * 0.1);

  if (Math.abs(contour) > 0.92) {
    // Equipotential line (white)
    this.color(1.0, 1.0, 1.0, 1.0);
  } else if (totalPotential > 0) {
    // Positive potential (Red gradient)
    const intensity = Math.min(Math.abs(totalPotential) * 0.02, 1.0);
    this.color(intensity, 0.1, 0.1, 1.0);
  } else {
    // Negative potential (Blue gradient)
    const intensity = Math.min(Math.abs(totalPotential) * 0.02, 1.0);
    this.color(0.1, 0.1, intensity, 1.0);
  }
})
.setOutput([800, 600])
.setGraphical(true);

Running the Kernel

Pass your charge data as flat arrays to the kernel:

const chargesX = [300, 500];
const chargesY = [300, 300];
const chargesQ = [1.0, -1.0]; // Dipole: one positive, one negative

renderPotential(chargesX, chargesY, chargesQ, chargesX.length);

3. Visualizing Magnetic Field Lines (Vector Fields)

Magnetic fields are vector fields (\(\mathbf{B}\)). For two-dimensional magnetic sources, such as parallel wires carrying current \(I\) perpendicular to the canvas, the magnetic vector potential \(\mathbf{A}\) has only a \(z\)-component:

\[A_z(x, y) = -\frac{\mu_0}{2\pi} \sum_{i=1}^{N} I_i \ln(r_i)\]

Contour lines of \(A_z\) correspond to magnetic field lines \(\mathbf{B}\).

Constructing the Magnetic Kernel

By calculating \(A_z\) across the grid, magnetic field lines can be rendered directly as contours without computationally expensive particle-tracing steps:

const renderMagneticField = gpu.createKernel(function(wiresX, wiresY, currents, numWires) {
  const x = this.thread.x;
  const y = this.thread.y;
  let Az = 0.0;

  for (let i = 0; i < numWires; i++) {
    const dx = x - wiresX[i];
    const dy = y - wiresY[i];
    const distSq = dx * dx + dy * dy + 1.0;
    
    // Az is proportional to -ln(r) = -0.5 * ln(r^2)
    Az += -0.5 * currents[i] * Math.log(distSq);
  }

  // Draw discrete field lines via repeating frequency bands
  const fieldLine = Math.sin(Az * 1.5);

  if (Math.abs(fieldLine) > 0.88) {
    // Magnetic field line (cyan)
    this.color(0.0, 0.9, 1.0, 1.0);
  } else {
    // Background
    this.color(0.05, 0.05, 0.08, 1.0);
  }
})
.setOutput([800, 600])
.setGraphical(true);

Rendering Current Wires

const wiresX = [350, 450];
const wiresY = [300, 300];
const currents = [10.0, -10.0]; // Opposing currents

renderMagneticField(wiresX, wiresY, currents, wiresX.length);

4. Performance Considerations

  • Array Sizes: Always pre-allocate fixed-length typed arrays (Float32Array) when updating charge/wire coordinates dynamically to prevent memory allocation during animation loops.
  • Avoid Branching: Minimize complex nested conditional logic inside the kernel loop. Simple mathematical approximations evaluate significantly faster across parallel GPU threads.
  • Graphical Output: Setting .setGraphical(true) ensures that the output writes directly to the WebGL framebuffer without transferring image data back to the CPU memory.
