Implement Dense Layer Forward Pass with GPU.js

This article explains how to implement the forward pass of a fully connected (dense) neural network layer using GPU.js. You will learn the underlying mathematical operations—matrix multiplication, bias addition, and activation functions—and how to translate them into a high-performance WebGL compute kernel to run directly on the GPU.

Understanding the Dense Layer Forward Pass

In a dense layer, every input neuron connects to every output neuron. The forward pass computes:

\[\mathbf{Z} = \mathbf{X}\mathbf{W} + \mathbf{B}\] \[\mathbf{A} = f(\mathbf{Z})\]

  • \(\mathbf{X}\) is the input matrix of shape [batch_size, input_features].
  • \(\mathbf{W}\) is the weight matrix of shape [input_features, output_features].
  • \(\mathbf{B}\) is the bias vector of length output_features (broadcast across the batch).
  • \(f\) is an element-wise activation function (such as ReLU).
  • \(\mathbf{A}\) is the activated output matrix of shape [batch_size, output_features].

Setting Up the Kernel in GPU.js

GPU.js maps parallel computations over a specified output grid. In a 2D kernel outputting [output_features, batch_size]:

  • this.thread.x maps to the column index (the output feature index).
  • this.thread.y maps to the row index (the batch sample index).

Here is the complete implementation of a dense layer forward pass with a ReLU activation:

const { GPU } = require('gpu.js');
const gpu = new GPU();

// Define dimensions
const batchSize = 3;
const inputFeatures = 4;
const outputFeatures = 2;

// Create the forward pass kernel
const denseForwardKernel = gpu.createKernel(function (X, W, B, inputLength) {
  let sum = 0;

  // Dot product of row y from X and column x from W
  for (let k = 0; k < inputLength; k++) {
    sum += X[this.thread.y][k] * W[k][this.thread.x];
  }

  // Add bias for the corresponding output feature
  const z = sum + B[this.thread.x];

  // Apply ReLU activation: max(0, z)
  return z > 0 ? z : 0;
})
.setOutput([outputFeatures, batchSize]);

// Sample Input Data: shape [3, 4]
const input = [
  [1.0, 2.0, -1.0, 0.5],
  [0.0, -1.5, 2.0, 1.0],
  [2.0, 0.5, 0.0, -1.0]
];

// Sample Weights: shape [4, 2]
const weights = [
  [0.2, -0.5],
  [0.5, 0.1],
  [-0.3, 0.8],
  [1.0, -0.2]
];

// Sample Biases: shape [2]
const biases = [0.1, -0.1];

// Execute the forward pass
const output = denseForwardKernel(input, weights, biases, inputFeatures);

console.log(output);

How the Implementation Works

  1. Output Mapping: The kernel dimensions are set via .setOutput([outputFeatures, batchSize]). In GPU.js, the first array element represents the horizontal axis (this.thread.x), and the second represents the vertical axis (this.thread.y).
  2. Inner Loop Reduction: Because GLSL loops must often be unrolled or evaluated with a fixed upper bound, passing inputFeatures as an argument controls how many multiplication-addition steps run inside the thread.
  3. Element-wise Activation: The bias addition and ReLU conditional check (z > 0 ? z : 0) occur inside the kernel immediately following the dot product, eliminating the overhead of a separate memory pass for activation.
