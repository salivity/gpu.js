Rendering Dense LiDAR Point Clouds Using GPU.js

This guide explains how to efficiently render dense 3D point clouds captured from LiDAR sensors directly in the browser using GPU.js. You will learn how to structure raw LiDAR coordinate arrays, construct a high-performance transformation and projection kernel, render points directly to an HTML5 canvas using GPU acceleration, and apply optimization strategies to maintain interactive frame rates with massive spatial datasets.

Preparing LiDAR Data for GPU.js

LiDAR datasets typically arrive as LAS/LAZ files or raw text (PCD/XYZ) containing millions of points with spatial coordinates \((X, Y, Z)\) and auxiliary attributes such as reflectance intensity or RGB values.

GPU.js accepts data best as typed arrays or flat numerical matrices. Before passing point data to your kernel, normalize the coordinates to prevent floating-point precision loss and flatten the arrays into contiguous buffers:

// Example: Flat array where every 4 values represent [X, Y, Z, Intensity]
const pointCount = 1000000;
const lidarData = new Float32Array(pointCount * 4);

Initializing the GPU.js Graphical Kernel

GPU.js allows you to execute JavaScript-like code on the GPU via WebGL shaders. To draw points to the screen, instantiate a graphical kernel with graphical: true.

A graphical kernel renders to an internal HTML5 canvas, calling this.color(r, g, b, a) for every pixel on that canvas:

const { GPU } = require('gpu.js'); // Or use the window.GPU browser bundle
const gpu = new GPU();

const width = 800;
const height = 600;

const renderKernel = gpu.createKernel(function(points, count, viewMatrix) {
    // Current pixel coordinate being evaluated on the canvas
    const x = this.thread.x;
    const y = this.thread.y;

    // Background color: Black
    let r = 0.0;
    let g = 0.0;
    let b = 0.0;

    // Scan through point list to find projections intersecting this pixel
    for (let i = 0; i < count; i++) {
        const px = points[i * 4];
        const py = points[i * 4 + 1];
        const pz = points[i * 4 + 2];
        const intensity = points[i * 4 + 3];

        // Apply a basic perspective projection
        const fov = 500.0;
        const screenX = Math.floor((px / (pz + 500.0)) * fov + 400.0);
        const screenY = Math.floor((py / (pz + 500.0)) * fov + 300.0);

        // Check if the point lands on the current pixel
        if (screenX === x && screenY === y) {
            r = intensity;
            g = intensity;
            b = 1.0;
        }
    }

    this.color(r, g, b, 1.0);
})
.setOutput([width, height])
.setGraphical(true);

Implementing an Scatter/Gather Approach

Iterating through all points for every pixel inside the GPU kernel (a "gather" approach) leads to \(O(\text{pixels} \times \text{points})\) runtime, which slows down significantly for dense clouds.

To achieve real-time interaction with millions of points, use GPU.js as a compute pipeline to transform the 3D points into a projected 2D buffer (a "scatter" approach), then draw the transformed buffer to a 2D rendering context:

// Step 1: Compute projected 2D coordinates in parallel
const projectKernel = gpu.createKernel(function(points, cosAngle, sinAngle) {
    const idx = this.thread.x * 4;
    const x = points[idx];
    const y = points[idx + 1];
    const z = points[idx + 2];
    const intensity = points[idx + 3];

    // Simple Y-axis rotation
    const rotX = x * cosAngle + z * sinAngle;
    const rotZ = -x * sinAngle + z * cosAngle;

    // Perspective projection
    const distance = 1000.0;
    const projX = (rotX / (rotZ + distance)) * 800.0 + 400.0;
    const projY = (y / (rotZ + distance)) * 800.0 + 300.0;

    // Output mapped Screen X, Screen Y, and Intensity
    return [projX, projY, intensity];
}).setOutput([pointCount]);

// Step 2: Render to standard Canvas
const canvas = document.getElementById('renderCanvas');
const ctx = canvas.getContext('2d');

function renderFrame(angle) {
    const cos = Math.cos(angle);
    const sin = Math.sin(angle);
    
    // Run GPU calculations
    const projectedPoints = projectKernel(lidarData, cos, sin);

    // Draw rasterized points
    const imgData = ctx.createImageData(canvas.width, canvas.height);
    const data = imgData.data;

    for (let i = 0; i < pointCount; i++) {
        const sx = Math.floor(projectedPoints[i][0]);
        const sy = Math.floor(projectedPoints[i][1]);
        const intensity = projectedPoints[i][2];

        if (sx >= 0 && sx < canvas.width && sy >= 0 && sy < canvas.height) {
            const pixelIdx = (sy * canvas.width + sx) * 4;
            data[pixelIdx] = intensity * 255;     // R
            data[pixelIdx + 1] = intensity * 255; // G
            data[pixelIdx + 2] = 255;             // B
            data[pixelIdx + 3] = 255;             // Alpha
        }
    }

    ctx.putImageData(imgData, 0, 0);
}

Optimizing Dense LiDAR Cloud Performance

  1. Octree and Chunking: Split dense scans into spatial chunks or an Octree. Run GPU kernels only on chunks within the active viewing frustum to bypass off-screen point processing.
  2. Texture Memory Pipelines: If chaining compute operations, configure GPU.js with pipeline: true. This keeps intermediate coordinate transformations directly in WebGL texture memory, avoiding high-overhead GPU-to-CPU readbacks.
  3. Point Budgets via Level of Detail (LOD): Subsample points dynamically. When rotating or panning the camera, render a sparse subset (e.g., 10% to 25% of points) to sustain 60 FPS, and process the full dense cloud only when user interaction ceases.
