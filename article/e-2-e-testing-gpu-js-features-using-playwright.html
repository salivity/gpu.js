E2E Testing GPU.js Features Using Playwright

Testing GPU-accelerated web applications requires real browser environments capable of executing WebGL or WebGPU contexts correctly. This guide demonstrates how to configure Microsoft Playwright to run end-to-end tests on gpu.js kernels, manage browser-level hardware acceleration flags, execute computations inside the page context, and assert computation accuracy across local and headless CI environments.

1. Install Required Dependencies

Initialize your project and install Playwright along with gpu.js:

npm init -y
npm install -D @playwright/test gpu.js
npx playwright install chromium

2. Configure Playwright for WebGL and Hardware Acceleration

By default, headless browsers disable hardware acceleration and WebGL support. To test gpu.js, you must pass explicit launch arguments to Chromium.

Create a playwright.config.ts (or .js) file to enable WebGL contexts and specify software rendering fallback (such as SwiftShader) for environments lacking a physical GPU:

import { defineConfig, devices } from '@playwright/test';

export default defineConfig({
  testDir: './tests',
  use: {
    ...devices['Desktop Chrome'],
    headless: true,
    launchOptions: {
      args: [
        '--enable-webgl',
        '--ignore-gpu-blocklist',
        '--use-gl=angle',
        '--use-angle=swiftshader', // Ensures execution in headless CI environments
      ],
    },
  },
});

3. Create a Test Page or In-Page Evaluation

You can test gpu.js either by loading a hosted web page that bundles the library or by injecting the library directly into a blank page during test execution.

The following test script mounts gpu.js, executes a matrix multiplication kernel, and validates that the GPU calculation produces expected values within an acceptable floating-point tolerance.

Create tests/gpu.spec.ts:

import { test, expect } from '@playwright/test';
import path from 'path';

test.describe('GPU.js End-to-End Tests', () => {
  test('should execute a matrix multiplication kernel successfully', async ({ page }) => {
    // Navigate to a blank page
    await page.goto('about:blank');

    // Inject the bundled GPU.js library into the browser context
    await page.addScriptTag({
      path: path.resolve('node_modules/gpu.js/dist/gpu-browser.min.js'),
    });

    // Execute the kernel in the browser environment
    const result = await page.evaluate(() => {
      // Access the GPU class attached to window
      const { GPU } = window as any;
      const gpu = new GPU();

      // Define a 2x2 matrix multiplication kernel
      const multiplyMatrix = gpu.createKernel(function (a: number[][], b: number[][]) {
        let sum = 0;
        for (let i = 0; i < 2; i++) {
          sum += a[this.thread.y][i] * b[i][this.thread.x];
        }
        return sum;
      }).setOutput([2, 2]);

      const matrixA = [
        [1, 2],
        [3, 4],
      ];
      const matrixB = [
        [5, 6],
        [7, 8],
      ];

      const output = multiplyMatrix(matrixA, matrixB);
      
      // Clean up GPU context
      gpu.destroy();

      // Convert Float32Array results to standard nested arrays for serialization
      return Array.from(output as any).map((row: any) => Array.from(row));
    });

    // Expected result:
    // [ [1*5 + 2*7, 1*6 + 2*8], [3*5 + 4*7, 3*6 + 4*8] ] => [ [19, 22], [43, 50] ]
    const expected = [
      [19, 22],
      [43, 50],
    ];

    expect(result).toEqual(expected);
  });

  test('should report WebGL mode instead of falling back to CPU', async ({ page }) => {
    await page.goto('about:blank');
    await page.addScriptTag({
      path: path.resolve('node_modules/gpu.js/dist/gpu-browser.min.js'),
    });

    const executionMode = await page.evaluate(() => {
      const { GPU } = window as any;
      const gpu = new GPU();
      
      const dummyKernel = gpu.createKernel(function () {
        return 1;
      }).setOutput([1]);

      dummyKernel();
      const mode = dummyKernel.subKernelOutput ? 'unknown' : (gpu as any).mode;
      gpu.destroy();
      
      return mode;
    });

    // Verify that the kernel ran on WebGL (or WebGL2) and did not drop back to CPU
    expect(['gpu', 'webgl', 'webgl2']).toContain(executionMode);
  });
});

4. Running the Tests Locally and in CI

Execute the test suite using the Playwright test runner:

npx playwright test

When integrating into automated CI pipelines (such as GitHub Actions), ensure that system-level OpenGL drivers are installed. On Ubuntu runners, install mesa-utils and libgl1-mesa-glx before running Playwright to guarantee SwiftShader can emulate WebGL contexts without a physical GPU.
