GPU.js Voxel Destruction with Parallel Stress Checks

Simulating real-time destruction and structural collapse in voxel environments requires evaluating the physical integrity of thousands of individual blocks simultaneously. By using gpu.js, you can offload structural stress propagation and connectivity checks from the CPU to the GPU using WebGL compute shaders. This article explains how to set up a 3D voxel grid, write parallel stress-checking kernels in gpu.js, detect unsupported voxels, and trigger dynamic crumbling mechanics efficiently.

Voxel Data Representation

To process a 3D voxel space within gpu.js, the world grid must be represented as a 1D or 3D flattened array of numbers. Each voxel contains state data, typically encoded as an integer or float representing its material, density, support value, and current stress.

A typical 3D grid with dimensions [WIDTH, HEIGHT, DEPTH] can be mapped into a flattened Float32Array:

const WIDTH = 64;
const HEIGHT = 64;
const DEPTH = 64;
const TOTAL_VOXELS = WIDTH * HEIGHT * DEPTH;

// 0: Air, 1: Solid block, 2: Anchor/Ground block
const voxelGrid = new Float32Array(TOTAL_VOXELS);

To maintain high throughput, data should remain on the GPU using pipeline: true mode across consecutive stress passes.

Structural Stress and Connectivity Algorithm

Structural integrity can be modeled by checking if a block has an unbroken connection to a grounded anchor voxel and whether the load transferred through that block exceeds its structural threshold.

A parallel relaxation approach evaluates neighbor connectivity over multiple iterations:

  1. Ground voxels receive an infinite support value.
  2. Air voxels have a support value of zero.
  3. Every iteration, a solid voxel calculates its new support value as a function of the highest support value among its immediate orthogonal neighbors, minus a weight/distance penalty.
  4. If a voxel's support value drops below its critical threshold, its structural integrity fails, marking it for detachment.

Creating the GPU.js Stress Kernel

In gpu.js, kernels run functions over output dimensions. Using a 3D output dimension allows the kernel to map this.thread.x, this.thread.y, and this.thread.z directly to voxel coordinates.

const { GPU } = require('gpu.js');
const gpu = new GPU();

const stressKernel = gpu.createKernel(function(grid, width, height, depth, penalty) {
    const x = this.thread.x;
    const y = this.thread.y;
    const z = this.thread.z;

    const index = x + y * width + z * width * height;
    const currentVal = grid[z][y][x];

    // Ignore air or indestructible ground voxels
    if (currentVal <= 0.0) return 0.0;
    if (y === 0) return 1.0; // Ground anchor with full support

    // Sample orthogonal neighbors
    const left   = x > 0 ? grid[z][y][x - 1] : 0.0;
    const right  = x < width - 1 ? grid[z][y][x + 1] : 0.0;
    const down   = y > 0 ? grid[z][y - 1][x] : 0.0;
    const up     = y < height - 1 ? grid[z][y + 1][x] : 0.0;
    const back   = z > 0 ? grid[z - 1][y][x] : 0.0;
    const front  = z < depth - 1 ? grid[z + 1][y][x] : 0.0;

    // Determine the highest support received from neighbors
    let maxNeighbor = down; // Give slight bias to upward support from below
    if (left > maxNeighbor) maxNeighbor = left;
    if (right > maxNeighbor) maxNeighbor = right;
    if (up > maxNeighbor) maxNeighbor = up;
    if (back > maxNeighbor) maxNeighbor = back;
    if (front > maxNeighbor) maxNeighbor = front;

    // Calculate decayed support
    const propagatedSupport = maxNeighbor - penalty;

    return propagatedSupport > 0.0 ? propagatedSupport : 0.0;
})
.setOutput([WIDTH, HEIGHT, DEPTH])
.setPipeline(true)
.setImmutable(true);

Running Iterative Propagation and Identifying Collapses

Because a GPU kernel processes a single step in parallel, stress and support must propagate across the structure over multiple passes. Running the kernel in a loop allows stress paths to traverse cantilevered beams and arches.

let currentGridTexture = initialVoxelTexture;
const propagationSteps = 16;
const structuralPenalty = 0.05;

for (let i = 0; i < propagationSteps; i++) {
    currentGridTexture = stressKernel(
        currentGridTexture,
        WIDTH,
        HEIGHT,
        DEPTH,
        structuralPenalty
    );
}

Once the propagation converges, an extraction kernel compares the final support value against the breaking point:

const destructionFilterKernel = gpu.createKernel(function(supportGrid, originalGrid) {
    const x = this.thread.x;
    const y = this.thread.y;
    const z = this.thread.z;

    const support = supportGrid[z][y][x];
    const originalType = originalGrid[z][y][x];

    // If voxel is solid but support reached zero, mark as crumbled (-1)
    if (originalType > 0.0 && support <= 0.0 && y > 0) {
        return -1.0; 
    }

    return originalType;
})
.setOutput([WIDTH, HEIGHT, DEPTH]);

Triggering Crumbling Mechanics

Once voxels are flagged as disconnected:

  1. Clear from Static Grid: Update the primary voxel buffer to remove broken voxels, preventing them from rendering as static geometry or contributing to collision meshes.
  2. Cluster Analysis (CPU or Secondary Kernel): Group adjacent collapsed voxels into connected components if rigid-body simulation is required for chunks.
  3. Spawn Dynamic Debris: Convert isolated crumbling voxels or clusters into dynamic particle entities or rigid bodies influenced by gravity, angular velocity, and external blast momentum.
  4. Mesh Regeneration: Dispatch an asynchronous update to regenerate the surrounding mesh faces where destruction occurred.

Performance Considerations

  • Minimize Texture Readbacks: Avoid calling .toArray() on gpu.js textures during intermediate passes. Keep the voxel data entirely on GPU memory until the final detachment check is reached.
  • Dirty Rectangles / Sub-Grids: When an explosion or impact happens, do not compute stress across the entire map. Limit kernel execution boundaries to an axis-aligned bounding box (AABB) surrounding the damage radius.
  • Kernel Fusion: Combine neighbor stress calculation with gravitational shear force calculation in the same kernel pass to avoid redundant memory fetch operations.
