Calculating Protein Contact Maps with GPU.js

This article explains how to compute protein inter-residue contact maps from 3D atomic coordinates using GPU.js for hardware-accelerated performance in JavaScript. You will learn how to extract representative alpha-carbon (\(C\alpha\)) coordinates, construct an efficient GPU kernel to calculate pairwise Euclidean distances in parallel, and apply a distance threshold to generate the final contact matrix.

What Is a Protein Contact Map?

A protein contact map is an \(N \times N\) symmetric binary matrix representing the tertiary structure of a protein containing \(N\) residues. Two residues \(i\) and \(j\) are considered in contact if the Euclidean distance between their representative atoms—typically the alpha-carbons (\(C\alpha\))—is below a defined physical threshold, usually between 6.0 and 8.0 Ångströms (Å):

\[d(i, j) = \sqrt{(x_i - x_j)^2 + (y_i - y_j)^2 + (z_i - z_j)^2}\]

\[\text{Contact}(i, j) = \begin{cases} 1 & \text{if } d(i, j) \le \text{threshold} \\ 0 & \text{otherwise} \end{cases}\]

Because computing this matrix requires \(O(N^2)\) distance evaluations, using the CPU for large proteins or multi-frame molecular dynamics trajectories can create a performance bottleneck. GPU.js compiles JavaScript functions into WebGL shaders, offloading these parallel computations to the graphics card.

Step 1: Preparing Coordinate Data

Extract the \(C\alpha\) Cartesian coordinates from your structural data (such as a .pdb or .cif file). To optimize data transfer to the GPU, flatten the coordinate components into three distinct typed arrays: xCoords, yCoords, and zCoords.

// Example coordinates for 4 residues
const xCoords = new Float32Array([24.1, 26.5, 29.8, 31.2]);
const yCoords = new Float32Array([12.3, 14.8, 13.9, 17.5]);
const zCoords = new Float32Array([45.6, 42.1, 40.5, 38.2]);

const residueCount = xCoords.length;
const distanceThreshold = 8.0; // in Ångströms

Step 2: Initializing the GPU.js Kernel

Install GPU.js via npm (npm install gpu.js) or import it via a script tag. Next, instantiate the GPU object and define a kernel that calculates the pairwise distance between residues \(i\) and \(j\), returning 1 for contact and 0 otherwise.

import { GPU } from 'gpu.js';

const gpu = new GPU();

const calculateContactMap = gpu.createKernel(function(x, y, z, threshold) {
    // this.thread.x corresponds to residue j
    // this.thread.y corresponds to residue i
    const dx = x[this.thread.y] - x[this.thread.x];
    const dy = y[this.thread.y] - y[this.thread.x];
    const dz = z[this.thread.y] - z[this.thread.x];
    
    const distanceSquared = (dx * dx) + (dy * dy) + (dz * dz);
    const thresholdSquared = threshold * threshold;

    if (distanceSquared <= thresholdSquared) {
        return 1;
    } else {
        return 0;
    }
})
.setOutput([residueCount, residueCount])
.setOutputToTexture(false); // Returns a nested JavaScript array

Comparing squared distances avoids the computational overhead of the square root operation (Math.sqrt), which improves kernel execution speed.

Step 3: Generating and Reading the Matrix

Pass the flattened coordinate arrays and the threshold value to the compiled kernel. The output is a 2D array of size [residueCount][residueCount].

const contactMap = calculateContactMap(xCoords, yCoords, zCoords, distanceThreshold);

// Access contact state between residue 0 and residue 2
console.log(contactMap[0][2]); // Outputs 1 or 0

Performance Considerations

  1. Memory Allocation: If you are analyzing long molecular dynamics trajectories, keep intermediate matrices on the GPU by setting .setOutputToTexture(true). This avoids costly data transfers between GPU and CPU memory on every frame.
  2. Dimension Constraints: WebGL implementations impose a maximum texture size (commonly 4096 or 8192 pixels per dimension). For exceptionally large macromolecular assemblies where \(N\) exceeds these dimensions, divide the contact map calculation into smaller sub-tiles.
