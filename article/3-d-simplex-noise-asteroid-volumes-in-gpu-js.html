3D Simplex Noise Asteroid Volumes in GPU.js

This article explains how to compute 3D multi-octave Simplex noise (Fractal Brownian Motion) volumes on the GPU using gpu.js to drive procedural asteroid generation. By offloading volumetric noise calculations to WebGL shaders, you can produce real-time, high-resolution 3D scalar density fields. These voxel fields serve as the direct foundation for polygon extraction algorithms like Marching Cubes or Surface Nets to render complex, cratered asteroid meshes.

Understanding the Asteroid Density Function

Procedural asteroid geometry is typically represented as an implicit surface defined by an Signed Distance Field (SDF) or a density threshold. A baseline sphere is perturbed using noise:

\[\text{Density}(x, y, z) = \text{Radius} - \sqrt{x^2 + y^2 + z^2} + \text{Noise}_{\text{multi-octave}}(x, y, z)\]

Points where the density is greater than zero represent solid asteroid rock, while values below zero represent empty space. Multi-octave Simplex noise adds layers of varying frequency and amplitude (Fractal Brownian Motion or FBM) to create both large structural deformities and fine surface roughness.

Setting Up the GPU.js Environment

Install gpu.js into your project:

npm install gpu.js

In your script, initialize a GPU instance. To generate a 3D volume, configure the output dimensions across three axes: \([X, Y, Z]\).

import { GPU } from 'gpu.js';

const gpu = new GPU();

Implementing 3D Simplex Noise in GPU.js

gpu.js compiles JavaScript functions into GLSL shaders. Because standard Math library functions are limited inside kernels, you must provide helper functions for vector math, permutation hashing, and simplex skewing.

Define a 3D Simplex noise function and register it with your GPU instance:

// Register the 3D Simplex noise helper
gpu.addFunction(function mod289(x) {
  return x - Math.floor(x * (1.0 / 289.0)) * 289.0;
});

gpu.addFunction(function permute(x) {
  return (x * 34.0 + 1.0) * x - Math.floor(((x * 34.0 + 1.0) * x) * (1.0 / 289.0)) * 289.0;
});

// Implementation of classic 3D simplex noise
gpu.addFunction(function simplex3D(x, y, z) {
  const C0 = 1.0 / 6.0;
  const C1 = 1.0 / 3.0;

  // Skew input space to determine simplex cell
  const s = (x + y + z) * C1;
  const i = Math.floor(x + s);
  const j = Math.floor(y + s);
  const k = Math.floor(z + s);

  const t = (i + j + k) * C0;
  const x0 = x - (i - t);
  const y0 = y - (j - t);
  const z0 = z - (k - t);

  // Determine simplex offsets
  let i1 = 0, j1 = 0, k1 = 0;
  let i2 = 0, j2 = 0, k2 = 0;

  if (x0 >= y0) {
    if (y0 >= z0) { i1 = 1; j1 = 0; k1 = 0; i2 = 1; j2 = 1; k2 = 0; }
    else if (x0 >= z0) { i1 = 1; j1 = 0; k1 = 0; i2 = 1; j2 = 0; k2 = 1; }
    else { i1 = 0; j1 = 0; k1 = 1; i2 = 1; j2 = 0; k2 = 1; }
  } else {
    if (y0 < z0) { i1 = 0; j1 = 0; k1 = 1; i2 = 0; j2 = 1; k2 = 1; }
    else if (x0 < z0) { i1 = 0; j1 = 1; k1 = 0; i2 = 0; j2 = 1; k2 = 1; }
    else { i1 = 0; j1 = 1; k1 = 0; i2 = 1; j2 = 1; k2 = 0; }
  }

  const x1 = x0 - i1 + C0;
  const y1 = y0 - j1 + C0;
  const z1 = z0 - k1 + C0;
  const x2 = x0 - i2 + 2.0 * C0;
  const y2 = y0 - j2 + 2.0 * C0;
  const z2 = z0 - k2 + 2.0 * C0;
  const x3 = x0 - 1.0 + 3.0 * C0;
  const y3 = y0 - 1.0 + 3.0 * C0;
  const z3 = z0 - 1.0 + 3.0 * C0;

  // Compute contributions from the four corners
  let n0 = 0.0, n1 = 0.0, n2 = 0.0, n3 = 0.0;

  let t0 = 0.6 - x0 * x0 - y0 * y0 - z0 * z0;
  if (t0 > 0.0) {
    t0 *= t0;
    n0 = t0 * t0 * (Math.sin(i * 12.9898 + j * 78.233 + k * 45.164) * 43758.5453 - Math.floor(Math.sin(i * 12.9898 + j * 78.233 + k * 45.164) * 43758.5453) - 0.5);
  }

  let t1 = 0.6 - x1 * x1 - y1 * y1 - z1 * z1;
  if (t1 > 0.0) {
    t1 *= t1;
    n1 = t1 * t1 * (Math.sin((i + i1) * 12.9898 + (j + j1) * 78.233 + (k + k1) * 45.164) * 43758.5453 - Math.floor(Math.sin((i + i1) * 12.9898 + (j + j1) * 78.233 + (k + k1) * 45.164) * 43758.5453) - 0.5);
  }

  let t2 = 0.6 - x2 * x2 - y2 * y2 - z2 * z2;
  if (t2 > 0.0) {
    t2 *= t2;
    n2 = t2 * t2 * (Math.sin((i + i2) * 12.9898 + (j + j2) * 78.233 + (k + k2) * 45.164) * 43758.5453 - Math.floor(Math.sin((i + i2) * 12.9898 + (j + j2) * 78.233 + (k + k2) * 45.164) * 43758.5453) - 0.5);
  }

  let t3 = 0.6 - x3 * x3 - y3 * y3 - z3 * z3;
  if (t3 > 0.0) {
    t3 *= t3;
    n3 = t3 * t3 * (Math.sin((i + 1.0) * 12.9898 + (j + 1.0) * 78.233 + (k + 1.0) * 45.164) * 43758.5453 - Math.floor(Math.sin((i + 1.0) * 12.9898 + (j + 1.0) * 78.233 + (k + 1.0) * 45.164) * 43758.5453) - 0.5);
  }

  return 32.0 * (n0 + n1 + n2 + n3);
});

Writing the Multi-Octave Asteroid Density Kernel

Combine the base noise into a Fractal Brownian Motion loop inside the kernel. The kernel evaluates each voxel coordinate in 3D grid space, normalizes the position to a range between \([-1, 1]\), computes the base spherical field, and offsets it using multiple octaves of noise.

const resolution = 64; // Size of the 3D scalar grid (64x64x64)

const generateAsteroidVolume = gpu.createKernel(function(baseRadius, octaves, lacunarity, gain, baseFrequency) {
  // Normalize voxel coordinates to [-1.0, 1.0]
  const x = (this.thread.x / (this.output.x - 1.0)) * 2.0 - 1.0;
  const y = (this.thread.y / (this.output.y - 1.0)) * 2.0 - 1.0;
  const z = (this.thread.z / (this.output.z - 1.0)) * 2.0 - 1.0;

  // Calculate radial distance from center
  const distance = Math.sqrt(x * x + y * y + z * z);

  // Compute Multi-Octave FBM Simplex Noise
  let noiseSum = 0.0;
  let freq = baseFrequency;
  let amp = 1.0;

  for (let o = 0; o < 8; o++) {
    if (o < octaves) {
      noiseSum += simplex3D(x * freq, y * freq, z * freq) * amp;
      freq *= lacunarity;
      amp *= gain;
    }
  }

  // Asteroid density formula: Positive values are solid, negative are void
  const density = (baseRadius - distance) + noiseSum;
  return density;
})
.setOutput([resolution, resolution, resolution])
.setPrecision('single');

Execution and Mesh Extraction

Execute the kernel by passing parameters for asteroid morphology:

const baseRadius = 0.6;     // Base spherical size relative to unit box
const octaves = 5;          // Structural detail layers
const lacunarity = 2.0;     // Frequency multiplier per octave
const gain = 0.5;           // Amplitude decay per octave
const baseFrequency = 1.2;  // Initial noise scale

// Returns a 3D nested Float32Array: [Z][Y][X]
const volumeData = generateAsteroidVolume(
  baseRadius,
  octaves,
  lacunarity,
  gain,
  baseFrequency
);

The resulting 3D array contains scalar density values. To transform this dataset into a renderable mesh, pass volumeData directly to an isosurface polygonizer such as Marching Cubes, setting the isolevel to 0.0. Every point in the grid where the density transitions across zero becomes an interpolated vertex on the final asteroid surface.
