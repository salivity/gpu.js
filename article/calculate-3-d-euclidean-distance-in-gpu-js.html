Calculate 3D Euclidean Distance in GPU.js

This article explains how to compute 3D Euclidean distances across parallel threads using GPU.js and the this.thread object. By leveraging 3D kernel execution dimensions, each GPU thread maps to a unique spatial coordinate \((x, y, z)\), enabling high-performance parallel distance calculations relative to arbitrary target points or other threads.

Setting Up the 3D Kernel

In GPU.js, defining a kernel output with three dimensions assigns each thread a unique position accessible through this.thread.x, this.thread.y, and this.thread.z.

To calculate the Euclidean distance from every thread in a 3D grid to an arbitrary target coordinate \((t_x, t_y, t_z)\), pass the target coordinates into the kernel as arguments:

const { GPU } = require('gpu.js');
const gpu = new GPU();

const calculateDistanceKernel = gpu.createKernel(function(targetX, targetY, targetZ) {
    const dx = this.thread.x - targetX;
    const dy = this.thread.y - targetY;
    const dz = this.thread.z - targetZ;

    return Math.sqrt(dx * dx + dy * dy + dz * dz);
}).setOutput([512, 512, 64]); // Dimensions: [X (width), Y (height), Z (depth)]

Running the Calculation

Invoke the kernel by supplying the arbitrary coordinates of the target thread or point:

// Target coordinates
const targetX = 120;
const targetY = 250;
const targetZ = 32;

// Execute kernel on the GPU
const distances = calculateDistanceKernel(targetX, targetY, targetZ);

// Access distance at a specific thread location: distances[z][y][x]
console.log(distances[32][250][120]); // Outputs 0 (distance to itself)
console.log(distances[0][0][0]);       // Distance from origin to target

Calculating Distances Between Arbitrary Thread Pairs

If you need to calculate pairwise distances between an arbitrary set of 3D points stored in memory rather than a continuous spatial grid, flatten the coordinates into arrays and use a 2D kernel where each thread represents a pair of indices \((i, j)\):

const calculatePairwiseDistanceKernel = gpu.createKernel(function(xCoords, yCoords, zCoords) {
    const i = this.thread.x;
    const j = this.thread.y;

    const dx = xCoords[i] - xCoords[j];
    const dy = yCoords[i] - yCoords[j];
    const dz = zCoords[i] - zCoords[j];

    return Math.sqrt(dx * dx + dy * dy + dz * dz);
}).setOutput([numPoints, numPoints]);

In this setup:

  • this.thread.x selects the first thread coordinate \((x_i, y_i, z_i)\).
  • this.thread.y selects the second thread coordinate \((x_j, y_j, z_j)\).
  • The resulting 2D matrix contains the exact Euclidean distance between any two arbitrary threads in the dataset.
