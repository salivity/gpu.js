Computing Membrane Stress Tensors Using GPU.js

This article explains how to compute finite strain and stress tensors in elastic membranes under mechanical loads using GPU.js to achieve hardware-accelerated parallel performance. By discretizing the membrane domain into a structured grid of nodal displacements, you can evaluate deformation gradients via finite differences and directly compute Green-Lagrange strain and Second Piola-Kirchhoff stress tensors inside WebGL compute shaders generated by GPU.js.

Mathematical Formulation

An elastic membrane subjected to out-of-plane and in-plane loads undergoes continuous deformation. Let the undeformed reference coordinates be \(\mathbf{X} = (X, Y)\) and the deformed coordinates be \(\mathbf{x} = \mathbf{X} + \mathbf{u}\), where \(\mathbf{u} = (u, v, w)\) is the displacement vector.

  1. Deformation Gradient Tensor (\(\mathbf{F}\)): The mapping from the reference to the current configuration in two dimensions is represented by: \[F_{ij} = \frac{\partial x_i}{\partial X_j}\]

  2. Green-Lagrange Strain Tensor (\(\mathbf{E}\)): To account for geometric nonlinearities (large deflections in thin membranes), use the Green-Lagrange strain tensor: \[\mathbf{E} = \frac{1}{2} (\mathbf{F}^T \mathbf{F} - \mathbf{I})\] Component-wise for plane configurations: \[E_{xx} = \frac{1}{2} \left( \left(\frac{\partial x}{\partial X}\right)^2 + \left(\frac{\partial y}{\partial X}\right)^2 + \left(\frac{\partial w}{\partial X}\right)^2 - 1 \right)\] \[E_{yy} = \frac{1}{2} \left( \left(\frac{\partial x}{\partial Y}\right)^2 + \left(\frac{\partial y}{\partial Y}\right)^2 + \left(\frac{\partial w}{\partial Y}\right)^2 - 1 \right)\] \[E_{xy} = \frac{1}{2} \left( \frac{\partial x}{\partial X}\frac{\partial x}{\partial Y} + \frac{\partial y}{\partial X}\frac{\partial y}{\partial Y} + \frac{\partial w}{\partial X}\frac{\partial w}{\partial Y} \right)\]

  3. Second Piola-Kirchhoff Stress Tensor (\(\mathbf{S}\)): For an isotropic, hyperelastic Saint Venant–Kirchhoff material under plane stress conditions: \[S_{xx} = \frac{E_{mod}}{1 - \nu^2} (E_{xx} + \nu E_{yy})\] \[S_{yy} = \frac{E_{mod}}{1 - \nu^2} (E_{yy} + \nu E_{xx})\] \[S_{xy} = \frac{E_{mod}}{1 + \nu} E_{xy}\] where \(E_{mod}\) is Young's modulus and \(\nu\) is Poisson's ratio.

Setting Up the Discretized Domain in GPU.js

Discretize the membrane into an \(N \times M\) grid with uniform spacing \(\Delta X\) and \(\Delta Y\). Spatial derivatives are computed using central finite differences at interior points:

\[\frac{\partial f_{i,j}}{\partial X} \approx \frac{f_{i+1,j} - f_{i-1,j}}{2\Delta X}, \quad \frac{\partial f_{i,j}}{\partial Y} \approx \frac{f_{i,j+1} - f_{i,j-1}}{2\Delta Y}\]

GPU.js maps each thread to an \((i, j)\) index on the membrane, enabling simultaneous calculation of all tensor components.

GPU.js Implementation

The following code defines the displacement field, sets up material constants, and executes the kernel to yield the symmetric components of the strain and stress tensors for every node.

const { GPU } = require('gpu.js');
const gpu = new GPU();

const width = 512;
const height = 512;
const dx = 0.01;
const dy = 0.01;
const youngModulus = 1e6; // Pascals
const poissonRatio = 0.3;

// Example displacement buffers: u (x-disp), v (y-disp), w (out-of-plane disp)
const u = new Float32Array(width * height);
const v = new Float32Array(width * height);
const w = new Float32Array(width * height);

// Populate fields with load-induced displacements (e.g., transverse pressure deflection)
for (let j = 0; j < height; j++) {
  for (let i = 0; i < width; i++) {
    const idx = j * width + i;
    const x = i * dx;
    const y = j * dy;
    w[idx] = 0.05 * Math.sin((Math.PI * x) / (width * dx)) * Math.sin((Math.PI * y) / (height * dy));
    u[idx] = 0.001 * x;
    v[idx] = 0.001 * y;
  }
}

// Kernel computing Green-Lagrange Strain Tensor [Exx, Eyy, Exy]
const computeStrainKernel = gpu.createKernel(function(u, v, w, dx, dy, width, height) {
  const i = this.thread.x;
  const j = this.thread.y;

  // Boundary handling using clamped derivatives
  const iLeft = i > 0 ? i - 1 : 0;
  const iRight = i < width - 1 ? i + 1 : width - 1;
  const jDown = j > 0 ? j - 1 : 0;
  const jUp = j < height - 1 ? j + 1 : height - 1;

  const inv2dx = 1.0 / (2.0 * dx);
  const inv2dy = 1.0 / (2.0 * dy);

  // Partial derivatives of displacements
  const du_dX = (u[j][iRight] - u[j][iLeft]) * inv2dx;
  const du_dY = (u[jUp][i] - u[jDown][i]) * inv2dy;

  const dv_dX = (v[j][iRight] - v[j][iLeft]) * inv2dx;
  const dv_dY = (v[jUp][i] - v[jDown][i]) * inv2dy;

  const dw_dX = (w[j][iRight] - w[j][iLeft]) * inv2dx;
  const dw_dY = (w[jUp][i] - w[jDown][i]) * inv2dy;

  // Deformation gradient components: F = I + grad(u)
  const F11 = 1.0 + du_dX;
  const F12 = du_dY;
  const F21 = dv_dX;
  const F22 = 1.0 + dv_dY;
  const F31 = dw_dX;
  const F32 = dw_dY;

  // Green-Lagrange Strain: E = 0.5 * (F^T * F - I)
  const Exx = 0.5 * (F11 * F11 + F21 * F21 + F31 * F31 - 1.0);
  const Eyy = 0.5 * (F12 * F12 + F22 * F22 + F32 * F32 - 1.0);
  const Exy = 0.5 * (F11 * F12 + F21 * F22 + F31 * F32);

  // Return components stored along a 3-element channel vector
  return [Exx, Eyy, Exy];
})
.setOutput([width, height])
.setPipeline(true); // Retain output on GPU for chained calculations

// Kernel computing Second Piola-Kirchhoff Stress Tensor [Sxx, Syy, Sxy]
const computeStressKernel = gpu.createKernel(function(strainTexture, E, nu) {
  const i = this.thread.x;
  const j = this.thread.y;

  const strain = strainTexture[j][i];
  const Exx = strain[0];
  const Eyy = strain[1];
  const Exy = strain[2];

  const factor = E / (1.0 - nu * nu);
  const Sxx = factor * (Exx + nu * Eyy);
  const Syy = factor * (Eyy + nu * Exx);
  const Sxy = (E / (1.0 + nu)) * Exy;

  return [Sxx, Syy, Sxy];
})
.setOutput([width, height]);

// Execute kernels
const strainTensorTexture = computeStrainKernel(u, v, w, dx, dy, width, height);
const stressTensor = computeStressKernel(strainTensorTexture, youngModulus, poissonRatio);

Pipeline Optimization and Boundary Considerations

  1. GPU Texture Pipeline: Setting setPipeline(true) on intermediate kernels keeps strain tensors in GPU memory as WebGL textures. This avoids costly CPU-GPU memory bandwidth overhead when feeding strains directly into the constitutive stress kernel.
  2. Boundary Truncation: First-order central difference schemes at grid boundaries lead to inaccuracies unless one-sided differences are applied. In the kernel implementation, edge coordinates sample their nearest interior neighbor to prevent out-of-bounds reads while preserving execution branching uniformity across SIMD warps.
  3. Cauchy Stress Transformation: If physical current-configuration stress (true Cauchy stress, \(\boldsymbol{\sigma}\)) is required instead of the Second Piola-Kirchhoff stress, normalize using the area ratio \(J = \det(\mathbf{F})\) via: \[\boldsymbol{\sigma} = \frac{1}{J} \mathbf{F} \mathbf{S} \mathbf{F}^T\] This transformation can be chained in an additional GPU.js pass using the stored deformation gradient data.
