How to Implement Reduction Operations in GPU.js

This article explains how to implement parallel reduction operations—such as calculating array sums and finding minimum values—using GPU.js. Because GPU.js compiles JavaScript functions into WebGL shaders, threads cannot communicate directly or share global mutable state in a single pass. To perform reductions efficiently on the GPU, you must implement a multi-pass tree reduction strategy that iteratively shrinks the dataset until a single scalar value remains.

The Multi-Pass Tree Reduction Concept

In WebGL-based environments like GPU.js, each thread computes the value of a single output element independently. You cannot create a single global accumulator variable across threads.

Instead, a reduction is executed hierarchically across multiple passes:

  1. An input array of size \(N\) is processed by \(N / 2\) threads.
  2. Each thread reads two elements, combines them (by adding them or selecting the smaller of the two), and writes the result to a new array of size \(N / 2\).
  3. This smaller array becomes the input for the next pass.
  4. The process repeats logarithmically (\(\lceil\log_2 N\rceil\) steps) until the output length is 1.

To prevent expensive data transfers between the GPU and CPU during intermediate steps, enable .setPipeline(true). This keeps intermediate textures stored directly in GPU VRAM.

Implementing Array Sum

Below is a complete implementation of a sum reduction in GPU.js using the multi-pass strategy.

const { GPU } = require('gpu.js');
const gpu = new GPU();

// Kernel to add pairs of adjacent elements
const sumKernel = gpu.createKernel(function(arr, currentLength) {
    const idx = this.thread.x * 2;
    if (idx + 1 < currentLength) {
        return arr[idx] + arr[idx + 1];
    }
    return arr[idx];
}).setPipeline(true);

function reduceSum(inputArray) {
    let currentLength = inputArray.length;
    let currentData = inputArray;

    while (currentLength > 1) {
        const nextLength = Math.ceil(currentLength / 2);
        
        // Resize the kernel's output dimension to the next step size
        sumKernel.setOutput([nextLength]);

        // Execute step
        const result = sumKernel(currentData, currentLength);

        // Clean up previous texture if it's not the initial input array
        if (currentData !== inputArray && typeof currentData.delete === 'function') {
            currentData.delete();
        }

        currentData = result;
        currentLength = nextLength;
    }

    // Read back final single value to CPU
    const finalResult = currentData.toArray();
    if (typeof currentData.delete === 'function') {
        currentData.delete();
    }
    
    return finalResult[0];
}

const numbers = [5, 2, 9, 1, 7, 6, 3, 4];
console.log('Sum:', reduceSum(numbers)); // Output: 37

Implementing Minimum Search

The minimum search reduction uses the same loop structure, substituting the addition operator with Math.min().

const minKernel = gpu.createKernel(function(arr, currentLength) {
    const idx = this.thread.x * 2;
    if (idx + 1 < currentLength) {
        return Math.min(arr[idx], arr[idx + 1]);
    }
    return arr[idx];
}).setPipeline(true);

function reduceMin(inputArray) {
    let currentLength = inputArray.length;
    let currentData = inputArray;

    while (currentLength > 1) {
        const nextLength = Math.ceil(currentLength / 2);
        minKernel.setOutput([nextLength]);

        const result = minKernel(currentData, currentLength);

        if (currentData !== inputArray && typeof currentData.delete === 'function') {
            currentData.delete();
        }

        currentData = result;
        currentLength = nextLength;
    }

    const finalResult = currentData.toArray();
    if (typeof currentData.delete === 'function') {
        currentData.delete();
    }

    return finalResult[0];
}

const values = [45, 12, 85, 3, 99, 27, 8];
console.log('Minimum:', reduceMin(values)); // Output: 3

Best Practices and Optimization

  1. Keep Textures in VRAM: Always use .setPipeline(true) for the reduction kernel. Calling .toArray() after every pass forces the GPU to transfer data back to the CPU over the PCI bus, negating parallel performance benefits.
  2. Free Intermediate Memory: Intermediate textures generated during loop iterations consume GPU memory. Calling .delete() on textures from preceding passes avoids memory leaks in long-running applications.
  3. Threshold for CPU Fallback: GPU reductions introduce overhead due to kernel compilation and pipeline setup. For arrays with fewer than \(10^4\) elements, standard JavaScript methods like Array.prototype.reduce() will generally outperform a GPU-based reduction. Reserve GPU reduction for large datasets or for pipelines where the data is already resident on the GPU.
