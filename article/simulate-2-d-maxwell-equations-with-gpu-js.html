Simulate 2D Maxwell Equations with GPU.js

This article explains how to model electromagnetic wave propagation in two dimensions by solving Maxwell's curl equations on the GPU using the gpu.js library. By discretizing the equations with the Finite-Difference Time-Domain (FDTD) method on a Yee grid, the spatial and temporal updates translate into parallel matrix computations. Using gpu.js, these operations run directly as WebGL shaders in JavaScript, allowing high-performance, real-time electromagnetic wave simulations in the browser or Node.js.

Mathematical Formulation: 2D FDTD

In a 2D Transverse Magnetic (\(TM_z\)) mode, the electromagnetic field consists of an out-of-plane electric field component (\(E_z\)) and in-plane magnetic field components (\(H_x\), \(H_y\)). Assuming lossless, isotropic media with permittivity \(\epsilon\) and permeability \(\mu\), Maxwell's curl equations reduce to:

\[\frac{\partial H_x}{\partial t} = -\frac{1}{\mu} \frac{\partial E_z}{\partial y}\]

\[\frac{\partial H_y}{\partial t} = \frac{1}{\mu} \frac{\partial E_z}{\partial x}\]

\[\frac{\partial E_z}{\partial t} = \frac{1}{\epsilon} \left( \frac{\partial H_y}{\partial x} - \frac{\partial H_x}{\partial y} \right)\]

Using the standard Yee lattice, fields are staggered in space by half a grid cell (\(\Delta x, \Delta y\)) and in time by half a time step (\(\Delta t\)). For numerical stability, the time step must satisfy the Courant-Friedrichs-Lewy (CFL) condition:

\[\Delta t \le \frac{1}{c \sqrt{\frac{1}{\Delta x^2} + \frac{1}{\Delta y^2}}}\]

where \(c = 1/\sqrt{\mu_0 \epsilon_0}\) is the speed of light.

Discretized Update Equations

Applying central finite differences leads to the leapfrog update equations:

  1. Update \(H_x\) at time \(t + \Delta t / 2\): \[H_x^{n+1/2}(i, j) = H_x^{n-1/2}(i, j) - \frac{\Delta t}{\mu \Delta y} \left( E_z^n(i, j+1) - E_z^n(i, j) \right)\]

  2. Update \(H_y\) at time \(t + \Delta t / 2\): \[H_y^{n+1/2}(i, j) = H_y^{n-1/2}(i, j) + \frac{\Delta t}{\mu \Delta x} \left( E_z^n(i+1, j) - E_z^n(i, j) \right)\]

  3. Update \(E_z\) at time \(t + 1\): \[E_z^{n+1}(i, j) = E_z^n(i, j) + \frac{\Delta t}{\epsilon} \left( \frac{H_y^{n+1/2}(i, j) - H_y^{n+1/2}(i-1, j)}{\Delta x} - \frac{H_x^{n+1/2}(i, j) - H_x^{n+1/2}(i, j-1)}{\Delta y} \right)\]

Implementing Kernels in gpu.js

Because the field update at each spatial coordinate depends only on adjacent cells from the previous step, the calculation is massively parallel.

To prevent expensive data transfers between the GPU and CPU every time step, set pipeline: true on the gpu.js kernels so that field states remain on GPU memory as textures.

1. Initialization and Setup

import { GPU } from 'gpu.js';

const gpu = new GPU();
const width = 256;
const height = 256;

const dx = 1e-3; // 1 mm
const dy = 1e-3;
const c = 299792458;
const dt = (1 / (c * Math.sqrt(1 / (dx * dx) + 1 / (dy * dy)))) * 0.99; // Courant stable
const eps0 = 8.8541878128e-12;
const mu0 = 1.25663706212e-6;

const chx = dt / (mu0 * dy);
const chy = dt / (mu0 * dx);
const cez = dt / eps0;

2. Defining GPU Kernels

Separate kernels update the \(H\) and \(E\) fields. Boundary conditions are enforced by clamping indices inside the kernels.

// Kernel: Update Hx
const updateHx = gpu.createKernel(function(Hx, Ez, chx) {
  const i = this.thread.x;
  const j = this.thread.y;
  
  if (j >= this.constants.height - 1) {
    return Hx[j][i];
  }
  return Hx[j][i] - chx * (Ez[j + 1][i] - Ez[j][i]);
}, {
  constants: { height },
  output: [width, height],
  pipeline: true,
  immutable: true
});

// Kernel: Update Hy
const updateHy = gpu.createKernel(function(Hy, Ez, chy) {
  const i = this.thread.x;
  const j = this.thread.y;
  
  if (i >= this.constants.width - 1) {
    return Hy[j][i];
  }
  return Hy[j][i] + chy * (Ez[j][i + 1] - Ez[j][i]);
}, {
  constants: { width },
  output: [width, height],
  pipeline: true,
  immutable: true
});

// Kernel: Update Ez
const updateEz = gpu.createKernel(function(Ez, Hx, Hy, cez, dx, dy) {
  const i = this.thread.x;
  const j = this.thread.y;

  if (i === 0 || j === 0) {
    return 0.0; // Perfect Electric Conductor (PEC) boundary
  }

  const dHy = (Hy[j][i] - Hy[j][i - 1]) / dx;
  const dHx = (Hx[j][i] - Hx[j - 1][i]) / dy;

  return Ez[j][i] + cez * (dHy - dHx);
}, {
  output: [width, height],
  pipeline: true,
  immutable: true
});

// Kernel: Soft-source injection for Ez
const injectSource = gpu.createKernel(function(Ez, sourceVal, srcX, srcY) {
  const i = this.thread.x;
  const j = this.thread.y;
  
  if (i === srcX && j === srcY) {
    return Ez[j][i] + sourceVal;
  }
  return Ez[j][i];
}, {
  output: [width, height],
  pipeline: true,
  immutable: true
});

The Simulation Loop

Initialize the field arrays with zeros and run the leapfrog iteration loop.

// Initialize empty arrays
let Ez = Array.from({ length: height }, () => new Float32Array(width));
let Hx = Array.from({ length: height }, () => new Float32Array(width));
let Hy = Array.from({ length: height }, () => new Float32Array(width));

const srcX = Math.floor(width / 2);
const srcY = Math.floor(height / 2);
const steps = 1000;
const t0 = 40;
const spread = 12;

for (let t = 0; t < steps; t++) {
  // Step 1: Update Magnetic Fields (half-step advance)
  Hx = updateHx(Hx, Ez, chx);
  Hy = updateHy(Hy, Ez, chy);

  // Step 2: Update Electric Field (full-step advance)
  Ez = updateEz(Ez, Hx, Hy, cez, dx, dy);

  // Step 3: Inject Gaussian Pulse Source
  const pulse = Math.exp(-0.5 * Math.pow((t - t0) / spread, 2));
  Ez = injectSource(Ez, pulse, srcX, srcY);
}

Rendering the Output

To visualize field propagation, gpu.js can render directly to an HTML canvas instead of extracting raw arrays back to the CPU:

const renderViewer = gpu.createKernel(function(Ez) {
  const val = Ez[this.thread.y][this.thread.x];
  // Map negative values to blue, positive to red
  const red = val > 0 ? val : 0;
  const blue = val < 0 ? -val : 0;
  this.color(red, 0.0, blue, 1.0);
})
.setOutput([width, height])
.setGraphical(true);

// Inside the animation loop:
renderViewer(Ez);
const canvas = renderViewer.canvas;
document.body.appendChild(canvas);

Using .setPipeline(true) ensures that Ez, Hx, and Hy circulate purely as WebGL textures, allowing real-time wave simulation at 60 FPS on typical modern graphics hardware.
