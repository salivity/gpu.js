Configure GPU.js in Electron with Node Integration

This guide explains how to properly configure and execute GPU.js inside an Electron application with nodeIntegration enabled. When nodeIntegration is active, GPU.js may attempt to initialize via Node.js native bindings rather than Chromium's WebGL engine. Below, you will find the necessary Electron main process flags, dependency installation steps, and renderer process code to ensure GPU.js runs directly on your system's GPU hardware.

1. Install Dependencies

Install Electron and GPU.js in your project directory:

npm install electron gpu.js

2. Configure the Main Process

In your main.js (or main process entry file), configure the BrowserWindow instance to support nodeIntegration. You must also ensure that hardware acceleration is enabled so Chromium can access the GPU.

const { app, BrowserWindow } = require('electron');
const path = require('path');

// Ensure hardware acceleration is enabled
app.commandLine.appendSwitch('ignore-gpu-blocklist');
app.commandLine.appendSwitch('enable-gpu-rasterization');
app.commandLine.appendSwitch('enable-zero-copy');

function createWindow() {
  const mainWindow = new BrowserWindow({
    width: 800,
    height: 600,
    webPreferences: {
      nodeIntegration: true,
      contextIsolation: false, // Required when accessing Node modules directly from renderer
      webgl: true
    }
  });

  mainWindow.loadFile('index.html');
}

app.whenReady().then(createWindow);

app.on('window-all-closed', () => {
  if (process.platform !== 'darwin') {
    app.quit();
  }
});

3. Initialize GPU.js in the Renderer Process

Because nodeIntegration is enabled, the global scope in your renderer contains both the browser window object and Node.js globals like require.

Standard imports via require('gpu.js') might attempt to resolve the headless Node.js implementation (which requires native compilation packages like headless-gl). To force GPU.js to use the browser's built-in WebGL context, instantiate GPU with the mode explicitly set to 'gpu'.

In your renderer.js:

const { GPU } = require('gpu.js');

// Explicitly enforce the browser GPU context
const gpu = new GPU({
  mode: 'gpu'
});

// Define a simple 512x512 matrix multiplication kernel
const multiplyMatrix = gpu.createKernel(function(a, b) {
  let sum = 0;
  for (let i = 0; i < 512; i++) {
    sum += a[this.thread.y][i] * b[i][this.thread.x];
  }
  return sum;
}).setOutput([512, 512]);

// Test matrices
const matrixA = Array(512).fill(0).map(() => Array(512).fill(1));
const matrixB = Array(512).fill(0).map(() => Array(512).fill(2));

// Run calculation
const result = multiplyMatrix(matrixA, matrixB);

// Verify runtime mode
console.log('Calculation complete.');
console.log('Active GPU Mode:', gpu.mode); // Should output: "gpu"

4. HTML Entry Point

Link your renderer.js file inside index.html:

<!DOCTYPE html>
<html>
<head>
  <meta charset="UTF-8">
  <title>GPU.js with Electron</title>
</head>
<body>
  <h1>GPU.js Computation</h1>
  <p>Check the developer console to view kernel output and GPU mode status.</p>
  <script src="renderer.js"></script>
</body>
</html>

Verification and Troubleshooting

  • Check the active mode: Run console.log(gpu.mode) after instantiating your kernel. If it outputs cpu, Electron failed to access the graphics device, likely due to disabled hardware acceleration flags or unsupported drivers.
  • Canvas context clashes: If using GPU.js to render directly to a <canvas>, pass the canvas element directly into the options object: new GPU({ canvas: document.getElementById('myCanvas'), mode: 'gpu' }).
