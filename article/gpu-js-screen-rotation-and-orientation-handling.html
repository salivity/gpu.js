GPU.js Screen Rotation and Orientation Handling

Managing screen rotation and device orientation changes in GPU.js graphical rendering requires dynamically resizing the underlying WebGL canvas, updating the kernel's output dimensions, and recalculating aspect ratios. Because GPU.js compiles JavaScript into WebGL shaders with fixed execution bounds, handling orientation shifts demands either rebuilding the compute kernels or resizing the canvas viewport dynamically while passing updated coordinate uniforms to prevent visual distortion and performance bottlenecks.

1. Listen for Orientation and Resize Events

Rely on the resize event or the screen.orientation API to detect when a user rotates their mobile or tablet device. Using a debounced listener prevents the engine from excessively recompiling shaders during continuous window resizing.

let resizeTimeout;

window.addEventListener('resize', () => {
  clearTimeout(resizeTimeout);
  resizeTimeout = setTimeout(() => {
    handleOrientationChange();
  }, 100);
});

if (screen.orientation) {
  screen.orientation.addEventListener('change', handleOrientationChange);
}

2. Update Canvas and Viewport Dimensions

When rendering graphically with GPU.js, the kernel outputs to an HTML5 <canvas> element. When an orientation change occurs, update the physical canvas width and height using the device's pixel ratio to maintain crisp rendering.

function getDisplayDimensions() {
  const dpr = window.devicePixelRatio || 1;
  return {
    width: Math.floor(window.innerWidth * dpr),
    height: Math.floor(window.innerHeight * dpr),
    aspectRatio: window.innerWidth / window.innerHeight
  };
}

3. Recreate the GPU.js Kernel

GPU.js kernels have their output dimensions hardcoded via the setOutput([width, height]) configuration method. When an orientation flips (e.g., from portrait [1080, 1920] to landscape [1920, 1080]), you must destroy the existing kernel and instantiate a new one with the updated bounds.

const gpu = new GPU();
let renderKernel = null;

function createKernel(width, height) {
  if (renderKernel) {
    renderKernel.destroy(); // Free WebGL resources
  }

  renderKernel = gpu.createKernel(function(aspectRatio) {
    // Normalize coordinates based on current dimensions
    const x = this.thread.x / this.output.x;
    const y = this.thread.y / this.output.y;

    // Adjust for aspect ratio distortion
    const uvX = (x - 0.5) * aspectRatio;
    const uvY = y - 0.5;

    // Example graphical output (R, G, B)
    this.color(uvX + 0.5, uvY + 0.5, 0.5, 1);
  })
  .setOutput([width, height])
  .setGraphical(true);
}

4. Adjust Aspect Ratio and Coordinate Math

When switching between portrait and landscape, the aspect ratio inverts. If hardcoded, graphical assets or procedural generation will stretch or compress unnaturally. Pass the updated width, height, and aspect ratio directly into the kernel function as parameters on every frame:

function render() {
  const { width, height, aspectRatio } = getDisplayDimensions();
  
  // Execute the graphical kernel
  renderKernel(aspectRatio);

  // Present the rendered output
  const canvas = renderKernel.canvas;
  document.body.appendChild(canvas);
}

function handleOrientationChange() {
  const { width, height } = getDisplayDimensions();
  createKernel(width, height);
  render();
}

5. Retain Context and Avoid Memory Leaks

Creating multiple WebGL contexts without cleaning up previous instances causes browser contexts to be lost. Always call .destroy() on the outdated GPU.js kernel before creating a replacement. If the canvas is attached directly to the DOM, update its CSS width and height alongside its physical buffer resolution to match the new screen dimensions accurately.
