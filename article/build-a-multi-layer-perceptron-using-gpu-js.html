Build a Multi-Layer Perceptron Using GPU.js

Yes, you can build a complete end-to-end multi-layer perceptron (MLP) from scratch using GPU.js. By compiling JavaScript functions into WebGL-enabled shaders, GPU.js executes parallel matrix operations directly on the GPU. This article demonstrates how to construct the fundamental building blocks of a neural network—including matrix multiplication, activation functions, forward propagation, backpropagation, and gradient descent—entirely within GPU kernels.

Core Mathematical Operations as GPU Kernels

A multi-layer perceptron relies heavily on linear algebra and element-wise computations. GPU.js runs these operations across parallel threads by assigning output indices to this.thread.x and this.thread.y.

1. Matrix Multiplication

Matrix multiplication is required to calculate the weighted sum of inputs for each layer:

const { GPU } = require('gpu.js');
const gpu = new GPU();

const matMul = gpu.createKernel(function(A, B, commonDim) {
  let sum = 0;
  for (let i = 0; i < commonDim; i++) {
    sum += A[this.thread.y][i] * B[i][this.thread.x];
  }
  return sum;
}).setOutput([outputCols, outputRows]);

2. Activation Functions and Derivatives

Activation functions introduce non-linearity. The Sigmoid function and its derivative can be defined as parallel element-wise kernels:

const sigmoid = gpu.createKernel(function(M) {
  return 1 / (1 + Math.exp(-M[this.thread.y][this.thread.x]));
}).setOutput([cols, rows]);

const sigmoidDerivative = gpu.createKernel(function(A) {
  let s = A[this.thread.y][this.thread.x];
  return s * (1 - s);
}).setOutput([cols, rows]);

Implementing the Forward Pass

The forward pass transforms input data through consecutive layers. For a single layer, the formula is:

\[A = \sigma(W \cdot X + B)\]

In GPU.js, combining matrix multiplication with bias addition into a single kernel minimizes kernel dispatch overhead:

const forwardLayer = gpu.createKernel(function(Weights, Inputs, Biases, inputDim) {
  let sum = 0;
  for (let i = 0; i < inputDim; i++) {
    sum += Weights[this.thread.y][i] * Inputs[i][this.thread.x];
  }
  let z = sum + Biases[this.thread.y][0];
  return 1 / (1 + Math.exp(-z)); // Sigmoid applied directly
}).setOutput([batchSize, hiddenDim]);

Implementing Backpropagation

Training requires calculating the gradients of the loss function with respect to weights, biases, and activations using the chain rule.

1. Output Layer Error

For Mean Squared Error (MSE), the gradient at the output layer is calculated as:

const computeOutputDelta = gpu.createKernel(function(Output, Target) {
  let out = Output[this.thread.y][this.thread.x];
  let target = Target[this.thread.y][this.thread.x];
  return (out - target) * (out * (1 - out));
}).setOutput([batchSize, outputDim]);

2. Hidden Layer Error

The error is propagated backward by multiplying the downstream delta by the transposed weight matrix:

const computeHiddenDelta = gpu.createKernel(function(NextWeights, NextDelta, CurrentActivation, nextDim) {
  let error = 0;
  for (let i = 0; i < nextDim; i++) {
    error += NextWeights[i][this.thread.y] * NextDelta[i][this.thread.x];
  }
  let a = CurrentActivation[this.thread.y][this.thread.x];
  return error * (a * (1 - a));
}).setOutput([batchSize, hiddenDim]);

Updating Weights (Gradient Descent)

Once deltas are computed, weights are updated by multiplying deltas by the transposed activations of the previous layer:

const updateWeights = gpu.createKernel(function(Weights, Delta, Activations, batchSize, learningRate) {
  let grad = 0;
  for (let i = 0; i < batchSize; i++) {
    grad += Delta[this.thread.y][i] * Activations[this.thread.x][i];
  }
  return Weights[this.thread.y][this.thread.x] - (learningRate * (grad / batchSize));
}).setOutput([inputDim, outputDim]);

Optimizing Performance with Textures

The primary bottleneck in GPU-accelerated computing is transferring data between CPU RAM and GPU VRAM. To keep execution fully end-to-end on the GPU:

  1. Enable pipeline mode by setting pipeline: true on intermediate kernels.
  2. Output results as textures rather than raw arrays using kernel.setOutputOrder('precision').
  3. Feed texture outputs directly into the subsequent kernels without reading them back into JavaScript until training is complete or evaluation is needed.
const forwardPipeline = gpu.createKernel(function(W, X) {
  // Compute step
}, {
  output: [hiddenDim, batchSize],
  pipeline: true
});

By chaining pipelined kernels for matrix multiplication, activation mapping, and delta computation, an entire Multi-Layer Perceptron operates efficiently on the GPU from scratch without external machine learning dependencies.
