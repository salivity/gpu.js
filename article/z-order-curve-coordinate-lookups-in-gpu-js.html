Z-Order Curve Coordinate Lookups in gpu.js

This article explains how to implement Morton order (Z-order curve) encoding and decoding algorithms within gpu.js kernels. By mapping multi-dimensional coordinates to a one-dimensional space-filling curve through bit-interleaving, you can significantly enhance cache locality and memory throughput for spatial algorithms running on the GPU.

Understanding Morton Code Bit Manipulation

Morton coding maps multidimensional data (such as 2D coordinates x and y) into a single linear index by interleaving their binary representations.

  • Encoding (2D to Morton): Spreads the bits of x and y apart by inserting zeros between each bit, then shifts the y bits by one position and combines them using a bitwise OR operation.
  • Decoding (Morton to 2D): Separates the even and odd bits of a Morton code, then compacts the bits back into continuous integers representing x and y.

In WebGL-based environments like gpu.js, 32-bit integer bitwise operations (&, |, ^, <<, >>) are supported when configured for integer manipulation.

Defining the Bit Manipulation Helper Functions

To implement this efficiently inside gpu.js, use the standard "magic bits" bit-masking technique. Register these functions with the GPU instance using gpu.addFunction() before compiling the kernel.

const { GPU } = require('gpu.js');
const gpu = new GPU();

// Spreads 16-bit integers into 32-bit integers by inserting 0s between bits
function splitBy1(x) {
  x = x & 0x0000ffff;
  x = (x | (x << 8)) & 0x00ff00ff;
  x = (x | (x << 4)) & 0x0f0f0f0f;
  x = (x | (x << 2)) & 0x33333333;
  x = (x | (x << 1)) & 0x55555555;
  return x;
}

// Compacts bits back together by discarding alternate bits
function compactBy1(x) {
  x = x & 0x55555555;
  x = (x ^ (x >> 1)) & 0x33333333;
  x = (x ^ (x >> 2)) & 0x0f0f0f0f;
  x = (x ^ (x >> 4)) & 0x00ff00ff;
  x = (x ^ (x >> 8)) & 0x0000ffff;
  return x;
}

// Encode: (x, y) -> Morton Code
function encodeMorton2D(x, y) {
  return splitBy1(x) | (splitBy1(y) << 1);
}

// Decode: Morton Code -> x coordinate
function decodeMortonX(m) {
  return compactBy1(m);
}

// Decode: Morton Code -> y coordinate
function decodeMortonY(m) {
  return compactBy1(m >> 1);
}

// Register helpers with gpu.js
gpu.addFunction(splitBy1);
gpu.addFunction(compactBy1);
gpu.addFunction(encodeMorton2D);
gpu.addFunction(decodeMortonX);
gpu.addFunction(decodeMortonY);

Implementing Lookups in a GPU Kernel

Depending on your architecture, you either have a 1D Morton-ordered buffer that needs decoding into a 2D spatial grid, or a 2D thread space that looks up values stored sequentially along the Z-order curve.

Scenario 1: Sampling a Morton-Ordered 1D Array into a 2D Grid

When your thread grid is 2D and your source data is laid out linearly according to the Z-order curve:

const renderMortonGrid = gpu.createKernel(function(mortonBuffer) {
  const x = this.thread.x;
  const y = this.thread.y;

  // Compute linear index in Morton order
  const mortonIndex = encodeMorton2D(x, y);

  // Fetch the data stored at the calculated Z-order index
  return mortonBuffer[mortonIndex];
}).setOutput([512, 512]);

Scenario 2: Decoding Coordinates from a 1D Thread Index

When processing tasks arranged linearly on a Morton curve and reconstructing the original 2D coordinates:

const processMortonStream = gpu.createKernel(function(inputTexture) {
  const mortonIndex = this.thread.x;

  // Retrieve 2D coordinates
  const x = decodeMortonX(mortonIndex);
  const y = decodeMortonY(mortonIndex);

  // Sample texture using de-interleaved coordinates
  return inputTexture[y][x];
}).setOutput([512 * 512]);

Performance Considerations

  • Integer Precision: Standard WebGL 1.0 does not guarantee native 32-bit integer bitwise operations across all mobile hardware. Ensure your application targets WebGL 2.0 or uses gpu.js with the { mode: 'gpu' } setting that verifies WebGL2 support.
  • Coordinate Limits: The splitBy1 implementation assumes inputs fit within 16 bits (0 to 65535). Coordinates exceeding this range will overflow the 32-bit unsigned integer limit.
