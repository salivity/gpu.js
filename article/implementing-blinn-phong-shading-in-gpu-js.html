Implementing Blinn-Phong Shading in GPU.js

This article explains how to implement the Blinn-Phong specular reflection model inside a graphical GPU.js kernel to achieve hardware-accelerated 3D lighting in the browser. The Blinn-Phong model improves upon the traditional Phong shading model by using a "halfway vector" between the viewer and the light source, reducing computational complexity while producing natural-looking highlights. Below, we examine the underlying mathematics, the setup of a graphical GPU.js kernel, and the complete code implementation required to render a lighted surface.

The Blinn-Phong Formula

The standard Phong model calculates specular reflection using the reflection vector \(R\) of the light ray and the view vector \(V\), evaluating \((R \cdot V)^\alpha\). Computing \(R\) requires an expensive reflection calculation for every fragment.

Blinn-Phong approximates this highlight by computing the halfway vector \(H\) between the light direction \(L\) and the view direction \(V\):

\[H = \frac{L + V}{\|L + V\|}\]

The specular intensity is then determined by the dot product of the surface normal \(N\) and the halfway vector \(H\):

\[I_{\text{specular}} = k_s \cdot \max(N \cdot H, 0)^\alpha\]

Where:

  • \(k_s\) is the specular reflection coefficient.
  • \(\alpha\) (shininess) controls the size and sharpness of the specular highlight.

The total illumination combines ambient, diffuse (Lambertian), and specular components:

\[I_{\text{total}} = I_{\text{ambient}} + I_{\text{diffuse}} + I_{\text{specular}}\]

GPU.js Graphical Kernel Constraints

GPU.js compiles JavaScript functions into WebGL fragment shaders. When implementing lighting in GPU.js:

  1. The kernel must be instantiated with { graphical: true } so it renders directly to an HTML5 canvas.
  2. Pixel output is defined using this.color(r, g, b, a), where color channels are floats between 0.0 and 1.0.
  3. Vector operations (like dot products and vector normalization) must be computed manually using scalar arithmetic, as GLSL vector types (vec3, vec4) are not natively exposed as high-level classes in standard JavaScript functions before compilation.

Implementation

The following example sets up a GPU.js graphical kernel that renders a 3D hemisphere on a 2D plane lit by a directional light using the Blinn-Phong model.

const { GPU } = require('gpu.js'); // Or use window.GPU in the browser
const gpu = new GPU();

const width = 512;
const height = 512;

const renderBlinnPhong = gpu.createKernel(function() {
    // Normalize coordinates so the center is (0, 0) and radius is 1
    const x = (this.thread.x - 256) / 256;
    const y = (this.thread.y - 256) / 256;
    const distSq = x * x + y * y;

    // Background color (dark gray)
    if (distSq > 1.0) {
        this.color(0.1, 0.1, 0.1, 1.0);
        return;
    }

    // 1. Calculate Surface Normal (N) for a hemisphere
    const z = Math.sqrt(1.0 - distSq);
    const nx = x;
    const ny = y;
    const nz = z;

    // 2. Light Direction Vector (L) - Normalized pointing toward [0.5, 0.5, 1.0]
    const lx = 0.408248;
    const ly = 0.408248;
    const lz = 0.816497;

    // 3. View Direction Vector (V) - Pointing straight down the Z-axis [0, 0, 1]
    const vx = 0.0;
    const vy = 0.0;
    const vz = 1.0;

    // 4. Calculate Halfway Vector (H = normalize(L + V))
    const hx_unnorm = lx + vx;
    const hy_unnorm = ly + vy;
    const hz_unnorm = lz + vz;
    
    const h_len = Math.sqrt(hx_unnorm * hx_unnorm + hy_unnorm * hy_unnorm + hz_unnorm * hz_unnorm);
    const hx = hx_unnorm / h_len;
    const hy = hy_unnorm / h_len;
    const hz = hz_unnorm / h_len;

    // 5. Diffuse Component (N dot L)
    const nDotL = Math.max(nx * lx + ny * ly + nz * lz, 0.0);

    // 6. Specular Component (N dot H)^shininess
    const nDotH = Math.max(nx * hx + ny * hy + nz * hz, 0.0);
    const shininess = 32.0;
    const specular = Math.pow(nDotH, shininess);

    // 7. Light and Material Colors
    const ambient = 0.1;
    const matR = 0.8;
    const matG = 0.2;
    const matB = 0.2;

    // 8. Combine Components
    const finalR = ambient * matR + nDotL * matR + specular;
    const finalG = ambient * matG + nDotL * matG + specular;
    const finalB = ambient * matB + nDotL * matB + specular;

    this.color(finalR, finalG, finalB, 1.0);
})
.setOutput([width, height])
.setGraphical(true);

// Execute the kernel
renderBlinnPhong();

// Append the canvas to the document body (in browser environments)
document.body.appendChild(renderBlinnPhong.canvas);

Step-by-Step Kernel Execution

  1. Coordinate Normalization: this.thread.x and this.thread.y provide the current pixel location. These are mapped to a range of [-1.0, 1.0] to simplify geometric checks.
  2. Normal Calculation: A unit hemisphere equation (\(z = \sqrt{1 - x^2 - y^2}\)) creates the normal vector coordinates \((N_x, N_y, N_z)\). Pixels outside the radius are discarded as background.
  3. Halfway Vector Computation: The light direction vector (\(L\)) and view direction vector (\(V\)) are summed. The magnitude is evaluated with Math.sqrt() and used to divide each component, completing the normalization of \(H\).
  4. Lighting Assembly:
    • Ambient: A constant base lighting factor prevents unlit areas from being completely pitch-black.
    • Diffuse: Multiplies the base material color by the dot product of \(N\) and \(L\).
    • Specular: Elevates the dot product of \(N\) and \(H\) to the power of shininess. The resulting white specular highlight is added directly to the color channels.
  5. Output: this.color() takes the summed color intensities and writes them directly to the WebGL frame buffer attached to the canvas element.
