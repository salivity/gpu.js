GPU.js addFunction Default Parameters Support

Default parameter values are not supported in functions registered using gpu.addFunction in GPU.js. When defining helper functions for GPU acceleration, any use of ES6 default parameters (such as function myFunc(a, b = 1.0)) will cause transpilation failures or runtime errors. To write working functions for GPU kernels, all arguments must be explicitly declared and supplied during execution.

Why Default Parameters Do Not Work

GPU.js works by parsing JavaScript code into an Abstract Syntax Tree (AST) and transpiling it into WebGL Shading Language (GLSL) code. GLSL does not support default function arguments.

When the GPU.js AST compiler encounters an ES6 default parameter (represented internally as an AssignmentPattern), it fails to map the syntax to a valid GLSL function signature. Instead of assigning a fallback value, the compiler typically throws a compilation or parsing error during kernel creation.

Example of Unsupported Syntax

Attempting to register a function with default values will fail:

// This will cause an error
gpu.addFunction(function addValues(a, b = 5.0) {
  return a + b;
});

Supported Alternatives and Workarounds

To achieve the desired behavior without default parameters, use one of the following approaches:

1. Pass All Arguments Explicitly

The standard approach in GPU.js is to define standard parameters and pass all arguments every time the function is called inside the kernel:

// Register without defaults
gpu.addFunction(function addValues(a, b) {
  return a + b;
});

// Kernel usage
const kernel = gpu.createKernel(function() {
  const result = addValues(this.thread.x, 5.0);
  return result;
}).setOutput([100]);

2. Define Multiple Specialized Functions

If varying sets of arguments are needed, define separate functions to represent each signature:

gpu.addFunction(function addWithDefault(a) {
  return a + 5.0;
});

gpu.addFunction(function addCustom(a, b) {
  return a + b;
});

3. Use Constants

If a default value represents a fixed configuration setting, define it as a GPU.js constant on the kernel instead of passing it as a function parameter:

const kernel = gpu.createKernel(function() {
  return addValues(this.thread.x, this.constants.defaultVal);
})
.setConstants({ defaultVal: 5.0 })
.setOutput([100]);
