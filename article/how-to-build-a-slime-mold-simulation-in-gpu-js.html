How to Build a Slime Mold Simulation in GPU.js

This article explains how to implement a self-organizing slime mold (Physarum polycephalum) simulation in the browser using GPU.js. You will learn the mechanics behind agent-based emergent simulations, how to offload particle movement and grid-based pheromone dynamics to WebGL via GPU.js kernels, and how to structure a high-performance ping-pong rendering loop to simulate hundreds of thousands of concurrent particles.

Understanding the Simulation Model

The standard algorithm for simulating slime mold relies on the model pioneered by Jeff Jones. It consists of two interacting components:

  1. Agents: Autonomous particles that have a position \((x, y)\) and an orientation angle \((\theta)\).
  2. Trail Map: A 2D grid (texture) where agents deposit a chemical trace and sense chemical concentrations to decide their next heading.

The simulation runs through three continuous phases:

  • Sense and Rotate: Each agent samples the trail map at three locations ahead (left, forward, right). The agent turns toward the highest detected concentration.
  • Move and Deposit: The agent moves forward by a set step size and leaves behind a pheromone deposit on the trail map.
  • Diffuse and Decay: Pheromones spread across neighboring pixels on the grid and gradually evaporate over time.

Because these operations are local and execute identically across thousands of particles and pixels, they are ideal candidates for GPU parallelization using GPU.js.

Setting Up GPU.js

First, instantiate GPU.js. For optimal performance, configure the instance to use WebGL2 and keep calculations in pipeline mode so data stays on the GPU as textures between steps.

const gpu = new GPU({ mode: 'gpu' });

Define the simulation dimensions and parameters:

const WIDTH = 800;
const HEIGHT = 800;
const NUM_AGENTS = 200000;

const SENSOR_ANGLE = 0.45; // ~25 degrees in radians
const SENSOR_DIST = 9.0;
const TURN_SPEED = 0.4;
const MOVE_SPEED = 1.5;
const DECAY_FACTOR = 0.96;
const DEPOSIT_AMOUNT = 5.0;

Initialize your agents in JavaScript as flat arrays or 2D coordinate matrices containing [x, y, angle]:

const agentData = [];
for (let i = 0; i < NUM_AGENTS; i++) {
  // Spawn in a circle facing inward or randomly
  const angle = Math.random() * Math.PI * 2;
  const radius = Math.random() * 200;
  const x = WIDTH / 2 + Math.cos(angle) * radius;
  const y = HEIGHT / 2 + Math.sin(angle) * radius;
  agentData.push([x, y, angle]);
}

Creating the Kernels

1. Agent Update Kernel (Sense and Move)

This kernel evaluates the agent's sensors, computes the steering direction, moves the agent, and wraps boundaries around the screen.

const updateAgentsKernel = gpu.createKernel(function(agents, trailMap, sensorDist, sensorAngle, turnSpeed, moveSpeed, width, height) {
  const agentIndex = this.thread.x;
  let x = agents[agentIndex][0];
  let y = agents[agentIndex][1];
  let angle = agents[agentIndex][2];

  // Sensor coordinates
  const senseL_x = Math.floor(x + Math.cos(angle - sensorAngle) * sensorDist);
  const senseL_y = Math.floor(y + Math.sin(angle - sensorAngle) * sensorDist);
  const senseF_x = Math.floor(x + Math.cos(angle) * sensorDist);
  const senseF_y = Math.floor(y + Math.sin(angle) * sensorDist);
  const senseR_x = Math.floor(x + Math.cos(angle + sensorAngle) * sensorDist);
  const senseR_y = Math.floor(y + Math.sin(angle + sensorAngle) * sensorDist);

  // Read pheromone values from trailMap texture
  const valL = trailMap[senseL_y % height][senseL_x % width];
  const valF = trailMap[senseF_y % height][senseF_x % width];
  const valR = trailMap[senseR_y % height][senseR_x % width];

  // Steering logic
  if (valF > valL && valF > valR) {
    // Continue forward
  } else if (valF < valL && valF < valR) {
    // Random turn if forward is blocked
    angle += (Math.sin(agentIndex) > 0 ? 1 : -1) * turnSpeed;
  } else if (valL > valR) {
    angle -= turnSpeed;
  } else if (valR > valL) {
    angle += turnSpeed;
  }

  // Update position
  x = (x + Math.cos(angle) * moveSpeed + width) % width;
  y = (y + Math.sin(angle) * moveSpeed + height) % height;

  return [x, y, angle];
})
.setOutput([NUM_AGENTS])
.setPipeline(true);

2. Pheromone Diffusion and Decay Kernel

This kernel applies a 3x3 box blur across the trail map to spread the pheromones, followed by an evaporation coefficient to prevent saturation.

const diffuseAndDecayKernel = gpu.createKernel(function(trailMap, decayFactor, width, height) {
  const y = this.thread.y;
  const x = this.thread.x;

  let sum = 0.0;
  for (let dy = -1; dy <= 1; dy++) {
    for (let dx = -1; dx <= 1; dx++) {
      const sampleX = (x + dx + width) % width;
      const sampleY = (y + dy + height) % height;
      sum += trailMap[sampleY][sampleX];
    }
  }

  const blurred = sum / 9.0;
  return blurred * decayFactor;
})
.setOutput([WIDTH, HEIGHT])
.setPipeline(true);

3. Trail Deposit Kernel

In standard GPU architectures, atomic additions from arbitrary agent coordinates into a shared grid can cause race conditions. In GPU.js, deposit is typically implemented in one of two ways:

  • Grid-Centric (Lookup): Each pixel searches a spatially bucketed list of agents.
  • Canvas Stamp: Rendering agents as points directly onto a 2D canvas context using WebGL blend modes (gl.ONE, gl.ONE), then capturing that canvas as an input texture for the trail map.

For high agent counts, rendering point primitives to a WebGL target buffer is the most performant method. If using a pure GPU.js pipeline, deposit can be approximated by sampling a small agent density matrix mapped over the grid.

The Simulation Loop (Ping-Pong Buffering)

Because kernels cannot read from and write to the same texture simultaneously, you must alternate input and output textures using ping-pong buffers.

let currentAgents = agentData;
let currentTrailMap = gpu.createKernel(function() { return 0.0; }).setOutput([WIDTH, HEIGHT]).setPipeline(true)();

function step() {
  // 1. Move and orient agents based on current trail map
  const nextAgents = updateAgentsKernel(
    currentAgents, 
    currentTrailMap, 
    SENSOR_DIST, 
    SENSOR_ANGLE, 
    TURN_SPEED, 
    MOVE_SPEED, 
    WIDTH, 
    HEIGHT
  );

  // 2. Diffuse and evaporate the previous pheromone map
  const nextTrailMap = diffuseAndDecayKernel(
    currentTrailMap, 
    DECAY_FACTOR, 
    WIDTH, 
    HEIGHT
  );

  // 3. Cycle buffers
  currentAgents = nextAgents;
  currentTrailMap = nextTrailMap;

  requestAnimationFrame(step);
}

step();

Tuning Emergent Behaviors

The system's macroscopic structure is sensitive to small changes in parameters:

  • Road Networks and Arteries: Set a small sensor angle (\(20^{\circ} - 35^{\circ}\)) with a medium decay factor (\(0.90 - 0.95\)).
  • Chaotic Bubbles and Spirals: Increase sensor angle (\(60^{\circ} - 90^{\circ}\)) and increase turn speed.
  • Clusters and Patches: Reduce movement speed and sensor distance, allowing agents to aggregate tightly without forming connected highways.
