Huygens-Fresnel Sound Diffraction in GPU.js

Simulating sound field diffraction around geometric barriers using the Huygens-Fresnel principle is entirely feasible within GPU.js. By translating wave equations into parallelized WebGL kernels, developers can discretize wave fronts into secondary wavelets and compute complex interference patterns in real time directly within a web browser. This article explores how the Huygens-Fresnel principle applies to acoustic barriers, details the architectural implementation in GPU.js, and evaluates the performance trade-offs of this approach.

The Physics: Huygens-Fresnel Principle and Barriers

The Huygens-Fresnel principle posits that every point on a propagating wavefront acts as a secondary source of spherical wavelets. The sound field at any subsequent point is the coherent superposition of these secondary wavelets, factoring in their amplitude, distance, and phase:

\[U(P) = -\frac{i}{\lambda} \iint_S U_0 \frac{e^{ikr}}{r} K(\theta) \, dS\]

Where:

  • \(U(P)\) is the complex acoustic pressure at an observation point \(P\).
  • \(k = \frac{2\pi}{\lambda}\) is the acoustic wavenumber.
  • \(r\) is the distance from the secondary source to point \(P\).
  • \(K(\theta)\) is the obliquity factor controlling directional radiation.

When a geometric barrier obstructs sound waves, it truncates the integration surface \(S\). The diffraction pattern observed in the geometric shadow zone arises from secondary wavelets emanating from the unobstructed apertures or past the barrier edges, interfering constructively and destructively.

Why GPU.js for Acoustic Diffraction

Evaluating the continuous surface integral across a discretized 2D or 3D acoustic field is computationally demanding. For a receiver grid of size \(N \times N\) and \(M\) secondary sources, calculating interference requires \(O(M \cdot N^2)\) operations per frequency.

GPU.js compiles standard JavaScript functions into WebGL compute shaders, executing them on the graphics processing unit. Because calculating the pressure at each field point \((x, y)\) is an embarrassingly parallel problem that depends solely on fixed source locations and barrier geometries, each GPU thread can independently evaluate the sum of all wavelets for a single pixel.

Implementation Architecture

Modeling diffraction in GPU.js follows a structured four-stage pipeline:

  1. Domain Discretization: Define a two-dimensional grid representing physical space. Specify a primary sound source (frequency, amplitude, position) and geometric barriers (polygons or line segments).
  2. Secondary Source Identification: Trace rays from the primary source or discretize the aperture line/edge into an array of secondary point sources. Each source holds coordinates \((x_s, y_s)\), an initial phase determined by distance from the primary source, and an initial amplitude.
  3. Kernel Construction: Create a GPU.js kernel that computes the pressure contribution of each secondary source. Inside the kernel, calculate the Euclidean distance \(r = \sqrt{(x - x_s)^2 + (y - y_s)^2}\), compute attenuation (\(1/r\)), apply phase shift (\(\cos(kr)\) and \(\sin(kr)\)), and accumulate real and imaginary components.
  4. Magnitude Extraction: Compute the absolute acoustic pressure \(\sqrt{\text{Real}^2 + \text{Imag}^2}\) and convert it to sound pressure level (dB) or a color gradient for rendering to a canvas.
const gpu = new GPU();

const computeDiffraction = gpu.createKernel(function(sourcesX, sourcesY, sourcesPhase, sourcesAmp, numSources, k) {
    const x = this.thread.x;
    const y = this.thread.y;
    let realSum = 0;
    let imagSum = 0;

    for (let i = 0; i < numSources; i++) {
        const dx = x - sourcesX[i];
        const dy = y - sourcesY[i];
        const r = Math.sqrt(dx * dx + dy * dy) + 0.001; // Avoid division by zero
        
        const phase = k * r + sourcesPhase[i];
        const amplitude = sourcesAmp[i] / Math.sqrt(r); // 2D cylindrical spreading

        realSum += amplitude * Math.cos(phase);
        imagSum += amplitude * Math.sin(phase);
    }

    return Math.sqrt(realSum * realSum + imagSum * imagSum);
}).setOutput([512, 512]);

Technical Considerations and Limitations

  • Spatial Sampling (Nyquist Criterion): The spatial grid must sample at least twice per wavelength (\(\Delta x < \frac{\lambda}{2}\)), with \(\Delta x \le \frac{\lambda}{8}\) preferred for numerical accuracy. Consequently, modeling high-frequency audio requires larger grid resolutions and increases memory bandwidth requirements.
  • GPU Loop Limits: WebGL shaders often require static or capped loop bounds. Pass array sizes as constant uniforms or set fixed maximum secondary source counts to avoid shader compilation failures.
  • Accuracy vs. Edge Diffraction Models: The standard Huygens-Fresnel formulation assumes planar apertures and does not inherently model high-order edge diffractions, surface impedance, or creeping waves around curved surfaces. For complex barrier topologies, the Geometrical Theory of Diffraction (GTD) or Boundary Element Methods (BEM) yield higher physical fidelity, though Huygens-Fresnel remains well-suited for interactive, real-time approximations.
