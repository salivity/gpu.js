Electron WebGL Hardware Acceleration for GPU.js

This article explains the specific command-line switches required to force full WebGL hardware acceleration in an Electron application running GPU.js. By default, Chromium may disable hardware acceleration or restrict WebGL features depending on the system's graphics drivers, causing GPU.js to fall back to CPU execution. Implementing the flags detailed below ensures that GPU.js utilizes dedicated GPU hardware for maximum compute performance.

Required Command-Line Flags

To bypass Chromium driver blocklists and force complete GPU rendering, pass the following switches to Electron:

  • --ignore-gpu-blocklist: Overrides the built-in software rendering list, forcing hardware acceleration even if the user's graphics card or driver version is marked as unstable by Chromium.
  • --enable-gpu-rasterization: Forces the GPU to handle rasterization tasks instead of relying on the CPU.
  • --enable-zero-copy: Allows raster worker threads to write directly to GPU memory, reducing memory overhead and latency during heavy compute operations.
  • --use-gl=desktop: Forces Electron to use the native desktop OpenGL driver rather than SwiftShader or ANGLE translation layers, providing the direct hardware access GPU.js requires on Linux and Windows. Alternatively, on Windows systems where native OpenGL drivers are missing, --use-gl=angle with --use-angle=d3d11 can be used.

Implementation in Electron

Command-line switches must be appended in the Electron main process before the app.whenReady() lifecycle event is triggered.

const { app, BrowserWindow } = require('electron');

// Enable full WebGL hardware acceleration
app.commandLine.appendSwitch('ignore-gpu-blocklist');
app.commandLine.appendSwitch('enable-gpu-rasterization');
app.commandLine.appendSwitch('enable-zero-copy');
app.commandLine.appendSwitch('use-gl', 'desktop');

function createWindow() {
  const win = new BrowserWindow({
    width: 800,
    height: 600,
    webPreferences: {
      nodeIntegration: true,
      contextIsolation: false
    }
  });

  win.loadFile('index.html');
}

app.whenReady().then(createWindow);

Verifying Hardware Acceleration

To verify that Electron is correctly utilizing the GPU:

  1. Call app.getGPUFeatureStatus() inside the main process after the ready event. The properties for webgl and webgl2 should return enabled rather than disabled_software or unavailable.
  2. In GPU.js within your renderer process, query the kernel mode: 
    const gpu = new GPU();
console.log(gpu.getMode()); // Should output 'gpu'

If configured properly, GPU.js will execute computations natively on the graphics processor without falling back to JavaScript CPU execution.
