Calculating MFCCs with GPU.js for Speech Recognition

This article provides a practical guide on accelerating the calculation of Mel-Frequency Cepstral Coefficients (MFCCs) using gpu.js. MFCC extraction is a vital preprocessing pipeline in speech recognition systems that converts raw audio waveforms into compact acoustic representations mirroring human hearing. By offloading resource-intensive linear algebra operations—such as windowing, discrete Fourier transforms, filterbank integration, and Discrete Cosine Transforms (DCT)—to the GPU via WebGL through gpu.js, you can achieve near real-time audio feature extraction directly in the browser or Node.js environments.

Understanding the MFCC Pipeline

Calculating MFCCs involves five sequential mathematical transformations:

  1. Pre-emphasis and Framing: Boosting high frequencies and splitting the continuous signal into overlapping frames (typically 20–40 ms).
  2. Windowing: Multiplying each frame by a window function (such as a Hamming window) to minimize spectral leakage.
  3. Fast Fourier Transform (FFT) / Power Spectrum: Converting time-domain frames into frequency-domain representations to compute spectral power.
  4. Mel Filterbank Processing: Mapping linear frequencies to the non-linear Mel scale using overlapping triangular filters.
  5. Log Dynamic Compression and DCT: Taking the logarithm of filterbank energies and applying a Type-II Discrete Cosine Transform to decorrelate the filter energies and yield the final cepstral coefficients.

Setting Up GPU.js

Install gpu.js in your project:

npm install gpu.js

Initialize the runtime in JavaScript:

const { GPU } = require('gpu.js');
const gpu = new GPU();

Step 1: GPU-Accelerated Framing and Windowing

Before applying the Fourier transform, raw audio frames must be scaled by a Hamming window function:

\[w(n) = 0.54 - 0.46 \cos\left(\frac{2\pi n}{N - 1}\right)\]

You can parallelize the windowing step across all samples in all frames simultaneously using a 2D gpu.js kernel.

const applyWindowKernel = gpu.createKernel(function (audioData, frameStep, frameSize) {
    const sampleIdx = this.thread.x;
    const frameIdx = this.thread.y;
    const rawIndex = frameIdx * frameStep + sampleIdx;

    // Hamming window weight calculation
    const pi = 3.141592653589793;
    const hamming = 0.54 - 0.46 * Math.cos((2.0 * pi * sampleIdx) / (frameSize - 1.0));

    return audioData[rawIndex] * hamming;
}).setOutput([frameSize, numFrames]);

Step 2: Computing the Power Spectrum

While radix-2 FFTs require multistage butterfly networks, computing the standard Discrete Fourier Transform (DFT) power spectrum directly is embarrassingly parallel and highly efficient on modern GPUs for standard speech frame sizes (e.g., \(N = 512\)).

The power spectrum \(P(k)\) for frequency bin \(k\) is given by:

\[P(k) = \frac{1}{N} \left| \sum_{n=0}^{N-1} x(n) e^{-i 2\pi k n / N} \right|^2\]

const powerSpectrumKernel = gpu.createKernel(function (windowedFrames, frameSize) {
    const k = this.thread.x; // Frequency bin index (0 to frameSize / 2)
    const frameIdx = this.thread.y;

    const pi = 3.141592653589793;
    let real = 0.0;
    let imag = 0.0;

    for (let n = 0; n < frameSize; n++) {
        const angle = (2.0 * pi * k * n) / frameSize;
        const sample = windowedFrames[frameIdx][n];
        real += sample * Math.cos(angle);
        imag -= sample * Math.sin(angle);
    }

    return (real * real + imag * imag) / frameSize;
}).setOutput([frameSize / 2 + 1, numFrames]);

Step 3: Applying the Mel Filterbank

The Mel scale models the human ear's frequency resolution:

\[m = 2595 \log_{10}\left(1 + \frac{f}{700}\right)\]

Precompute a static 2D weight matrix representing \(M\) triangular filters (typically \(M = 26\) to \(40\)) across the \((N/2 + 1)\) spectral bins on the CPU, and pass it to the GPU kernel to obtain the log energy outputs.

const melFilterbankKernel = gpu.createKernel(function (powerSpectra, melFilters, numBins) {
    const filterIdx = this.thread.x; // Filter index
    const frameIdx = this.thread.y;  // Frame index

    let energy = 0.0;
    for (let bin = 0; bin < numBins; bin++) {
        energy += powerSpectra[frameIdx][bin] * melFilters[filterIdx][bin];
    }

    // Floor energy to prevent log(0)
    if (energy < 1e-6) {
        energy = 1e-6;
    }

    return Math.log(energy);
}).setOutput([numFilters, numFrames]);

Step 4: Discrete Cosine Transform (DCT-II)

The final step converts the log filterbank energies into orthogonal cepstral coefficients using a DCT-II kernel. Standard speech recognition pipelines retain the first 12–13 coefficients:

\[C_m = \sum_{k=0}^{M-1} E_k \cos\left( \frac{\pi m (k + 0.5)}{M} \right)\]

const dctKernel = gpu.createKernel(function (logMelEnergies, numFilters, numCoeffs) {
    const m = this.thread.x; // Coefficient index (0 to numCoeffs - 1)
    const frameIdx = this.thread.y;

    const pi = 3.141592653589793;
    let sum = 0.0;

    for (let k = 0; k < numFilters; k++) {
        const angle = (pi * m * (k + 0.5)) / numFilters;
        sum += logMelEnergies[frameIdx][k] * Math.cos(angle);
    }

    return sum;
}).setOutput([numCoeffs, numFrames]);

Execution and Memory Optimization

To achieve maximum throughput with gpu.js:

  1. Keep Data on the GPU: Use pipeline: true on your intermediate kernels (applyWindowKernel, powerSpectrumKernel, and melFilterbankKernel). This keeps intermediate calculations stored directly as WebGL textures in VRAM, eliminating expensive GPU-to-CPU data transfer overhead.
  2. Execute Sequentially: 
    const windowed = applyWindowKernel(audioData, frameStep, frameSize);
const powerSpectra = powerSpectrumKernel(windowed, frameSize);
const logMelEnergies = melFilterbankKernel(powerSpectra, melFilters, frameSize / 2 + 1);
const mfccFeatures = dctKernel(logMelEnergies, numFilters, 13);
  3. Extract Result: Call .toArray() on the final kernel result (mfccFeatures) only when the final matrix of MFCC vectors is needed for downstream inference or model input.
