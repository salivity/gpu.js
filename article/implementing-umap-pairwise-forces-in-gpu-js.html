Implementing UMAP Pairwise Forces in GPU.js

This article provides a comprehensive guide to implementing the pairwise force calculations of the Uniform Manifold Approximation and Projection (UMAP) algorithm using GPU.js. You will learn the mathematical formulation governing UMAP's attractive and repulsive forces, how to structure parallel computation kernels for execution on WebGL-enabled GPUs, and how to update low-dimensional coordinates directly in JavaScript for accelerated dimensionality reduction.

Understanding UMAP Pairwise Forces

UMAP projects high-dimensional data into a low-dimensional space (typically 2D or 3D) by optimizing an objective function based on fuzzy set cross-entropy. During the optimization phase, points exert two types of forces on each other:

  1. Attractive Forces: Pull together pairs of points that share high similarity in the high-dimensional space (represented by weights \(P_{ij} \in [0, 1]\)).
  2. Repulsive Forces: Push points apart to prevent clustering collapse and preserve global structure.

The distance kernel in the low-dimensional embedding is parameterized by constants \(a\) and \(b\) (commonly \(a \approx 1.5769434\) and \(b \approx 0.8950618\) for default spread and min-distance values):

\[\Psi(d^2) = \frac{1}{1 + a \cdot (d^2)^b}\]

Given the squared Euclidean distance \(d^2 = \|y_i - y_j\|^2\) between embeddings \(y_i\) and \(y_j\), the gradients governing the forces along dimension \(k\) are:

  • Attractive Gradient: \[\nabla_{y_i}^{\text{attr}} = \frac{-2 \cdot b \cdot a \cdot (d^2)^{b-1}}{1 + a \cdot (d^2)^b} \cdot P_{ij} \cdot (y_{ik} - y_{jk})\]

  • Repulsive Gradient: \[\nabla_{y_i}^{\text{rep}} = \frac{2 \cdot b}{(\epsilon + d^2)(1 + a \cdot (d^2)^b)} \cdot (1 - P_{ij}) \cdot (y_{ik} - y_{jk})\]

Here, \(\epsilon\) is a small constant (e.g., \(0.001\)) added to prevent division by zero when two low-dimensional points coincide.

GPU.js Kernel Setup

GPU.js compiles standard JavaScript functions into WebGL shaders, enabling massive parallelization across data points. Because calculating pairwise forces for \(N\) points requires computing \(O(N^2)\) interactions, offloading the summation of forces to the GPU delivers significant performance gains over a single-threaded CPU loop.

1. Installing and Initializing GPU.js

npm install gpu.js
import { GPU } from 'gpu.js';

const gpu = new GPU();

2. Constructing the Force Kernel

The kernel computes the total net gradient acting on point \(i\) in dimension \(k\) across all other points \(j\). We configure the kernel output dimension to [dim, N], where dim is the target dimensionality (e.g., 2) and N is the total number of points.

const createUMAPForceKernel = (gpuInstance, numPoints, dim) => {
  return gpuInstance.createKernel(function(positions, similarities, a, b, numPoints, dim) {
    const pointIdx = this.thread.y; // Point index i
    const dIdx = this.thread.x;     // Embedding coordinate (0 for X, 1 for Y)

    let totalForce = 0.0;
    const currentCoord = positions[pointIdx][dIdx];

    for (let j = 0; j < numPoints; j++) {
      if (pointIdx !== j) {
        // Calculate squared Euclidean distance between pointIdx and j
        let distSq = 0.0;
        for (let d = 0; d < dim; d++) {
          const diff = positions[pointIdx][d] - positions[j][d];
          distSq += diff * diff;
        }

        const delta = currentCoord - positions[j][dIdx];
        const pVal = similarities[pointIdx][j]; // High-dimensional probability
        
        const distPowBMinus1 = Math.pow(distSq, b - 1.0);
        const distPowB = distPowBMinus1 * distSq;
        const denom = 1.0 + a * distPowB;

        // Attractive term
        let attr = 0.0;
        if (pVal > 0.0) {
          attr = (-2.0 * b * a * distPowBMinus1 / denom) * pVal * delta;
        }

        // Repulsive term
        let rep = 0.0;
        if (pVal < 1.0) {
          rep = (2.0 * b / ((0.001 + distSq) * denom)) * (1.0 - pVal) * delta;
        }

        totalForce += (attr + rep);
      }
    }

    return totalForce;
  })
  .setOutput([dim, numPoints])
  .setDynamicOutput(false);
};

Updating Embeddings with Gradient Descent

Once the forces are calculated, an integration step adjusts the positions using an optimization scheme such as Gradient Descent with momentum.

const createUpdateKernel = (gpuInstance, numPoints, dim) => {
  return gpuInstance.createKernel(function(positions, forces, learningRate) {
    const pointIdx = this.thread.y;
    const dIdx = this.thread.x;

    // Gradient clipping to prevent exploding steps
    let force = forces[pointIdx][dIdx];
    if (force > 4.0) force = 4.0;
    if (force < -4.0) force = -4.0;

    return positions[pointIdx][dIdx] - (learningRate * force);
  })
  .setOutput([dim, numPoints]);
};

Complete Execution Pipeline

To run an optimization step using the compiled kernels:

const numPoints = 1000;
const dim = 2;
const learningRate = 1.0;
const a = 1.5769434;
const b = 0.8950618;

// Initialize random 2D positions
let positions = Array.from({ length: numPoints }, () => [
  (Math.random() - 0.5) * 10,
  (Math.random() - 0.5) * 10
]);

// Simulated sparse/dense high-dimensional similarity matrix (N x N)
let similarities = Array.from({ length: numPoints }, () => 
  new Float32Array(numPoints).fill(0.01)
);

// Instantiate kernels
const computeForces = createUMAPForceKernel(gpu, numPoints, dim);
const updatePositions = createUpdateKernel(gpu, numPoints, dim);

// Optimization loop
const epochs = 100;
for (let epoch = 0; epoch < epochs; epoch++) {
  // Compute accumulated forces per point per axis
  const forces = computeForces(positions, similarities, a, b, numPoints, dim);

  // Apply positions update
  const updated = updatePositions(positions, forces, learningRate);

  // GPU.js returns TypedArrays/nested structures that can be fed into next step
  positions = updated;
}

Optimizations for Large Datasets

  1. Pipeline Mode (Pipeline: true): Configure both kernels with { pipeline: true } to keep the position and force textures entirely in GPU memory between iterations, eliminating CPU-GPU memory transfer overhead.
  2. Sparse Neighbor Approximation: In full UMAP implementations, repulsive forces are often approximated via negative sampling rather than computing all \(N \times N\) pairs. In WebGL, this can be implemented by passing a texture of pre-sampled negative indices instead of executing the full nested loop over all \(N\) elements.
