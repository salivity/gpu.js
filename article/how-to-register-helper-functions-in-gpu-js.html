How to Register Helper Functions in GPU.js

In GPU.js, you can define and reuse custom mathematical helper functions—such as vector normalization—across multiple compute kernels. While GPU.js does not use the browser's global window or Node.js runtime scope directly inside the GPU thread, it allows you to register functions at the GPU instance level using the gpu.addFunction() API, making them globally available to any kernel created by that instance.

Registering Functions with gpu.addFunction()

To use a helper function across several kernels without redefining it each time, register it directly to your GPU instance.

Here is an example of defining and registering a 3D vector normalization function:

const { GPU } = require('gpu.js');
const gpu = new GPU();

// Define the mathematical helper function
function normalizeX(x, y, z) {
  const length = Math.sqrt(x * x + y * y + z * z);
  return length > 0 ? x / length : 0;
}

function normalizeY(x, y, z) {
  const length = Math.sqrt(x * x + y * y + z * z);
  return length > 0 ? y / length : 0;
}

function normalizeZ(x, y, z) {
  const length = Math.sqrt(x * x + y * y + z * z);
  return length > 0 ? z / length : 0;
}

// Register globally on the GPU instance
gpu.addFunction(normalizeX);
gpu.addFunction(normalizeY);
gpu.addFunction(normalizeZ);

Once registered via gpu.addFunction(), these functions become accessible within the execution context of every kernel subsequently created from that gpu instance.

const computeNormalizedVectors = gpu.createKernel(function(vectorsX, vectorsY, vectorsZ) {
  const i = this.thread.x;
  const nx = normalizeX(vectorsX[i], vectorsY[i], vectorsZ[i]);
  return nx;
}).setOutput([1024]);

Passing Functions via Kernel Settings

If you prefer scoping helper functions to specific kernels rather than the entire instance, you can pass them via the functions array in the kernel configuration options:

const kernel = gpu.createKernel(function(x, y, z) {
  return normalizeX(x[this.thread.x], y[this.thread.x], z[this.thread.x]);
}, {
  output: [1024],
  functions: [normalizeX]
});

Constraints on Helper Functions

When writing mathematical helper functions for GPU.js, ensure they adhere to the transpiler's rules:

  • Pure Computations: Helper functions cannot reference variables outside their local scope, access the DOM, or use complex JavaScript objects.
  • Supported Math Methods: Use built-in operations supported by the GLSL transpiler, such as Math.sqrt(), Math.sin(), and standard arithmetic operators.
  • Return Types: Functions must return primitive numeric values (integers or floats) or fixed-size arrays supported by the WebGL/GLSL context.
