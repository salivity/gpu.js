gpu.js String Manipulation Inside Kernels

This article explains how gpu.js handles text, detailing why native string manipulation is fundamentally unsupported inside GPU kernels and how developers can work around this limitation using numeric encoding. Because GPUs are optimized for mathematical operations rather than text processing, string data must be converted into numerical formats—such as ASCII or Unicode arrays—before it can be processed within a kernel.

Native String Limitations in gpu.js

gpu.js translates written JavaScript functions into WebGL shaders (GLSL) or OpenCL code to run them in parallel on the GPU. Because underlying graphics shading languages like GLSL do not possess a native String type, dynamic memory allocation, or standard text-processing methods, gpu.js does not support native JavaScript strings or string manipulation inside kernels.

Attempting to pass a raw string into a kernel, instantiate a string, or invoke methods such as .split(), .substring(), or string concatenation (+) will trigger a compilation failure during kernel generation.

The Numeric Workaround: Encoding Characters

To perform text processing or pattern recognition on the GPU with gpu.js, you must map characters to numbers on the CPU before passing them into the kernel, and decode them back to text once the computation concludes.

1. Encode Strings to Character Codes (CPU)

Convert the target text into an array of integers representing character codes (such as ASCII or UTF-16) using standard JavaScript:

const text = "HELLO GPU";
const charCodes = Array.from(text).map(char => char.charCodeAt(0));

2. Process Numbers in the Kernel (GPU)

Pass the numeric array to the kernel. Inside the kernel, you can perform parallel operations like character matching, sorting, or substitution (such as a Caesar cipher) using integer math:

const gpu = new GPU();

const shiftKernel = gpu.createKernel(function(data, shift) {
    // Each thread processes one character code
    return data[this.thread.x] + shift;
}).setOutput([charCodes.length]);

const shiftedCodes = shiftKernel(charCodes, 1);

3. Decode Numbers Back to Strings (CPU)

Once the kernel outputs the resulting numeric array, convert the integers back into a string:

const resultText = String.fromCharCode(...shiftedCodes);

Performance Considerations

While mapping strings to numeric arrays enables operations like large-scale regex evaluation, DNA sequence analysis, or brute-force text comparisons on the GPU, simple string operations often encounter bottlenecks. The overhead of converting strings to arrays on the CPU, uploading buffer data to the GPU via WebGL textures, and reading results back to CPU memory can easily outweigh the parallel performance gains for small datasets. As a result, string processing in gpu.js is generally reserved for massive, uniform character arrays where thousands of comparisons occur simultaneously.
