GPU.js Kernel Return Types: Floats, Ints, Colors

GPU.js allows developers to execute parallel computing tasks on the GPU using JavaScript syntax, compiling functions directly into WebGL shaders. While WebGL operations fundamentally rely on floating-point arithmetic, GPU.js kernels can output multiple forms of data, including single-precision floats, integer-like values, multi-dimensional numeric arrays, and direct graphical color representations (RGBA). Understanding how GPU.js treats these types is essential for configuring kernel settings, optimizing pipeline performance, and rendering output directly to a canvas.

Numeric Outputs: Floats and Integers

By default, GPU.js outputs 32-bit floating-point numbers. In standard calculation modes, return statements containing numeric values evaluate as floats within the generated GLSL shader:

const kernel = gpu.createKernel(function() {
    return 42.5;
}).setOutput([1]);

GPU.js does not provide a strict native integer return type when outputting to standard JavaScript arrays, as WebGL typically writes float buffers back to the CPU. However, you can produce integer results logically by using functions like Math.floor(), Math.ceil(), or Math.round() inside the kernel. The returned array will contain whole numbers stored as standard JavaScript double-precision values.

Multi-Channel and Vector Outputs

Kernels can return small fixed-size arrays representing vectors. For example, returning an array of two, three, or four values maps directly to GLSL vector types (vec2, vec3, vec4):

const kernel = gpu.createKernel(function(a, b) {
    return [a[this.thread.x], b[this.thread.x]];
}).setOutput([100]);

This returns a multi-dimensional array or sub-arrays to the CPU, useful for coordinate computations, physics simulations, or processing multi-channel data.

Graphical and Color Outputs

GPU.js supports rendering color directly to an HTML canvas using the graphical: true option. In graphical mode, the kernel must return pixel colors using the built-in this.color(r, g, b, a) method rather than a raw number:

const renderKernel = gpu.createKernel(function() {
    // Red, Green, Blue, Alpha values between 0.0 and 1.0
    this.color(1.0, 0.0, 0.0, 1.0);
}, {
    output: [512, 512],
    graphical: true
});

renderKernel();
document.body.appendChild(renderKernel.canvas);

Each color component accepts a normalized float ranging from 0.0 to 1.0. Instead of returning an array of data to JavaScript, the kernel writes these color values directly to WebGL framebuffers or canvas contexts.

Outputting as Textures (Pipelining)

When chaining multiple kernels, data types can be kept on the GPU as textures using the pipeline: true setting. Instead of converting GPU floats or vectors into JavaScript arrays and incurring CPU transfer overhead, the kernel outputs a WebGL texture handle. Downstream kernels can accept this texture directly as an input, preserving high-performance 32-bit float or RGBA data formats throughout the pipeline.
