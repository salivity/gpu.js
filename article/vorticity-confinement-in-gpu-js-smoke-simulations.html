Vorticity Confinement in GPU.js Smoke Simulations

This article provides a practical guide to implementing vorticity confinement for grid-based smoke simulations using gpu.js. In Eulerian fluid simulations, numerical dissipation tends to damp out fine turbulent details, causing smoke to appear unnaturally viscous and smooth. Vorticity confinement counteracts this artificial damping by detecting rotational motion and injecting artificial energy back into the velocity field. By implementing these calculations as parallel GPU kernels using gpu.js, you can preserve realistic swirling smoke dynamics at interactive frame rates in the browser.

1. Mathematical Formulation

Vorticity confinement consists of three distinct mathematical steps applied on a discrete Eulerian grid:

Step 1: Calculate Vorticity

In a two-dimensional grid, the vorticity \(\omega\) is a scalar field representing the local spin of the velocity field \(\mathbf{u} = (u, v)\):

\[\omega = (\nabla \times \mathbf{u})_z = \frac{\partial v}{\partial x} - \frac{\partial u}{\partial y}\]

Using central differences on a grid with spacing \(\Delta x\):

\[\omega_{i, j} \approx \frac{v_{i+1, j} - v_{i-1, j}}{2\Delta x} - \frac{u_{i, j+1} - u_{i, j-1}}{2\Delta x}\]

Step 2: Calculate the Vorticity Gradient

Next, compute the gradient vector of the absolute vorticity \(|\omega|\), which points toward the center of local vortices:

\[\eta = \nabla |\omega| = \left( \frac{|\omega_{i+1, j}| - |\omega_{i-1, j}|}{2\Delta x}, \frac{|\omega_{i, j+1}| - |\omega_{i, j-1}|}{2\Delta x} \right)\]

Normalize this vector to prevent numerical instability:

\[\mathbf{N} = \frac{\eta}{\|\eta\| + 10^{-5}}\]

Step 3: Compute the Confinement Force

The confinement force vector \(\mathbf{f}_{conf}\) acts perpendicular to the gradient vector:

\[\mathbf{f}_{conf} = \epsilon \cdot \Delta x \cdot (\mathbf{N} \times \omega \hat{\mathbf{z}})\]

In 2D Cartesian coordinates, this simplifies to:

\[f_x = \epsilon \cdot \Delta x \cdot (N_y \cdot \omega)\] \[f_y = -\epsilon \cdot \Delta x \cdot (N_x \cdot \omega)\]

Where \(\epsilon\) is a tunable parameter controlling the strength of the turbulence. Finally, add this force to the velocity field:

\[\mathbf{u}^{new} = \mathbf{u} + \Delta t \cdot \mathbf{f}_{conf}\]

2. Implementing GPU Kernels with GPU.js

Because each cell's calculations depend only on neighboring cells, the process maps directly to parallel GPU shader operations. We split the calculation into two sequential gpu.js kernels: one to calculate the vorticity scalar field, and another to calculate and apply the force.

Initializing GPU.js

const gpu = new GPU();
const width = 256;
const height = 256;
const dx = 1.0;
const dt = 0.016;
const epsilon = 2.5; // Turbulence strength

Kernel 1: Computing the Vorticity Field

This kernel accepts separate 2D arrays for the horizontal (\(u\)) and vertical (\(v\)) velocity components and outputs a single 2D float array of vorticity values.

const computeVorticityKernel = gpu.createKernel(function(u, v, dx) {
    const x = this.thread.x;
    const y = this.thread.y;

    // Handle grid boundaries
    if (x === 0 || x === this.constants.width - 1 || 
        y === 0 || y === this.constants.height - 1) {
        return 0;
    }

    // Central difference calculation
    const dv_dx = (v[y][x + 1] - v[y][x - 1]) / (2.0 * dx);
    const du_dy = (u[y + 1][x] - u[y - 1][x]) / (2.0 * dx);

    return dv_dx - du_dy;
})
.setConstants({ width, height })
.setOutput([width, height])
.setPipeline(true); // Retain output in GPU memory

Kernel 2: Applying the Confinement Force

This kernel reads the vorticity field, calculates the normalized gradient vector, computes the perpendicular force, and outputs the updated velocity. Because WebGL kernels return a single value or vector, we can compute the updated \(u\) component (and duplicate the kernel logic for \(v\)).

const applyVorticityUKernel = gpu.createKernel(function(u, omega, dx, dt, eps) {
    const x = this.thread.x;
    const y = this.thread.y;

    if (x === 0 || x === this.constants.width - 1 || 
        y === 0 || y === this.constants.height - 1) {
        return u[y][x];
    }

    // Gradient of the absolute vorticity magnitude
    const dOmega_dx = (Math.abs(omega[y][x + 1]) - Math.abs(omega[y][x - 1])) / (2.0 * dx);
    const dOmega_dy = (Math.abs(omega[y + 1][x]) - Math.abs(omega[y - 1][x])) / (2.0 * dx);

    const length = Math.sqrt(dOmega_dx * dOmega_dx + dOmega_dy * dOmega_dy) + 0.00001;
    const Ny = dOmega_dy / length;

    // Fx = eps * dx * (Ny * omega)
    const currentOmega = omega[y][x];
    const forceX = eps * dx * (Ny * currentOmega);

    return u[y][x] + dt * forceX;
})
.setConstants({ width, height })
.setOutput([width, height])
.setPipeline(true);

const applyVorticityVKernel = gpu.createKernel(function(v, omega, dx, dt, eps) {
    const x = this.thread.x;
    const y = this.thread.y;

    if (x === 0 || x === this.constants.width - 1 || 
        y === 0 || y === this.constants.height - 1) {
        return v[y][x];
    }

    const dOmega_dx = (Math.abs(omega[y][x + 1]) - Math.abs(omega[y][x - 1])) / (2.0 * dx);
    const dOmega_dy = (Math.abs(omega[y + 1][x]) - Math.abs(omega[y - 1][x])) / (2.0 * dx);

    const length = Math.sqrt(dOmega_dx * dOmega_dx + dOmega_dy * dOmega_dy) + 0.00001;
    const Nx = dOmega_dx / length;

    // Fy = eps * dx * (-Nx * omega)
    const currentOmega = omega[y][x];
    const forceY = eps * dx * (-Nx * currentOmega);

    return v[y][x] + dt * forceY;
})
.setConstants({ width, height })
.setOutput([width, height])
.setPipeline(true);

3. Integration into the Simulation Pipeline

To ensure physical stability, vorticity confinement must be placed correctly in the standard stable fluids update loop:

  1. Advection: Advect velocity components (\(u, v\)) and smoke density using semi-Lagrangian backtracing.
  2. External Forces: Apply buoyancy and gravity forces.
  3. Vorticity Confinement:
    • Execute computeVorticityKernel(u, v, dx).
    • Execute applyVorticityUKernel(u, omega, dx, dt, epsilon).
    • Execute applyVorticityVKernel(v, omega, dx, dt, epsilon).
  4. Projection (Pressure Solve): Run Jacobi or Conjugate Gradient iterations to enforce divergence-free flow (\(\nabla \cdot \mathbf{u} = 0\)).

Placing vorticity confinement immediately before the projection step ensures that the artificial rotational forces do not introduce divergence or compressibility artifacts into the final velocity field. Enabling .setPipeline(true) on all kernels prevents expensive data readbacks between the GPU and CPU across simulation steps.
