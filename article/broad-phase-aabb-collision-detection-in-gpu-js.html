Broad-Phase AABB Collision Detection in GPU.js

This article provides a direct guide to implementing broad-phase Axis-Aligned Bounding Box (AABB) collision detection using GPU.js. By parallelizing pair-wise bounding box evaluations on the GPU, you can handle thousands of simultaneous entities efficiently without choking the main CPU thread. The following sections walk through data structuring, kernel construction, and extracting collision pairs.

1. Data Representation

GPU kernels operate most efficiently with flat 1D arrays of primitive numbers rather than nested JavaScript objects. For 2D AABB detection, split your bounding box coordinates into four parallel arrays representing the minimum and maximum boundaries for each entity:

  • minX: Array of left edges
  • minY: Array of bottom edges
  • maxX: Array of right edges
  • maxY: Array of top edges
const entityCount = 1000;

const minX = new Float32Array(entityCount);
const minY = new Float32Array(entityCount);
const maxX = new Float32Array(entityCount);
const maxY = new Float32Array(entityCount);

// Example population of entity data
for (let i = 0; i < entityCount; i++) {
  const x = Math.random() * 800;
  const y = Math.random() * 600;
  const width = 10 + Math.random() * 20;
  const height = 10 + Math.random() * 20;

  minX[i] = x;
  minY[i] = y;
  maxX[i] = x + width;
  maxY[i] = y + height;
}

2. Writing the GPU.js Kernel

To perform broad-phase checks, compute an \(N \times N\) matrix where output coordinates (x, y) represent entity pairs.

Two AABBs overlap if and only if they overlap on all coordinate axes simultaneously:

\[\text{Overlap} = (A_{\min X} \le B_{\max X}) \land (A_{\max X} \ge B_{\min X}) \land (A_{\min Y} \le B_{\max Y}) \land (A_{\max Y} \ge B_{\min Y})\]

To optimize execution:

  • Ignore self-collision where i === j.
  • Skip redundant checks by ensuring i < j (evaluating only the upper triangle of the matrix).
const { GPU } = require('gpu.js'); // Or window.GPU if using a browser bundle
const gpu = new GPU();

const detectCollisions = gpu.createKernel(function(minX, minY, maxX, maxY) {
  const i = this.thread.x;
  const j = this.thread.y;

  // Avoid self-check and symmetric duplicates
  if (i >= j) {
    return 0;
  }

  // AABB intersection test
  const overlapX = minX[i] <= maxX[j] && maxX[i] >= minX[j];
  const overlapY = minY[i] <= maxY[j] && maxY[i] >= minY[j];

  if (overlapX && overlapY) {
    return 1; // Collision detected
  }

  return 0;
})
.setOutput([entityCount, entityCount])
.setOutputOrder('y,x');

3. Executing and Parsing Results

Invoke the kernel by passing the coordinate arrays. The result will be a 2D array of zeros and ones.

const collisionMatrix = detectCollisions(minX, minY, maxX, maxY);

const potentialPairs = [];

for (let j = 0; j < entityCount; j++) {
  for (let i = j + 1; i < entityCount; i++) {
    if (collisionMatrix[j][i] === 1) {
      potentialPairs.push([i, j]);
    }
  }
}

console.log(`Found ${potentialPairs.length} candidate pairs for narrow-phase processing.`);

4. Expanding to 3D

To extend the system to 3D environments, add minZ and maxZ arrays, update kernel input parameters, and incorporate depth collision conditions:

const overlapZ = minZ[i] <= maxZ[j] && maxZ[i] >= minZ[j];

if (overlapX && overlapY && overlapZ) {
  return 1;
}

This GPU-driven implementation bypasses CPU iteration limits, supplying broad-phase candidate pairs directly to narrow-phase collision solvers.
