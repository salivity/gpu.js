Circular Hough Transform in GPU.js for Iris Detection

The Circular Hough Transform (CHT) is a foundational feature extraction technique used to detect circular patterns in digital images, making it ideal for pinpointing pupil and iris boundaries. Because 3D accumulator voting (covering center coordinates \(x, y\) and radius \(r\)) is computationally intensive in standard JavaScript, offloading this workload to the GPU via gpu.js allows for real-time execution in the browser or Node.js. This guide details the complete process of structuring and executing a hardware-accelerated Circular Hough Transform for ocular biometric extraction using gpu.js.

The Detection Pipeline

Detecting the iris and pupil follows a multi-stage computer vision pipeline:

  1. Preprocessing: Convert the input image to grayscale and apply a blur to suppress noise.
  2. Edge Extraction: Run a Sobel or Canny filter to identify high-gradient boundary pixels.
  3. Accumulator Voting: Map edge pixels into parameter space \((a, b, r)\) where \((x - a)^2 + (y - b)^2 = r^2\).
  4. Peak Selection: Locate the coordinates with the highest votes to determine the center and radius.

Because the pupil is smaller and exhibits a starker dark-to-light boundary than the outer iris contour, detection is split into two targeted radius bands: a smaller radius range for the pupil (\(r_{min\_pupil}\) to \(r_{max\_pupil}\)) and a larger radius range for the iris (\(r_{min\_iris}\) to \(r_{max\_iris}\)).

Preprocessing: Edge Detection Kernel

Before voting, edges must be isolated. Using gpu.js, you can compute image gradients using a Sobel operator to generate a binary or thresholded edge map.

const { GPU } = require('gpu.js');
const gpu = new GPU();

const sobelKernel = gpu.createKernel(function(image, width, height) {
    const x = this.thread.x;
    const y = this.thread.y;

    if (x <= 0 || x >= width - 1 || y <= 0 || y >= height - 1) {
        return 0;
    }

    // Sobel kernels
    const gx = 
        -1 * image[y - 1][x - 1] + 1 * image[y - 1][x + 1] +
        -2 * image[y][x - 1]     + 2 * image[y][x + 1] +
        -1 * image[y + 1][x - 1] + 1 * image[y + 1][x + 1];

    const gy = 
        -1 * image[y - 1][x - 1] - 2 * image[y - 1][x] - 1 * image[y - 1][x + 1] +
         1 * image[y + 1][x - 1] + 2 * image[y + 1][x] + 1 * image[y + 1][x + 1];

    const magnitude = Math.sqrt(gx * gx + gy * gy);
    return magnitude > 0.3 ? 1.0 : 0.0; // Binary threshold
}).setOutput([width, height]);

Circular Hough Transform Kernel

In traditional CPU approaches, every edge pixel votes for all possible center points along a circular trajectory. On the GPU, inverted mapping is more efficient: each thread represents a candidate center \((a, b)\) for a fixed radius \(r\) and evaluates how many edge pixels intersect its circumference.

The kernel below computes the accumulator vote for a specific circle radius:

const houghVoteKernel = gpu.createKernel(function(edgeMap, width, height, radius, numSamples) {
    const a = this.thread.x; // Candidate center X
    const b = this.thread.y; // Candidate center Y
    let votes = 0;
    const PI2 = 6.28318530718;

    for (let i = 0; i < numSamples; i++) {
        const theta = (i / numSamples) * PI2;
        const edgeX = Math.floor(a + radius * Math.cos(theta));
        const edgeY = Math.floor(b + radius * Math.sin(theta));

        if (edgeX >= 0 && edgeX < width && edgeY >= 0 && edgeY < height) {
            if (edgeMap[edgeY][edgeX] > 0.5) {
                votes += 1;
            }
        }
    }

    return votes;
}).setOutput([width, height]);

Implementing Two-Stage Detection

Because the pupil and iris are roughly concentric, you can optimize execution time by detecting the pupil first and narrowing the iris search space to the pupil's localized neighborhood.

1. Pupil Detection

The pupil boundary has strong gradient contrast. Search within the pupil's expected radius range:

function detectPupil(edgeMap, width, height, minR, maxR, stepR = 1) {
    let maxVotes = 0;
    let bestCircle = { x: 0, y: 0, r: 0 };
    const numSamples = 64;

    for (let r = minR; r <= maxR; r += stepR) {
        const accumulator = houghVoteKernel(edgeMap, width, height, r, numSamples);

        for (let y = 0; y < height; y++) {
            for (let x = 0; x < width; x++) {
                const votes = accumulator[y][x];
                if (votes > maxVotes) {
                    maxVotes = votes;
                    bestCircle = { x, y, r };
                }
            }
        }
    }
    return bestCircle;
}

2. Iris Detection

The iris boundary is larger and often occluded by eyelids and eyelashes. Restrict the center coordinates \((a, b)\) to within a small offset (e.g., \(\pm 5\) to \(10\) pixels) of the detected pupil center to eliminate false positives:

function detectIris(edgeMap, width, height, pupilCenter, minR, maxR, stepR = 2) {
    let maxVotes = 0;
    let bestIris = { x: pupilCenter.x, y: pupilCenter.y, r: minR };
    const numSamples = 128;
    const centerTolerance = 8;

    for (let r = minR; r <= maxR; r += stepR) {
        const accumulator = houghVoteKernel(edgeMap, width, height, r, numSamples);

        const minY = Math.max(0, pupilCenter.y - centerTolerance);
        const maxY = Math.min(height - 1, pupilCenter.y + centerTolerance);
        const minX = Math.max(0, pupilCenter.x - centerTolerance);
        const maxX = Math.min(width - 1, pupilCenter.x + centerTolerance);

        for (let y = minY; y <= maxY; y++) {
            for (let x = minX; x <= maxX; x++) {
                const votes = accumulator[y][x];
                if (votes > maxVotes) {
                    maxVotes = votes;
                    bestIris = { x, y, r };
                }
            }
        }
    }
    return bestIris;
}

Performance Considerations

  • Sampling Density: In houghVoteKernel, numSamples dictates the angular resolution. A value between 64 and 128 balances precision with high frame rates.
  • Pipeline Memory Management: Ensure data remains on the GPU across operations by setting pipeline: true in the kernel options if chaining preprocessing kernels directly into the Hough accumulator.
  • Radius Step Size: Use an adaptive step size for the radius sweep. A step of 1 pixel is suitable for the pupil, while a step of 2 or 3 pixels accelerates the wider radius range required for the iris.
