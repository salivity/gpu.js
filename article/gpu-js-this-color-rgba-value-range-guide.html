GPU.js this.color RGBA Value Range Guide

When working with graphical kernels in GPU.js, setting pixel values relies on the built-in this.color() method. This article provides a direct overview of the expected numerical range for the Red, Green, Blue, and Alpha (RGBA) channels in GPU.js, explains how to convert standard color formats into compatible values, and demonstrates proper usage inside a kernel.

The Expected Numerical Range

In GPU.js, this.color(r, g, b, a) expects floating-point values ranging strictly from 0.0 to 1.0 for all four channels:

  • Red (R): 0.0 (minimum intensity / none) to 1.0 (maximum intensity / full red)
  • Green (G): 0.0 (minimum intensity / none) to 1.0 (maximum intensity / full green)
  • Blue (B): 0.0 (minimum intensity / none) to 1.0 (maximum intensity / full blue)
  • Alpha (A): 0.0 (completely transparent) to 1.0 (completely opaque)

Passing values outside of the 0.0 to 1.0 range will either cause clamping by the underlying WebGL context or lead to unexpected visual artifacts.

Converting from Standard 0–255 Formats

Standard 8-bit image formats, CSS colors, and typical canvas pixel arrays use integer values between 0 and 255. Because GPU.js operates on normalized WebGL fragment coordinates and values, any traditional 0–255 value must be normalized by dividing it by 255.

  • Formula: normalizedValue = standardValue / 255.0

For example:

  • A pure green channel value of 255 becomes 255 / 255 = 1.0.
  • A half-intensity blue value of 128 becomes 128 / 255 ≈ 0.5019.
  • A transparent alpha value of 0 becomes 0 / 255 = 0.0.

Practical Kernel Implementation

To use this.color(), the kernel must be initialized with the graphical: true setting enabled.

const gpu = new GPU();

const render = gpu.createKernel(function() {
    // Generates a solid purple color: full red, no green, full blue, full opacity
    const r = 1.0;
    const g = 0.0;
    const b = 1.0;
    const a = 1.0;

    this.color(r, g, b, a);
}, {
    output: [512, 512],
    graphical: true
});

render();

// Append the canvas output to the DOM
document.body.appendChild(render.canvas);

If alpha is omitted, WebGL assumes an alpha value of 1.0 (fully opaque). However, explicitly supplying all four parameters ensures consistent cross-platform rendering across all supported WebGL environments.
