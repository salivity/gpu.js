2D Convolution for Audio Filtering in GPU.js

This article explains how to implement hardware-accelerated 2D convolution using gpu.js for audio and signal filtering tasks. By converting time-domain audio signals into two-dimensional representations such as spectrograms (Short-Time Fourier Transforms), you can utilize GPU parallel processing to apply spatial filters like noise reduction, frequency smoothing, and harmonic enhancement significantly faster than on a CPU.

Converting Audio to 2D Representations

Audio waveforms are fundamentally 1D time-domain arrays. To apply 2D convolution, the signal is typically transformed into a 2D matrix—such as an STFT spectrogram—where the X-axis represents time frames and the Y-axis represents frequency bins. Filtering this matrix with a 2D kernel allows you to target specific time-frequency patterns, such as isolating transient clicks, removing stationary hums, or blurring spectral leakage.

Setting Up GPU.js

GPU.js compiles JavaScript functions into WebGL shaders, allowing parallel execution on the GPU. Install gpu.js via npm or import it via a CDN:

npm install gpu.js

Initialize an instance in your JavaScript environment:

const { GPU } = require('gpu.js');
const gpu = new GPU();

Implementing the 2D Convolution Kernel

A 2D convolution involves sliding a small matrix (the kernel) over the input matrix, computing element-wise products, and summing the results for each output cell.

Below is the implementation using gpu.createKernel:

const createConvolution2D = (inputWidth, inputHeight, kernelSize) => {
  const halfKernel = Math.floor(kernelSize / 2);

  return gpu.createKernel(function(inputMatrix, kernel) {
    let sum = 0.0;
    const x = this.thread.x;
    const y = this.thread.y;

    for (let ky = -this.constants.halfKernel; ky <= this.constants.halfKernel; ky++) {
      for (let kx = -this.constants.halfKernel; kx <= this.constants.halfKernel; kx++) {
        const posX = x + kx;
        const posY = y + ky;

        // Boundary handling: clamp to edge values
        const clampedX = Math.max(0, Math.min(this.constants.width - 1, posX));
        const clampedY = Math.max(0, Math.min(this.constants.height - 1, posY));

        const kernelVal = kernel[ky + this.constants.halfKernel][kx + this.constants.halfKernel];
        sum += inputMatrix[clampedY][clampedX] * kernelVal;
      }
    }

    return sum;
  })
  .setConstants({
    halfKernel: halfKernel,
    width: inputWidth,
    height: inputHeight
  })
  .setOutput([inputWidth, inputHeight]);
};

Designing the Filter Kernel

The kernel values determine the filtering behavior. A normalized Gaussian filter smooths spectral components to remove random phase noise, while an edge-detection filter can isolate spectral onsets:

// Example: 3x3 Gaussian smoothing kernel for spectral denoising
const gaussianKernel = [
  [1 / 16, 2 / 16, 1 / 16],
  [2 / 16, 4 / 16, 2 / 16],
  [1 / 16, 2 / 16, 1 / 16]
];

// Example: Horizontal edge detection (isolates constant frequency tones)
const horizontalFilter = [
  [-1, -2, -1],
  [ 0,  0,  0],
  [ 1,  2,  1]
];

Executing the Convolution

To process the signal, pass your 2D audio array (e.g., amplitude spectrogram) and the defined kernel into the generated GPU function:

const spectrogramWidth = 1024;  // Time frames
const spectrogramHeight = 512;  // Frequency bins
const kernelDimension = 3;

// Instantiate kernel function
const convolveAudio = createConvolution2D(spectrogramWidth, spectrogramHeight, kernelDimension);

// Run the convolution on the GPU
const filteredSpectrogram = convolveAudio(spectrogramData, gaussianKernel);

Performance Considerations

  1. Avoid Frequent CPU-GPU Transfers: If running consecutive operations (e.g., convolution followed by dynamic range compression), use .setPipeline(true) on the kernel. This keeps output data in GPU memory textures rather than serializing it back to the CPU after every step.
  2. Kernel Size Limits: GPU unrolling performs best with smaller kernels (typically 3x3, 5x5, or 7x7). For very large filter windows, consider separable convolutions (two 1D passes) or FFT-based frequency domain multiplication.
