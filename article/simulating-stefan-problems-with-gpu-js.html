Simulating Stefan Problems with gpu.js

Simulating Stefan problems, which model phase changes and moving boundaries such as melting ice, is entirely feasible using gpu.js. By leveraging browser-based WebGL acceleration, gpu.js enables parallelized numerical computations on structured grids. Using fixed-grid methods like the enthalpy formulation or phase-field modeling, developers can bypass the complex geometric tracking of moving interfaces and solve the underlying partial differential equations directly on the GPU.

The Physics of the Stefan Problem

A Stefan problem describes the temperature distribution in a medium undergoing a phase transition, characterized by a boundary that moves over time. In the case of melting ice, heat diffuses through both the liquid and solid phases according to the heat equation:

\[\frac{\partial T}{\partial t} = \alpha \nabla^2 T\]

At the interface between water and ice, the boundary condition dictates that the speed of the interface is proportional to the jump in heat flux across it, governed by the latent heat of fusion:

\[\rho L \frac{dn}{dt} = k_s \nabla T_s \cdot \mathbf{n} - k_l \nabla T_l \cdot \mathbf{n}\]

Tracking this boundary explicitly on a GPU is computationally prohibitive. However, implicit numerical methods transform this moving boundary problem into a continuous domain problem suitable for parallel execution.

Suitable Numerical Approaches for gpu.js

Because gpu.js excels at operations on uniform 2D and 3D arrays using compute shaders, fixed-domain methods are the best choice for this implementation:

  1. The Enthalpy Method: Instead of solving purely for temperature, the system tracks total enthalpy (\(H\)), which combines sensible heat and latent heat. Enthalpy is conserved across the entire domain, and temperature (\(T\)) is derived directly from \(H\) via an algebraic relation. This removes the need to explicitly calculate the boundary position.
  2. The Phase-Field Method: This approach introduces an auxiliary continuous order parameter (\(\phi\)) that varies smoothly between values representing solid (e.g., \(0\)) and liquid (e.g., \(1\)). Coupled with the heat equation, the phase-field equation governs the evolution of the interface naturally across the grid.

Implementing the Simulation in gpu.js

To implement a Stefan problem simulation using the enthalpy method in gpu.js, follow this computational pipeline:

1. Discretization and Grid Setup

Represent the physical space as a uniform 2D grid where each cell corresponds to a pixel or matrix element. Allocate matrices for the state variables:

  • Current temperature field
  • Current enthalpy field
  • Phase state (solid, liquid, or mushy zone)

2. Designing the GPU Kernels

Create kernels to update the state at each discrete time step using an explicit finite difference scheme:

  • Diffusion Kernel: Evaluates the discrete Laplacian (\(\nabla^2 T\)) using a standard 5-point stencil on the temperature grid to calculate heat conduction.
  • Enthalpy Update Kernel: Updates the enthalpy value at each cell: \[H^{n+1}_{i,j} = H^n_{i,j} + \Delta t \cdot \left( \text{diffusion terms} \right)\]
  • Phase Inversion Kernel: Recomputes the local temperature and phase fraction based on the updated enthalpy:
    • If \(H < H_{solid}\), the cell is solid ice (\(T < T_{melt}\)).
    • If \(H_{solid} \le H \le H_{liquid}\), the cell is undergoing phase change (\(T = T_{melt}\)).
    • If \(H > H_{liquid}\), the cell is liquid water (\(T > T_{melt}\)).

3. Execution via Ping-Pong Buffers

Because WebGL shaders cannot read from and write to the same texture simultaneously, gpu.js utilizes texture outputs. You must alternate input and output arrays (ping-ponging) between successive time steps to update the simulation continuously without memory read conflicts.

Performance Considerations and Limitations

  • Numerical Stability: Explicit time-stepping schemes require small time steps (\(\Delta t \le \frac{\Delta x^2}{4\alpha}\)) to maintain stability, requiring thousands of kernel iterations.
  • Floating-Point Precision: gpu.js relies on WebGL textures, which historically default to 16-bit or 32-bit floats depending on hardware and browser extensions. Ensure precision: 'single' is enabled to prevent significant numerical drift during heat conservation checks.
  • Boundary Localization: While implicit methods make computation straightforward, extracting the exact sharp boundary coordinates for visualization requires running a secondary edge-detection filter (such as marching squares) on the phase grid.
