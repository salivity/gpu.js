How to Implement Activation Functions in GPU.js

This article provides an overview and practical guide on implementing common neural network activation functions—ReLU, Sigmoid, and Leaky ReLU—using GPU.js. You will learn the mathematical foundation for each function, how GPU.js translates JavaScript into WebGL shaders for parallel execution, and the exact code snippets required to execute these operations on 2D arrays (matrices) using the GPU.

Understanding the GPU.js Execution Model

GPU.js compiles a subset of JavaScript into GLSL (OpenGL Shading Language) and executes it on the graphics processor. When processing activations over layers, operations run concurrently across array elements using thread indices (this.thread.x, this.thread.y, or this.thread.z).

To apply an activation function across a 2D matrix, a kernel evaluates each cell based on its coordinates:

const { GPU } = require('gpu.js');
const gpu = new GPU();

1. Rectified Linear Unit (ReLU)

ReLU maps negative values to zero and keeps positive values unchanged:

\[f(x) = \max(0, x)\]

In GPU.js, you use Math.max() within the kernel function:

const createReLUKernel = (width, height) => {
  return gpu.createKernel(function(matrix) {
    const val = matrix[this.thread.y][this.thread.x];
    return Math.max(0, val);
  }).setOutput([width, height]);
};

// Usage
const relu = createReLUKernel(3, 3);
const input = [
  [-1.5,  2.0, -0.1],
  [ 0.0,  5.2, -3.4],
  [ 1.1, -0.9,  4.0]
];
const output = relu(input);

2. Sigmoid Activation

The Sigmoid function squashes values into a range between 0 and 1:

\[f(x) = \frac{1}{1 + e^{-x}}\]

GPU.js supports standard Math.exp() for floating-point calculations:

const createSigmoidKernel = (width, height) => {
  return gpu.createKernel(function(matrix) {
    const val = matrix[this.thread.y][this.thread.x];
    return 1 / (1 + Math.exp(-val));
  }).setOutput([width, height]);
};

// Usage
const sigmoid = createSigmoidKernel(3, 3);
const output = sigmoid(input);

3. Leaky ReLU Activation

Leaky ReLU prevents the "dying ReLU" problem by allowing a small, non-zero gradient (\(\alpha\), typically 0.01) when the input is negative:

\[f(x) = \begin{cases} x & \text{if } x > 0 \\ \alpha x & \text{if } x \le 0 \end{cases}\]

GPU.js allows ternary operators and parameter passing directly into the kernel:

const createLeakyReLUKernel = (width, height) => {
  return gpu.createKernel(function(matrix, alpha) {
    const val = matrix[this.thread.y][this.thread.x];
    return val > 0 ? val : val * alpha;
  }).setOutput([width, height]);
};

// Usage
const leakyRelu = createLeakyReLUKernel(3, 3);
const alpha = 0.01;
const output = leakyRelu(input, alpha);

Optimizing Performance with Pipelines

When chaining activation functions with matrix multiplication, reading data back to the CPU creates a memory bottleneck. Enable the pipeline mode in GPU.js to keep intermediate textures on the GPU:

const leakyReluPipeline = gpu.createKernel(function(matrix, alpha) {
  const val = matrix[this.thread.y][this.thread.x];
  return val > 0 ? val : val * alpha;
})
.setOutput([width, height])
.setPipeline(true);

By returning a GPU texture instead of a raw JavaScript array, subsequent forward or backward propagation layers can consume the activated output directly without memory transfer overhead.
