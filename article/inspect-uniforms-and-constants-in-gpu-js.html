Inspect Uniforms and Constants in GPU.js

Debugging GPU-accelerated code can be challenging because data executes directly on the graphics hardware rather than in the standard JavaScript thread. This article provides a clear guide on how to inspect uniform values and constant bindings passed to a gpu.js shader. By using gpu.js built-in debugging options, examining internal kernel state, and leveraging WebGL inspection extensions, you can verify that your pipeline passes data accurately.

Enable Debug Mode

The most direct way to observe how gpu.js maps your variables to shader uniforms and constants is to initialize the GPU or kernel in debug mode. When debug mode is active, gpu.js logs the generated WebGL/GLSL shader source to the browser console, allowing you to view variable declarations directly.

const gpu = new GPU({ mode: 'dev' }); // Runs on CPU with full console logging

// Or configure debugging per kernel:
const kernel = gpu.createKernel(function(a) {
  return a[this.thread.x] + this.constants.factor;
}, {
  debug: true,
  constants: { factor: 10 }
});

In dev mode, execution falls back to JavaScript, making it trivial to place standard debugger; statements or console.log() calls inside the kernel function to inspect argument values.

Inspect the Kernel Object Directly

After creating and executing a kernel, the kernel instance itself retains references to compiled WebGL metadata, uniform locations, and bound constants.

You can inspect these properties via the console:

// Access compiled constants
console.log(kernel.constants);

// Access internal WebGL program uniform locations
console.log(kernel.uniforms);
console.log(kernel.program);
  • kernel.constants: Holds the key-value dictionary of values bound via the constants configuration option.
  • kernel.uniforms: Contains the uniform names and target slots mapped by the gpu.js compiler.

Inspect the Generated GLSL Code

To see the exact uniform names and constant substitutions generated by the compiler, output the kernel's compiled shader string:

console.log(kernel.toString());

This outputs the complete WebGL shader string. Look for the uniform keyword at the top of the fragment shader to identify variable types, precision qualifiers, and the internal identifiers gpu.js assigns to your parameters.

Use Spector.js for Live WebGL Inspection

Because gpu.js compiles down to WebGL under the hood, standard WebGL debugging tools can inspect active GPU state in real time:

  1. Install the Spector.js browser extension.
  2. Open your page containing the running gpu.js kernel.
  3. Click the Spector.js record button to capture a frame.
  4. Select the draw call corresponding to your kernel (typically drawArrays).
  5. Navigate to the Uniforms tab to see every bound uniform value, texture unit binding, and active matrix currently assigned to the shader program on the GPU.
