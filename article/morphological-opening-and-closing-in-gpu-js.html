Morphological Opening and Closing in GPU.js

This article provides a practical guide to implementing high-performance morphological opening and closing operations on high-resolution image masks using gpu.js. By leveraging WebGL shaders through JavaScript, you can process multi-megapixel binary or grayscale masks in milliseconds. Below, you will find the theoretical foundation of erosion and dilation, the implementation of reusable GPU kernels, and how to chain these operations using pipelined textures to eliminate CPU-GPU memory bottlenecks.

Core Principles: Erosion and Dilation

Morphological opening and closing are compound operations built upon two fundamental mathematical morphology operators:

  1. Erosion: Computes the local minimum within a neighborhood defined by a structuring element (kernel). It shrinks foreground regions and removes small positive noise.
  2. Dilation: Computes the local maximum within the neighborhood. It expands foreground regions and fills small negative holes.

From these base operations:

  • Opening: An erosion followed by a dilation (\(A \circ B = (A \ominus B) \oplus B\)). It removes isolated foreground artifacts while preserving the general shape and size of larger objects.
  • Closing: A dilation followed by an erosion (\(A \bullet B = (A \oplus B) \ominus B\)). It bridges small gaps and fills interior holes while maintaining the overall boundaries.

Handling High-Resolution Masks with Pipelining

Processing high-resolution masks (such as 4K images) requires minimizing the transfer of large typed arrays between system RAM and GPU VRAM. In gpu.js, you should enable the pipeline: true mode on your kernels. This keeps the intermediate output of an operation as a WebGL texture on the GPU, allowing the next operation to consume it directly without readback delays.

GPU.js Implementation

Below is a complete implementation defining the erosion and dilation kernels, followed by the combined opening and closing functions.

import { GPU } from 'gpu.js';

const gpu = new GPU();

// Configuration
const KERNEL_RADIUS = 1; // 1 gives a 3x3 structuring element, 2 gives 5x5, etc.

/**
 * Creates an Erosion Kernel.
 * Computes the minimum value in a (2 * radius + 1) window.
 */
function createErodeKernel(width, height, radius) {
  return gpu.createKernel(
    function (mask) {
      let minVal = 1.0;
      for (let dy = -this.constants.radius; dy <= this.constants.radius; dy++) {
        for (let dx = -this.constants.radius; dx <= this.constants.radius; dx++) {
          const x = this.thread.x + dx;
          const y = this.thread.y + dy;

          // Boundary check
          if (x >= 0 && x < this.constants.width && y >= 0 && y < this.constants.height) {
            const val = mask[y][x];
            if (val < minVal) {
              minVal = val;
            }
          } else {
            // Treat borders as background for erosion
            minVal = 0.0;
          }
        }
      }
      return minVal;
    },
    {
      constants: { radius, width, height },
      output: [width, height],
      pipeline: true,
      immutable: true
    }
  );
}

/**
 * Creates a Dilation Kernel.
 * Computes the maximum value in a (2 * radius + 1) window.
 */
function createDilateKernel(width, height, radius) {
  return gpu.createKernel(
    function (mask) {
      let maxVal = 0.0;
      for (let dy = -this.constants.radius; dy <= this.constants.radius; dy++) {
        for (let dx = -this.constants.radius; dx <= this.constants.radius; dx++) {
          const x = this.thread.x + dx;
          const y = this.thread.y + dy;

          // Boundary check
          if (x >= 0 && x < this.constants.width && y >= 0 && y < this.constants.height) {
            const val = mask[y][x];
            if (val > maxVal) {
              maxVal = val;
            }
          }
        }
      }
      return maxVal;
    },
    {
      constants: { radius, width, height },
      output: [width, height],
      pipeline: true,
      immutable: true
    }
  );
}

Executing Opening and Closing

To produce final usable data, the last kernel execution in the sequence can either have pipeline: false or have its output extracted via .toArray().

class MorphologyPipeline {
  constructor(width, height, radius = 1) {
    this.width = width;
    this.height = height;
    this.erode = createErodeKernel(width, height, radius);
    this.dilate = createDilateKernel(width, height, radius);
  }

  /**
   * Opening: Erosion followed by Dilation.
   * Cleans noise and detaches weakly connected components.
   */
  open(inputMask) {
    // Step 1: Erode (keeps intermediate texture on GPU)
    const erodedTexture = this.erode(inputMask);

    // Step 2: Dilate
    const dilatedTexture = this.dilate(erodedTexture);

    // Retrieve data to JavaScript array
    const result = dilatedTexture.toArray();

    // Clean up GPU textures to prevent memory leaks
    erodedTexture.delete();
    dilatedTexture.delete();

    return result;
  }

  /**
   * Closing: Dilation followed by Erosion.
   * Fills small holes and bridges separated components.
   */
  close(inputMask) {
    // Step 1: Dilate (keeps intermediate texture on GPU)
    const dilatedTexture = this.dilate(inputMask);

    // Step 2: Erode
    const erodedTexture = this.erode(dilatedTexture);

    // Retrieve data to JavaScript array
    const result = erodedTexture.toArray();

    // Clean up GPU textures to prevent memory leaks
    dilatedTexture.delete();
    erodedTexture.delete();

    return result;
  }
}

Performance Considerations

  1. Memory Management: High-resolution masks consume significant GPU memory. Always call .delete() on intermediate texture handles once they are no longer needed by downstream kernels.
  2. Separable Structuring Elements: For standard rectangular structuring elements larger than \(5 \times 5\), separate 2D kernels into two 1D passes (horizontal pass followed by a vertical pass). This reduces the computational complexity per pixel from \(\mathcal{O}(K^2)\) to \(\mathcal{O}(2K)\), substantially improving frame rates on \(4\text{K}\) or \(8\text{K}\) inputs.
  3. Data Format: Input 2D masks as flattened Float32Array buffers or normalized single-channel arrays where values range from 0.0 (background) to 1.0 (foreground) to match standard floating-point texture formats.
