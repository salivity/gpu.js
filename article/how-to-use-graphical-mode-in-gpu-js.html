How to Use Graphical Mode in GPU.js

GPU.js is a JavaScript acceleration library that compiles user-written functions into WebGL shaders, allowing complex computations to run on the graphics processor. While typically used for processing data matrices and returning numerical arrays, GPU.js includes a feature called graphical mode that enables direct visual rendering to an HTML <canvas> element. This article explains what graphical mode is, how it functions internally, and how to activate and implement it using the setGraphical(true) method.

What is Graphical Mode in GPU.js?

By default, a GPU.js kernel operates as a compute shader. It processes input data and outputs a 1D, 2D, or 3D array of numerical values back to the CPU memory. While useful for general-purpose computing (GPGPU), converting these arrays back into visual elements via standard DOM or 2D canvas operations creates a performance bottleneck due to continuous data transfer between the CPU and GPU.

Graphical mode alters the kernel's execution model so that it acts as a fragment shader. Instead of returning raw numbers to JavaScript, the kernel outputs colors directly to a WebGL rendering context tied to an HTML <canvas>. This eliminates the overhead of copying pixel data back to the CPU, allowing for high-performance rendering of fractals, cellular automata, image filters, and particle systems directly in the browser.

Activating Graphical Mode with setGraphical(true)

To activate graphical mode, you chain the .setGraphical(true) method to your kernel creation call. Once enabled, two main differences occur in how the kernel is written and accessed:

  1. Pixel Coloring (this.color): Rather than returning a numeric value, the kernel function uses the built-in this.color(r, g, b, a) method. The arguments are normalized floating-point numbers between 0.0 and 1.0 representing the red, green, blue, and alpha channels of the current pixel.
  2. Accessing the Canvas: The kernel object exposes a .canvas property, which references the WebGL canvas element rendered by the GPU. You can append this canvas directly to the DOM.

Implementation Example

The following example demonstrates how to configure, activate, and render a basic color gradient using graphical mode:

import { GPU } from 'gpu.js';

const gpu = new GPU();

// 1. Define the kernel function and chain .setGraphical(true)
const renderKernel = gpu.createKernel(function() {
    // Determine color based on the current thread (pixel) coordinates
    const r = this.thread.x / this.output.x;
    const g = this.thread.y / this.output.y;
    const b = 0.5;

    // Set pixel color (r, g, b, a) with values from 0.0 to 1.0
    this.color(r, g, b, 1.0);
})
.setOutput([500, 500])
.setGraphical(true);

// 2. Execute the kernel to render the image
renderKernel();

// 3. Append the generated canvas element to the document body
document.body.appendChild(renderKernel.canvas);

Key Considerations

  • Coordinate System: In graphical mode, this.thread.x runs from left to right, and this.thread.y runs from bottom to top, matching standard WebGL texture coordinates rather than typical top-to-bottom screen space.
  • Canvas Resizing: The output dimensions specified in .setOutput([width, height]) determine the internal pixel resolution of the canvas. Changing the visual size via CSS can cause standard pixel scaling.
  • Animation Loops: For animations, you do not need to append the canvas repeatedly. You can invoke the kernel within a requestAnimationFrame loop, and the canvas updates automatically on each draw call.
