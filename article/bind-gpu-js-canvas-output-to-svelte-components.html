Bind GPU.js Canvas Output to Svelte Components

This article provides a direct guide to integrating GPU.js graphical kernels with Svelte’s reactivity system. You will learn how to configure a GPU.js kernel for visual rendering, mount its generated WebGL canvas into the Svelte DOM, and use Svelte's reactive declarations ($:) to automatically re-render the canvas whenever component state changes.

Core Concepts

GPU.js allows developers to run complex computations on the GPU via WebGL. When the graphical: true option is enabled, a kernel outputs directly to an internal <canvas> element via the this.color(r, g, b, a) API instead of returning a numeric array.

In Svelte, the most reliable way to bind this graphical output is to:

  1. Initialize the GPU instance and kernel on component mount.
  2. Append the kernel's internal canvas (kernel.canvas) to a DOM element bound using bind:this.
  3. Use a reactive declaration ($:) that triggers kernel execution whenever dynamic parameters update.

Implementation

Below is a complete implementation demonstrating how to bind and reactively update a GPU.js graphical canvas inside a Svelte component:

<script>
  import { onMount, onDestroy } from 'svelte';
  import { GPU } from 'gpu.js';

  // Reactive state inputs
  export let width = 500;
  export let height = 500;
  export let redIntensity = 0.8;
  export let blueIntensity = 0.5;

  let container;
  let gpu;
  let renderKernel;

  onMount(() => {
    // 1. Initialize GPU instance
    gpu = new GPU();

    // 2. Define the graphical kernel
    renderKernel = gpu.createKernel(function (r, b) {
      const x = this.thread.x / this.output.x;
      const y = this.thread.y / this.output.y;
      this.color(x * r, y * 0.5, b, 1);
    })
    .setOutput([width, height])
    .setGraphical(true);

    // 3. Mount the GPU canvas into the DOM container
    container.appendChild(renderKernel.canvas);

    // Initial render
    renderKernel(redIntensity, blueIntensity);
  });

  // 4. Reactive declaration triggers re-render when dependencies change
  $: if (renderKernel) {
    renderKernel(redIntensity, blueIntensity);
  }

  // Cleanup WebGL context on unmount
  onDestroy(() => {
    if (gpu) {
      gpu.destroy();
    }
  });
</script>

<div class="canvas-wrapper" bind:this={container}></div>

<style>
  .canvas-wrapper {
    display: inline-block;
    overflow: hidden;
  }
</style>

How the Reactivity Works

  1. DOM Attachment: GPU.js manages its own HTML5 <canvas> element internally. Using Svelte's bind:this={container} inside onMount, the canvas is appended directly to the DOM tree once the component is mounted.
  2. Reactive Dependency Tracking: Svelte analyzes the reactive statement $: if (renderKernel) { renderKernel(redIntensity, blueIntensity); }. Whenever redIntensity or blueIntensity updates (for example, via bound form inputs or parent props), Svelte invalidates the statement and re-executes the kernel function.
  3. In-Place WebGL Updates: Calling renderKernel(...) performs GPU calculations and updates the existing WebGL context in place, eliminating the need to re-create the DOM node on every state change.

Handling Dynamic Canvas Dimensions

If the canvas dimensions (width and height) need to change dynamically, the kernel must be rebuilt, as GPU.js fixes thread outputs at kernel creation:

$: if (gpu && (width || height)) {
  if (renderKernel) {
    renderKernel.destroy();
  }
  
  renderKernel = gpu.createKernel(function (r, b) {
    this.color(this.thread.x / this.output.x * r, 0.2, b, 1);
  })
  .setOutput([width, height])
  .setGraphical(true);

  // Replace old canvas in container
  container.innerHTML = '';
  container.appendChild(renderKernel.canvas);
  renderKernel(redIntensity, blueIntensity);
}

This ensures that resizing events preserve reactivity without producing orphaned WebGL contexts.
