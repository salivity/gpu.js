Simulating Cardiac Signal Dispersion with GPU.js

Simulating electrical signal propagation across cardiac muscle tissue requires solving reaction-diffusion differential equations over large spatial grids. This article demonstrates how to accelerate this computational process using GPU.js, a library that transpiles JavaScript functions into WebGL shaders. By implementing a simplified cardiac electrophysiology model, such as the FitzHugh-Nagumo model, you can compute wave diffusion across a 2D myocardial grid in parallel, achieving real-time performance inside a web browser or Node.js environment.

The Electrophysiological Model

Cardiac muscle cells (cardiomyocytes) conduct electrical excitation via ion channel dynamics and gap junctions. On a macroscopic scale, this can be modeled using a reaction-diffusion system:

\[\frac{\partial u}{\partial t} = D \nabla^2 u + f(u) - v\] \[\frac{\partial v}{\partial t} = \epsilon (k u - v)\]

  • \(u\) represents the normalized transmembrane potential.
  • \(v\) represents the recovery variable (inactivation of ion channels).
  • \(D\) is the diffusion coefficient representing intercellular coupling via gap junctions.
  • \(\nabla^2 u\) is the 2D Laplacian operator describing spatial voltage diffusion.
  • \(f(u) = u(1 - u)(u - a)\) models the non-linear excitation threshold.
  • \(\epsilon\), \(a\), and \(k\) are dimensionless scaling parameters.

Setting Up GPU.js

First, include GPU.js in your project via npm or a CDN script tag:

npm install gpu.js

Initialize the GPU context and configure the grid dimensions:

import { GPU } from 'gpu.js';

const gpu = new GPU();
const width = 512;
const height = 512;

Implementing the Simulation Kernel

Because finite difference approximations require reading neighboring cells, compute the discrete 5-point 2D Laplacian:

\[\nabla^2 u_{x,y} \approx \frac{u_{x+1,y} + u_{x-1,y} + u_{x,y+1} + u_{x,y-1} - 4u_{x,y}}{\Delta x^2}\]

Define the GPU.js kernel to compute both diffusion and reaction kinetics in a single pass. GPU.js handles array indexes via this.thread.x and this.thread.y:

const updateCardiacTissue = gpu.createKernel(function(uGrid, vGrid, dt, D, a, epsilon, k) {
    const x = this.thread.x;
    const y = this.thread.y;
    const w = this.output.x;
    const h = this.output.y;

    // Periodic or no-flux boundary conditions
    const left = x > 0 ? uGrid[y][x - 1] : uGrid[y][x];
    const right = x < w - 1 ? uGrid[y][x + 1] : uGrid[y][x];
    const top = y < h - 1 ? uGrid[y + 1][x] : uGrid[y][x];
    const bottom = y > 0 ? uGrid[y - 1][x] : uGrid[y][x];

    const currentU = uGrid[y][x];
    const currentV = vGrid[y][x];

    // Compute Laplacian
    const laplacian = (left + right + top + bottom - 4.0 * currentU);

    // Compute FitzHugh-Nagumo reaction kinetics
    const dU = (D * laplacian + currentU * (1.0 - currentU) * (currentU - a) - currentV) * dt;
    const dV = (epsilon * (k * currentU - currentV)) * dt;

    // Pack updated states into a 2D vector or run separate kernels
    return currentU + dU;
})
.setOutput([width, height])
.setPipeline(true); // Keeps output in GPU memory as a texture

For the recovery variable \(v\), create a companion kernel or configure the primary kernel to update \(v\) simultaneously:

const updateRecovery = gpu.createKernel(function(uGrid, vGrid, dt, epsilon, k) {
    const x = this.thread.x;
    const y = this.thread.y;
    const currentU = uGrid[y][x];
    const currentV = vGrid[y][x];
    
    return currentV + (epsilon * (k * currentU - currentV)) * dt;
})
.setOutput([width, height])
.setPipeline(true);

Initializing the Tissue State

Create initial 2D arrays containing resting state values (\(u \approx 0, v \approx 0\)) and stimulate a specific region by elevating the potential \(u\) to trigger depolarization:

let uState = [];
let vState = [];

for (let y = 0; y < height; y++) {
    const uRow = [];
    const vRow = [];
    for (let x = 0; x < width; x++) {
        // Stimulate the left edge to initiate an electrical wavefront
        uRow.push(x < 10 ? 1.0 : 0.0);
        vRow.push(0.0);
    }
    uState.push(uRow);
    vState.push(vRow);
}

Running the Temporal Evolution Loop

Because .setPipeline(true) returns WebGL textures instead of raw arrays, chain the simulation steps using ping-pong buffering. This minimizes memory transfer overhead between the CPU and GPU:

// Model parameters
const dt = 0.05;
const D = 1.0;
const a = 0.1;
const epsilon = 0.01;
const k = 0.5;

function stepSimulation() {
    // Run GPU calculations
    const nextU = updateCardiacTissue(uState, vState, dt, D, a, epsilon, k);
    const nextV = updateRecovery(uState, vState, dt, epsilon, k);

    // Update references for the next iteration
    uState = nextU;
    vState = nextV;
}

// Execution loop
function animate() {
    for (let i = 0; i < 10; i++) { // Sub-stepping for numerical stability
        stepSimulation();
    }
    requestAnimationFrame(animate);
}
animate();

Rendering the Dispersion Pattern

To visualize the propagating signal, utilize a final rendering kernel that reads the current uState texture and maps the normalized membrane voltage to an RGBA canvas output:

const renderTissue = gpu.createKernel(function(uGrid) {
    const u = uGrid[this.thread.y][this.thread.x];
    // Map voltage to an action-potential color ramp (e.g., black to red to yellow)
    this.color(u, u * 0.5, 0.2 * (1.0 - u), 1);
})
.setOutput([width, height])
.setGraphical(true);

// Inside the animation loop:
renderTissue(uState);
const canvas = renderTissue.canvas;
document.body.appendChild(canvas);

Using this pipeline, electrical waves will spread smoothly across the 2D domain, displaying depolarization fronts, repolarization tails, and, under appropriate tissue heterogeneity parameters, realistic spiral wave breakup analogous to cardiac arrhythmia.
