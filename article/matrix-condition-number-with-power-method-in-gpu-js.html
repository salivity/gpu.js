Matrix Condition Number with Power Method in GPU.js

This article explains how to compute the 2-norm condition number of a matrix on the GPU using gpu.js and iterative power algorithms. The condition number measures how sensitive a linear system is to errors or perturbations, defined as the ratio of the matrix's largest singular value to its smallest. By implementing the standard Power Iteration to find the dominant singular value and Shifted Power Iteration to find the smallest singular value, you can offload compute-heavy matrix-vector operations directly to WebGL shaders for high-performance calculations in JavaScript.

Understanding the Condition Number

The 2-norm condition number \(\kappa(A)\) of a real matrix \(A\) is given by:

\[\kappa(A) = \frac{\sigma_{\max}(A)}{\sigma_{\min}(A)} = \sqrt{\frac{\lambda_{\max}(A^T A)}{\lambda_{\min}(A^T A)}}\]

Here, \(\lambda_{\max}\) and \(\lambda_{\min}\) are the maximum and minimum eigenvalues of the symmetric, positive semi-definite matrix \(M = A^T A\).

To compute these values without calculating full matrix inverses or factorizations:

  1. Power Iteration extracts the largest eigenvalue \(\lambda_{\max}\) of \(M\).
  2. Shifted Power Iteration targets the smallest eigenvalue \(\lambda_{\min}\) by applying the power method to the shifted operator \(S = \lambda_{\max} I - M\), whose dominant eigenvalue corresponds to \(\lambda_{\max} - \lambda_{\min}\).

Evaluating \(M x = A^T(A x)\) directly through two successive matrix-vector multiplications avoids explicitly constructing the \(A^T A\) matrix, saving memory bandwidth on the GPU.

Defining the GPU Kernels

gpu.js requires defining kernel functions that run in parallel on WebGL threads. You need kernels for matrix-vector multiplication, vector scaling (normalization), and the shifted matrix-vector operation.

const { GPU } = require('gpu.js');
const gpu = new GPU();

// Computes y = A * x
const kernelMatVec = gpu.createKernel(function (A, x, cols) {
    let sum = 0;
    for (let i = 0; i < cols; i++) {
        sum += A[this.thread.x][i] * x[i];
    }
    return sum;
}).setOutput([/* rows */]);

// Computes y = A^T * x
const kernelMatTransposeVec = gpu.createKernel(function (A, x, rows) {
    let sum = 0;
    for (let i = 0; i < rows; i++) {
        sum += A[i][this.thread.x] * x[i];
    }
    return sum;
}).setOutput([/* cols */]);

// Computes y = (shift * x) - (A^T * (A * x))
const kernelShiftedMatVec = gpu.createKernel(function (shift, Ax, AtAx, x) {
    return (shift * x[this.thread.x]) - AtAx[this.thread.x];
}).setOutput([/* cols */]);

// Vector normalization helper (L2 norm)
function l2Norm(vec) {
    let sum = 0;
    for (let i = 0; i < vec.length; i++) {
        sum += vec[i] * vec[i];
    }
    return Math.sqrt(sum);
}

function normalize(vec) {
    const norm = l2Norm(vec);
    return vec.map(val => val / (norm || 1));
}

Step 1: Calculating the Maximum Eigenvalue (\(\lambda_{\max}\))

Initialize a normalized random vector \(v\). In each iteration, compute \(w = A^T(A v)\) using the GPU kernels, calculate the Rayleigh quotient approximation for \(\lambda_{\max}\), and normalize the resulting vector for the next step.

function computeMaxEigenvalue(A, rows, cols, maxIterations = 100, tolerance = 1e-6) {
    kernelMatVec.setOutput([rows]);
    kernelMatTransposeVec.setOutput([cols]);

    // Initialize random unit vector
    let v = normalize(Array.from({ length: cols }, () => Math.random() - 0.5));
    let lambdaMax = 0;

    for (let iter = 0; iter < maxIterations; iter++) {
        // Step 1: Ax = A * v
        const Ax = kernelMatVec(A, v, cols);
        // Step 2: AtAx = A^T * (A * v)
        const AtAx = kernelMatTransposeVec(A, Ax, rows);

        // Calculate Rayleigh quotient: (v^T * AtAx) / (v^T * v)
        let currentLambda = 0;
        for (let i = 0; i < cols; i++) {
            currentLambda += v[i] * AtAx[i];
        }

        const nextV = normalize(Array.from(AtAx));

        if (Math.abs(currentLambda - lambdaMax) < tolerance) {
            lambdaMax = currentLambda;
            break;
        }

        lambdaMax = currentLambda;
        v = nextV;
    }

    return { lambdaMax, eigenvector: v };
}

Step 2: Calculating the Minimum Eigenvalue (\(\lambda_{\min}\))

Because \(M = A^T A\) is positive semi-definite, its eigenvalues satisfy \(0 \le \lambda_{\min} \le \lambda_{\max}\). The shifted matrix \(S = \lambda_{\max} I - M\) has eigenvalues \(\mu_i = \lambda_{\max} - \lambda_i\).

Applying the power method to \(S\) converges to its dominant eigenvalue \(\mu_{\max} = \lambda_{\max} - \lambda_{\min}\), from which \(\lambda_{\min}\) can be recovered:

\[\lambda_{\min} = \lambda_{\max} - \mu_{\max}\]

function computeMinEigenvalue(A, rows, cols, lambdaMax, maxIterations = 150, tolerance = 1e-6) {
    kernelMatVec.setOutput([rows]);
    kernelMatTransposeVec.setOutput([cols]);
    kernelShiftedMatVec.setOutput([cols]);

    let v = normalize(Array.from({ length: cols }, () => Math.random() - 0.5));
    let muMax = 0;

    for (let iter = 0; iter < maxIterations; iter++) {
        const Ax = kernelMatVec(A, v, cols);
        const AtAx = kernelMatTransposeVec(A, Ax, rows);
        
        // Compute S * v = (lambdaMax * v) - AtAx on GPU
        const Sv = kernelShiftedMatVec(lambdaMax, Ax, AtAx, v);

        let currentMu = 0;
        for (let i = 0; i < cols; i++) {
            currentMu += v[i] * Sv[i];
        }

        const nextV = normalize(Array.from(Sv));

        if (Math.abs(currentMu - muMax) < tolerance) {
            muMax = currentMu;
            break;
        }

        muMax = currentMu;
        v = nextV;
    }

    const lambdaMin = Math.max(0, lambdaMax - muMax);
    return lambdaMin;
}

Step 3: Computing the Condition Number

Combine both procedures to evaluate the condition number \(\kappa(A)\):

function calculateConditionNumber(A) {
    const rows = A.length;
    const cols = A[0].length;

    const { lambdaMax } = computeMaxEigenvalue(A, rows, cols);

    if (lambdaMax <= 1e-12) {
        return Infinity; // Matrix is essentially zero
    }

    const lambdaMin = computeMinEigenvalue(A, rows, cols, lambdaMax);

    if (lambdaMin <= 1e-12) {
        return Infinity; // Matrix is singular or rank-deficient
    }

    const sigmaMax = Math.sqrt(lambdaMax);
    const sigmaMin = Math.sqrt(lambdaMin);

    return sigmaMax / sigmaMin;
}

// Example usage:
const matrix = [
    [4, 1, -1],
    [2, 5, -2],
    [1, 1,  3]
];

const conditionNumber = calculateConditionNumber(matrix);
console.log(`Matrix Condition Number: ${conditionNumber.toFixed(4)}`);

Performance Considerations

  1. Memory Transfers: Keep intermediate vectors on the GPU across iterations where possible by enabling pipeline: true on your gpu.js kernels. This prevents costly GPU-to-CPU data round trips during normalization.
  2. Convergence Rates: The shifted power iteration's convergence rate depends on the spectral gap \((\lambda_{\max} - \lambda_2) / \lambda_{\max}\). If eigenvalues are clustered tightly, more iterations are required to resolve \(\lambda_{\min}\) accurately.
  3. Dimensions: For dense matrices larger than \(256 \times 256\), the parallel execution in gpu.js significantly outperforms single-threaded CPU implementations.
