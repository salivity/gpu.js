Feature Extraction and Corner Detection with GPU.js

This article explains how to implement hardware-accelerated corner detection and feature extraction using GPU.js. By translating standard JavaScript operations into WebGL shaders, GPU.js allows you to execute computer vision algorithms—specifically the Harris Corner Detector pipeline—directly on the graphics card. You will learn the mathematical pipeline behind feature detection, how to structure parallel kernel functions for image gradients and corner responses, and how to extract final feature coordinates through non-maximum suppression.

The Corner Detection Pipeline

Feature detection algorithms like the Harris Corner Detector identify points of interest by finding regions with high intensity variations in all directions. Executing this on the CPU pixel-by-pixel is computationally expensive. On the GPU, every pixel is evaluated concurrently.

The detection pipeline consists of four main phases:

  1. Grayscale Conversion: Reducing color channels to a single intensity value.
  2. Gradient Computation: Calculating spatial derivatives (\(I_x\) and \(I_y\)) using Sobel operators.
  3. Structure Tensor Calculation: Computing products of derivatives (\(I_x^2\), \(I_y^2\), \(I_x I_y\)) and smoothing them with a local filter.
  4. Corner Response & Non-Maximum Suppression (NMS): Scoring each pixel based on cornerness and filtering out non-peak values.

Step 1: Initializing GPU.js and Grayscale Conversion

Before processing, install GPU.js via npm (npm install gpu.js) or import it into your HTML page. The first kernel takes raw RGBA image data and converts it into a 2D intensity array.

const { GPU } = require('gpu.js');
const gpu = new GPU();

const toGrayscale = gpu.createKernel(function(image, width, height) {
    const x = this.thread.x;
    const y = this.thread.y;
    // GPU.js coordinates: bottom-left is (0, 0)
    const index = (y * width + x) * 4;
    const r = image[index];
    const g = image[index + 1];
    const b = image[index + 2];
    
    // Standard luminance formula
    return 0.299 * r + 0.587 * g + 0.114 * b;
}).setOutput([width, height]);

Step 2: Spatial Gradients (\(I_x\) and \(I_y\))

Next, create a kernel that applies Sobel convolution kernels to determine horizontal and vertical edge gradients.

const computeGradients = gpu.createKernel(function(gray, width, height) {
    const x = this.thread.x;
    const y = this.thread.y;

    if (x <= 0 || x >= width - 1 || y <= 0 || y >= height - 1) {
        return [0, 0];
    }

    // Horizontal Sobel (Ix)
    const gx = 
        -1 * gray[y - 1][x - 1] + 1 * gray[y - 1][x + 1] +
        -2 * gray[y][x - 1]     + 2 * gray[y][x + 1] +
        -1 * gray[y + 1][x - 1] + 1 * gray[y + 1][x + 1];

    // Vertical Sobel (Iy)
    const gy = 
        -1 * gray[y - 1][x - 1] - 2 * gray[y - 1][x] - 1 * gray[y - 1][x + 1] +
         1 * gray[y + 1][x - 1] + 2 * gray[y + 1][x] + 1 * gray[y + 1][x + 1];

    return [gx, gy];
}).setOutput([width, height]);

Step 3: Computing Harris Response (\(R\))

A corner is characterized by a matrix \(M\) formed by local gradient covariances:

\[M = \sum \begin{bmatrix} I_x^2 & I_x I_y \\ I_x I_y & I_y^2 \end{bmatrix}\]

The corner response score \(R\) is calculated as: \[R = \det(M) - k \cdot (\text{trace}(M))^2\] \[R = (S_{xx} S_{yy} - S_{xy}^2) - k \cdot (S_{xx} + S_{yy})^2\]

Where \(k\) is an empirical sensitivity constant (typically between \(0.04\) and \(0.06\)).

const computeHarrisResponse = gpu.createKernel(function(gradients, width, height, k) {
    const x = this.thread.x;
    const y = this.thread.y;
    const windowRadius = 1;

    if (x < windowRadius || x >= width - windowRadius || y < windowRadius || y >= height - windowRadius) {
        return 0;
    }

    let sxx = 0;
    let syy = 0;
    let sxy = 0;

    // Convolve over a 3x3 window
    for (let dy = -1; dy <= 1; dy++) {
        for (let dx = -1; dx <= 1; dx++) {
            const grad = gradients[y + dy][x + dx];
            const ix = grad[0];
            const iy = grad[1];
            sxx += ix * ix;
            syy += iy * iy;
            sxy += ix * iy;
        }
    }

    const det = (sxx * syy) - (sxy * sxy);
    const trace = sxx + syy;
    
    return det - k * (trace * trace);
}).setOutput([width, height]);

Step 4: Non-Maximum Suppression (NMS)

A thresholded corner response will produce clusters of high-scoring pixels around an interest point. Non-Maximum Suppression compares each score to its neighbors and keeps only local maxima.

const nonMaximumSuppression = gpu.createKernel(function(scores, width, height, threshold) {
    const x = this.thread.x;
    const y = this.thread.y;

    if (x <= 0 || x >= width - 1 || y <= 0 || y >= height - 1) {
        return 0;
    }

    const currentScore = scores[y][x];

    if (currentScore < threshold) {
        return 0;
    }

    // Check if the current pixel is greater than all surrounding neighbors
    for (let dy = -1; dy <= 1; dy++) {
        for (let dx = -1; dx <= 1; dx++) {
            if (dx === 0 && dy === 0) continue;
            if (scores[y + dy][x + dx] >= currentScore) {
                return 0;
            }
        }
    }

    return currentScore;
}).setOutput([width, height]);

Step 5: Extracting Feature Descriptors

Once the candidate corners are filtered by the GPU kernels, read the final 2D array back into standard JavaScript execution to extract the coordinates and compute local feature descriptors (such as BRIEF or simple patch-based pixel vectors).

function extractKeypoints(nmsGrid, width, height) {
    const keypoints = [];

    for (let y = 0; y < height; y++) {
        for (let x = 0; x < width; x++) {
            if (nmsGrid[y][x] > 0) {
                keypoints.push({ x, y, score: nmsGrid[y][x] });
            }
        }
    }

    return keypoints;
}

To create descriptors, extract a fixed-size square patch (e.g., \(9 \times 9\) or \(16 \times 16\)) centered at each keypoint from the original grayscale image. Normalize the pixel values within this patch to create an illumination-invariant descriptor vector for tasks such as object matching or image alignment.
