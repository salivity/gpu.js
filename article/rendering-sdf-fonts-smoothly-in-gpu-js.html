Rendering SDF Fonts Smoothly in GPU.js

This guide explains how to render Signed Distance Field (SDF) text glyphs smoothly at arbitrary zoom levels using GPU.js. You will learn the mechanics of SDF textures, how to implement scale-aware smoothing to prevent pixelation and edge degradation, and how to write an efficient GPU.js kernel that dynamically sharpens or softens text edges across any scale factor.

Understanding Signed Distance Fields for Text

Traditional bitmap fonts store direct pixel opacity, which causes text to blur when enlarged and alias (pixelate) when scaled down. A Signed Distance Field (SDF) atlas instead encodes the distance from each pixel to the nearest glyph edge. By convention:

  • Values below 0.5 represent points outside the glyph.
  • A value of exactly 0.5 represents the exact edge boundary.
  • Values above 0.5 represent points inside the glyph.

Because distance changes linearly across space, a GPU can continuously reconstruct crisp vector edges at any resolution by evaluating where this boundary lies.

Step 1: Prepare the SDF Atlas

Before processing in GPU.js, generate an SDF font atlas using a generator such as stb_truetype or msdf-bmfont-xml. Load this atlas into an HTML Image or convert it into a normalized 2D/3D numerical array representing grayscale distance values ranging from 0.0 to 1.0.

Step 2: Formulate Scale-Dependent Anti-Aliasing

In standard WebGL shaders, screen-space derivatives like fwidth() dynamically calculate edge anti-aliasing. Because GPU.js transpiles standard JavaScript math to WebGL, you must explicitly pass a zoom or scale parameter to compute the edge smoothing transition.

The transition range (anti-aliasing band) is inversely proportional to the zoom factor:

\[\text{smoothing} = \frac{\text{spread}}{\text{fontSize} \times \text{zoom}}\]

  • Spread: The distance range in pixels configured when generating the SDF atlas (typically 4 to 8 pixels).
  • Zoom: The current rendering scale.

Using a smoothstep function over the interval [0.5 - smoothing, 0.5 + smoothing] provides smooth, anti-aliased edges without blur.

Step 3: Implement the GPU.js Kernel

Below is a complete GPU.js kernel setup designed to render SDF font glyphs to a canvas.

const { GPU } = require('gpu.js');
const gpu = new GPU();

// Custom smoothstep implementation compatible with GPU.js transpilation
function smoothstep(edge0, edge1, x) {
  const t = Math.max(0, Math.min(1, (x - edge0) / (edge1 - edge0)));
  return t * t * (3 - 2 * t);
}
gpu.addFunction(smoothstep);

const renderSDFGlyph = gpu.createKernel(function(sdfAtlas, glyphUvBounds, zoom, textColor) {
  // Map thread coordinates to screen space
  const x = this.thread.x;
  const y = this.thread.y;

  // Calculate normalized UV coordinates within the SDF atlas for this pixel
  const uMin = glyphUvBounds[0];
  const vMin = glyphUvBounds[1];
  const uMax = glyphUvBounds[2];
  const vMax = glyphUvBounds[3];

  const u = uMin + (x / this.output.x) * (uMax - uMin);
  const v = vMin + (y / this.output.y) * (vMax - vMin);

  // Sample distance from the atlas (atlas texture dimensions mapped)
  const atlasX = Math.floor(u * 512);
  const atlasY = Math.floor(v * 512);
  const distance = sdfAtlas[atlasY][atlasX];

  // Dynamic anti-aliasing threshold derived from zoom level
  const baseSpread = 8.0; 
  const smoothing = baseSpread / (32.0 * zoom);

  // Compute final edge alpha
  const alpha = smoothstep(0.5 - smoothing, 0.5 + smoothing, distance);

  // Set the output pixel (RGBA)
  this.color(textColor[0], textColor[1], textColor[2], alpha * textColor[3]);
})
.setOutput([256, 256])
.setGraphical(true);

Step 4: Manage Scaling and Edge Sharpness

To maintain consistent visual clarity across extreme magnification ranges:

  1. High Zoom (Close-Up): The smoothing width decreases, ensuring that high-resolution magnification does not produce fuzzy contours.
  2. Low Zoom (Far-Out): The smoothing width expands across the distance field, suppressing subpixel aliasing and jitter.
  3. Atlas Precision: If rendering glyphs at very small sizes (under 12px), single-channel SDF can exhibit rounded corners. To correct this, implement Multi-channel Signed Distance Fields (MSDF), where the kernel checks the median of three color channels (RGB) rather than a single scalar distance:
function median(r, g, b) {
  return Math.max(Math.min(r, g), Math.min(Math.max(r, g), b));
}

By computing the coverage value dynamically through smoothstep scaled to the current transformation matrix, GPU.js renders vector-quality text at any camera distance with minimal memory overhead.
