Computing Multi-Head Attention with GPU.js

This article explains how to implement the scaled dot-product stage of multi-head self-attention using GPU.js. You will learn how to structure multidimensional tensor data for parallel execution, write custom GPU kernels to compute parallel matrix multiplications for query and key matrices, scale the attention scores, and apply the softmax normalization and value aggregation directly on the GPU.

Core Formula and Dimensions

Scaled dot-product attention maps queries (\(Q\)), keys (\(K\)), and values (\(V\)) to an output matrix according to the equation:

\[\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{Q K^T}{\sqrt{d_k}}\right) V\]

In multi-head attention, the sequence is divided across \(H\) independent heads, where each head operates on vectors of dimension \(d_k\).

Given:

  • numHeads (\(H\)): Number of parallel attention heads.
  • seqLen (\(S\)): Length of the input token sequence.
  • depth (\(d_k\)): Dimension per head (\(d_{model} / H\)).

The primary tensors are structured as 3D arrays with dimensions [numHeads][seqLen][depth].

Step 1: Initializing GPU.js

Install and import GPU.js in your environment (Node.js or browser), then create a GPU instance:

const { GPU } = require('gpu.js');
const gpu = new GPU();

Step 2: Computing Scaled \(Q K^T\)

The first kernel computes the dot product between queries and keys for each head, dividing by \(\sqrt{d_k}\) in the same execution pass.

In GPU.js, thread coordinates run along \(X\), \(Y\), and \(Z\):

  • this.thread.x: Target column index (key sequence index \(j\))
  • this.thread.y: Target row index (query sequence index \(i\))
  • this.thread.z: Head index (\(h\))
const createScaledDotProductKernel = (seqLen, depth, numHeads) => {
  return gpu.createKernel(function (Q, K, sqrtDk) {
    const kIdx = this.thread.x;
    const qIdx = this.thread.y;
    const head = this.thread.z;

    let sum = 0.0;
    for (let d = 0; d < this.constants.depth; d++) {
      sum += Q[head][qIdx][d] * K[head][kIdx][d];
    }

    return sum / sqrtDk;
  })
  .setConstants({ depth })
  .setOutput([seqLen, seqLen, numHeads]);
};

Step 3: Row-Wise Softmax

Softmax is computed independently across the key dimension (columns) for every query row in every head. This converts raw attention logits into probabilities.

const createSoftmaxKernel = (seqLen, numHeads) => {
  return gpu.createKernel(function (scores) {
    const kIdx = this.thread.x;
    const qIdx = this.thread.y;
    const head = this.thread.z;

    // Find maximum score for numerical stability
    let maxVal = -1e9;
    for (let i = 0; i < this.constants.seqLen; i++) {
      const val = scores[head][qIdx][i];
      if (val > maxVal) {
        maxVal = val;
      }
    }

    // Compute denominator (sum of exponents)
    let sumExp = 0.0;
    for (let i = 0; i < this.constants.seqLen; i++) {
      sumExp += Math.exp(scores[head][qIdx][i] - maxVal);
    }

    // Softmax probability for current element
    const currentScore = scores[head][qIdx][kIdx];
    return Math.exp(currentScore - maxVal) / sumExp;
  })
  .setConstants({ seqLen })
  .setOutput([seqLen, seqLen, numHeads]);
};

Step 4: Value Aggregation (\(\text{Weights} \times V\))

Multiply the calculated attention probabilities with the value matrix \(V\) to compute the weighted representation:

  • this.thread.x: Value feature index (\(d \in [0, d_k)\))
  • this.thread.y: Query token index (\(i \in [0, seqLen)\))
  • this.thread.z: Head index (\(h \in [0, numHeads)\))
const createAttentionOutputKernel = (seqLen, depth, numHeads) => {
  return gpu.createKernel(function (weights, V) {
    const dIdx = this.thread.x;
    const qIdx = this.thread.y;
    const head = this.thread.z;

    let sum = 0.0;
    for (let s = 0; s < this.constants.seqLen; s++) {
      sum += weights[head][qIdx][s] * V[head][s][dIdx];
    }

    return sum;
  })
  .setConstants({ seqLen })
  .setOutput([depth, seqLen, numHeads]);
};

Step 5: Execution Pipeline

Chain the compiled kernels together to process the tensors:

function runMultiHeadAttention(Q, K, V, seqLen, depth, numHeads) {
  const sqrtDk = Math.sqrt(depth);

  // Compile kernels
  const dotProductKernel = createScaledDotProductKernel(seqLen, depth, numHeads);
  const softmaxKernel = createSoftmaxKernel(seqLen, numHeads);
  const outputKernel = createAttentionOutputKernel(seqLen, depth, numHeads);

  // Pipeline execution
  // 1. Raw scaled scores: [numHeads][seqLen][seqLen]
  const scaledScores = dotProductKernel(Q, K, sqrtDk);

  // 2. Softmax normalization: [numHeads][seqLen][seqLen]
  const attentionWeights = softmaxKernel(scaledScores);

  // 3. Final weighted aggregation: [numHeads][seqLen][depth]
  const context = outputKernel(attentionWeights, V);

  return context;
}

Performance Considerations

  1. Pipeline Mode: Set pipeline: true on upstream kernels (like dotProductKernel and softmaxKernel) to keep intermediate matrices in WebGL texture memory instead of serializing data back to the CPU between steps.
  2. Dimension Order: GPU.js handles thread loops from inner to outer as x, then y, then z. Mapping the reduction axis to loop indices inside the kernel guarantees maximum parallel occupancy across your hardware's compute units.
