Simulating Gray-Scott Reaction-Diffusion with GPU.js

This guide demonstrates how to build a high-performance Gray-Scott reaction-diffusion simulation running directly in the browser using gpu.js. You will learn the core mathematical principles behind the Gray-Scott model, how to express the discrete Laplacian operator on a two-dimensional grid, and how to harness WebGL hardware acceleration to compute and visualize dynamic Turing patterns at real-time frame rates.

The Gray-Scott Model Equations

The Gray-Scott model simulates the interaction of two virtual chemical substances, \(U\) and \(V\). Over time, these chemicals diffuse across a grid, react with one another, and are replenished or removed at specific rates. The reaction converts two units of \(V\) and one unit of \(U\) into three units of \(V\) (\(2V + U \to 3V\)).

The spatial changes over time are governed by two coupled partial differential equations:

\[\frac{\partial u}{\partial t} = D_u \nabla^2 u - uv^2 + F(1 - u)\]

\[\frac{\partial v}{\partial t} = D_v \nabla^2 v + uv^2 - (F + k)v\]

Where:

  • \(u\) and \(v\) represent chemical concentrations between \(0.0\) and \(1.0\).
  • \(D_u\) and \(D_v\) are diffusion coefficients (\(D_u\) is typically significantly higher than \(D_v\)).
  • \(\nabla^2\) is the 2D Laplacian operator modeling diffusion to neighboring cells.
  • \(F\) is the feed rate replenishing \(U\).
  • \(k\) is the kill rate removing \(V\).

Approximating the Laplacian Operator

On a discrete 2D grid, the Laplacian \(\nabla^2\) is computed by taking the weighted sum of adjacent cells using a standard convolution matrix. A common 9-point stencil is:

  • Center cell: weight of -1.0
  • Orthogonal neighbors (up, down, left, right): weight of 0.2
  • Diagonal neighbors: weight of 0.05

Setting Up GPU.js

GPU.js allows you to write complex math in JavaScript and automatically compiles it into GLSL shaders running on the GPU. Because a reaction-diffusion simulation reads from the previous frame to write the next, you must maintain two state textures and swap them iteratively (ping-pong buffering).

1. Installation

Include GPU.js via CDN in your HTML file:

<script src="https://cdn.jsdelivr.net/npm/gpu.js@latest/dist/gpu-browser.min.js"></script>
<canvas id="renderCanvas" width="512" height="512"></canvas>

2. State Initialization

Initialize two 2D arrays: one for chemical \(U\) (initialized mostly to 1.0) and one for chemical \(V\) (initialized mostly to 0.0 with a small perturbed seed region in the center):

const width = 512;
const height = 512;

let gridU = [];
let gridV = [];

for (let y = 0; y < height; y++) {
  gridU[y] = [];
  gridV[y] = [];
  for (let x = 0; x < width; x++) {
    gridU[y][x] = 1.0;
    // Seed a central square with chemical V
    if (x > 240 && x < 272 && y > 240 && y < 272) {
      gridV[y][x] = 1.0;
    } else {
      gridV[y][x] = 0.0;
    }
  }
}

3. Creating the Computation Kernels

You need two computational kernels: one to update chemical \(U\) and one to update chemical \(V\). Set pipeline: true so the output remains in GPU VRAM between steps.

const gpu = new GPU();

const Du = 0.2097;
const Dv = 0.105;
const F = 0.0545; // Feed rate
const K = 0.062;  // Kill rate
const dt = 1.0;

const updateU = gpu.createKernel(function(gridU, gridV, Du, F, dt) {
  const x = this.thread.x;
  const y = this.thread.y;

  const u = gridU[y][x];
  const v = gridV[y][x];

  // 9-point stencil Laplacian
  const lapU = 
    gridU[y - 1][x] * 0.2 +
    gridU[y + 1][x] * 0.2 +
    gridU[y][x - 1] * 0.2 +
    gridU[y][x + 1] * 0.2 +
    gridU[y - 1][x - 1] * 0.05 +
    gridU[y - 1][x + 1] * 0.05 +
    gridU[y + 1][x - 1] * 0.05 +
    gridU[y + 1][x + 1] * 0.05 -
    u;

  const uvv = u * v * v;
  const du = (Du * lapU - uvv + F * (1.0 - u)) * dt;
  
  return Math.max(0.0, Math.min(1.0, u + du));
})
.setOutput([width, height])
.setPipeline(true)
.setImmutable(true);

const updateV = gpu.createKernel(function(gridU, gridV, Dv, F, K, dt) {
  const x = this.thread.x;
  const y = this.thread.y;

  const u = gridU[y][x];
  const v = gridV[y][x];

  // 9-point stencil Laplacian
  const lapV = 
    gridV[y - 1][x] * 0.2 +
    gridV[y + 1][x] * 0.2 +
    gridV[y][x - 1] * 0.2 +
    gridV[y][x + 1] * 0.2 +
    gridV[y - 1][x - 1] * 0.05 +
    gridV[y - 1][x + 1] * 0.05 +
    gridV[y + 1][x - 1] * 0.05 +
    gridV[y + 1][x + 1] * 0.05 -
    v;

  const uvv = u * v * v;
  const dv = (Dv * lapV + uvv - (F + K) * v) * dt;

  return Math.max(0.0, Math.min(1.0, v + dv));
})
.setOutput([width, height])
.setPipeline(true)
.setImmutable(true);

4. Creating the Render Kernel

The rendering kernel reads the current state texture of chemical \(V\) and writes color components directly to an HTML5 canvas.

const canvas = document.getElementById('renderCanvas');

const render = gpu.createKernel(function(gridU, gridV) {
  const u = gridU[this.thread.y][this.thread.x];
  const v = gridV[this.thread.y][this.thread.x];

  // Color mapping based on chemical concentrations
  const value = 1.0 - v;
  this.color(value, value * 0.8, value * 0.9, 1.0);
})
.setOutput([width, height])
.setOutputToTexture(false)
.setCanvas(canvas);

5. Running the Simulation Loop

Run several calculation sub-steps per animation frame to accelerate the visible formation of patterns without introducing numerical instability.

function step() {
  const iterationsPerFrame = 8;

  for (let i = 0; i < iterationsPerFrame; i++) {
    const nextU = updateU(gridU, gridV, Du, F, dt);
    const nextV = updateV(gridU, gridV, Dv, F, K, dt);

    // Free previous GPU textures to prevent memory leaks
    if (gridU.delete) gridU.delete();
    if (gridV.delete) gridV.delete();

    gridU = nextU;
    gridV = nextV;
  }

  render(gridU, gridV);
  requestAnimationFrame(step);
}

requestAnimationFrame(step);

Pattern Tuning Reference

The visual outputs depend strongly on \(F\) and \(k\). Small variations create drastically different morphological structures:

  • Solitons / Spots: \(F = 0.030\), \(k = 0.062\)
  • Labyrinths / Mazes: \(F = 0.029\), \(k = 0.057\)
  • Dividing Cells / Mitosis: \(F = 0.0367\), \(k = 0.0649\)
  • Spirals / Chaotic Waves: \(F = 0.018\), \(k = 0.051\)
