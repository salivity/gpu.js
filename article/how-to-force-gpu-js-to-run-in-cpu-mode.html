How to Force GPU.js to Run in CPU Mode

GPU.js allows developers to offload complex JavaScript computations to the GPU using WebGL. However, for unit testing, continuous integration (CI) pipelines, and benchmarking, you can explicitly force GPU.js to execute entirely on the CPU. This article explains how to configure GPU.js to run in CPU fallback mode using the built-in configuration options.

To force GPU.js to run on the CPU globally, pass the mode option set to 'cpu' when instantiating the main GPU class:

const { GPU } = require('gpu.js');

// Force CPU execution globally
const gpu = new GPU({ mode: 'cpu' });

When initialized with { mode: 'cpu' }, any kernel created by this instance will compile to pure JavaScript and execute on the CPU via standard loops instead of compiling to WebGL shaders.

Alternatively, if you want a GPU-enabled instance but need to force CPU mode for a specific kernel, you can configure the mode directly on the kernel:

const gpu = new GPU();

const myKernel = gpu.createKernel(function(a, b) {
  return a[this.thread.x] + b[this.thread.x];
}, {
  mode: 'cpu'
}).setOutput([100]);

Use Cases for CPU Mode

  1. Headless CI/CD and Unit Testing: Cloud build agents (such as GitHub Actions, GitLab CI, or Travis CI) often lack dedicated graphics cards and WebGL context. Forcing CPU mode allows unit test runners (like Jest or Mocha) to validate mathematical logic and output accuracy without crashing due to missing WebGL drivers.
  2. Benchmarking Performance: Comparing execution times between GPU and CPU implementations is essential for determining whether your dataset is large enough to overcome the overhead of transferring data to the graphics card. Creating two instances—one with default settings and one with { mode: 'cpu' }—allows you to accurately measure execution differences side-by-side.
  3. Debugging and Breakpoints: Debugging WebGL shaders in JavaScript can be difficult. Running in CPU mode allows you to use standard debugging tools, inspect variables at specific loop iterations, and log values directly to the console.
