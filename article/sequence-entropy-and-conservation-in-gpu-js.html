Sequence Entropy and Conservation in gpu.js

This article explains how to compute Shannon sequence entropy and position-specific conservation scores across large aligned genomic profiles using gpu.js. By parallelizing frequency counts and logarithmic calculations across alignment columns on the GPU, you can accelerate bioinformatics workflows directly in JavaScript environments such as Node.js or modern web browsers.

Mathematical Formulation

For an alignment containing \(N\) sequences of length \(L\), the conservation of each column position \(x\) is typically evaluated using Shannon entropy (\(H\)):

\[H(x) = -\sum_{i \in \{A, C, G, T\}} p_i(x) \log_2(p_i(x))\]

Where \(p_i(x)\) represents the relative frequency of nucleotide \(i\) at column \(x\). Because standard DNA alignments have four possible states (excluding gaps), the theoretical maximum entropy is \(\log_2(4) = 2\text{ bits}\).

The conservation score \(R(x)\) can be defined as the uncertainty reduction:

\[R(x) = 2 - H(x)\]

A completely conserved position yields an entropy of 0 and a conservation score of 2, while a totally random distribution across all four bases yields an entropy of 2 and a conservation score of 0.

Data Encoding for the GPU

GPU kernels operate most efficiently on numerical arrays rather than strings. Before passing the aligned sequences to gpu.js, convert the text characters into integer tokens:

  • 0: Adenine (A)
  • 1: Cytosine (C)
  • 2: Guanine (G)
  • 3: Thymine (T)
  • 4: Gap (-)

The profile is formatted as a 2D matrix where dimensions correspond to [numSequences][alignmentLength].

Implementation with gpu.js

Below is the complete implementation using gpu.js to parallelize the column-wise calculation.

import { GPU } from 'gpu.js';

const gpu = new GPU();

/**
 * Creates a GPU kernel to compute conservation scores per alignment column.
 * @param {number} numSequences - Number of aligned profiles (rows)
 * @param {number} alignmentLength - Length of the alignment (columns)
 */
function createConservationKernel(numSequences, alignmentLength) {
  return gpu.createKernel(function (matrix) {
    const col = this.thread.x;
    
    let countA = 0;
    let countC = 0;
    let countG = 0;
    let countT = 0;
    let validBases = 0;

    // Tally nucleotide occurrences in column 'col'
    for (let row = 0; row < this.constants.numSequences; row++) {
      const base = matrix[row][col];
      if (base === 0) { countA++; validBases++; }
      else if (base === 1) { countC++; validBases++; }
      else if (base === 2) { countG++; validBases++; }
      else if (base === 3) { countT++; validBases++; }
      // Gaps (4) are excluded from the conservation calculation
    }

    if (validBases === 0) {
      return 0; // Return 0 conservation if the column is entirely gaps
    }

    // Calculate probabilities
    const pA = countA / validBases;
    const pC = countC / validBases;
    const pG = countG / validBases;
    const pT = countT / validBases;

    // Compute Shannon Entropy: H = -sum(p * log2(p))
    // GPU functions support natural log: log2(p) = ln(p) / ln(2)
    const LN2 = 0.69314718056;
    let entropy = 0.0;

    if (pA > 0.0) { entropy -= pA * (Math.log(pA) / LN2); }
    if (pC > 0.0) { entropy -= pC * (Math.log(pC) / LN2); }
    if (pG > 0.0) { entropy -= pG * (Math.log(pG) / LN2); }
    if (pT > 0.0) { entropy -= pT * (Math.log(pT) / LN2); }

    // Conservation Score: Max Entropy (2 bits) - Observed Entropy
    const conservation = 2.0 - entropy;

    return conservation;
  })
  .setConstants({ numSequences })
  .setOutput([alignmentLength]);
}

Executing the Kernel

Encode your alignment and invoke the kernel:

// Example: 4 sequences of length 6
const rawAlignment = [
  "ACGT--",
  "ACGT-T",
  "ACGT-T",
  "AGGT-T"
];

const charMap = { 'A': 0, 'C': 1, 'G': 2, 'T': 3, '-': 4 };

const numSequences = rawAlignment.length;
const alignmentLength = rawAlignment[0].length;

// Pre-process into numerical 2D array
const numericMatrix = rawAlignment.map(seq => 
  seq.split('').map(char => charMap[char] ?? 4)
);

// Compile and run the kernel
const computeScores = createConservationKernel(numSequences, alignmentLength);
const conservationScores = computeScores(numericMatrix);

console.log("Column Conservation Scores:", Array.from(conservationScores));

Key Considerations for GPU Acceleration

  1. Logarithm of Zero: In GPU kernels, executing Math.log(0) results in NaN or -Infinity. Guard every logarithmic step with a strict check (p > 0.0).
  2. Memory Layout: When processing tens of thousands of sequences, ensure data is passed using typed arrays (e.g., Float32Array or Int32Array) to prevent high garbage collection overhead and reduce host-to-device memory transfer latency.
  3. Handling Gaps: Depending on the specific biological application, gaps can either be treated as an independent 5th state (setting theoretical maximum entropy to \(\log_2(5) \approx 2.32\) bits) or penalized separately as done in the implementation above.
