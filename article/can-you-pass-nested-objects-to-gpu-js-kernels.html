Can You Pass Nested Objects to GPU.js Kernels?

GPU.js allows developers to accelerate complex JavaScript computations through WebGL shaders, but it strictly limits the data types that can be supplied to a kernel function. This article explores whether object literals with nested properties can be passed as kernel arguments, explains the underlying WebGL limitations that prevent it, and details the standard workarounds used to feed structured data into GPU-accelerated code.

The short answer is no. GPU.js does not support passing JavaScript object literals with nested properties directly into a kernel function. If you attempt to pass an object like { settings: { threshold: 0.5, scale: 2 } }, GPU.js will fail during compilation or execution because WebGL shaders cannot parse dynamic, nested JavaScript object structures.

GPU.js works by transpiling JavaScript functions into WebGL shader code (GLSL). GLSL is a strictly typed, low-level shading language designed to execute on the GPU. In GLSL, function inputs (uniforms) must map to fixed hardware types, such as integers, floats, vectors, matrices, or sampler textures. Because the GPU has no JavaScript runtime, it lacks memory pointers, dynamic heaps, and mechanisms to traverse nested object hierarchies.

To supply values contained in nested objects to your GPU.js kernels, use one of the following alternatives:

1. Flattening into Primitive Arguments Extract the individual nested values in JavaScript before invoking the kernel, and pass them as flat, primitive scalar types (integers or floats).

// Instead of passing: { config: { speed: 1.5, factor: 3 } }
const speed = config.speed;
const factor = config.factor;

const kernel = gpu.createKernel(function(speed, factor) {
  return this.thread.x * speed + factor;
}).setOutput([100]);

kernel(speed, factor);

2. Flattening into Flat Arrays or TypedArrays If your nested object holds sequences of numerical data, convert the nested hierarchy into a flat 1D or 2D array or a Float32Array. GPU.js natively supports standard arrays and typed arrays, mapping them directly to GPU memory buffers.

// Instead of passing: [{ pos: { x: 1, y: 2 } }, { pos: { x: 3, y: 4 } }]
// Flatten to: [1, 2, 3, 4]
const flattenedPositions = [1, 2, 3, 4];

const kernel = gpu.createKernel(function(positions) {
  const index = this.thread.x * 2;
  const x = positions[index];
  const y = positions[index + 1];
  return x + y;
}).setOutput([2]);

kernel(flattenedPositions);

3. Packing Data into Textures For larger datasets, pack your structured values into custom image textures or use GPU.js input textures via gpu.createKernelMap or gpu.mode = 'gpu'. Each pixel in a texture can store four floating-point values (RGBA), serving as an efficient container for uniform structured records.
