GPU.js 2D Delaunay Triangulation Circumcircles

Computing 2D Delaunay triangulation updates on the GPU involves parallelizing the empty circumcircle test using spatial predicates. This article demonstrates how to translate the geometric in-circle determinant into a GPU kernel using gpu.js, how to format triangle and vertex buffers for massively parallel execution, and how to query circumcircle violations to drive dynamic triangulation algorithms like Bowyer-Watson.

The In-Circle Predicate

A triangle formed by vertices \(A(x_a, y_a)\), \(B(x_b, y_b)\), and \(C(x_c, y_c)\) in counter-clockwise (CCW) order satisfies the Delaunay condition for a test point \(P(x_p, y_p)\) if \(P\) lies outside the triangle's circumcircle.

This geometric check evaluates the sign of the following \(3 \times 3\) determinant:

\[ \det \begin{bmatrix} x_a - x_p & y_a - y_p & (x_a - x_p)^2 + (y_a - y_p)^2 \\ x_b - x_p & y_b - y_p & (x_b - x_p)^2 + (y_b - y_p)^2 \\ x_c - x_p & y_c - y_p & (x_c - x_p)^2 + (y_c - y_p)^2 \end{bmatrix} \]

If the determinant is greater than zero, \(P\) lies strictly inside the circumcircle, violating the Delaunay condition. If it equals zero, the points are cocircular; if less than zero, \(P\) is strictly outside.

Data Layout for GPU.js

GPU kernels operate most efficiently over flat, typed arrays or 2D coordinate matrices. To verify multiple triangles simultaneously against an inserted point, represent the existing triangulation as flattened vertex coordinates:

// Triangle vertices arranged counter-clockwise: [Ax, Ay, Bx, By, Cx, Cy]
const triangles = [
  0.0, 0.0,  2.0, 0.0,  1.0, 2.0, // Triangle 0
  2.0, 0.0,  3.0, 2.0,  1.0, 2.0  // Triangle 1
];

// Query point P to test against all circumcircles
const queryPoint = [1.0, 0.5];

Implementing the Circumcircle Kernel

Using gpu.js, you can compile a kernel that assigns one thread per triangle. Each thread loads the three triangle vertices, computes the determinant relative to the query point, and outputs a flag indicating a circumcircle violation.

const { GPU } = require('gpu.js');
const gpu = new GPU();

const checkInCircleKernel = gpu.createKernel(function(triangles, px, py) {
  const triIndex = this.thread.x * 6;

  // Triangle vertices
  const ax = triangles[triIndex];
  const ay = triangles[triIndex + 1];
  const bx = triangles[triIndex + 2];
  const by = triangles[triIndex + 3];
  const cx = triangles[triIndex + 4];
  const cy = triangles[triIndex + 5];

  // Coordinates relative to query point P
  const adx = ax - px;
  const ady = ay - py;
  const bdx = bx - px;
  const bdy = by - py;
  const cdx = cx - px;
  const cdy = cy - py;

  // Squared distances from relative origin
  const alift = adx * adx + ady * ady;
  const blift = bdx * bdx + bdy * bdy;
  const clift = cdx * cdx + cdy * cdy;

  // Compute 3x3 determinant
  const det = 
    adx * (bdy * clift - blift * cdy) -
    ady * (bdx * clift - blift * cdx) +
    alift * (bdx * cdy - bdy * cdx);

  // Return 1 if inside circumcircle (violation), otherwise 0
  return det > 0.000001 ? 1 : 0;
}).setOutput([triangles.length / 6]);

Applying the Results to Triangulation Updates

The kernel returns an array of binary flags corresponding to each triangle in the mesh:

  1. Cavity Identification: Triangles flagged with 1 have circumcircles that contain the newly inserted point. In an incremental Bowyer-Watson algorithm, these flagged triangles form the insertion cavity.
  2. Boundary Extraction: On the CPU or through a secondary reduction kernel, gather the outer boundary edges of the cavity by removing shared internal edges between flagged triangles.
  3. Re-triangulation: Connect the query point to each vertex on the boundary of the cavity to form new Delaunay-compliant triangles.
  4. Buffer Synchronization: Append the newly formed triangles to the coordinate buffer and remove the invalid ones before executing the next GPU check.
