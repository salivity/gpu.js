Compute Structure Tensor Fields Using GPU.js

This article explains how to construct and analyze structure tensor fields using gpu.js to determine local image orientation and feature coherence in JavaScript. By accelerating pixel-level operations on the GPU, you will learn the mathematical foundation of structure tensors, how to calculate spatial image gradients, smooth the tensor components, and extract local orientation angles and anisotropy with high performance.

Understanding the Structure Tensor

A structure tensor (often called the second-moment matrix) summarizes the predominant directions of the gradient in a specified neighborhood of a point. For a 2D grayscale image \(I(x, y)\), the gradients along the horizontal and vertical axes are \(I_x\) and \(I_y\).

The structure tensor \(J\) is defined as:

\[ J = \begin{bmatrix} K_\sigma * I_x^2 & K_\sigma * (I_x I_y) \\ K_\sigma * (I_x I_y) & K_\sigma * I_y^2 \end{bmatrix} = \begin{bmatrix} J_{xx} & J_{xy} \\ J_{xy} & J_{yy} \end{bmatrix} \]

where \(K_\sigma\) is a Gaussian smoothing filter that defines the integration scale.

From the components of \(J\), the dominant local orientation \(\theta\) is derived using:

\[ \theta = \frac{1}{2} \operatorname{atan2}(2 J_{xy}, J_{xx} - J_{yy}) \]

The degree of directional consensus (coherence) can be calculated via eigenvalues \(\lambda_1\) and \(\lambda_2\):

\[ C = \left( \frac{\lambda_1 - \lambda_2}{\lambda_1 + \lambda_2} \right)^2 = \frac{(J_{xx} - J_{yy})^2 + 4 J_{xy}^2}{(J_{xx} + J_{yy})^2} \]

Step 1: Initializing GPU.js and Computing Gradients

Compute the partial derivatives \(I_x\) and \(I_y\) using a Sobel operator. Initialize the GPU instance and configure a kernel to output a 2-channel vector containing the gradients.

const { GPU } = require('gpu.js');
const gpu = new GPU();

const computeGradients = gpu.createKernel(function(image, width, height) {
    const x = this.thread.x;
    const y = this.thread.y;

    if (x === 0 || x === width - 1 || y === 0 || y === height - 1) {
        return [0, 0];
    }

    // Sobel horizontal gradient (Ix)
    const gx = 
        -1 * image[y - 1][x - 1] + 1 * image[y - 1][x + 1] +
        -2 * image[y][x - 1]     + 2 * image[y][x + 1] +
        -1 * image[y + 1][x - 1] + 1 * image[y + 1][x + 1];

    // Sobel vertical gradient (Iy)
    const gy = 
        -1 * image[y - 1][x - 1] - 2 * image[y - 1][x] - 1 * image[y - 1][x + 1] +
         1 * image[y + 1][x - 1] + 2 * image[y + 1][x] + 1 * image[y + 1][x + 1];

    return [gx, gy];
})
.setOutput([width, height])
.setPipeline(true);

Step 2: Generating and Smoothing Tensor Components

The second step computes the outer product components (\(I_x^2\), \(I_y^2\), \(I_x I_y\)) and applies local neighborhood averaging. Combining the component calculation and spatial integration into a single kernel reduces memory transfers.

const computeSmoothedTensor = gpu.createKernel(function(gradients, width, height, radius) {
    const x = this.thread.x;
    const y = this.thread.y;

    let jxx = 0;
    let jyy = 0;
    let jxy = 0;
    let count = 0;

    // Apply a box filter integration window
    for (let dy = -radius; dy <= radius; dy++) {
        for (let dx = -radius; dx <= radius; dx++) {
            const nx = x + dx;
            const ny = y + dy;

            if (nx >= 0 && nx < width && ny >= 0 && ny < height) {
                const grad = gradients[ny][nx];
                const ix = grad[0];
                const iy = grad[1];

                jxx += ix * ix;
                jyy += iy * iy;
                jxy += ix * iy;
                count++;
            }
        }
    }

    return [jxx / count, jyy / count, jxy / count];
})
.setOutput([width, height])
.setPipeline(true);

Step 3: Deriving Local Orientation and Coherence

Extract the local orientation angle \(\theta\) and feature coherence from the smoothed tensor components \(J_{xx}\), \(J_{yy}\), and \(J_{xy}\).

const computeOrientationField = gpu.createKernel(function(tensors) {
    const tensor = tensors[this.thread.y][this.thread.x];
    const jxx = tensor[0];
    const jyy = tensor[1];
    const jxy = tensor[2];

    // Calculate orientation angle in radians [-PI/2, PI/2]
    const angle = 0.5 * Math.atan2(2 * jxy, jxx - jyy);

    // Calculate coherence [0, 1]
    const trace = jxx + jyy;
    let coherence = 0;
    if (trace > 0.00001) {
        const diff = jxx - jyy;
        coherence = ((diff * diff) + (4 * jxy * jxy)) / (trace * trace);
    }

    // Output: [angle, coherence]
    return [angle, coherence];
})
.setOutput([width, height]);

Executing the Pipeline

Combine the kernels sequentially. Enabling setPipeline(true) on intermediate steps keeps the data buffers in GPU VRAM, preventing CPU-GPU bottlenecking.

function analyzeOrientation(imageMatrix, width, height, integrationRadius = 3) {
    // 1. Compute spatial gradients on GPU
    const gradients = computeGradients(imageMatrix, width, height);

    // 2. Compute integrated tensor elements on GPU
    const tensors = computeSmoothedTensor(gradients, width, height, integrationRadius);

    // 3. Extract final orientation angle and coherence
    const orientationField = computeOrientationField(tensors);

    // Free intermediate textures from GPU memory
    gradients.delete();
    tensors.delete();

    return orientationField;
}

The output matrix contains pairs of [angle, coherence] for every pixel. An angle close to \(0\) indicates horizontal structures, \(\pm\pi/2\) represents vertical structures, and coherence values approaching \(1.0\) indicate strong, unidirectional flow (such as edges and ridges) versus isotropic noise where coherence approaches \(0.0\).
