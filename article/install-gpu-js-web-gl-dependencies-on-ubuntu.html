Install gpu.js WebGL Dependencies on Ubuntu

This article outlines the essential system libraries and build tools required to compile native WebGL bindings for gpu.js on an Ubuntu system. Because gpu.js relies on headless WebGL implementations in Node.js environments, your system must provide the appropriate C++ compilation tools, X11 libraries, and OpenGL development packages to build these native binaries successfully.

The Underlying Dependency: headless-gl

When gpu.js runs in a Node.js server environment instead of a browser, it uses headless-gl to emulate WebGL. This library contains native C/C++ bindings that are compiled during the npm install phase using node-gyp. Without the underlying Linux graphics libraries and header files, the installation will fail with compilation errors.

Required Packages

To compile these native bindings on Ubuntu, install the following core packages:

  • build-essential: Provides gcc, g++, and make necessary for compiling native C/C++ addons.
  • python3: Required by node-gyp to configure the build environment.
  • libxi-dev: Provides header files for the X11 Input extension.
  • libglu1-mesa-dev: The Mesa OpenGL Utility library headers.
  • libglew-dev: The OpenGL Extension Wrangler Library headers.
  • pkg-config: Helps the build scripts query the correct compiler flags and paths for installed libraries.
  • libx11-dev and libxext-dev: Essential X Window System client-side library headers.

Installation Steps

  1. Update your local package index:

    sudo apt-get update

  2. Install the necessary build tools and OpenGL development libraries:

    sudo apt-get install -y \
  build-essential \
  python3 \
  pkg-config \
  libxi-dev \
  libglu1-mesa-dev \
  libglew-dev \
  libx11-dev \
  libxext-dev

  3. Install gpu.js in your project:

    npm install gpu.js

Running on Headless Servers

If you are running gpu.js on a headless Ubuntu server (such as an AWS EC2 instance, Docker container, or CI/CD runner) without a physical display or running display server, you may also need a virtual framebuffer:

sudo apt-get install -y xvfb

You can then run your Node.js application utilizing virtual rendering:

xvfb-run -s "-ac -screen 0 1280x1024x24" node your-script.js
