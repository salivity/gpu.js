GPU.js Contrastive Loss for Siamese Networks

This article demonstrates how to implement contrastive loss for Siamese neural network architectures using the GPU.js library. You will learn the mathematical mechanics of contrastive loss, how to structure Siamese embedding outputs for parallel hardware acceleration, and how to write and execute a GPU-accelerated kernel in JavaScript to process batch pairwise distances and losses efficiently.

Contrastive Loss Formulation

Siamese networks output low-dimensional embedding vectors for pairs of input items. Let \(A\) and \(B\) represent two output embedding vectors of dimensionality \(D\), and let \(Y\) be a binary ground-truth label where \(Y = 1\) denotes a similar pair and \(Y = 0\) denotes a dissimilar pair.

The Euclidean distance \(d\) between the vectors is:

\[d = \sqrt{\sum_{k=0}^{D-1} (A_k - B_k)^2}\]

Contrastive loss calculates penalty based on whether items are matched or unmatched, constrained by a hyperparameter margin \(m\):

\[L = \frac{1}{2} \left[ Y \cdot d^2 + (1 - Y) \cdot \max(0, m - d)^2 \right]\]

For similar pairs (\(Y=1\)), the loss penalizes larger distances. For dissimilar pairs (\(Y=0\)), the loss penalizes pairs that are closer than the margin \(m\).

Setting Up the GPU.js Kernel

GPU.js compiles JavaScript functions into WebGL shaders (or OpenCL on supported systems), allowing fast vector operations over batches without relying on the CPU's main thread.

Install GPU.js using npm or include it via a CDN:

npm install gpu.js

Initialize the GPU instance and define your batch dimensions:

const { GPU } = require('gpu.js');
const gpu = new GPU();

const batchSize = 128;
const embeddingDim = 64;
const margin = 1.0;

Implementing the Loss Kernel

To calculate the contrastive loss in parallel across a batch, create a kernel that iterates through the vector dimensions for each thread representing a batch item.

const contrastiveLossKernel = gpu.createKernel(function(a, b, labels, margin, dim) {
    const i = this.thread.x;
    
    // Compute squared Euclidean distance
    let sumSq = 0;
    for (let k = 0; k < dim; k++) {
        const diff = a[i][k] - b[i][k];
        sumSq += diff * diff;
    }
    
    const d = Math.sqrt(sumSq);
    const y = labels[i];
    
    // Positive pair component
    const positiveLoss = y * (d * d);
    
    // Negative pair component with margin cutoff
    const marginDiff = Math.max(0, margin - d);
    const negativeLoss = (1 - y) * (marginDiff * marginDiff);
    
    return 0.5 * (positiveLoss + negativeLoss);
})
.setOutput([batchSize]);

Running Forward Inference

Pass 2D arrays for the batch embeddings and 1D arrays for the pairwise labels into the compiled kernel:

// Example synthetic data
const embeddingsA = Array.from({ length: batchSize }, () => 
    Array.from({ length: embeddingDim }, () => Math.random())
);

const embeddingsB = Array.from({ length: batchSize }, () => 
    Array.from({ length: embeddingDim }, () => Math.random())
);

// 1 for matching pairs, 0 for non-matching pairs
const labels = Array.from({ length: batchSize }, () => (Math.random() > 0.5 ? 1 : 0));

// Execute kernel on the GPU
const losses = contrastiveLossKernel(embeddingsA, embeddingsB, labels, margin, embeddingDim);

// Compute total mean batch loss
let totalLoss = 0;
for (let i = 0; i < batchSize; i++) {
    totalLoss += losses[i];
}
const meanBatchLoss = totalLoss / batchSize;

Implementing Backward Pass Gradients

Training a Siamese network requires computing the analytical gradient with respect to embedding vector \(A\) (and inversely for \(B\)). The partial derivative of the contrastive loss with respect to embedding feature \(A_{i,k}\) is:

\[\frac{\partial L}{\partial A_{i,k}} = \begin{cases} (A_{i,k} - B_{i,k}) & \text{if } Y = 1 \\ -\frac{m - d}{d}(A_{i,k} - B_{i,k}) & \text{if } Y = 0 \text{ and } d < m \\ 0 & \text{otherwise} \end{cases}\]

This can be mapped into a 2D GPU kernel:

const contrastiveGradientKernel = gpu.createKernel(function(a, b, labels, margin, dim) {
    const k = this.thread.x; // Embedding index
    const i = this.thread.y; // Batch index
    
    let sumSq = 0;
    for (let j = 0; j < dim; j++) {
        const diff = a[i][j] - b[i][j];
        sumSq += diff * diff;
    }
    
    const d = Math.max(Math.sqrt(sumSq), 1e-6); // Epsilon avoids division by zero
    const y = labels[i];
    const diff_k = a[i][k] - b[i][k];
    
    if (y === 1) {
        return diff_k;
    } else {
        if (d < margin) {
            return -((margin - d) / d) * diff_k;
        } else {
            return 0;
        }
    }
})
.setOutput([embeddingDim, batchSize]);

const gradientsA = contrastiveGradientKernel(embeddingsA, embeddingsB, labels, margin, embeddingDim);

Using these GPU.js kernels enables parallelization of forward and backward loss steps directly within JavaScript, avoiding CPU loop bottlenecks when training Siamese architectures.
