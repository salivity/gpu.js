Optical Flow Tracking in Video Frames Using GPU.js

Optical flow tracking estimates the motion of objects between consecutive video frames by calculating vector fields of apparent velocities. In client-side web applications, real-time pixel-level calculations can cause CPU bottlenecks. By leveraging GPU.js, you can offload intense matrix operations and pixel-neighborhood evaluations to the GPU via WebGL shaders, achieving high-frame-rate optical flow directly in the browser.

Core Principles of Lucas-Kanade Optical Flow

The Lucas-Kanade method is the most common algorithm for sparse and dense optical flow. It relies on the brightness constancy assumption, which states that pixel intensities do not change drastically from frame to frame:

\[I(x, y, t) = I(x + \delta x, y + \delta y, t + \delta t)\]

For small movements, this yields the optical flow constraint equation:

\[I_x u + I_y v + I_t = 0\]

Where:

  • \(I_x = \frac{\partial I}{\partial x}\) and \(I_y = \frac{\partial I}{\partial y}\) are spatial gradients.
  • \(I_t = \frac{\partial I}{\partial t}\) is the temporal gradient between the previous and current frame.
  • \(u\) and \(v\) represent horizontal and vertical velocity components.

Assuming a local neighborhood (window) of pixels moves with the same velocity, we solve this overdetermined system for each window using least-squares:

\[\begin{bmatrix} u \\ v \end{bmatrix} = \begin{bmatrix} \sum I_x^2 & \sum I_x I_y \\ \sum I_x I_y & \sum I_y^2 \end{bmatrix}^{-1} \begin{bmatrix} -\sum I_x I_t \\ -\sum I_y I_t \end{bmatrix}\]

Setting Up GPU.js

Install GPU.js via npm or import it via a CDN:

<script src="https://cdnjs.cloudflare.com/ajax/libs/gpu.js/2.16.0/gpu-browser.min.js"></script>

Initialize the GPU instance and configure the canvas size. To maximize performance, use the same dimensions as your target downsampled video stream:

const gpu = new GPU();
const width = 320;
const height = 240;

Creating the GPU Kernels

Optical flow processing requires two primary steps: grayscale conversion and gradient-based flow vector calculation.

1. Grayscale Conversion Kernel

Convert consecutive RGBA frames to single-channel intensity arrays:

const toGrayscale = gpu.createKernel(function(videoFrame) {
    const pixel = videoFrame[this.thread.y][this.thread.x];
    // Standard luminosity formula
    return 0.299 * pixel[0] + 0.587 * pixel[1] + 0.114 * pixel[2];
}).setOutput([width, height]);

2. Lucas-Kanade Flow Kernel

The optical flow kernel computes spatial gradients (\(I_x, I_y\)), temporal differences (\(I_t\)), aggregates them over a local window (e.g., \(3 \times 3\)), and inverts the \(2 \times 2\) matrix to compute \(u\) and \(v\):

const computeOpticalFlow = gpu.createKernel(function(prevFrame, currFrame) {
    const x = this.thread.x;
    const y = this.thread.y;
    const radius = 1; // 3x3 window

    let sumIx2 = 0.0;
    let sumIy2 = 0.0;
    let sumIxIy = 0.0;
    let sumIxIt = 0.0;
    let sumIyIt = 0.0;

    // Boundary check
    if (x >= radius && x < (this.constants.width - radius) && 
        y >= radius && y < (this.constants.height - radius)) {

        for (let wy = -radius; wy <= radius; wy++) {
            for (let wx = -radius; wx <= radius; wx++) {
                const px = x + wx;
                const py = y + wy;

                // Central differences for spatial gradients
                const ix = (currFrame[py][px + 1] - currFrame[py][px - 1]) * 0.5;
                const iy = (currFrame[py + 1][px] - currFrame[py - 1][px]) * 0.5;
                
                // Temporal gradient
                const it = currFrame[py][px] - prevFrame[py][px];

                sumIx2 += ix * ix;
                sumIy2 += iy * iy;
                sumIxIy += ix * iy;
                sumIxIt += ix * it;
                sumIyIt += iy * it;
            }
        }

        // Determinant of A^T * A
        const det = (sumIx2 * sumIy2) - (sumIxIy * sumIxIy);

        // Threshold to avoid division by zero in homogeneous regions
        if (Math.abs(det) > 0.0001) {
            const u = (-sumIy2 * sumIxIt + sumIxIy * sumIyIt) / det;
            const v = (-sumIx2 * sumIyIt + sumIxIy * sumIxIt) / det;
            return [u, v];
        }
    }

    return [0.0, 0.0];
}, {
    constants: { width, height },
    output: [width, height],
    returnType: 'Array(2)'
});

Running the Tracking Loop

Capture video frames using an HTML5 <video> element, draw them to a hidden canvas, pass the pixel arrays to the GPU kernels, and process the output across animation frames.

const video = document.getElementById('webcamVideo');
const canvas = document.createElement('canvas');
canvas.width = width;
canvas.height = height;
const ctx = canvas.getContext('2d');

let prevGrayscale = null;

function processFrame() {
    ctx.drawImage(video, 0, 0, width, height);
    const frameData = ctx.getImageData(0, 0, width, height).data;

    // Restructure 1D Uint8ClampedArray into a 2D/3D array [height][width][4]
    const formattedFrame = [];
    for (let y = 0; y < height; y++) {
        const row = [];
        for (let x = 0; x < width; x++) {
            const idx = (y * width + x) * 4;
            row.push([
                frameData[idx] / 255,
                frameData[idx + 1] / 255,
                frameData[idx + 2] / 255,
                frameData[idx + 3] / 255
            ]);
        }
        formattedFrame.push(row);
    }

    const currGrayscale = toGrayscale(formattedFrame);

    if (prevGrayscale) {
        // Execute the optical flow computation on GPU
        const flowVectors = computeOpticalFlow(prevGrayscale, currGrayscale);
        
        // flowVectors is a 2D array [height][width] where each item is [u, v]
        renderFlow(flowVectors);
    }

    // Keep reference for next frame
    prevGrayscale = currGrayscale;
    requestAnimationFrame(processFrame);
}

function renderFlow(flow) {
    // Example: Read velocity at center of screen
    const midY = Math.floor(height / 2);
    const midX = Math.floor(width / 2);
    const [u, v] = flow[midY][midX];
    
    // Use u and v to drive gesture controls or visual vector fields
}

// Start processing once video metadata is available
video.addEventListener('play', () => {
    requestAnimationFrame(processFrame);
});

Optimization Techniques

  • Use Kernel Pipelining: Configure pipeline: true on intermediate kernels like toGrayscale. This retains data as WebGL textures on the GPU rather than transferring large multidimensional arrays back to the CPU memory.
  • Downsample Input Resolutions: Optical flow complexity scales linearly with total pixel count. Tracking at resolutions between 160x120 and 320x240 captures large-scale gesture dynamics without high GPU utilization.
  • Window Sizing: Increasing the local neighborhood radius increases accuracy on texture-less objects, but adds loops to the fragment shader. A radius of 1 or 2 provides an optimal balance between accuracy and rendering time in WebGL.
