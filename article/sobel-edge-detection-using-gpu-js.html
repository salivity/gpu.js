Sobel Edge Detection Using GPU.js

This article explains how to implement the Sobel edge detection algorithm in JavaScript using gpu.js to leverage hardware-accelerated parallel processing. You will learn how the mathematical operator is structured, how to translate the convolution kernels into a GPU.js compute kernel, and how to execute the edge-detection pipeline on image data in real time using the browser's WebGL context.

Understanding the Sobel Operator

The Sobel edge detection algorithm computes an approximation of the image intensity gradient to identify boundaries between distinct visual regions. It calculates image gradients across two primary axes using a pair of \(3 \times 3\) convolution kernels:

  • Horizontal Gradient (\(G_x\)):

    [-1,  0,  1]
[-2,  0,  2]
[-1,  0,  1]

  • Vertical Gradient (\(G_y\)):

    [-1, -2, -1]
[ 0,  0,  0]
[ 1,  2,  1]

For each pixel in an image, the algorithm computes the scalar product of its surrounding \(3 \times 3\) neighborhood with both kernels. The total edge gradient magnitude is then calculated using the Euclidean norm:

\[G = \sqrt{G_x^2 + G_y^2}\]

If \(G\) exceeds a specified threshold, the pixel is classified as an edge.

Structuring the GPU.js Kernel

Standard JavaScript processes pixel arrays sequentially via nested CPU loops, resulting in high latency for high-resolution images. GPU.js compiles written JavaScript directly into WebGL shader code, allowing every pixel in the image to execute the Sobel calculation simultaneously across GPU cores.

In GPU.js, each thread represents a single pixel coordinate accessed via this.thread.x and this.thread.y.

Kernel Implementation

const { GPU } = require('gpu.js'); // Or imported via <script> tag
const gpu = new GPU();

const sobelKernel = gpu.createKernel(function(image, width, height) {
    const x = this.thread.x;
    const y = this.thread.y;

    // Prevent out-of-bounds neighbor sampling at image borders
    if (x <= 0 || x >= width - 1 || y <= 0 || y >= height - 1) {
        this.color(0, 0, 0, 1);
        return;
    }

    // Helper: sample pixel luminance (grayscale) from image matrix
    // Assumes input format [height][width][channels] or flattened RGBA
    // For normalized RGBA textures:
    const p00 = (image[y - 1][x - 1][0] + image[y - 1][x - 1][1] + image[y - 1][x - 1][2]) / 3;
    const p01 = (image[y - 1][x    ][0] + image[y - 1][x    ][1] + image[y - 1][x    ][2]) / 3;
    const p02 = (image[y - 1][x + 1][0] + image[y - 1][x + 1][1] + image[y - 1][x + 1][2]) / 3;

    const p10 = (image[y    ][x - 1][0] + image[y    ][x - 1][1] + image[y    ][x - 1][2]) / 3;
    const p12 = (image[y    ][x + 1][0] + image[y    ][x + 1][1] + image[y    ][x + 1][2]) / 3;

    const p20 = (image[y + 1][x - 1][0] + image[y + 1][x - 1][1] + image[y + 1][x - 1][2]) / 3;
    const p21 = (image[y + 1][x    ][0] + image[y + 1][x    ][1] + image[y + 1][x    ][2]) / 3;
    const p22 = (image[y + 1][x + 1][0] + image[y + 1][x + 1][1] + image[y + 1][x + 1][2]) / 3;

    // Apply horizontal convolution (Gx)
    const gx = (-1 * p00) + (1 * p02) +
               (-2 * p10) + (2 * p12) +
               (-1 * p20) + (1 * p22);

    // Apply vertical convolution (Gy)
    const gy = (-1 * p00) + (-2 * p01) + (-1 * p02) +
               ( 1 * p20) + ( 2 * p21) + ( 1 * p22);

    // Calculate magnitude
    const magnitude = Math.sqrt((gx * gx) + (gy * gy));

    // Threshold or direct intensity mapping
    const edgeVal = magnitude > 0.2 ? magnitude : 0.0;

    // Set pixel color (R, G, B, A)
    this.color(edgeVal, edgeVal, edgeVal, 1.0);
})
.setOutput([800, 600]) // Match output dimensions [width, height]
.setGraphical(true);   // Enables direct output to an HTML5 canvas

Executing the Execution Pipeline

Executing the GPU.js Sobel kernel involves three phases: preparation, execution, and rendering.

1. Preparing the Input Data

GPU.js accepts HTML Image elements, Video elements, Canvas contexts, or multi-dimensional numerical arrays. Passing an HTML <img> or <canvas> directly avoids the overhead of converting the source into JavaScript arrays:

const sourceImage = document.getElementById('source-image');
const width = sourceImage.width;
const height = sourceImage.height;

// Reconfigure output dimensions to match input resolution dynamically
sobelKernel.setOutput([width, height]);

2. Running the Kernel

The kernel is invoked like a standard JavaScript function. When configured with .setGraphical(true), GPU.js draws directly to an internal WebGL canvas instead of serializing the result back into CPU memory.

sobelKernel(sourceImage, width, height);

3. Displaying and Reusing Output

The resulting output canvas can be retrieved and mounted into the DOM or copied to an existing canvas context:

const resultCanvas = sobelKernel.canvas;
document.body.appendChild(resultCanvas);

If the edge-detected output needs to be passed downstream to another algorithm (such as non-maximum suppression or Hough transforms), omit .setGraphical(true) and configure .setPipeline(true). This preserves the data as an on-chip GPU texture, eliminating data transfers across the CPU-GPU bus.
