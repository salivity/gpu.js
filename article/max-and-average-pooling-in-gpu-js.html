Max and Average Pooling in GPU.js

This guide explains how to implement 2D Max Pooling and Average Pooling operations using GPU.js to accelerate neural network layers directly in the browser or Node.js. By parallelizing spatial reduction over GPU threads, you can significantly reduce the computational overhead of processing 2D feature maps compared to traditional CPU loops.

Understanding 2D Pooling Dimensions

Pooling layers reduce the spatial dimensions (height and width) of a feature map. Given an input matrix of size \(W_{in} \times H_{in}\), a square kernel of size \(K\), and a stride \(S\):

\[\text{Output Width } (W_{out}) = \left\lfloor \frac{W_{in} - K}{S} \right\rfloor + 1\] \[\text{Output Height } (H_{out}) = \left\lfloor \frac{H_{in} - K}{S} \right\rfloor + 1\]

Each thread in GPU.js computes a single value in the output feature map, indexed by this.thread.x (column) and this.thread.y (row).

Max Pooling Implementation

Max pooling extracts the maximum value within each sliding window, retaining the most prominent features.

import { GPU } from 'gpu.js';

const gpu = new GPU();

function createMaxPoolingKernel(inputWidth, inputHeight, kernelSize, stride) {
  const outputWidth = Math.floor((inputWidth - kernelSize) / stride) + 1;
  const outputHeight = Math.floor((inputHeight - kernelSize) / stride) + 1;

  return gpu.createKernel(function(inputMap, kSize, s) {
    const startX = this.thread.x * s;
    const startY = this.thread.y * s;
    
    // Initialize with the first element in the pooling window
    let maxVal = inputMap[startY][startX];

    for (let y = 0; y < kSize; y++) {
      for (let x = 0; x < kSize; x++) {
        const val = inputMap[startY + y][startX + x];
        if (val > maxVal) {
          maxVal = val;
        }
      }
    }

    return maxVal;
  }).setOutput([outputWidth, outputHeight]);
}

// Example usage:
const input = [
  [1, 2, 3, 0],
  [4, 5, 6, 1],
  [7, 8, 9, 2],
  [0, 1, 2, 3]
];

const maxPool = createMaxPoolingKernel(4, 4, 2, 2);
const maxPooledResult = maxPool(input, 2, 2);
console.log(maxPooledResult);

Average Pooling Implementation

Average pooling calculates the arithmetic mean of all values within the window, providing a smoother downsampling operation.

function createAveragePoolingKernel(inputWidth, inputHeight, kernelSize, stride) {
  const outputWidth = Math.floor((inputWidth - kernelSize) / stride) + 1;
  const outputHeight = Math.floor((inputHeight - kernelSize) / stride) + 1;

  return gpu.createKernel(function(inputMap, kSize, s) {
    const startX = this.thread.x * s;
    const startY = this.thread.y * s;
    
    let sum = 0;

    for (let y = 0; y < kSize; y++) {
      for (let x = 0; x < kSize; x++) {
        sum += inputMap[startY + y][startX + x];
      }
    }

    return sum / (kSize * kSize);
  }).setOutput([outputWidth, outputHeight]);
}

// Example usage:
const avgPool = createAveragePoolingKernel(4, 4, 2, 2);
const avgPooledResult = avgPool(input, 2, 2);
console.log(avgPooledResult);

Key Execution Considerations

  1. Memory Ordering: In GPU.js, array indexing maps to [y][x] when reading a 2D input array, whereas thread coordinates are accessed via this.thread.x and this.thread.y. Ensure bounds align properly to prevent memory lookups outside the allocated texture.
  2. Dynamic Kernels: Kernel creation is computationally expensive due to shader compilation. Always instantiate the kernel once per dimension setup and execute the compiled function repeatedly across pipeline iterations.
  3. Pipeline Mode: If pooling immediately feeds into another GPU operation (such as a fully connected layer or activation function), set kernel.setPipeline(true). This preserves output directly in WebGL texture memory, bypassing the CPU readback bottleneck.
