Image Sharpening with Unsharp Mask in GPU.js

Unsharp masking is a classic image processing technique that enhances edge contrast and sharpens high-frequency details by subtracting a smoothed version of an image from the original. This article covers the step-by-step implementation of an unsharp mask filter using GPU.js, enabling high-performance, hardware-accelerated image sharpening directly in JavaScript environments.

The Unsharp Mask Principle

The standard unsharp mask algorithm follows this formula:

\[\text{Sharpened} = \text{Original} + \text{Strength} \times (\text{Original} - \text{Blurred})\]

When using a 3×3 convolution kernel, this process can be combined into a single pass. For a standard four-neighbor Laplacian approximation:

  • Center pixel weight: 1 + (4 * strength)
  • Direct neighbor weights (up, down, left, right): -strength
  • Diagonal neighbor weights: 0

This approach calculates the local blur and edge amplification concurrently inside a single fragment shader.

Implementation Steps

  1. Install and Import GPU.js: Ensure the GPU.js library is available in your project via CDN or npm package.
  2. Define the Kernel: Use gpu.createKernel() with graphical output enabled (.setGraphical(true)) to leverage WebGL textures and render directly to an HTML canvas.
  3. Handle Edge Boundaries: Bound coordinate checks inside the kernel to prevent sampling out-of-bounds pixels.
  4. Apply Color Clamping: Clamp resulting color values between 0.0 and 1.0.

Complete Code Example

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>GPU.js Unsharp Mask</title>
  <script src="https://cdn.jsdelivr.net/npm/gpu.js@latest/dist/gpu-browser.min.js"></script>
</head>
<body>
  <canvas id="output-canvas"></canvas>

  <script>
    const gpu = new GPU();

    function createSharpenKernel(width, height) {
      return gpu.createKernel(function(image, strength) {
        const x = this.thread.x;
        const y = this.thread.y;

        // Sample center pixel
        const center = image[y][x];

        // Sample neighboring pixels with boundary clamping
        const left = image[y][Math.max(0, x - 1)];
        const right = image[y][Math.min(this.constants.width - 1, x + 1)];
        const top = image[Math.min(this.constants.height - 1, y + 1)][x];
        const bottom = image[Math.max(0, y - 1)][x];

        // Apply unsharp mask convolution
        const centerWeight = 1.0 + (4.0 * strength);
        const r = (center[0] * centerWeight) - ((left[0] + right[0] + top[0] + bottom[0]) * strength);
        const g = (center[1] * centerWeight) - ((left[1] + right[1] + top[1] + bottom[1]) * strength);
        const b = (center[2] * centerWeight) - ((left[2] + right[2] + top[2] + bottom[2]) * strength);

        // Clamp RGB channels between 0 and 1, preserve original alpha
        this.color(
          Math.max(0.0, Math.min(1.0, r)),
          Math.max(0.0, Math.min(1.0, g)),
          Math.max(0.0, Math.min(1.0, b)),
          center[3]
        );
      })
      .setConstants({ width: width, height: height })
      .setOutput([width, height])
      .setGraphical(true);
    }

    // Load and process image
    const img = new Image();
    img.crossOrigin = "Anonymous";
    img.src = "path/to/your/image.jpg";

    img.onload = () => {
      const sharpenKernel = createSharpenKernel(img.width, img.height);

      // Execute kernel: image source and sharpening strength (e.g., 0.5 to 1.5)
      sharpenKernel(img, 0.75);

      // Replace or display the resulting canvas
      const canvas = sharpenKernel.canvas;
      document.body.appendChild(canvas);
    };
  </script>
</body>
</html>

Key Considerations

  • Strength Calibration: A strength value between 0.2 and 0.8 produces subtle, natural sharpening. Values exceeding 1.5 often introduce noise, chromatic aberrations, and halo artifacts around high-contrast edges.
  • Coordinate Systems: WebGL calculates pixel positions starting from the bottom-left corner ((0,0)), whereas DOM images map coordinates from the top-left corner. GPU.js handles this mapping automatically when passing DOM image elements directly to graphical kernels.
