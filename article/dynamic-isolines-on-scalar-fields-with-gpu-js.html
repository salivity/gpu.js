Dynamic Isolines on Scalar Fields with GPU.js

Generating dynamic isolines on scalar fields requires high-throughput parallel computation to calculate field values and render contour thresholds in real time. By offloading these mathematical evaluations to the graphics card using GPU.js, developers can transform standard JavaScript functions into compiled WebGL shaders capable of animating complex scalar fields and extracting contour lines at interactive frame rates. This guide details how to define scalar field functions, detect isoline boundaries directly within a GPU kernel, and dynamically render animated contours onto an HTML canvas.

Understanding the Pipeline

A scalar field maps spatial coordinates \((x, y)\) to single numerical values, such as temperature, elevation, or potential. Isolines represent curves where this scalar value remains constant.

While algorithms like Marching Squares extract vector geometries for contour lines on the CPU, an image-space fragment approach executed on the GPU is significantly faster for dynamic visualization. Instead of building geometric line segments, a GPU.js kernel evaluates the scalar value at each pixel, checks if the value falls within an isoline threshold interval, and colors the pixel accordingly.

Setting Up the GPU.js Kernel

To render directly to the screen without costly CPU-GPU memory transfers, initialize GPU.js with graphical output enabled. The output dimensions should match your target canvas.

const gpu = new GPU();

const renderContours = gpu.createKernel(function(time, contourSpacing, lineWidth) {
    // Normalize canvas coordinates
    const x = (this.thread.x / this.output.x) * 10.0 - 5.0;
    const y = (this.thread.y / this.output.y) * 10.0 - 5.0;

    // Define a dynamic scalar field: f(x, y, t)
    const val1 = Math.sin(x + time) * Math.cos(y + time);
    const val2 = Math.sin(Math.sqrt(x * x + y * y) - time);
    const scalar = val1 + val2;

    // Calculate isolines using modulo arithmetic
    const normalizedVal = Math.abs(scalar);
    const remainder = normalizedVal % contourSpacing;
    const halfWidth = lineWidth / 2.0;

    // Determine if the current pixel is on a contour edge
    if (remainder < halfWidth || remainder > (contourSpacing - halfWidth)) {
        // Line color (e.g., bright cyan)
        this.color(0.0, 0.9, 1.0, 1.0);
    } else {
        // Background color mapped to scalar intensity
        const intensity = (scalar + 2.0) / 4.0;
        this.color(intensity * 0.1, intensity * 0.2, intensity * 0.3, 1.0);
    }
})
.setOutput([800, 600])
.setGraphical(true);

Implementing Dynamic Isolines

The kernel uses modulo arithmetic (scalar % contourSpacing) to create repeating isolines across continuous value gradients. To produce smooth, dynamic animations:

  1. Pass Animation Variables as Uniforms: Define changing parameters like time, threshold offsets, or interaction points as arguments to the kernel.
  2. Handle Line Thickness: Simple distance checks relative to lineWidth define how many neighboring pixels trigger the isoline color.
  3. Embed the Canvas: Append the kernel's built-in canvas element to the document DOM.
document.body.appendChild(renderContours.canvas);

let startTime = Date.now();

function animate() {
    const elapsed = (Date.now() - startTime) * 0.001;
    
    // Arguments: time, contour spacing, line width
    renderContours(elapsed, 0.4, 0.03);

    requestAnimationFrame(animate);
}

animate();

Anti-Aliasing and Screen-Space Derivations

Uniform line thickness across variable gradients requires accounting for how fast the scalar field changes. Where the gradient is steep, naive modulo checks create thinner lines; where the gradient is flat, lines become wider.

To achieve uniform isoline thickness, approximate the spatial gradient using finite differences within the kernel:

// Sample neighboring values along X and Y axes
const delta = 0.01;
const xNext = x + delta;
const yNext = y + delta;

const scalarX = Math.sin(xNext + time) * Math.cos(y + time) + Math.sin(Math.sqrt(xNext * xNext + y * y) - time);
const scalarY = Math.sin(x + time) * Math.cos(yNext + time) + Math.sin(Math.sqrt(x * x + yNext * yNext) - time);

// Calculate gradient magnitude
const dx = (scalarX - scalar) / delta;
const dy = (scalarY - scalar) / delta;
const gradientLen = Math.sqrt(dx * dx + dy * dy);

// Scale line tolerance by gradient magnitude for consistent pixel width
const threshold = (lineWidth * 0.5) * Math.max(gradientLen, 0.001);
const distToLine = Math.abs(remainder - (remainder > contourSpacing * 0.5 ? contourSpacing : 0.0));

if (distToLine < threshold) {
    this.color(1.0, 1.0, 1.0, 1.0);
} else {
    this.color(0.05, 0.05, 0.1, 1.0);
}

Performance Best Practices

  • Avoid Conditionals in Complex Fields: Keep branching minimal inside the kernel to maximize thread convergence on the GPU.
  • Maintain Graphical Mode: Always use .setGraphical(true) when visualizing fields directly. Calling .toArray() forces memory readbacks from the GPU to the CPU, introducing significant rendering bottlenecks.
  • Precompute Static Field Textures: If the scalar field data is static and only isoline levels are moving, pass the scalar data as an input texture or array, allowing the kernel to sample precomputed values rather than recomputing heavy mathematical formulas per pixel per frame.
