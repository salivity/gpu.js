Rasterize GeoTIFF DEMs to Contours Using GPU.js

This article explains how to efficiently convert large GeoTIFF digital elevation models (DEMs) into visual contour lines by offloading computation to the graphics card using gpu.js. You will learn how to extract elevation data from GeoTIFF files, initialize a WebGL compute kernel, execute an isoline algorithm in parallel, and render the resulting visual contours directly onto an HTML canvas.

1. Extracting Elevation Data from the GeoTIFF

Before performing GPU operations, you must parse the GeoTIFF file into a flat array of floating-point elevation values. You can use the standard geotiff.js library to read the file structure and extract the raster data.

import { fromArrayBuffer } from 'geotiff';

async function loadDEM(arrayBuffer) {
  const tiff = await fromArrayBuffer(arrayBuffer);
  const image = await tiff.getImage();
  const width = image.getWidth();
  const height = image.getHeight();
  
  // Read elevation values as a 1D Float32Array
  const rasters = await image.readRasters();
  const elevations = rasters[0]; 

  return { elevations, width, height };
}

2. Setting Up the GPU.js Kernel

gpu.js compiles standard JavaScript functions into WebGL shader language (GLSL), allowing massively parallel pixel operations. To generate contours, initialize an instance of GPU and configure a kernel with the dimensions of your GeoTIFF. By enabling graphical: true, the kernel outputs color values directly to an internal HTML <canvas> element.

import { GPU } from 'gpu.js';

const gpu = new GPU();

function createContourKernel(width, height) {
  return gpu.createKernel(function(elevations, interval, lineWidth) {
    const x = this.thread.x;
    const y = this.thread.y;
    const currentIdx = y * this.constants.width + x;
    const currentElevation = elevations[currentIdx];

    // Read neighboring pixels to calculate elevation gradients
    const rightElevation = elevations[currentIdx + 1];
    const topElevation = elevations[currentIdx + this.constants.width];

    // Determine contour boundaries
    const currentLevel = Math.floor(currentElevation / interval);
    const rightLevel = Math.floor(rightElevation / interval);
    const topLevel = Math.floor(topElevation / interval);

    // If an elevation interval boundary is crossed between pixels, draw a contour line
    if (currentLevel !== rightLevel || currentLevel !== topLevel) {
      this.color(0.1, 0.1, 0.1, 1.0); // Line color (Dark Gray)
    } else {
      this.color(1.0, 1.0, 1.0, 0.0); // Transparent background
    }
  })
  .setConstants({ width, height })
  .setOutput([width, height])
  .setGraphical(true);
}

3. Rendering Large Datasets via Tiling

WebGL textures are constrained by hardware limits (typically 4096×4096 or 16384×16384 pixels). Large GeoTIFF datasets often exceed these limits and can exhaust GPU memory if processed in a single dispatch. To manage this:

  1. Subdivide the Dataset: Break the elevation array into square tiles (e.g., 1024×1024 or 2048×2048).
  2. Include Overlaps: Add a 1-pixel border to each tile from adjacent tiles so the neighbor-sampling logic along the edges does not produce visual seams.
  3. Execute in Sequence: Run each tile through the kernel and draw the resulting canvas regions into a final destination canvas using CanvasRenderingContext2D.drawImage().
async function renderContourMap(elevations, width, height, interval) {
  const kernel = createContourKernel(width, height);
  
  // Execute kernel on the GPU
  kernel(elevations, interval, 1.0);

  // Retrieve the canvas with rendered contours
  const contourCanvas = kernel.canvas;
  document.body.appendChild(contourCanvas);
}

4. Customizing Contour Styles

You can extend the kernel's logic without a significant performance penalty:

  • Index Contours: Highlight major contour intervals (e.g., every 5th line) by checking if currentLevel % 5.0 === 0.0 and applying a darker color or thicker pixel footprint.
  • Hypsometric Tints: Blend an underlying terrain color gradient based on the raw elevation value (currentElevation / maxElevation) beneath the contour lines instead of using transparent pixels.
  • NoData Handling: Add an early exit condition inside the kernel function (e.g., if (currentElevation <= -9999.0) { this.color(0, 0, 0, 0); return; }) to exclude nodata values typical in DEM sources like SRTM or USGS 3DEP.
