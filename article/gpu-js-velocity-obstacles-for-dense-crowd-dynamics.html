GPU.js Velocity Obstacles for Dense Crowd Dynamics

Simulating dense crowd dynamics in real-time requires high-throughput computation to resolve local collision avoidance for thousands of simultaneous entities. The Velocity Obstacle (VO) formulation and its reciprocal variants (such as RVO) prevent collisions by restricting an agent's velocity space based on the positions and velocities of nearby neighbors. This article explains how to implement a parallelized Velocity Obstacle model using gpu.js, enabling hardware-accelerated crowd dynamics directly in the browser via WebGL shaders.

Understanding the Velocity Obstacle Model

A Velocity Obstacle \(VO_{A|B}^\tau\) represents the set of all relative velocities between agent \(A\) and agent \(B\) that will result in a collision before a specific time horizon \(\tau\).

Geometrically, if agent \(A\) has radius \(r_A\) and agent \(B\) has radius \(r_B\), the obstacle can be treated as a disc of radius \(R = r_A + r_B\) centered at position \(\mathbf{p}_B - \mathbf{p}_A\). The velocity obstacle consists of a cone originating at the relative origin with boundaries tangent to the combined disc. Any relative velocity \(\mathbf{v}_A - \mathbf{v}_B\) falling inside this cone guarantees a collision within time \(\tau\).

In dense reciprocal multi-agent scenarios, Reciprocal Velocity Obstacles (RVO) or ClearPath formulations are commonly used. In RVO, both agents share equal responsibility by translating the cone apex to \(\frac{\mathbf{v}_A + \mathbf{v}_B}{2}\) rather than \(\mathbf{v}_B\), reducing oscillations.

Architecture in GPU.js

Because WebGL shaders execute code independently per pixel/thread, simulating \(N\) agents maps directly to a 1D GPU kernel of size \(N\).

Instead of solving complex linear programs on the GPU, the most efficient approach in a shader is candidate velocity sampling:

  1. Each thread corresponds to an agent \(i\).
  2. The agent generates candidate velocities biased toward its preferred goal velocity.
  3. The kernel loops through neighboring agents to test candidates against their respective velocity obstacle cones.
  4. The candidate closest to the goal velocity that does not violate any VO is selected.

Data Layout

GPU.js works best with flat arrays or 2D textures. For \(N\) agents, represent dynamic attributes as flattened 1D arrays:

  • positions: [x0, y0, x1, y1, ...]
  • velocities: [vx0, vy0, vx1, vy1, ...]
  • goals: [gx0, gy0, gx1, gy1, ...]
  • radii: [r0, r1, ...]

Step-by-Step Implementation

1. Setting Up the GPU Instance

Initialize GPU.js and define constants such as the maximum speed, time horizon \(\tau\), and agent count.

import { GPU } from 'gpu.js';

const gpu = new GPU();
const NUM_AGENTS = 2048;
const TIME_HORIZON = 2.0;
const MAX_SPEED = 2.5;

2. Writing the Velocity Obstacle Kernel

The following kernel calculates the collision-free velocity for every agent. To maintain performance in GLSL, the kernel evaluates a discrete set of sampled velocities around the agent's preferred velocity vector.

const computeVelocitiesKernel = gpu.createKernel(function(
  positions,
  velocities,
  goals,
  radii,
  numAgents,
  tau,
  maxSpeed
) {
  const i = this.thread.x;
  const pAx = positions[i * 2];
  const pAy = positions[i * 2 + 1];
  const vAx = velocities[i * 2];
  const vAy = velocities[i * 2 + 1];
  const gAx = goals[i * 2];
  const gAy = goals[i * 2 + 1];
  const rA = radii[i];

  // Preferred velocity toward goal
  const toGoalX = gAx - pAx;
  const toGoalY = gAy - pAy;
  const distGoal = Math.sqrt(toGoalX * toGoalX + toGoalY * toGoalY);
  
  let prefVx = 0;
  let prefVy = 0;
  if (distGoal > 0.001) {
    const scale = Math.min(maxSpeed, distGoal) / distGoal;
    prefVx = toGoalX * scale;
    prefVy = toGoalY * scale;
  }

  let bestVx = 0.0;
  let bestVy = 0.0;
  let minPenalty = 999999.0;

  // Search pattern: Test a grid of candidate velocities
  for (let stepX = -3; stepX <= 3; stepX++) {
    for (let stepY = -3; stepY <= 3; stepY++) {
      const candVx = prefVx + (stepX * maxSpeed * 0.3);
      const candVy = prefVy + (stepY * maxSpeed * 0.3);
      
      const candSpeedSq = candVx * candVx + candVy * candVy;
      if (candSpeedSq <= maxSpeed * maxSpeed) {
        let collides = 0;

        // Check candidate velocity against all other agents
        for (let j = 0; j < numAgents; j++) {
          if (i !== j) {
            const pBx = positions[j * 2];
            const pBy = positions[j * 2 + 1];
            const vBx = velocities[j * 2];
            const vBy = velocities[j * 2 + 1];
            const rB = radii[j];

            // Minkowski sum radius
            const totalR = rA + rB;
            const relPx = pBx - pAx;
            const relPy = pBy - pAy;
            const distSq = relPx * relPx + relPy * relPy;

            // Reciprocal Velocity formulation: Apex at (vA + vB) / 2
            const apexX = (vAx + vBx) * 0.5;
            const apexY = (vAy + vBy) * 0.5;
            const testVx = 2.0 * (candVx - apexX);
            const testVy = 2.0 * (candVy - apexY);

            // Ray-sphere intersection inside time horizon tau
            const dotProduct = testVx * relPx + testVy * relPy;
            if (dotProduct > 0.0) {
              const testSpeedSq = testVx * testVx + testVy * testVy;
              const projection = dotProduct / testSpeedSq;
              const clampedTime = Math.min(tau, Math.max(0.0, projection));
              
              const closestPointX = testVx * clampedTime;
              const closestPointY = testVy * clampedTime;
              const diffX = relPx - closestPointX;
              const diffY = relPy - closestPointY;

              if ((diffX * diffX + diffY * diffY) < (totalR * totalR)) {
                collides = 1;
                break;
              }
            }
          }
        }

        // Distance from ideal velocity penalty
        const diffPrefX = candVx - prefVx;
        const diffPrefY = candVy - prefVy;
        const penalty = Math.sqrt(diffPrefX * diffPrefX + diffPrefY * diffPrefY) + (collides * 1000.0);

        if (penalty < minPenalty) {
          minPenalty = penalty;
          bestVx = candVx;
          bestVy = candVy;
        }
      }
    }
  }

  // Output flattened: index % 2 determines x or y channel
  return (this.thread.y === 0) ? bestVx : bestVy;
})
.setOutput([NUM_AGENTS, 2])
.setPipeline(true);

3. State Integration

After computing optimal velocities, update position vectors using simple Euler integration:

const integratePositionKernel = gpu.createKernel(function(positions, newVelocities, dt) {
  const agentIdx = this.thread.x;
  const axis = this.thread.y; // 0 for X, 1 for Y
  
  const currentPos = positions[axis][agentIdx];
  const currentVel = newVelocities[axis][agentIdx];
  
  return currentPos + currentVel * dt;
})
.setOutput([NUM_AGENTS, 2])
.setPipeline(true);

4. Executing the Simulation Loop

Using pipeline mode (.setPipeline(true)) allows textures to remain in GPU memory between calculation passes, avoiding expensive readbacks to the CPU on every frame:

let positionsTexture = initialPositions;
let velocitiesTexture = initialVelocities;

function update(dt) {
  // Step 1: Compute non-colliding velocities on GPU
  velocitiesTexture = computeVelocitiesKernel(
    positionsTexture,
    velocitiesTexture,
    goalsArray,
    radiiArray,

    MAX_SPEED
  );

  // Step 2: Integrate positions
  positionsTexture = integratePositionKernel(
    positionsTexture,
    velocitiesTexture,
    dt
  );
}

Performance Optimizations

  1. Neighborhood Pruning: Evaluating all \(N\) agents against each other results in \(O(N^2)\) complexity per frame. For dense crowds beyond 5,000 agents, pre-bin agent indices into a uniform spatial grid texture. Restrict the inner collision loop to scan only neighboring grid cells.
  2. Velocity Sampling Density: Increase the candidate sampling resolution dynamically. Use a coarse grid to determine the general direction, followed by fine-grained evaluations in a localized angle range.
  3. Pipeline Mode Retention: Keep render data on the GPU by using WebGL render contexts to draw directly from the output textures rather than converting outputs to JavaScript arrays via .toArray().
