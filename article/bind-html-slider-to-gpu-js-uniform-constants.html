Bind HTML Slider to gpu.js Uniform Constants

Interactive browser graphics and computations often require feeding dynamic user input into parallelized GPU operations. In GPU.js, primitive parameters passed into an active kernel function behave as uniform constants, meaning their values stay consistent across all concurrent threads during a single execution. This article explains how to capture input from a standard HTML range slider, route its numerical value into a GPU.js kernel, and update the GPU output in real time as the slider moves.

Core Architecture

GPU.js does not require a dedicated uniform-binding syntax like raw WebGL shaders. Instead, primitive data types (integers and floats) passed directly as arguments to a compiled kernel function automatically serve as uniform values.

To achieve real-time interactivity:

  1. Define an HTML range slider element in the DOM.
  2. Initialize the GPU context and compile the kernel to accept a parameter for the slider value.
  3. Attach an event listener to the slider that calls the kernel whenever the input changes.

Step-by-Step Implementation

1. HTML Markup

Set up an <input type="range"> element and an output container. If your kernel renders graphics directly to the screen, compile the kernel with graphical output enabled to append its canvas to the DOM.

<label for="intensitySlider">Intensity:</label>
<input type="range" id="intensitySlider" min="0" max="1" step="0.01" value="0.5">

<div id="canvas-container"></div>

2. Kernel Definition

Initialize the GPU instance and declare the kernel function. Include an argument representing the slider's value.

const gpu = new GPU();

// Create a graphical kernel that takes sliderVal as a uniform constant
const renderKernel = gpu.createKernel(function(sliderVal) {
    // sliderVal is accessible across all parallel threads
    const x = this.thread.x / this.output.x;
    const y = this.thread.y / this.output.y;
    
    // Use sliderVal to control visual output
    this.color(x * sliderVal, y * sliderVal, 0.5, 1);
})
.setOutput([500, 500])
.setGraphical(true);

// Append the generated WebGL canvas to the document
document.getElementById('canvas-container').appendChild(renderKernel.canvas);

3. Binding the Event Listener

Attach an event listener to the slider. Use the input event rather than the change event to ensure the kernel re-runs continuously while dragging the slider handle.

const slider = document.getElementById('intensitySlider');

function updateGPU() {
    // Parse the slider string value to a float
    const uniformVal = parseFloat(slider.value);
    
    // Execute the kernel with the uniform constant
    renderKernel(uniformVal);
}

// Listen for continuous slider movement
slider.addEventListener('input', updateGPU);

// Initial execution to draw the first frame
updateGPU();

Performance Best Practices

  • Parse Strings to Numbers: HTML slider values are strings by default. Always pass them through parseFloat() or parseInt() before executing the kernel. Passing strings directly will degrade performance or cause WebGL compilation errors.
  • Avoid Recompilation: Compile gpu.createKernel() once during application initialization. Never place createKernel inside the slider's event callback; instead, only invoke the pre-compiled kernel instance with the new uniform arguments.
  • Throttle High-Density Workloads: If the kernel performs complex computations instead of simple rendering, wrap the event handler in window.requestAnimationFrame() to sync execution with the browser's refresh rate and prevent dropped frames.
