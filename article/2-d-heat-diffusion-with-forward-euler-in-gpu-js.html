2D Heat Diffusion with Forward Euler in gpu.js

This guide explains how to numerically solve the two-dimensional heat diffusion equation using the Forward-Time Central-Space (FTCS) finite-difference scheme accelerated on the GPU with gpu.js. You will learn the mathematical discretization, the numerical stability constraints, and the setup of a high-performance ping-pong texture pipeline in JavaScript to compute successive time steps directly in WebGL shaders.

Mathematical Formulation and Discretization

The continuous two-dimensional heat equation is defined as:

\[\frac{\partial u}{\partial t} = \alpha \left( \frac{\partial^2 u}{\partial x^2} + \frac{\partial^2 u}{\partial y^2} \right)\]

where \(u(x, y, t)\) represents temperature at spatial coordinates \((x, y)\) and time \(t\), and \(\alpha\) is the thermal diffusivity coefficient.

Using the Forward Euler method for the temporal derivative and central differences for the spatial derivatives on a grid with uniform spacing \(\Delta x = \Delta y\):

\[\frac{u_{i,j}^{n+1} - u_{i,j}^n}{\Delta t} = \alpha \left( \frac{u_{i+1,j}^n - 2u_{i,j}^n + u_{i-1,j}^n}{\Delta x^2} + \frac{u_{i,j+1}^n - 2u_{i,j}^n + u_{i,j-1}^n}{\Delta x^2} \right)\]

Rearranging for the next state \(u_{i,j}^{n+1}\) yields:

\[u_{i,j}^{n+1} = u_{i,j}^n + r \left( u_{i+1,j}^n + u_{i-1,j}^n + u_{i,j+1}^n + u_{i,j-1}^n - 4u_{i,j}^n \right)\]

where \(r\) is the dimensionless diffusion number:

\[r = \frac{\alpha \Delta t}{\Delta x^2}\]

Stability Criterion

The explicit Forward Euler scheme is conditionally stable. In two dimensions, the Von Neumann stability analysis requires:

\[r \le \frac{1}{4} = 0.25\]

Exceeding this value causes numerical oscillations and unbounded divergence.

Implementing in gpu.js

Because time-stepping requires reading from the current state and writing to the next state, the calculation requires a ping-pong buffering pattern. You maintain two GPU textures, alternately reading from one and writing to the other.

1. Initialize gpu.js and the Grid

const { GPU } = require('gpu.js'); // or window.GPU in the browser
const gpu = new GPU();

const WIDTH = 512;
const HEIGHT = 512;

// Simulation parameters
const alpha = 1.0;
const dx = 1.0;
const dt = 0.2; // r = 1.0 * 0.2 / (1.0^2) = 0.2 <= 0.25 (Stable)
const r = (alpha * dt) / (dx * dx);

2. Define Initial Conditions

Create a 2D array representing the initial heat distribution, such as a cold plate with a hot region in the center:

function createInitialGrid(width, height) {
  const grid = [];
  for (let y = 0; y < height; y++) {
    const row = [];
    for (let x = 0; x < width; x++) {
      // Hotspot in the center
      const distFromCenter = Math.hypot(x - width / 2, y - height / 2);
      row.push(distFromCenter < 30 ? 100.0 : 0.0);
    }
    grid.push(row);
  }
  return grid;
}

let currentGrid = createInitialGrid(WIDTH, HEIGHT);

3. Create the Simulation Kernel

The kernel computes the stencil update for each pixel \((x, y)\) in parallel. Boundaries are held at a fixed temperature (Dirichlet boundary conditions).

const heatStepKernel = gpu.createKernel(
  function (grid, r, width, height) {
    const x = this.thread.x;
    const y = this.thread.y;

    // Dirichlet boundary conditions: keep borders fixed at 0.0
    if (x === 0 || x === width - 1 || y === 0 || y === height - 1) {
      return grid[y][x];
    }

    const center = grid[y][x];
    const left   = grid[y][x - 1];
    const right  = grid[y][x + 1];
    const bottom = grid[y - 1][x];
    const top    = grid[y + 1][x];

    // Discrete 5-point Laplacian stencil update
    const laplacian = left + right + top + bottom - 4.0 * center;
    return center + r * laplacian;
  },
  {
    output: [WIDTH, HEIGHT],
    pipeline: true,        // Keeps outputs on the GPU as textures
    immutable: true        // Optimizes memory allocation for chained executions
  }
);

4. Execute Time-Stepping via Ping-Pong

Run the simulation loop by continuously passing the GPU texture back into the kernel:

const totalSteps = 1000;

for (let step = 0; step < totalSteps; step++) {
  // Compute next time step on the GPU
  const nextGrid = heatStepKernel(currentGrid, r, WIDTH, HEIGHT);

  // If previous step was a texture (not the initial JS array), clean it up
  if (currentGrid.delete) {
    currentGrid.delete();
  }

  currentGrid = nextGrid;
}

// Extract final numerical values to a standard 2D JavaScript array
const finalState = currentGrid.toArray();
console.log("Simulation complete. Center value:", finalState[HEIGHT / 2][WIDTH / 2]);

Performance Considerations

  • pipeline: true: Ensures data stays in WebGL texture memory between iterations rather than transferring between CPU and GPU memory every step.
  • immutable: true: Instructs gpu.js not to overwrite active textures, enabling safe texture reuse and predictable garbage collection.
  • Resource Management: When repeatedly replacing GPU textures in a loop, invoke .delete() on the prior texture reference to prevent VRAM memory leaks.
