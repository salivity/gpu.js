Granular Chute Flow and Sandpile Physics in GPU.js

This article explains how to simulate granular chute flow and sandpile avalanches on the web using custom friction kernels in GPU.js. By modeling granular material as a discrete heightfield or a continuum depth-averaged fluid on a GPU-accelerated grid, you can compute real-time Mohr-Coulomb friction thresholds and mass redistribution. Below, you will explore the underlying physics of internal friction angles, how to write the compute shaders in GPU.js, and how to structure a ping-pong rendering loop for stable, real-time performance.

Governing Dynamics: Friction and Avalanches

Granular flow down an inclined plane (a chute) and the formation of sandpiles are governed by the material's internal friction angle, or angle of repose (\(\theta_r\)).

  1. Sandpile Avalanches: A cell remains stable as long as the local surface gradient between adjacent cells does not exceed the critical slope: \[\tan(\theta) \le \mu = \tan(\theta_r)\] When the slope exceeds \(\tan(\theta_r)\), an avalanche is triggered. The excess mass flows down the steepest descent vector until the angle drops back to or below \(\theta_r\).

  2. Chute Flow: On an inclined chute tilted at an angle \(\alpha\), gravity provides a driving acceleration \(g \sin(\alpha)\) along the bed, while the basal friction counteracts it with a magnitude proportional to \(g \cos(\alpha) \tan(\delta)\), where \(\delta\) is the basal friction angle. Flow occurs when \(\alpha > \delta\).

Grid State and Memory Architecture

To implement this efficiently in GPU.js, represent the terrain and granular mass using 2D arrays:

  • Height (\(H\)): Elevation of the sand at each coordinate \((x, y)\).
  • Velocity (\(V_x, V_y\)): Momentum or flux components (if implementing hydrodynamic depth-averaged Saint-Venant granular equations).

GPU.js does not support in-place array mutation within kernels. Consequently, you must alternate between two memory buffers (ping-pong buffering): one buffer acts as the read-only input state for the current time step, while the kernel writes the updated state to the second buffer.

Constructing the GPU.js Friction Kernels

The core logic requires calculating height differences across immediate neighbors (Von Neumann or Moore neighborhood) and adjusting mass based on the friction threshold.

const { GPU } = require('gpu.js'); // or import { GPU } from 'gpu.js' in browser
const gpu = new GPU();

const GRID_WIDTH = 512;
const GRID_HEIGHT = 512;

// Kernel 1: Evaluate avalanches based on critical slope
const avalancheKernel = gpu.createKernel(function(grid, criticalSlope, transferRate) {
    const x = this.thread.x;
    const y = this.thread.y;
    
    let currentHeight = grid[y][x];
    let netChange = 0.0;
    
    // Check 4-connected neighbors: North, South, East, West
    const neighborsX = [0, 0, -1, 1];
    const neighborsY = [-1, 1, 0, 0];
    
    for (let i = 0; i < 4; i++) {
        const nx = x + neighborsX[i];
        const ny = y + neighborsY[i];
        
        // Ensure boundaries are respected
        if (nx >= 0 && nx < this.constants.width && ny >= 0 && ny < this.constants.height) {
            const neighborHeight = grid[ny][nx];
            const diff = currentHeight - neighborHeight;
            
            // Outflow: Current cell is significantly taller than neighbor
            if (diff > criticalSlope) {
                netChange -= (diff - criticalSlope) * transferRate;
            }
            // Inflow: Neighbor is significantly taller than current cell
            else if (-diff > criticalSlope) {
                netChange += (-diff - criticalSlope) * transferRate;
            }
        }
    }
    
    return currentHeight + netChange;
}, {
    constants: { width: GRID_WIDTH, height: GRID_HEIGHT },
    output: [GRID_WIDTH, GRID_HEIGHT],
    pipeline: true // Keeps data as textures on GPU memory
});

Adding Chute Inclination and Basal Resistance

To convert the static pile into an inclined chute flow, apply body forces representing the gravity component along the incline and subtract kinetic friction:

const chuteFlowKernel = gpu.createKernel(function(heights, velocities, chuteAngleRad, frictionCoeff, dt) {
    const x = this.thread.x;
    const y = this.thread.y;
    
    const h = heights[y][x];
    let v = velocities[y][x];
    
    if (h <= 0.001) {
        return 0.0;
    }
    
    const g = 9.81;
    // Driving force down the chute (assumed aligned with Y-axis)
    const drivingForce = g * Math.sin(chuteAngleRad);
    
    // Normal Coulomb basal friction force
    const normalForce = g * Math.cos(chuteAngleRad);
    const frictionForce = normalForce * frictionCoeff;
    
    // Net acceleration
    let netAcc = drivingForce - frictionForce;
    
    // If friction exceeds drive and velocity is negligible, mass arrests
    if (drivingForce <= frictionForce && Math.abs(v) < 0.01) {
        v = 0.0;
    } else {
        v += netAcc * dt;
        if (v < 0.0) v = 0.0; // Prevent reverse flow on a unidirectional chute
    }
    
    return v;
}, {
    output: [GRID_WIDTH, GRID_HEIGHT],
    pipeline: true
});

Chute Advection Kernel

Once velocities are determined, mass must be advected downstream to complete the chute dynamics:

const advectionKernel = gpu.createKernel(function(heights, velocities, dt) {
    const x = this.thread.x;
    const y = this.thread.y;
    
    const h = heights[y][x];
    const v = velocities[y][x];
    
    // Upwind mass shift along chute vector (flowing in +y direction)
    let inflow = 0.0;
    if (y > 0) {
        const vUp = velocities[y - 1][x];
        const hUp = heights[y - 1][x];
        inflow = hUp * vUp * dt;
    }
    
    const outflow = h * v * dt;
    
    return Math.max(0.0, h + inflow - outflow);
}, {
    output: [GRID_WIDTH, GRID_HEIGHT],
    pipeline: true
});

Execution Loop

Run the simulation by chaining the compute kernels. Setting pipeline: true ensures that the matrices remain on GPU VRAM as WebGL textures, avoiding expensive CPU-GPU serialization bottlenecks.

let currentHeightMap = initialTerrainTexture; 
let currentVelocityMap = initialVelocityTexture;

const CRITICAL_SLOPE = 0.58; // tan(30 degrees angle of repose)
const TRANSFER_RATE = 0.125; // Relaxation constant per step
const CHUTE_ANGLE = 0.65;    // Incline angle in radians (~37 degrees)
const MU_BED = 0.45;         // Chute bottom friction coefficient
const DT = 0.016;            // Simulation delta time (~60fps)

function stepSimulation() {
    // 1. Solve internal friction and local sandpile collapse
    const relaxedHeights = avalancheKernel(currentHeightMap, CRITICAL_SLOPE, TRANSFER_RATE);
    
    // 2. Compute chute velocities under gravity and basal friction
    const updatedVelocities = chuteFlowKernel(relaxedHeights, currentVelocityMap, CHUTE_ANGLE, MU_BED, DT);
    
    // 3. Advect mass down the chute
    const advectedHeights = advectionKernel(relaxedHeights, updatedVelocities, DT);
    
    // Cycle references for next frame
    currentHeightMap = advectedHeights;
    currentVelocityMap = updatedVelocities;
}

function render() {
    stepSimulation();
    requestAnimationFrame(render);
}

render();

By decoupling internal shear failures (sandpile avalanches) from basal sliding (chute dynamics), this approach maintains physical accuracy while keeping execution times within the frame budget of WebGL through GPU.js.
