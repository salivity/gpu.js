Shallow-Water Atmospheric Modeling in GPU.js

Planetary atmospheric circulation can be effectively approximated using shallow-water equations implemented in gpu.js. By treating the atmosphere as a thin, single-layer fluid where horizontal scales vastly exceed vertical depth, the shallow-water equations capture fundamental planetary-scale phenomena like Coriolis deflection, geostrophic balance, and Rossby waves. Using gpu.js, these calculations can be compiled directly into WebGL shaders, enabling real-time, browser-based simulations of rotating fluid dynamics on standard consumer hardware.

The shallow-water equations are a standard approximation in geophysical fluid dynamics. They govern the behavior of an incompressible fluid layer under the influence of gravity and rotation. For atmospheric applications, the equations account for fluid depth (representing geopotential height or surface pressure) and horizontal velocity components across a grid. By incorporating a latitude-dependent Coriolis parameter—either on a simplified beta-plane or projected onto spherical coordinates—the equations naturally generate characteristic atmospheric circulation structures, such as zonal jet streams, equatorial Kelvin waves, and cyclonic vortices.

Implementing this system in gpu.js relies on finite-difference or finite-volume schemes mapped to GPU kernels. The simulation domain is represented as a discrete 2D grid where each cell tracks velocity (\(u, v\)) and fluid height (\(h\)). Because the shallow-water equations are explicit partial differential equations, calculating the next time step requires evaluating local spatial gradients (advection and pressure) and local forces (Coriolis acceleration and friction). In gpu.js, these local stencil operations execute concurrently across thousands of GPU threads, updating the entire grid in parallel.

To run stably in WebGL through gpu.js, the implementation must use a ping-pong buffer technique. Because WebGL shaders cannot read from and write to the same texture simultaneously, gpu.js swaps two state arrays on each iteration: one acts as the input state for the current time step, while the other stores the newly computed values. Standard numerical techniques such as the Lax-Wendroff method, Adams-Bashforth time-stepping, or an Arakawa C-grid spatial discretization help minimize numerical dissipation and prevent grid-scale instabilities.

While gpu.js makes real-time atmospheric simulation accessible without complex native dependencies, the model has distinct physical and computational limitations. Physically, shallow-water equations exclude vertical stratification, baroclinic instability, moisture transport, and thermodynamic radiation, restricting results to barotropic phenomena. Computationally, gpu.js relies on WebGL, which typically limits arithmetic to single-precision 32-bit floats. This reduced precision can accumulate rounding errors over long integration periods, requiring deliberate numerical damping.

Despite these constraints, approximating planetary circulation with shallow-water equations in gpu.js is both feasible and computationally efficient. It provides an accessible platform for interactive scientific visualization, educational demonstrations of planetary wave mechanics, and rapid prototyping of geophysical models entirely within a web browser.
