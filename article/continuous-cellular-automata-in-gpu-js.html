Continuous Cellular Automata in GPU.js

Computing continuous cellular automata involves transitioning from discrete grid states to real-number fields, enabling smooth, organic patterns such as those seen in SmoothLife or Lenia. Implementing these systems in gpu.js requires setting up floating-point textures, defining continuous spatial neighborhood kernels, and evaluating non-linear growth functions directly on the GPU. This guide details how to configure WebGL float pipelines, write the neighborhood convolution kernel, and compute continuous state updates efficiently using gpu.js.

1. Enabling Floating-Point Textures

Continuous cellular automata store states as floating-point numbers typically normalized between 0.0 and 1.0. Standard WebGL textures truncate values to 8-bit integers ([0, 255]), which eliminates the precision needed for continuous equations. You must configure gpu.js to output float textures to preserve real-number precision across computation cycles.

const gpu = new GPU();

// Verify float texture support in your WebGL context
const updateCA = gpu.createKernel(function(grid, width, height, dt, mu, sigma) {
    // Kernel logic here
}, {
    output: [width, height],
    pipeline: true,        // Keeps data on GPU as a texture
    floatTextures: true,   // Enables IEEE floating-point precision
    floatOutput: true
});

Using pipeline: true prevents costly CPU-GPU memory transfers between simulation steps by recycling the output texture directly as the input for the next frame.

2. Continuous Neighborhood Integration

In discrete automata like Conway's Game of Life, neighbors are counted via discrete sums. In continuous automata, neighborhood values are computed via spatial integration (convolution) over a continuous radius \(R\), often using an annular or Gaussian kernel to determine the local field density \(U\).

Inside a gpu.js kernel, access coordinates using this.thread.x and this.thread.y:

const computeField = gpu.createKernel(function(grid, width, height, radius) {
    let sum = 0.0;
    let totalWeight = 0.0;
    const cx = this.thread.x;
    const cy = this.thread.y;

    const r = Math.floor(radius);
    for (let dy = -r; dy <= r; dy++) {
        for (let dx = -r; dx <= r; dx++) {
            // Toroidal boundary conditions (wrap-around)
            const nx = (cx + dx + width) % width;
            const ny = (cy + dy + height) % height;

            const dist = Math.sqrt(dx * dx + dy * dy) / radius;

            // Define an annular kernel (ring-shaped neighborhood)
            if (dist <= 1.0) {
                // Example: bump or Gaussian distribution kernel weight
                const weight = Math.exp(-Math.pow((dist - 0.5) / 0.15, 2) / 2.0);
                sum += grid[ny][nx] * weight;
                totalWeight += weight;
            }
        }
    }

    return totalWeight > 0.0 ? (sum / totalWeight) : 0.0;
}, {
    output: [width, height],
    pipeline: true,
    floatTextures: true
});

3. Applying Continuous Growth Functions

Once the neighborhood density \(U\) is computed, the cell's future state is determined by a continuous growth mapping \(G(U)\) and integrated over an infinitesimal time step \(\Delta t\):

\[A^{t + \Delta t} = \text{clamp}(A^t + \Delta t \cdot G(U), 0.0, 1.0)\]

A standard growth function is a Gaussian centered at \(\mu\) with variance \(\sigma\):

\[G(U) = 2 \cdot e^{-\frac{(U - \mu)^2}{2\sigma^2}} - 1\]

You can combine the neighborhood integration and the state update into a single unified gpu.js step:

const stepLenia = gpu.createKernel(function(grid, width, height, dt, mu, sigma, radius) {
    let sum = 0.0;
    let totalWeight = 0.0;
    const cx = this.thread.x;
    const cy = this.thread.y;

    const r = Math.floor(radius);
    for (let dy = -r; dy <= r; dy++) {
        for (let dx = -r; dx <= r; dx++) {
            const nx = (cx + dx + width) % width;
            const ny = (cy + dy + height) % height;
            const dist = Math.sqrt(dx * dx + dy * dy) / radius;

            if (dist <= 1.0) {
                const weight = Math.exp(-Math.pow((dist - 0.5) / 0.15, 2.0) / 2.0);
                sum += grid[ny][nx] * weight;
                totalWeight += weight;
            }
        }
    }

    const U = totalWeight > 0.0 ? (sum / totalWeight) : 0.0;
    
    // Continuous growth mapping
    const growth = 2.0 * Math.exp(-Math.pow((U - mu) / sigma, 2.0) / 2.0) - 1.0;
    
    // Euler integration step
    const currentState = grid[cy][cx];
    const nextState = currentState + dt * growth;

    // Clamp values to real range [0.0, 1.0]
    return Math.max(0.0, Math.min(1.0, nextState));
}, {
    output: [width, height],
    pipeline: true,
    floatTextures: true
});

4. Executing the Simulation Loop

To run the simulation, initialize a 2D array of floats, pass it to the GPU pipeline, and swap the input/output references on every frame:

const width = 256;
const height = 256;
let state = new Float32Array(width * height).map(() => Math.random());

const dt = 0.1;
const mu = 0.15;
const sigma = 0.017;
const radius = 13.0;

// Simulation loop
function animate() {
    state = stepLenia(state, width, height, dt, mu, sigma, radius);
    requestAnimationFrame(animate);
}
animate();

Because pipeline: true is enabled, state holds a reference to a WebGL texture object rather than a JavaScript array, keeping all real-number operations hardware-accelerated without crossing the CPU bus.
