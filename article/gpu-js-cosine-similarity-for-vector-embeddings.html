GPU.js Cosine Similarity for Vector Embeddings

This article explains how to leverage GPU.js to accelerate cosine similarity calculations across high-dimensional vector embeddings directly in JavaScript. By offloading floating-point vector mathematics to the GPU via WebGL shaders, you can compare large batches of embeddings—such as 768-dimensional or 1536-dimensional representations from modern language models—orders of magnitude faster than with standard CPU-bound loops.

The Mathematical Approach and Pre-normalization

Cosine similarity measures the cosine of the angle between two non-zero vectors \(A\) and \(B\):

\[\text{Cosine Similarity} = \frac{A \cdot B}{\|A\| \|B\|}\]

Computing vector magnitudes (\(\|A\|\) and \(\|B\|\)) and square roots repeatedly inside a GPU kernel introduces unnecessary computational overhead. The standard optimization for high-throughput embedding search is pre-normalizing all vectors to unit length (\(L_2\) norm = 1) on ingestion:

\[A_{\text{norm}} = \frac{A}{\|A\|}\]

When embeddings are unit-normalized, the denominator equals 1, reducing the cosine similarity operation strictly to a dot product:

\[\text{Cosine Similarity} = A_{\text{norm}} \cdot B_{\text{norm}} = \sum_{k=0}^{D-1} A_k B_k\]

Implementing the GPU.js Kernel

To compare a single query embedding against a matrix of target embeddings, construct a kernel using GPU.js that assigns each dot product calculation to a distinct parallel thread.

1. Setup and Installation

In a Node.js or browser environment, install and import the library:

npm install gpu.js

2. Kernel Definition

Initialize the GPU instance and define a custom kernel configured for 1D output, where the output length matches the number of target vectors.

import { GPU } from 'gpu.js';

const gpu = new GPU();

// Function to create the similarity kernel
function createCosineSimilarityKernel(vectorCount, dimensions) {
  return gpu.createKernel(
    function (queryVector, targetVectors) {
      let dotProduct = 0;
      for (let i = 0; i < this.constants.dimensions; i++) {
        dotProduct += queryVector[i] * targetVectors[this.thread.x][i];
      }
      return dotProduct;
    },
    {
      constants: { dimensions },
      output: [vectorCount],
      precision: 'single'
    }
  );
}

Complete Execution Example

The following script normalizes high-dimensional sample data, passes the data into the compiled GPU kernel, and extracts the similarity scores.

import { GPU } from 'gpu.js';

const gpu = new GPU();

// Helper: Normalize vector to unit length
function normalizeVector(vector) {
  const norm = Math.sqrt(vector.reduce((acc, val) => acc + val * val, 0));
  return vector.map(val => (norm === 0 ? 0 : val / norm));
}

// Configuration
const DIMENSIONS = 1536; // OpenAI embedding size
const VECTOR_COUNT = 10000;

// Generate dummy data
const rawQuery = Array.from({ length: DIMENSIONS }, () => Math.random() - 0.5);
const rawTargets = Array.from({ length: VECTOR_COUNT }, () =>
  Array.from({ length: DIMENSIONS }, () => Math.random() - 0.5)
);

// Pre-normalize inputs
const queryVector = normalizeVector(rawQuery);
const targetVectors = rawTargets.map(normalizeVector);

// Initialize Kernel
const calculateSimilarities = gpu.createKernel(
  function (query, targets) {
    let dotProduct = 0;
    for (let i = 0; i < this.constants.dim; i++) {
      dotProduct += query[i] * targets[this.thread.x][i];
    }
    return dotProduct;
  },
  {
    constants: { dim: DIMENSIONS },
    output: [VECTOR_COUNT],
    precision: 'single'
  }
);

// Execute on GPU
const similarities = calculateSimilarities(queryVector, targetVectors);

console.log(`Computed ${similarities.length} similarity scores.`);
console.log(`Top match score:`, Math.max(...similarities));

Performance Best Practices

  1. Reuse Compiled Kernels: The compilation of the WebGL shader via gpu.createKernel involves significant overhead. Compile the kernel once during initialization and reuse it across multiple query passes.
  2. Flatten Arrays for Massive Datasets: While GPU.js natively supports 2D arrays, converting datasets into flattened Float32Array buffers can reduce garbage collection spikes and minimize memory serialization overhead between the CPU and the GPU.
  3. Pipeline Subsequent Operations: If you need to retrieve top-\(k\) values, consider chaining a parallel sorting or reduction kernel in GPU.js to avoid transferring the entire similarity array back to main memory.
