How to Convert Video to Grayscale Using GPU.js

Converting real-time RGB video frames into grayscale can be computationally heavy on the CPU, but offloading this pixel manipulation to the GPU using GPU.js makes the process fast and efficient. This article demonstrates how to configure an element-wise GPU.js kernel, capture frames from an HTML5 video element, and apply standard luminance weighting to render high-performance grayscale video directly in the browser.

The Luminance Formula

To convert an RGB color to grayscale, you compute a weighted sum of the red, green, and blue channels to account for human visual perception:

\[\text{Gray} = (0.299 \times R) + (0.587 \times G) + (0.114 \times B)\]

In GPU.js, color channels are normalized between 0.0 and 1.0.

Creating the Graphical Kernel

Using GPU.js's graphical: true option allows the kernel to render its results directly to an internal WebGL canvas via the this.color(r, g, b, a) function.

GPU.js accepts an <video> or <canvas> element directly as an input texture. The kernel runs element-wise for every pixel coordinate [this.thread.x, this.thread.y]:

const gpu = new GPU();

function createGrayscaleKernel(width, height) {
  return gpu.createKernel(
    function(videoFrame) {
      const pixel = videoFrame[this.thread.y][this.thread.x];
      const gray = 0.299 * pixel.r + 0.587 * pixel.g + 0.114 * pixel.b;
      this.color(gray, gray, gray, 1.0);
    },
    {
      output: [width, height],
      graphical: true
    }
  );
}

Implementing the Video Loop

To continuously process the video stream, query requestAnimationFrame once the video's metadata is loaded. Pass the <video> element into the compiled kernel each tick:

const video = document.getElementById('my-video');
let kernel;

video.addEventListener('loadedmetadata', () => {
  const width = video.videoWidth;
  const height = video.videoHeight;

  // Initialize kernel with video dimensions
  kernel = createGrayscaleKernel(width, height);

  // Append GPU.js output canvas to the DOM
  document.body.appendChild(kernel.canvas);

  // Start processing frames
  render();
});

function render() {
  if (!video.paused && !video.ended) {
    kernel(video);
  }
  requestAnimationFrame(render);
}

Key Considerations

  • Texture Orientation: WebGL coordinates originate from the bottom-left corner, whereas HTML video coordinates start at the top-left. GPU.js handles most coordinate flipping automatically, but if your output appears inverted, invert the vertical lookup using (height - 1 - this.thread.y) in the kernel.
  • Performance: Running the kernel with graphical: true bypasses the costly step of transferring raw pixel arrays back to CPU memory, allowing for smooth 60 FPS playback even on high-resolution streams.
