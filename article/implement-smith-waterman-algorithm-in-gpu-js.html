Implement Smith-Waterman Algorithm in GPU.js

This article explains how to implement the Smith-Waterman local sequence alignment algorithm for DNA strings using gpu.js. Because the traditional Smith-Waterman algorithm relies on dynamic programming with sequential cell dependencies, porting it directly to parallel hardware requires specific architectural patterns. You will learn how to encode DNA strings into numeric buffers, parallelize scoring across sequences or matrix anti-diagonals, and run hardware-accelerated kernels in JavaScript.

Understanding the Computational Constraints

The Smith-Waterman algorithm calculates the local alignment score between two sequences, \(A\) (length \(n\)) and \(B\) (length \(m\)), using a substitution matrix and a linear or affine gap penalty. The recurrence relation is:

\[H(i, j) = \max \begin{cases} 0 \\ H(i-1, j-1) + s(A_i, B_j) \\ H(i-1, j) - W \\ H(i, j-1) - W \end{cases}\]

Because cell \((i, j)\) depends strictly on \((i-1, j-1)\), \((i-1, j)\), and \((i, j-1)\), an entire matrix cannot be calculated in a single parallel step. To accelerate this in gpu.js, there are two primary approaches:

  1. Anti-Diagonal (Wavefront) Parallelization: Aligning a single pair of long sequences by processing cells along the anti-diagonals (\(i + j = k\)) in parallel.
  2. Batched Parallel Alignment: Aligning one query sequence against hundreds or thousands of target sequences simultaneously, where each GPU thread computes a complete alignment matrix for a single pair.

For GPU compute environments like gpu.js, which operate over WebGL shaders, Batched Parallel Alignment provides the highest throughput by eliminating CPU-GPU kernel invocation overhead on every diagonal step.

Step 1: Preprocessing and Encoding DNA Strings

gpu.js executes WebGL compute shaders, which cannot natively parse JavaScript string characters ('A', 'C', 'G', 'T'). DNA sequences must be converted into numeric arrays.

const DNA_MAP = { A: 0, C: 1, G: 2, T: 3 };

function encodeDNA(sequence) {
  const encoded = new Float32Array(sequence.length);
  for (let i = 0; i < sequence.length; i++) {
    encoded[i] = DNA_MAP[sequence[i].toUpperCase()] ?? -1;
  }
  return encoded;
}

Target sequences must be padded to uniform lengths so they fit into a structured 2D array suitable for texture input in gpu.js.

Step 2: Defining the Batched Kernel

In this implementation, each thread handles the comparison between the query sequence and one target sequence from a database.

Install and import the dependency:

npm install gpu.js

Define the alignment kernel:

const { GPU } = require('gpu.js');
const gpu = new GPU();

// Scoring parameters
const MATCH = 2;
const MISMATCH = -1;
const GAP = -1;

const MAX_TARGET_LEN = 128; 
const MAX_QUERY_LEN = 128;

const batchedSmithWaterman = gpu.createKernel(function (targets, query, queryLength, targetLengths) {
  const targetIndex = this.thread.x;
  const currentTargetLength = targetLengths[targetIndex];
  
  // Scoring matrix buffer inside local thread memory
  // WebGL requires statically sized arrays within kernels
  let H0 = 0;
  let maxScore = 0;

  // We maintain a 1D row array to track previous row values: H[i-1][j]
  let prevRow[129]; // MAX_QUERY_LEN + 1
  for (let j = 0; j <= queryLength; j++) {
    prevRow[j] = 0;
  }

  for (let i = 1; i <= currentTargetLength; i++) {
    let diag = 0; // Represents H[i-1][j-1]
    
    for (let j = 1; j <= queryLength; j++) {
      const targetChar = targets[targetIndex][i - 1];
      const queryChar = query[j - 1];
      
      const scoreSub = (targetChar === queryChar) ? 2 : -1; // MATCH : MISMATCH
      
      const up = prevRow[j] - 1;       // H[i-1][j] - GAP
      const left = prevRow[j - 1] - 1; // H[i][j-1] - GAP
      const match = diag + scoreSub;   // H[i-1][j-1] + s(a,b)

      let current = 0;
      if (match > current) current = match;
      if (up > current) current = up;
      if (left > current) current = left;

      diag = prevRow[j];
      prevRow[j] = current;

      if (current > maxScore) {
        maxScore = current;
      }
    }
  }

  return maxScore;
})
.setOutput([1000]) // Number of sequences to process in parallel
.setDynamicOutput(true);

Step 3: Anti-Diagonal Kernel for Single Long Sequences

When aligning two very long sequences where memory limits prevent thread-local arrays, use the wavefront method. An iteration loop on the CPU dispatches kernel updates diagonal by diagonal across a 2D matrix stored in GPU texture memory:

const computeDiagonalCell = gpu.createKernel(function (matrix, seqA, seqB, diagonal) {
  const i = this.thread.x + 1;
  const j = diagonal - i;

  if (j >= 1 && j <= this.constants.lenB && i <= this.constants.lenA) {
    const isMatch = seqA[i - 1] === seqB[j - 1];
    const score = isMatch ? 2 : -1;

    const diag = matrix[i - 1][j - 1] + score;
    const up = matrix[i - 1][j] - 1;
    const left = matrix[i][j - 1] - 1;

    let max = 0;
    if (diag > max) max = diag;
    if (up > max) max = up;
    if (left > max) max = left;

    return max;
  }

  return matrix[i][j];
})
.setConstants({ lenA: 512, lenB: 512 })
.setOutput([512])
.setPipeline(true); // Keeps output textures in GPU memory

In this mode, enable .setPipeline(true) to retain matrices on the GPU between successive diagonal iterations, avoiding PCI-e bus transfer bottlenecks.

Step 4: Running Alignment and Extracting Scores

Using the batched model, pack the sequences into arrays and invoke the compiled GPU kernel:

const query = encodeDNA("ACGTACGTACGTACGT");
const targetStrings = [
  "ACGTTCGTACGTACGT",
  "TTCGACGTACGTAAAC",
  "CCCCCCCCCCCCCCCC",
  "ACGTACGTACGTACGT"
];

const targetCount = targetStrings.length;
const paddedTargets = [];
const targetLengths = [];

for (let i = 0; i < targetCount; i++) {
  const encoded = encodeDNA(targetStrings[i]);
  paddedTargets.push(Array.from(encoded));
  targetLengths.push(encoded.length);
}

batchedSmithWaterman.setOutput([targetCount]);

// Run on GPU
const scores = batchedSmithWaterman(paddedTargets, Array.from(query), query.length, targetLengths);

console.log("Alignment Scores:", scores);

Performance Considerations

  • Local Array Limits: WebGL restricts dynamic array allocations inside shaders. Set explicit upper bounds for sequence lengths when declaring loop counters and row caches.
  • Pipeline Mode: For anti-diagonal passes, avoid reading back data to JavaScript inside the diagonal loop. Read from GPU memory only after all anti-diagonals have been computed.
  • Precision: Use 32-bit floating-point or integer arrays for sequences and coordinates. Converting inputs to Float32Array speeds up data transfer to WebGL textures.
