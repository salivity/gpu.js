Batch Normalization in GPU.js Across Channels

Batch normalization stabilizes and accelerates deep neural network execution by standardizing intermediate activations across mini-batches and spatial dimensions. Implementing channel-wise batch normalization using GPU.js allows web-based applications to leverage WebGL shaders for high-throughput parallel processing of multi-dimensional tensors directly in the browser or Node.js. This guide details the mathematical formulation, kernel architecture, and step-by-step implementation required to execute channel-specific batch normalization using GPU.js.

Mathematical Formulation

In convolutional neural networks, batch normalization is applied independently to each feature channel. Given an activation tensor formatted in 4D space as \((N, C, H, W)\) or across 3D feature maps \((W, H, C)\) for single-instance evaluation, the transformation standardizes each channel \(c\) using:

\[\hat{x}_{c} = \frac{x_{c} - \mu_c}{\sqrt{\sigma_c^2 + \epsilon}}\]

\[y_{c} = \gamma_c \cdot \hat{x}_{c} + \beta_c\]

Where:

  • \(x_{c}\) is the input activation value at channel \(c\).
  • \(\mu_c\) is the mean calculated (or precomputed running mean) for channel \(c\).
  • \(\sigma_c^2\) is the variance (or precomputed running variance) for channel \(c\).
  • \(\epsilon\) (epsilon) is a tiny constant added to prevent division by zero (e.g., \(10^{-5}\)).
  • \(\gamma_c\) (gamma) is the learnable channel scaling factor.
  • \(\beta_c\) (beta) is the learnable channel shifting factor.

Kernel Architecture in GPU.js

GPU.js maps multi-dimensional output spaces directly to GPU shader execution threads. When processing a tensor shaped as [Width, Height, Channels]:

  1. The output dimensions of the kernel are configured as [width, height, channels].
  2. GPU.js provides access to current thread indices via this.thread.x, this.thread.y, and this.thread.z.
  3. In this coordinate system, this.thread.x corresponds to the width index, this.thread.y to the height index, and this.thread.z to the channel index.
  4. Channel parameters (gamma, beta, mean, and variance) are passed as 1D arrays, indexed directly by this.thread.z.

Step-by-Step Implementation

1. Initialize GPU.js

Instantiate the GPU environment:

const { GPU } = require('gpu.js');
const gpu = new GPU();

2. Construct the Batch Normalization Kernel

Create a customized WebGL kernel capable of reading the 3D tensor alongside the 1D arrays of channel parameters:

const createBatchNormKernel = (width, height, channels) => {
  return gpu.createKernel(
    function (input, mean, variance, gamma, beta, epsilon) {
      const c = this.thread.z;
      const y = this.thread.y;
      const x = this.thread.x;

      const val = input[c][y][x];
      const m = mean[c];
      const v = variance[c];
      const g = gamma[c];
      const b = beta[c];

      // Standardize and apply affine transformation
      const normalized = (val - m) / Math.sqrt(v + epsilon);
      return (normalized * g) + b;
    }
  )
  .setOutput([width, height, channels])
  .setPrecision('single');
};

3. Prepare Tensor and Parameter Data

Input tensors must be formatted to match the coordinate structure defined by the kernel. For an activation volume with dimensions \(4 \times 4 \times 3\):

const width = 4;
const height = 4;
const channels = 3;
const epsilon = 1e-5;

// Channel-specific parameters (size = channels)
const mean = [0.5, -0.2, 1.1];
const variance = [0.25, 0.81, 0.04];
const gamma = [1.0, 0.5, 2.0];
const beta = [0.0, 0.1, -0.5];

// Generate synthetic 3D input tensor: [channels][height][width]
const inputTensor = [];
for (let c = 0; c < channels; c++) {
  const channelPlane = [];
  for (let y = 0; y < height; y++) {
    const row = [];
    for (let x = 0; x < width; x++) {
      row.push(Math.random() * 2 - 1);
    }
    channelPlane.push(row);
  }
  inputTensor.push(channelPlane);
}

4. Execute the Kernel

Instantiate and execute the compiled kernel using the parameters:

const batchNormKernel = createBatchNormKernel(width, height, channels);
const outputTensor = batchNormKernel(
  inputTensor,
  mean,
  variance,
  gamma,
  beta,
  epsilon
);

console.log(outputTensor);

Handling 4D Mini-Batches

To extend this pattern to 4D tensors \((Batch, Channel, Height, Width)\), you can flatten the batch and channel dimensions or define a 3D kernel where:

  • this.thread.x = Width
  • this.thread.y = Height
  • this.thread.z = Flattened Index (batchIndex * totalChannels + channelIndex)

Inside the kernel, retrieve the specific channel using modulo arithmetic:

const c = this.thread.z % totalChannels;
const m = mean[c];
const v = variance[c];
const g = gamma[c];
const b = beta[c];

This keeps memory access parallel while ensuring each feature map receives normalization parameters dedicated to its specific channel.
