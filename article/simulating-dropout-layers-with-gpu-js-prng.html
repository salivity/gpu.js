Simulating Dropout Layers with GPU.js PRNG

Simulating dropout layers using GPU-based pseudo-random number generators (PRNG) in gpu.js is entirely possible and highly effective for deep learning pipelines in JavaScript. Because standard WebGL and GPU environments lack a native random number generator like JavaScript's Math.random(), dropout requires implementing a deterministic PRNG function directly inside a gpu.js kernel. By feeding unique thread coordinates and an external seed into mathematical hash functions, developers can generate parallelized, independent random masks to deactivate neural connections during training.

How Dropout Works on the GPU

Dropout acts as a regularization technique during neural network training by randomly setting a subset of layer inputs or activations to zero with a probability of \(p\). To maintain mathematical consistency without altering the scale of downstream operations, the network typically applies "inverted dropout." Inverted dropout scales the remaining active nodes by \(1 / (1 - p)\) during training, eliminating the need to modify weights or activations during inference.

In a CPU environment, this is achieved by iterating over an array and calling Math.random(). In a massively parallel GPU environment, each thread computes the activation of a single neuron independently. Therefore, each thread must generate its own pseudo-random value based on its unique spatial location and a changing time-step seed.

Implementing a GPU PRNG in gpu.js

Because gpu.js compiles JavaScript functions into GLSL shaders, any PRNG used within a kernel must rely strictly on arithmetic operations. Common algorithms suitable for GPU execution include Linear Congruential Generators (LCG) or hash-based functions using fractional parts of trigonometric functions.

A lightweight, commonly used hash-based PRNG in shader programming is:

function gpuRandom(x, y, seed) {
  // A standard pseudo-random hash common in GLSL
  let dotProduct = x * 12.9898 + y * 78.233 + seed * 43758.5453;
  let sinVal = Math.sin(dotProduct);
  return Math.abs(sinVal - Math.floor(sinVal));
}

When registered as a gpu.js custom function, this routine can evaluate coordinates independently for each thread.

Building the Dropout Kernel

To construct the dropout layer in gpu.js, the kernel takes the input tensor, the dropout rate \(p\), and a unique seed generated per training batch. The kernel determines whether a neuron stays active based on the generated threshold.

const { GPU } = require('gpu.js');
const gpu = new GPU();

// Register the PRNG as a kernel function
gpu.addFunction(function gpuRandom(x, y, seed) {
  let val = Math.sin(x * 12.9898 + y * 78.233 + seed * 37.719) * 43758.5453;
  return Math.abs(val - Math.floor(val));
});

const dropoutLayer = gpu.createKernel(function(inputs, dropoutRate, seed) {
  const x = this.thread.x;
  const y = this.thread.y;
  
  // Generate a random float between 0.0 and 1.0
  const rand = gpuRandom(x, y, seed);

  // If the random value is less than the dropout rate, zero it out
  if (rand < dropoutRate) {
    return 0;
  } else {
    // Inverted dropout: scale active neurons by 1 / (1 - p)
    return inputs[y][x] / (1 - dropoutRate);
  }

Key Implementation Considerations

  • Seed Variation Across Iterations: GPUs are strictly deterministic. If the same seed parameter is passed every epoch or batch, the exact same neurons will be dropped each time. To ensure proper regularization, generate a new floating-point seed on the CPU (e.g., via Math.random()) for every forward pass.
  • PRNG Quality and Correlation: Sine-based fractional PRNGs can exhibit patterns or correlation artifacts across adjacent threads depending on the precision of the underlying GPU hardware. For deeper networks requiring higher-grade randomness, consider integer-based hash implementations such as PCG or Jenkins hashes adapted for gpu.js functions.
  • Inference Mode Separation: In production or evaluation phases, dropout must be turned off entirely. Rather than running the PRNG kernel with a rate of 0.0, bypass the dropout kernel completely in JavaScript to save GPU compute cycles.
