SPH Density and Pressure in GPU.js

This article demonstrates how to implement the core density and pressure calculation steps of a Smoothed Particle Hydrodynamics (SPH) fluid simulation using gpu.js. By translating particle-particle interaction mathematics into WebGL kernels via gpu.js, you can offload expensive \(O(N^2)\) neighbor evaluations or fixed-radius lookups to the GPU, enabling real-time performance inside the browser or Node.js environments.

1. Mathematical Formulation

Smoothed Particle Hydrodynamics models fluids as discrete particles carrying mass, velocity, density, and pressure. Evaluating fluid mechanics requires estimating continuous field quantities from surrounding neighbor particles using a smoothing kernel function \(W(r, h)\), where \(r\) is the distance between particles and \(h\) is the smoothing radius (support radius).

Density Calculation (Poly6 Kernel)

The density \(\rho_i\) at particle \(i\) is calculated by summing the mass contributions of all neighboring particles within radius \(h\):

\[\rho_i = \sum_{j} m_j W(|\mathbf{r}_i - \mathbf{r}_j|, h)\]

A standard kernel for density estimation in 2D is the Poly6 kernel:

\[W(r, h) = \frac{4}{\pi h^8} (h^2 - r^2)^3 \quad \text{for } 0 \le r \le h\]

Pressure Calculation (Equation of State)

Once density is computed, particle pressure \(P_i\) is derived using an Equation of State (EOS), such as the ideal gas state equation with a rest density offset:

\[P_i = k (\rho_i - \rho_0)\]

Where:

  • \(k\) is the fluid stiffness parameter.
  • \(\rho_0\) is the target rest density.
  • Negative pressures are typically clamped to zero (\(P_i = \max(0, P_i)\)) to prevent particles from clustering unnaturally.

2. Setting Up GPU.js

Initialize the GPU instance and configure the simulation constants.

const { GPU } = require('gpu.js'); // Or window.GPU in the browser
const gpu = new GPU();

const NUM_PARTICLES = 2048;
const H = 16.0;                    // Smoothing radius
const H2 = H * H;                 // Precomputed h^2
const REST_DENSITY = 1.0;
const STIFFNESS = 200.0;
const MASS = 1.0;

// Poly6 normalization constant for 2D: 4 / (PI * h^8)
const POLY6_FACTOR = 4.0 / (Math.PI * Math.pow(H, 8));

3. Implementing the Density Kernel

In gpu.js, the density calculation evaluates each particle in parallel along the thread index this.thread.x. Each thread iterates through every other particle to determine if it falls within distance \(h\).

const calculateDensity = gpu.createKernel(function(positions, count, mass, h2, poly6Factor) {
    const i = this.thread.x;
    const px = positions[i][0];
    const py = positions[i][1];

    let density = 0.0;

    for (let j = 0; j < count; j++) {
        const dx = px - positions[j][0];
        const dy = py - positions[j][1];
        const distSq = dx * dx + dy * dy;

        if (distSq < h2) {
            const diff = h2 - distSq;
            // W(r, h) = poly6Factor * (h^2 - r^2)^3
            density += mass * poly6Factor * (diff * diff * diff);
        }
    }

    return density;
})
.setOutput([NUM_PARTICLES])
.setPipeline(true); // Keeps output on GPU memory for subsequent passes

4. Implementing the Pressure Kernel

Because pressure is an explicit function of local density, its calculation does not require neighbor iteration. It can be computed in an independent kernel using the output of the density kernel.

const calculatePressure = gpu.createKernel(function(densities, restDensity, stiffness) {
    const i = this.thread.x;
    const density = densities[i];
    
    // P = k * (rho - rho0)
    let pressure = stiffness * (density - restDensity);
    
    // Clamp negative pressures to avoid unnatural attraction
    if (pressure < 0.0) {
        pressure = 0.0;
    }

    return pressure;
})
.setOutput([NUM_PARTICLES])
.setPipeline(true);

5. Fused Density-Pressure Implementation

To optimize memory bandwidth and reduce kernel invocation overhead, density and pressure can be calculated within a single unified kernel that outputs a 2D vector [density, pressure].

const calculateDensityAndPressure = gpu.createKernel(function(positions, count, mass, h2, poly6Factor, restDensity, stiffness) {
    const i = this.thread.x;
    const px = positions[i][0];
    const py = positions[i][1];

    let density = 0.0;

    for (let j = 0; j < count; j++) {
        const dx = px - positions[j][0];
        const dy = py - positions[j][1];
        const distSq = dx * dx + dy * dy;

        if (distSq < h2) {
            const diff = h2 - distSq;
            density += mass * poly6Factor * (diff * diff * diff);
        }
    }

    let pressure = stiffness * (density - restDensity);
    if (pressure < 0.0) {
        pressure = 0.0;
    }

    // Output: index 0 = density, index 1 = pressure
    return [density, pressure];
})
.setOutput([NUM_PARTICLES]);

6. Execution Loop

Prepare flat coordinate data and execute the calculation pipeline:

// Initialize particle positions [ [x0, y0], [x1, y1], ... ]
const positions = new Float32Array(NUM_PARTICLES * 2);
for (let i = 0; i < NUM_PARTICLES; i++) {
    positions[i * 2] = Math.random() * 200;
    positions[i * 2 + 1] = Math.random() * 200;
}

// Convert flat array to array of pairs for gpu.js input
const particleCoords = [];
for (let i = 0; i < NUM_PARTICLES; i++) {
    particleCoords.push([positions[i * 2], positions[i * 2 + 1]]);
}

// Execute density and pressure computation
const fluidState = calculateDensityAndPressure(
    particleCoords,
    NUM_PARTICLES,
    MASS,
    H2,
    POLY6_FACTOR,
    REST_DENSITY,
    STIFFNESS
);

// Access results: fluidState[i][0] is density, fluidState[i][1] is pressure
console.log(`Particle 0 - Density: ${fluidState[0][0]}, Pressure: ${fluidState[0][1]}`);

Using .setPipeline(true) allows these calculated fields to remain on the GPU texture memory, where they can be piped directly into force and integration kernels (such as Navier-Stokes pressure gradient and viscosity evaluation) without CPU round-trips.
