Compute Image SSIM Maps Using GPU.js

This article provides an overview of calculating the Structural Similarity Index Measure (SSIM) map between two images using gpu.js. It details the mathematical principles behind the local SSIM algorithm, outlines how to translate sliding-window operations into parallel WebGL shader kernels, and provides an end-to-end code example for computing the SSIM map directly in the browser or Node.js environment.

Understanding the SSIM Formula

The Structural Similarity Index Measure evaluates image degradation by comparing luminance, contrast, and structure across localized image patches. For two corresponding local windows, \(x\) and \(y\), the local SSIM value is computed as:

\[\text{SSIM}(x, y) = \frac{(2\mu_x\mu_y + C_1)(2\sigma_{xy} + C_2)}{(\mu_x^2 + \mu_y^2 + C_1)(\sigma_x^2 + \sigma_y^2 + C_2)}\]

  • \(\mu_x\) and \(\mu_y\) represent the local mean intensities of windows \(x\) and \(y\).
  • \(\sigma_x^2\) and \(\sigma_y^2\) represent the local variances.
  • \(\sigma_{xy}\) represents the local covariance.
  • \(C_1 = (K_1 \cdot L)^2\) and \(C_2 = (K_2 \cdot L)^2\) are stabilization constants, where \(L\) is the dynamic range of pixel values (typically 255 for 8-bit images or 1.0 for normalized floats), \(K_1 = 0.01\), and \(K_2 = 0.03\).

Evaluating this over every pixel produces an SSIM map, where each coordinate holds a similarity score ranging from -1 to 1 (with 1 representing identical patches).

Implementing SSIM on the GPU

Computing local statistics across an entire image requires sliding an \(N \times N\) window (typically \(8 \times 8\) or \(11 \times 11\)) over every pixel. Executing this on the CPU is computationally expensive due to nested iteration loops. gpu.js compiles JavaScript functions into WebGL fragment shaders, mapping each thread directly to an output pixel coordinate (this.thread.x, this.thread.y) for massive parallel execution.

1. Preparing the Data

Convert your source images to grayscale and flatten them into 2D arrays of identical dimensions [height][width], normalized to values between 0.0 and 1.0.

2. Writing the gpu.js Kernel

The kernel computes the local window statistics per pixel. Using a uniform sliding window with radius \(R\) (window size \(W = 2R + 1\)):

import { GPU } from 'gpu.js';

const gpu = new GPU();

function createSSIMKernel(width, height, windowRadius = 4) {
  return gpu.createKernel(
    function (img1, img2, radius, c1, c2) {
      const x = this.thread.x;
      const y = this.thread.y;

      let sumX = 0;
      let sumY = 0;
      let sumX2 = 0;
      let sumY2 = 0;
      let sumXY = 0;
      let count = 0;

      // Iterate through the local window
      for (let dy = -radius; dy <= radius; dy++) {
        for (let dx = -radius; dx <= radius; dx++) {
          const px = x + dx;
          const py = y + dy;

          // Boundary checks to ignore padding
          if (px >= 0 && px < this.constants.width && py >= 0 && py < this.constants.height) {
            const val1 = img1[py][px];
            const val2 = img2[py][px];

            sumX += val1;
            sumY += val2;
            sumX2 += val1 * val1;
            sumY2 += val2 * val2;
            sumXY += val1 * val2;
            count += 1;
          }
        }
      }

      // Compute means
      const muX = sumX / count;
      const muY = sumY / count;

      // Compute variances and covariance
      const varX = (sumX2 / count) - (muX * muX);
      const varY = (sumY2 / count) - (muY * muY);
      const covXY = (sumXY / count) - (muX * muY);

      // Compute local SSIM
      const numerator = (2 * muX * muY + c1) * (2 * covXY + c2);
      const denominator = (muX * muX + muY * muY + c1) * (varX + varY + c2);

      return numerator / denominator;
    },
    {
      constants: { width, height },
      output: [width, height],
      pipeline: false // Set to true if chaining kernels to prevent GPU-CPU readback
    }
  );
}

Execution and Mean SSIM (MSSIM) Calculation

Once the kernel completes execution, the returned matrix contains the local similarity indices. To derive the global Mean Structural Similarity (MSSIM) score, calculate the average of all valid pixels within the generated map.

const width = 512;
const height = 512;
const radius = 4; // Yields a 9x9 local window

// Dynamic range constants for normalized [0, 1] inputs
const L = 1.0;
const K1 = 0.01;
const K2 = 0.03;
const C1 = (K1 * L) ** 2;
const C2 = (K2 * L) ** 2;

// Initialize kernel
const ssimKernel = createSSIMKernel(width, height, radius);

// Run calculation with two 2D arrays: imageA and imageB
const ssimMap = ssimKernel(imageA, imageB, radius, C1, C2);

// Compute overall MSSIM on CPU
let totalSSIM = 0;
for (let y = 0; y < height; y++) {
  for (let x = 0; x < width; x++) {
    totalSSIM += ssimMap[y][x];
  }
}
const mssim = totalSSIM / (width * height);

Optimization Considerations

  • Window Size vs. Texture Reads: Larger radii increase memory access within the shader. A radius of \(4\) or \(5\) (\(9\times9\) or \(11\times11\)) achieves an optimal balance between statistical accuracy and texture sampling overhead.
  • Separable Convolution: For strict conformance with the original Wang et al. specification (which uses a Gaussian weight filter), implement the computation in two passes (horizontal and vertical Gaussian blur kernels) before combining terms in a final SSIM kernel.
  • Pipeline Mode: If the resulting SSIM map must be used downstream (such as for visualization or loss tracking in machine learning pipelines), enable pipeline: true on the kernel to keep texture buffers directly in VRAM without incurring memory readback penalties.
