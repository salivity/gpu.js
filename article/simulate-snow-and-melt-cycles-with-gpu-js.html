Simulate Snow and Melt Cycles with GPU.js

Simulating realistic snow accumulation and melting across geometric landscapes requires heavy per-cell mathematical calculations, which can bottleneck standard CPU-bound JavaScript applications. By leveraging GPU.js, developers can execute parallel compute shaders directly in the browser using familiar JavaScript syntax, offloading terrain physics to the graphics processor. This article explains how to set up heightfield-based terrain matrices, calculate environmental factors like temperature lapse rates and solar exposure, and write iterative GPU.js kernels that govern accumulation, melting, and slope-based snow slippage.

1. Representing the Landscape and Climate Data

A geometric landscape is most efficiently represented on the GPU as a 2D matrix (a heightmap), where each coordinate (x, y) stores the terrain's base elevation. To track the lifecycle of snow, maintain a secondary 2D matrix of the same dimensions for snow depth.

The simulation relies on three key environmental variables:

  • Temperature Lapse Rate: Air temperature decreases as elevation increases, determining whether precipitation falls as snow or rain.
  • Insolation (Solar Radiation): South-facing and steep slopes receive varying amounts of direct sunlight based on surface normals, accelerating melt rates.
  • Angle of Repose: Snow unstable on steep slopes slides downward to lower elevations (avalanching).

2. Initializing GPU.js

Install and import GPU.js into your project, then instantiate the GPU context:

import { GPU } from 'gpu.js';

const gpu = new GPU();
const resolution = 512; // Grid resolution (512x512)

3. Creating the Accumulation and Melt Kernel

The primary kernel computes changes in snow depth for each grid point based on precipitation, ambient temperature, elevation, and direct sunlight exposure.

const simulateSnowCycle = gpu.createKernel(function(
  terrain,
  snow,
  ambientTemp,
  snowfallRate,
  sunDirX,
  sunDirY,
  sunDirZ,
  cellSize
) {
  const x = this.thread.x;
  const y = this.thread.y;

  const currentElevation = terrain[y][x];
  const currentSnow = snow[y][x];
  const totalHeight = currentElevation + currentSnow;

  // 1. Calculate Local Temperature (Lapse rate: -6.5C per 1000m)
  const localTemp = ambientTemp - (totalHeight * 0.0065);

  // 2. Accumulation: Only accumulate if below freezing
  let newSnow = currentSnow;
  if (localTemp <= 0.0) {
    newSnow += snowfallRate;
  }

  // 3. Approximate Surface Normal for Solar Radiation
  // Sample adjacent heights to get terrain gradient
  const left = terrain[y][Math.max(0, x - 1)] + snow[y][Math.max(0, x - 1)];
  const right = terrain[y][Math.min(511, x + 1)] + snow[y][Math.min(511, x + 1)];
  const down = terrain[Math.max(0, y - 1)][x] + snow[Math.max(0, y - 1)][x];
  const up = terrain[Math.min(511, y + 1)][x] + snow[Math.min(511, y + 1)][x];

  const dx = (right - left) / (2.0 * cellSize);
  const dy = (up - down) / (2.0 * cellSize);
  const dz = 1.0;

  // Normalize surface normal vector
  const length = Math.sqrt(dx * dx + dy * dy + dz * dz);
  const nx = -dx / length;
  const ny = -dy / length;
  const nz = dz / length;

  // 4. Calculate Solar Exposure (Dot Product)
  const dotSun = Math.max(0.0, (nx * sunDirX) + (ny * sunDirY) + (nz * sunDirZ));

  // 5. Melt Calculation
  if (localTemp > 0.0) {
    // Ambient heat melt + direct solar radiation melt
    const meltAmount = (localTemp * 0.02) + (dotSun * 0.05);
    newSnow = Math.max(0.0, newSnow - meltAmount);
  }

  return newSnow;
})
.setOutput([resolution, resolution])
.setPipeline(true); // Keeps output in GPU memory for performance

4. Simulating Mass Movement (Snow Slumping)

Snow cannot maintain vertical edges indefinitely. If the angle between a cell and its neighbors exceeds the critical angle of repose (typically around 35 to 45 degrees), excess snow must shift downhill.

const simulateSlippage = gpu.createKernel(function(terrain, snow, maxSlope, cellSize) {
  const x = this.thread.x;
  const y = this.thread.y;

  let currentSnow = snow[y][x];
  const centerHeight = terrain[y][x] + currentSnow;

  // Check 4-connected neighbors for steep downhill gradients
  const offsetsX = [-1, 1, 0, 0];
  const offsetsY = [0, 0, -1, 1];

  for (let i = 0; i < 4; i++) {
    const nx = Math.min(Math.max(x + offsetsX[i], 0), 511);
    const ny = Math.min(Math.max(y + offsetsY[i], 0), 511);

    const neighborHeight = terrain[ny][nx] + snow[ny][nx];
    const diff = centerHeight - neighborHeight;

    // If slope exceeds threshold, shed excess snow
    if (diff > maxSlope && currentSnow > 0.0) {
      const transfer = (diff - maxSlope) * 0.125;
      currentSnow -= Math.min(currentSnow, transfer);
    }
  }

  return currentSnow;
})
.setOutput([resolution, resolution])
.setPipeline(true);

5. Running the Simulation Loop

To execute the simulation continuously, chain the pipeline kernels in an update loop:

let snowTexture = initialSnowMatrix; // Can start as zeros

function updateSimulation() {
  // Step 1: Accumulate and melt based on weather
  const weatherPass = simulateSnowCycle(
    terrainMatrix,
    snowTexture,
    5.0,            // Ambient temperature in Celsius
    0.1,            // Snowfall rate
    0.577, 0.577, 0.577, // Normalized sun direction vector
    1.0             // Cell size
  );

  // Step 2: Handle slippage/avalanching
  snowTexture = simulateSlippage(
    terrainMatrix,
    weatherPass,
    1.5,            // Maximum slope height difference
    1.0             // Cell size
  );

  requestAnimationFrame(updateSimulation);
}

updateSimulation();

6. Visualizing the Result

Because .setPipeline(true) is used, the output remains on the GPU as a WebGL texture. This texture can be passed directly to rendering frameworks such as Three.js or Babylon.js as a displacement map or combined into custom terrain shaders to dynamically color snow white and rock brown based on the computed snow depth.
