Simulate FitzHugh-Nagumo Spiral Waves in GPU.js

This article explains how to simulate excitable media and generate spiral wave dynamics using the FitzHugh-Nagumo (FHN) reaction-diffusion model accelerated by gpu.js. You will learn the underlying mathematical equations, how to implement finite-difference spatial diffusion on the GPU using WebGL shaders, how to create the initial conditions required to produce spiral breakups, and how to render the simulation in real time directly to an HTML5 canvas.

The FitzHugh-Nagumo Model

The FitzHugh-Nagumo model is a simplified two-variable reduction of the Hodgkin-Huxley model describing electrophysiological excitation. In a two-dimensional spatial domain, it functions as a reaction-diffusion system:

\[\frac{\partial u}{\partial t} = D \nabla^2 u + u - \frac{u^3}{3} - v\]

\[\frac{\partial v}{\partial t} = \epsilon (u + a - b v)\]

Where:

  • \(u\) represents the fast activator variable (membrane potential).
  • \(v\) represents the slow inhibitor variable (recovery variable).
  • \(D\) is the diffusion coefficient of the activator (inhibitor diffusion is typically assumed to be zero or negligible).
  • \(\nabla^2\) is the 2D Laplacian operator modeling spatial diffusion.
  • \(\epsilon, a,\) and \(b\) are dimensionless kinetic parameters determining excitability and threshold kinetics.

Setting Up GPU.js

gpu.js compiles JavaScript functions into WebGL fragment shaders, allowing thousands of grid cells to be updated concurrently on the GPU.

First, include the library in your environment:

<script src="https://cdn.jsdelivr.net/npm/gpu.js@latest/dist/gpu-browser.min.js"></script>

Initialize the GPU context:

const gpu = new GPU();
const width = 512;
const height = 512;

Discretizing the Spatial Domain

The Laplacian \(\nabla^2 u\) is computed using a 2D five-point discrete stencil on a regular Cartesian grid with grid spacing \(h\):

\[\nabla^2 u_{i,j} \approx \frac{u_{i+1,j} + u_{i-1,j} + u_{i,j+1} + u_{i,j-1} - 4u_{i,j}}{h^2}\]

Using periodic boundary conditions ensures that waves exiting one boundary re-enter from the opposite side without artificial boundary reflections.

Implementing the Computation Kernel

To advance the state, both variables must be integrated numerically using the forward Euler method with a stable time-step \(dt\). The state is stored across two 2D arrays: one for \(u\) and one for \(v\).

const updateFHN = gpu.createKernel(function(u, v, dt, D, eps, a, b, dx) {
    const x = this.thread.x;
    const y = this.thread.y;
    const w = this.constants.width;
    const h = this.constants.height;

    // Periodic boundary conditions
    const left = (x === 0) ? w - 1 : x - 1;
    const right = (x === w - 1) ? 0 : x + 1;
    const down = (y === 0) ? h - 1 : y - 1;
    const up = (y === h - 1) ? 0 : y + 1;

    const u_center = u[y][x];
    const v_center = v[y][x];

    // Compute discrete Laplacian for the activator
    const laplacian = (
        u[y][left] + 
        u[y][right] + 
        u[up][x] + 
        u[down][x] - 
        4.0 * u_center
    ) / (dx * dx);

    // FitzHugh-Nagumo reaction dynamics
    const du = (D * laplacian + u_center - (u_center * u_center * u_center) / 3.0 - v_center) * dt;
    const dv = (eps * (u_center + a - b * v_center)) * dt;

    // Return new u value (run a second kernel or output multi-channel for v)
    return u_center + du;
})
.setConstants({ width, height })
.setOutput([width, height])
.setPipeline(true);

For optimal performance, update \(v\) using an identical kernel structure configured to output the recovery field. Enabling .setPipeline(true) ensures that the textures stay directly in GPU VRAM between integration steps.

Generating Spiral Waves

Spiral waves (rotors) do not occur from resting states; they require a broken wavefront where an excited wave meets a refractory region.

  1. Planar Wave Generation: Excite a vertical stripe of the domain by setting \(u = 1.0\) for \(x \in [0, 50]\) while the rest of the domain remains in the rest state (\(u = -1.2, v = -0.6\)).
  2. Wave Cutting: Allow the planar wave to propagate halfway across the grid. Set the bottom half of the domain (\(y < height / 2\)) to the refractory recovery state (\(v = 1.0\)) while setting \(u = 0.0\).
  3. Curling: The top half of the wave continues propagating, while the bottom portion stalls against the refractory zone. The free end curls around the singular phase point, initiating a self-sustaining spiral wave.
function initializeStates() {
    let u = [];
    let v = [];
    for (let y = 0; y < height; y++) {
        let uRow = [];
        let vRow = [];
        for (let x = 0; x < width; x++) {
            // Broken wavefront configuration
            if (x > width / 4 && x < width / 2 && y > height / 2) {
                uRow.push(1.5); // Excited
                vRow.push(-0.5);
            } else if (y <= height / 2 && x > width / 4 && x < 3 * width / 4) {
                uRow.push(-1.0);
                vRow.push(1.0);  // Refractory barrier
            } else {
                uRow.push(-1.2); // Rest state
                vRow.push(-0.6);
            }
        }
        u.push(uRow);
        v.push(vRow);
    }
    return { u, v };
}

Rendering to Canvas

Use a dedicated rendering kernel to project activator values directly into graphical fragment outputs using an HTML canvas:

const renderKernel = gpu.createKernel(function(u) {
    const val = (u[this.thread.y][this.thread.x] + 2.0) / 4.0; // Normalize between 0 and 1
    this.color(val, val * 0.2, 1.0 - val, 1.0);
})
.setOutput([width, height])
.setGraphical(true);

document.body.appendChild(renderKernel.canvas);

Execution Loop

Run integration and drawing steps continuously using requestAnimationFrame:

let { u, v } = initializeStates();
const dt = 0.05;
const D = 1.0;
const eps = 0.08;
const a = 0.7;
const b = 0.8;
const dx = 1.0;

function step() {
    // Perform multiple reaction-diffusion steps per visual frame
    for (let i = 0; i < 8; i++) {
        const nextU = updateFHN(u, v, dt, D, eps, a, b, dx);
        const nextV = updateRecovery(u, v, dt, eps, a, b);

requestAnimationFrame(step);
