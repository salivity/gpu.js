Tube Saturation and Waveshaping in gpu.js

This guide demonstrates how to implement nonlinear waveshaping distortion and vacuum tube saturation algorithms on the GPU using gpu.js. By delegating per-sample transfer functions to parallel shader pipelines, you can process large buffers of audio data with high computational efficiency. Below, you will explore the mathematical foundations of symmetric and asymmetric transfer functions, followed by concrete kernel implementations for real-time or offline audio processing.

Mathematical Transfer Functions

Waveshaping modifies an audio signal by mapping an input sample \(x\) to an output sample \(y\) using a static nonlinear function \(f(x)\):

\[y = f(x)\]

Symmetrical Waveshaping (Soft Clipping)

Symmetric functions generate predominantly odd harmonics, producing an overdriven solid-state sound. Common functions include the hyperbolic tangent (\(\tanh\)) or algebraic soft clippers:

\[f(x) = \tanh(\alpha \cdot x)\]

Or an algebraic approximation that computes faster in GLSL:

\[f(x) = \frac{x}{\sqrt{1 + x^2}}\]

Tube Saturation (Asymmetric Clipping)

Vacuum tubes (such as 12AX7 triodes) exhibit asymmetric clipping, where the positive half of the waveform rounds off smoothly while the negative half clips more abruptly or compresses differently. This asymmetry generates both even and odd harmonics, creating warmth.

A common triode transfer model introduces a DC operating point (grid bias) and an exponential or asymmetric curve:

\[f(x) = \frac{(x + b) - k(x + b)^3}{1 + c|x + b|}\]

Where:

  • \(b\) is the grid bias (creates even-order harmonics).
  • \(k\) controls compression sharpness.
  • \(c\) shapes the knee.

Implementing Kernels in gpu.js

Because gpu.js transpiles JavaScript functions into WebGL shaders, control flow and math operations are constrained to operations supported by GLSL (e.g., standard arithmetic, Math.tanh, Math.abs, Math.exp, Math.sqrt).

1. Setup and Initialization

First, initialize GPU and define the audio buffer size. GPU processing is most efficient when handling large chunks of audio (e.g., 65,536 samples or multi-channel stems) to amortize the cost of sending data to VRAM.

import { GPU } from 'gpu.js';

const gpu = new GPU();

2. Defining the Waveshaping Kernel

This kernel applies adjustable input gain (drive), an asymmetric transfer function, a DC bias to generate tube-like even harmonics, and output scaling.

const processTubeDistortion = gpu.createKernel(function(samples, drive, bias, mix) {
    const i = this.thread.x;
    const input = samples[i];

    // Apply input drive and bias offset
    const x = (input * drive) + bias;

    // Asymmetric transfer function
    let y = 0.0;
    if (x > 0.0) {
        // Soft positive saturation (triode conduction)
        y = 1.0 - Math.exp(-x);
    } else {
        // Harder negative saturation (cutoff region)
        y = -Math.log(1.0 - x);
    }

    // Remove DC component introduced by bias
    const shaped = y - bias;

    // Dry/Wet mixing
    return (shaped * mix) + (input * (1.0 - mix));
}).setOutput([44100]); // Process 1 second of 44.1kHz audio at a time

3. Mathematical Approximation for Pure WebGL Optimization

When targeting platforms where transcendental functions (Math.exp, Math.log) incur high performance costs, use an algebraic polynomial:

const processFastTube = gpu.createKernel(function(samples, drive, bias) {
    const i = this.thread.x;
    let x = (samples[i] * drive) + bias;

    // Clamp range to avoid instability
    if (x > 1.5) x = 1.5;
    if (x < -1.5) x = -1.5;

    // Asymmetric cubic polynomial
    let out = 0.0;
    if (x < -1.0) {
        out = -0.6666;
    } else if (x > 1.0) {
        out = 0.6666;
    } else {
        // Produces even harmonics via the quadratic term (x * x)
        out = x - 0.15 * (x * x) - 0.3333 * (x * x * x);
    }

    // Output normalization and DC removal
    return out - bias;
}).setOutput([44100]);

Execution Pipeline

To process audio buffers:

  1. Extract audio channel data as a Float32Array.
  2. Pass the array and parameters to the compiled kernel.
  3. Retrieve the typed array result from the GPU.
const sampleRate = 44100;
const inputBuffer = new Float32Array(sampleRate);

// Populate input buffer with test signal (e.g., sine wave)
for (let i = 0; i < sampleRate; i++) {
    inputBuffer[i] = Math.sin((2 * Math.PI * 440 * i) / sampleRate);
}

// Processing parameters
const drive = 2.5; // Gain applied to signal
const bias = 0.2;   // Tube grid bias (asymmetry factor)
const mix = 1.0;    // 100% wet

// Execute on GPU
const processedBuffer = processTubeDistortion(inputBuffer, drive, bias, mix);

Key Considerations for Audio in WebGL

  • Aliasing: Nonlinear distortion creates high-frequency harmonics that easily exceed the Nyquist frequency (\(f_s / 2\)). In production, run the GPU kernel at an oversampled rate (e.g., \(2\times\) or \(4\times\) buffer size), then apply an anti-aliasing low-pass filter before downsampling.
  • Latency vs. Throughput: The PCI bus transfer between system RAM and GPU memory creates overhead. Using gpu.js for audio is optimal for offline rendering, batch-processing stems, or multi-voice synthesizers where thousands of simultaneous voices are calculated in parallel.
