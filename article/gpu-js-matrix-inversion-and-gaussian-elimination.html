GPU.js Matrix Inversion and Gaussian Elimination

This article provides a practical guide on implementing matrix inversion using the Gauss-Jordan elimination algorithm accelerated by GPU.js. You will learn the computational mechanics of mapping matrix row operations to parallel GPU kernels, managing state transitions across elimination steps, and writing clean, executable JavaScript to invert dense matrices efficiently on the GPU.

Understanding Parallel Gauss-Jordan Elimination

Standard Gaussian elimination transforms a matrix into upper triangular form, while Gauss-Jordan elimination reduces it fully to reduced row-echelon form. To compute the inverse of an \(n \times n\) matrix \(A\):

  1. Create an augmented matrix \([A \mid I]\) of dimension \(n \times 2n\), where \(I\) is the identity matrix.
  2. For each pivot column \(k\) from \(0\) to \(n - 1\):
    • Normalize the pivot row so that the pivot element equals \(1\).
    • Eliminate the values in column \(k\) for all other rows \(i \neq k\) by subtracting a multiple of the pivot row.
  3. The augmented matrix transforms into \([I \mid A^{-1}]\), where the right half contains the inverted matrix.

Because each elimination step depends on the previous row's results, the outer pivot loop (\(k = 0 \dots n-1\)) must run sequentially on the CPU. However, updating the \(n \times 2n\) elements during each step is an embarrassingly parallel operation perfectly suited for GPU execution via GPU.js.

Setting Up the GPU.js Elimination Kernel

GPU.js compiles JavaScript functions into WebGL shaders. To avoid expensive readbacks between CPU and GPU on each iteration, enable pipeline mode (pipeline: true).

const { GPU } = require('gpu.js');
const gpu = new GPU();

// Kernel to perform one step of Gauss-Jordan elimination
const eliminateStep = gpu.createKernel(function(matrix, n, k) {
    const row = this.thread.y;
    const col = this.thread.x;

    // Read the pivot element
    const pivot = matrix[k][k];
    
    // Guard against singular matrix (zero pivot)
    if (Math.abs(pivot) < 1e-8) {
        return matrix[row][col];
    }

    // Read current element
    const currentVal = matrix[row][col];

    // Normalize the pivot row
    if (row === k) {
        return currentVal / pivot;
    }

    // Eliminate column elements in non-pivot rows
    const factor = matrix[row][k] / pivot;
    const pivotRowVal = matrix[k][col];

    return currentVal - factor * pivotRowVal;
})
.setDynamicOutput(true)
.setPipeline(true);

Implementing Matrix Inversion

To invert the matrix, augment it with the identity matrix, iteratively dispatch the kernel across all pivot rows, and slice out the resulting inverse.

function invertMatrix(A) {
    const n = A.length;
    const totalCols = 2 * n;

    // Step 1: Build the augmented matrix [A | I]
    const augmented = [];
    for (let i = 0; i < n; i++) {
        augmented[i] = new Float32Array(totalCols);
        for (let j = 0; j < n; j++) {
            augmented[i][j] = A[i][j];
        }
        augmented[i][n + i] = 1.0; // Identity component
    }

    // Configure the kernel output size: [columns, rows]
    eliminateStep.setOutput([totalCols, n]);

    // Step 2: Iterative elimination across each pivot
    let currentMatrix = augmented;
    for (let k = 0; k < n; k++) {
        currentMatrix = eliminateStep(currentMatrix, n, k);
    }

    // Step 3: Extract the inverted matrix from the GPU
    const resultAugmented = currentMatrix.toArray();
    const inverse = [];
    for (let i = 0; i < n; i++) {
        inverse[i] = [];
        for (let j = 0; j < n; j++) {
            inverse[i][j] = resultAugmented[i][n + j];
        }
    }

    return inverse;
}

Usage Example

const matrix = [
    [4, 7],
    [2, 6]
];

const inverse = invertMatrix(matrix);
console.log(inverse);
// Output: 
// [ [ 0.6, -0.7 ], 
//   [ -0.2, 0.4 ] ]

Performance Considerations

  • Pipeline Mode: Setting pipeline: true keeps matrix textures in VRAM between iterations, eliminating CPU-to-GPU data transfer overhead during the \(n\) loop steps.
  • Pivoting: The basic implementation assumes non-zero diagonal entries. For numerically unstable or near-singular matrices, add a partial pivoting step (row swapping) on the CPU before each kernel dispatch.
  • Matrix Dimension Thresholds: The overhead of WebGL draw calls makes this GPU implementation most beneficial for larger matrices (\(n \ge 256\)). For smaller matrices, standard CPU-based LU or QR decomposition is generally faster.
