Render Real-Time Volumetric Clouds with GPU.js

This article provides a technical walkthrough for rendering real-time volumetric clouds in the browser by combining procedural 3D noise generation via gpu.js with a WebGL raymarching fragment shader. You will learn how to compute multi-frequency 3D Worley and Perlin noise buffers using GPU-accelerated JavaScript kernels, pack them into a 3D WebGL texture, and evaluate cloud density, light transmittance, and atmospheric scattering inside a real-time volumetric raymarcher.

1. Generating 3D Noise with gpu.js

Realistic volumetric clouds require a combination of low-frequency base shape noise (Perlin-Worley) to define the bulk mass and high-frequency erosion noise (Worley) to carve billowy details. Because computing these 3D noise fields is computationally heavy on the CPU, gpu.js allows you to offload the mathematical generation directly to the graphics hardware using browser compute kernels.

Set up a gpu.js kernel with a 3D output dimension (e.g., \(128 \times 128 \times 128\)):

const gpu = new GPU();

// Kernel generating 3D Worley/Cellular noise
const createWorleyNoise3D = gpu.createKernel(function(scale) {
    let x = this.thread.x / this.constants.size;
    let y = this.thread.y / this.constants.size;
    let z = this.thread.z / this.constants.size;

    // Procedural cell feature point distance check
    let minDist = 1.0;
    for (let i = -1; i <= 1; i++) {
        for (let j = -1; j <= 1; j++) {
            for (let k = -1; k <= 1; k++) {
                // Determine pseudo-random cell point position
                let cell = [Math.floor(x * scale) + i, Math.floor(y * scale) + j, Math.floor(z * scale) + k];
                let feature = pseudoRandom3D(cell[0], cell[1], cell[2]);
                let diff = [cell[0] + feature[0] - x * scale, cell[1] + feature[1] - y * scale, cell[2] + feature[2] - z * scale];
                let dist = Math.sqrt(diff[0]*diff[0] + diff[1]*diff[1] + diff[2]*diff[2]);
                if (dist < minDist) minDist = dist;
            }
        }
    }
    return 1.0 - minDist;
})
.setConstants({ size: 128 })
.setOutput([128, 128, 128])
.setOutputToTexture(false); // Outputs a typed array

This kernel generates an array of continuous 3D density points representing single or multi-octave cellular patterns.

2. Transferring the Noise Buffer to WebGL 2

WebGL 2 natively supports the gl.TEXTURE_3D target. The 3D flat output array produced by gpu.js must be passed into an OpenGL 3D texture buffer so that the fragment shader can perform trilinear volumetric texture filtering.

const noiseData = new Uint8Array(createWorleyNoise3D(4.0).flat(2).map(v => v * 255));

const texture3D = gl.createTexture();
gl.bindTexture(gl.TEXTURE_3D, texture3D);
gl.texParameteri(gl.TEXTURE_3D, gl.TEXTURE_MIN_FILTER, gl.LINEAR);
gl.texParameteri(gl.TEXTURE_3D, gl.TEXTURE_MAG_FILTER, gl.LINEAR);
gl.texParameteri(gl.TEXTURE_3D, gl.TEXTURE_WRAP_S, gl.REPEAT);
gl.texParameteri(gl.TEXTURE_3D, gl.TEXTURE_WRAP_T, gl.REPEAT);
gl.texParameteri(gl.TEXTURE_3D, gl.TEXTURE_WRAP_R, gl.REPEAT);

gl.texImage3D(
    gl.TEXTURE_3D, 0, gl.R8,
    128, 128, 128, 0,
    gl.RED, gl.UNSIGNED_BYTE, noiseData
);

3. Implementing the Volumetric Raymarching Shader

The rendering pipeline utilizes a screen-filling quad or an inverted geometric container (like a bounding box or planetary atmosphere shell). Inside the fragment shader, a ray is projected from the camera through each pixel into the world space.

Ray-Box Intersection

Calculate where the camera ray enters (\(t_{\text{near}}\)) and exits (\(t_{\text{far}}\)) the cloud volume. Raymarching steps only need to occur between these two boundary distances.

Sampling Density

At each ray step along the ray vector:

  1. Translate world coordinates by a wind vector over time: p = rayPos + windVector * time.
  2. Map world coordinates into normalized texture coordinates: uvw = p / volumeDimensions.
  3. Sample the base 3D noise texture generated by gpu.js.
  4. Subtract detail noise to carve the cloud edges: density = max(0.0, baseNoise - (detailNoise * erosionFactor)).

4. Light Transport and Shading

For realistic light propagation through the cloud, combine the Beer-Lambert Law for transmission extinction with the Henyey-Greenstein phase function for directional forward scattering.

  • Beer-Lambert Law: Calculates the light absorbed by the medium: \[\text{Transmittance} = \exp(-\text{density} \times \text{absorptionCoefficient} \times \text{stepSize})\]
  • Henyey-Greenstein Phase Function: Approximates silver-lining effects by boosting scattered light when looking towards the sun: \[P(\theta) = \frac{1 - g^2}{4\pi (1 + g^2 - 2g \cos\theta)^{1.5}}\] (where \(g\) is the forward-scattering asymmetry factor, typically between \(0.2\) and \(0.8\))

To compute shadows inside the cloud, march a secondary, shorter ray from the current sample position toward the directional light source (the sun) to approximate light-path density.

5. Shader Integration Structure

#version 300 es
precision highp float;
precision highp sampler3D;

uniform sampler3D u_noiseTexture;
uniform vec3 u_cameraPos;
uniform vec3 u_lightDir;
in vec2 v_uv;
out vec4 fragColor;

void main() {
    vec3 rayDir = getRayDirection(v_uv, u_cameraPos);
    vec2 tHit = intersectAABB(u_cameraPos, rayDir); // Returns near and far hits

    if (tHit.x > tHit.y) discard;

    float t = max(0.0, tHit.x);
    float stepSize = (tHit.y - t) / 64.0;
    
    vec4 accumulatedColor = vec4(0.0);
    float transmittance = 1.0;

    for (int i = 0; i < 64; i++) {
        vec3 p = u_cameraPos + rayDir * t;
        float density = texture(u_noiseTexture, p * 0.001).r;

        if (density > 0.01) {
            // Light Marching (Shadowing)
            float lightDensity = texture(u_noiseTexture, (p + u_lightDir * 5.0) * 0.001).r;
            float lightTransmittance = exp(-lightDensity * 2.0);

            // Scattering and Absorption
            float stepTransmittance = exp(-density * stepSize);
            accumulatedColor.rgb += transmittance * (1.0 - stepTransmittance) * lightTransmittance * vec3(1.0);
            transmittance *= stepTransmittance;

            if (transmittance < 0.01) break; // Early ray termination
        }
        t += stepSize;
    }

    fragColor = vec4(accumulatedColor.rgb, 1.0 - transmittance);
}

6. Performance Optimizations

  • Half-Resolution Buffers: Perform the raymarching pass on an off-screen render target at half or quarter resolution, then bilaterally upscale the result over the full-resolution background scene to avoid fill-rate bottlenecks.
  • Temporal Reprojection: Jitter sample origins per-pixel using a Bayer dither matrix and reproject previous frames to smooth low-sample-count noise.
  • Early Exit: Halt the raymarch loop once transmittance drops below 1%, cutting unnecessary fragment iterations within dense internal cloud regions.
