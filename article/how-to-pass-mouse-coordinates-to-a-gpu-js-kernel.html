How to Pass Mouse Coordinates to a GPU.js Kernel

This article explains how to capture mouse click events on an HTML canvas and pass the resulting coordinates into a graphical GPU.js kernel. By mapping DOM coordinates to WebGL texture space, you can make your GPU-accelerated graphics respond dynamically to user interactions in real time.

Step 1: Set Up GPU.js with a Graphical Kernel

A graphical kernel in GPU.js outputs directly to a canvas rather than returning a standard data array. You must enable graphical mode using .setGraphical(true) and call this.color(r, g, b, a) within the kernel function to define pixel colors.

const width = 800;
const height = 600;

const gpu = new GPU();

const renderKernel = gpu.createKernel(function(clickX, clickY) {
    // Calculate distance from current thread (pixel) to the click point
    const dx = this.thread.x - clickX;
    const dy = this.thread.y - clickY;
    const distance = Math.sqrt(dx * dx + dy * dy);

    // Draw a red circle around the click location
    if (distance < 30.0) {
        this.color(1.0, 0.2, 0.2, 1.0);
    } else {
        this.color(0.1, 0.1, 0.1, 1.0);
    }
})
.setOutput([width, height])
.setGraphical(true);

Step 2: Add the Canvas to the DOM

Retrieve the canvas generated by the kernel and attach it to your document:

const canvas = renderKernel.canvas;
document.body.appendChild(canvas);

// Initial render off-screen or at default coordinates
renderKernel(-100, -100);

Step 3: Capture Mouse Clicks and Adjust Coordinates

DOM click events register (0, 0) at the top-left corner of the element, whereas GPU.js thread coordinates begin at (0, 0) in the bottom-left corner. To align user clicks with kernel execution:

  1. Use getBoundingClientRect() to calculate the click offset relative to the canvas.
  2. Invert the Y-axis so it matches WebGL's coordinate system.
canvas.addEventListener('click', (event) => {
    const rect = canvas.getBoundingClientRect();

    // Calculate position inside canvas
    const domX = event.clientX - rect.left;
    const domY = event.clientY - rect.top;

    // Convert to GPU.js coordinate space (invert Y)
    const gpuX = domX;
    const gpuY = canvas.height - domY;

    // Execute the kernel with updated coordinates
    renderKernel(gpuX, gpuY);
});

Complete Working Example

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Interactive GPU.js</title>
    <script src="https://cdn.jsdelivr.net/npm/gpu.js@latest/dist/gpu-browser.min.js"></script>
    <style>
        body { margin: 0; display: flex; justify-content: center; align-items: center; height: 100vh; background: #222; }
        canvas { border: 1px solid #444; cursor: pointer; }
    </style>
</head>
<body>
    <script>
        const width = 600;
        const height = 400;
        const gpu = new GPU();

        const render = gpu.createKernel(function(clickX, clickY) {
            const dist = Math.sqrt(
                Math.pow(this.thread.x - clickX, 2) + 
                Math.pow(this.thread.y - clickY, 2)
            );

            // Draw a circle with soft edges at the click location
            const intensity = Math.max(0.0, 1.0 - dist / 50.0);
            this.color(intensity * 0.2, intensity * 0.8, intensity, 1.0);
        })
        .setOutput([width, height])
        .setGraphical(true);

        const canvas = render.canvas;
        document.body.appendChild(canvas);

        render(-100, -100); // Initial blank render

        canvas.addEventListener('mousedown', (e) => {
            const rect = canvas.getBoundingClientRect();
            const clickX = e.clientX - rect.left;
            const clickY = canvas.height - (e.clientY - rect.top);

            render(clickX, clickY);
        });
    </script>
</body>
</html>

Key Considerations

  • Event Selection: Using mousedown instead of click yields a faster visual response because it triggers immediately when the mouse button is pressed.
  • Continuous Tracking: Replace the event with mousemove to continuously feed coordinates for real-time cursor tracking.
  • Multiple Inputs: To pass multiple points (such as clicks from multiple touches or a history of clicks), pass 1D flattened arrays of coordinates (e.g., [x1, y1, x2, y2]) into the kernel along with an integer indicating the active count.
