Color Space Transformations in GPU.js: RGB, HSV, HSL

GPU.js accelerates color space transformations between RGB, HSV, and HSL by compiling custom JavaScript transformation algorithms into WebGL shaders that run in parallel across the GPU. Because GPU.js does not contain built-in color conversion APIs, it relies on transpiling user-defined mathematical formulas into GLSL (OpenGL Shading Language). This approach allows developers to convert massive image datasets or real-time video feeds pixel-by-pixel with high throughput and low CPU overhead.

The GPU.js Execution Model for Color Conversion

GPU.js operates by taking standard JavaScript functions and compiling them into GLSL fragment shaders at runtime. When processing an image, each pixel's color values are mapped to an individual GPU execution thread.

Instead of iterating through an array of pixels sequentially with a CPU loop, GPU.js processes millions of pixels concurrently using thread coordinates obtained via this.thread.x and this.thread.y. This architecture is ideal for RGB, HSV, and HSL transformations, as each pixel's calculation is independent of its neighbors.

Data Normalization

GLSL operates primarily on floating-point values between 0.0 and 1.0. Standard RGB values (ranging from 0 to 255), Hue angles (ranging from 0 to 360 degrees), and Saturation/Lightness percentages (0 to 100%) must be normalized before processing:

  • RGB: Divide \(R\), \(G\), and \(B\) by 255.0.
  • Hue: Divide \(H\) by 360.0 inside GLSL kernels to keep coordinates uniform, or maintain standard degree notation using custom conditional logic.
  • Saturation/Value/Lightness: Scale inputs to the range [0.0, 1.0].

Transforming RGB to HSV and HSL

To perform transformations, developers define the conversion equations within a GPU.js kernel. The kernel evaluates the minimum and maximum components of RGB to find the chroma delta (\(\Delta = \max - \min\)), which determines both saturation and hue.

const { GPU } = require('gpu.js');
const gpu = new GPU();

// Kernel to convert normalized RGB to HSV
const rgbToHsv = gpu.createKernel(function(r, g, b) {
    const max = Math.max(r[this.thread.y][this.thread.x], Math.max(g[this.thread.y][this.thread.x], b[this.thread.y][this.thread.x]));
    const min = Math.min(r[this.thread.y][this.thread.x], Math.min(g[this.thread.y][this.thread.x], b[this.thread.y][this.thread.x]));
    const delta = max - min;

    let h = 0;
    let s = 0;
    const v = max;

    if (max > 0.0) {
        s = delta / max;
    }

    if (delta > 0.0) {
        if (max === r[this.thread.y][this.thread.x]) {
            h = (g[this.thread.y][this.thread.x] - b[this.thread.y][this.thread.x]) / delta + (g[this.thread.y][this.thread.x] < b[this.thread.y][this.thread.x] ? 6 : 0);
        } else if (max === g[this.thread.y][this.thread.x]) {
            h = (b[this.thread.y][this.thread.x] - r[this.thread.y][this.thread.x]) / delta + 2;
        } else {
            h = (r[this.thread.y][this.thread.x] - g[this.thread.y][this.thread.x]) / delta + 4;
        }
        h = h / 6;
    }

    // Output normalized H, S, V components
    return [h, s, v];
}).setOutput([width, height]);

For HSL, the calculation differs slightly:

  • Lightness is calculated as \(L = (\max + \min) / 2\).
  • Saturation depends on lightness: \(S = \Delta / (1 - |2L - 1|)\) when \(L > 0\) and \(L < 1\).

Modularity with addFunction

When building bi-directional conversion pipelines (such as reading RGB, adjusting HSV values, and outputting back to RGB), GPU.js allows external helper functions to be registered using gpu.addFunction().

Registering standalone transformation functions ensures that the transpiler can inline conversion algorithms across multiple kernels without duplicating code:

function hsvToRgbComponent(h, s, v, n) {
    const k = (n + h * 6) % 6;
    return v - v * s * Math.max(0, Math.min(k, Math.min(4 - k, 1)));
}
gpu.addFunction(hsvToRgbComponent);

Direct Graphical Output

For rendering tasks, GPU.js supports direct pipeline rendering using the { graphical: true } mode. Instead of returning raw typed arrays representing color components, the kernel uses this.color(r, g, b, a) to write directly to an HTML5 canvas.

When converting from HSV or HSL to RGB in graphical mode, the final RGB values are passed straight into this.color(), completely bypassing the overhead of transferring large data arrays back from the GPU memory to the CPU host memory.
