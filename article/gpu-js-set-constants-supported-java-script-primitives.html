GPU.js setConstants: Supported JavaScript Primitives

In GPU.js, the setConstants method allows developers to pass static values directly into GPU-accelerated kernel functions. Because GPU.js transpiles JavaScript functions into WebGL shader language (GLSL), the range of acceptable data types is strictly constrained by hardware limitations. Specifically, among JavaScript primitive types, only Numbers and Booleans are supported, while primitives such as Strings, BigInts, Symbols, null, and undefined are not supported.

Supported JavaScript Primitives

  1. Number (Float and Integer) JavaScript uses double-precision floats for all numbers, but GPU shaders distinguish between integers and floating-point values. GPU.js automatically parses numeric values provided in setConstants into corresponding GLSL types:

    • Floating-Point Numbers: Values with decimal precision (e.g., 3.14 or 0.5) are compiled to GLSL float types.
    • Integers: Whole numbers (e.g., 1, 42) can be interpreted as either integers or floats depending on how they are utilized inside the kernel function.

  2. Boolean JavaScript boolean literals (true and false) are valid inputs for setConstants. Within the compiled kernel, these map directly to native GLSL bool types and can be used for conditional logic and branching inside shader routines.

Unsupported JavaScript Primitives

The following JavaScript primitives cannot be used in setConstants because GLSL lacks native equivalents or GPU.js does not provide a transpilation path for them:

  • String: GLSL has no text processing or character string data type.
  • BigInt: 64-bit arbitrary-precision integers are not supported by standard WebGL implementations.
  • Symbol: Symbols are unique tokens specific to the JavaScript runtime and cannot be represented in GPU memory.
  • Undefined and Null: Neither represents a valid numeric or logical state in GLSL shader pipelines and will lead to compilation errors.

Usage Example

const gpu = new GPU();

const kernel = gpu.createKernel(function() {
  if (this.constants.enableMultiplier) {
    return this.thread.x * this.constants.scaleFactor;
  }
  return this.thread.x;
})
.setConstants({
  scaleFactor: 2.5,       // Number (Float)
  enableMultiplier: true  // Boolean
})
.setOutput([100]);

kernel();

When passing constants via setConstants, restrict primitive inputs strictly to standard numbers and boolean flags to ensure valid GLSL compilation and optimal execution.
