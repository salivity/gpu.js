Pairwise t-SNE Student-t Similarities in GPU.js

This article explains how to compute pairwise t-SNE Student-t distribution similarities across high-dimensional vectors using GPU acceleration with gpu.js. You will learn the mathematical formulation of the Student-t kernel, how to structure your vector data for GPU processing, and how to write and execute a custom WebGL kernel to evaluate pairwise similarities in parallel.

The Student-t Distribution Kernel

In t-SNE, the joint similarity between two low- or high-dimensional points \(x_i\) and \(x_j\) using a 1-degree-of-freedom Student-t distribution (Cauchy distribution) is defined by its unnormalized kernel:

\[w_{ij} = \frac{1}{1 + \|x_i - x_j\|^2} \quad \text{for } i \neq j\]

When \(i = j\), the similarity \(w_{ii}\) is set to zero. To obtain true probabilities (\(q_{ij}\)), these values are normalized by dividing by the sum of all pairs:

\[q_{ij} = \frac{w_{ij}}{\sum_{k \neq l} w_{kl}}\]

Computing this across \(N\) vectors requires calculating an \(N \times N\) matrix. Because each cell evaluation is independent, this operation maps directly to GPU parallelism.

Setting Up GPU.js

To run computations on the GPU in JavaScript environments, initialize the GPU instance from the gpu.js library:

const { GPU } = require('gpu.js');
const gpu = new GPU();

In a browser, you can load the library via a script tag and instantiate const gpu = new GPU(); directly.

Writing the Pairwise Student-t Kernel

The compute kernel evaluates each pair \((i, j)\) concurrently. It reads the high-dimensional vectors from a 2D array, computes the squared Euclidean distance across all dimensions \(D\), and applies the reciprocal Student-t function.

const createStudentTKernel = (gpu, numVectors, dimensions) => {
  return gpu.createKernel(
    function (vectors, dimensions) {
      const i = this.thread.y;
      const j = this.thread.x;

      // Diagonal elements represent identical pairs
      if (i === j) {
        return 0.0;
      }

      // Compute squared Euclidean distance across all dimensions
      let sumSquaredDiff = 0.0;
      for (let d = 0; d < dimensions; d++) {
        const diff = vectors[i][d] - vectors[j][d];
        sumSquaredDiff += diff * diff;
      }

      // Apply the 1-degree-of-freedom Student-t kernel
      return 1.0 / (1.0 + sumSquaredDiff);
    },
    {
      output: [numVectors, numVectors],
      pipeline: false // Set to true if feeding output to another GPU kernel
    }
  );
};

Complete Execution Pipeline

The following example generates mock data, defines dimensions, and computes the complete pairwise matrix:

const { GPU } = require('gpu.js');
const gpu = new GPU();

// Configuration
const N = 1000; // Number of vectors
const D = 50;   // Dimensionality of each vector

// Generate random sample vectors (N x D)
const vectors = Array.from({ length: N }, () =>
  Array.from({ length: D }, () => Math.random())
);

// Instantiate the kernel
const computeSimilarities = createStudentTKernel(gpu, N, D);

// Execute on GPU
console.time('GPU Computation');
const similarityMatrix = computeSimilarities(vectors, D);
console.timeEnd('GPU Computation');

// Access results
console.log(`Matrix dimensions: ${similarityMatrix.length}x${similarityMatrix[0].length}`);
console.log(`Sample similarity [0][1]: ${similarityMatrix[0][1]}`);
console.log(`Diagonal check [0][0]: ${similarityMatrix[0][0]}`);

Normalizing the Similarities

If full normalized probabilities (\(q_{ij}\)) are needed for the gradient computation step in t-SNE, aggregate the matrix values to compute the denominator sum.

You can compute this sum on the CPU for moderate sizes:

let totalSum = 0;
for (let i = 0; i < N; i++) {
  for (let j = 0; j < N; j++) {
    totalSum += similarityMatrix[i][j];
  }
}

// Ensure numerical stability against division by zero
const minProb = 1e-12;
const normalizedMatrix = similarityMatrix.map(row =>
  row.map(val => Math.max(val / totalSum, minProb))
);

For large datasets where \(N > 10{,}000\), chain this computation using GPU pipeline mode (pipeline: true) with a reduction kernel to compute the sum directly in GPU memory before dividing.
