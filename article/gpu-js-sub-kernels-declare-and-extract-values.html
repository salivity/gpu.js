GPU.js SubKernels: Declare and Extract Values

This guide explains how to declare and extract values from subKernels in GPU.js within a single execution pass. By using gpu.createKernelMap(), you can execute multiple calculations simultaneously on the GPU, avoiding redundant passes over the same data. The following sections walk through the mechanics of defining helper functions, declaring the kernel map, invoking the subKernels, and destructuring the resulting outputs.

Declaring SubKernels with createKernelMap

Standard kernels created with gpu.createKernel() can only return a single value per thread. To compute and extract multiple distinct outputs simultaneously, use gpu.createKernelMap().

The createKernelMap method accepts two primary arguments:

  1. The SubKernel Collection: An object or array defining the subKernel functions. Using an object allows you to assign specific keys to the outputs.
  2. The Main Kernel Function: The primary function executed on the GPU, which invokes the subKernels during its execution.

Defining the Functions

Each subKernel must be a valid JavaScript function that can compile to WebGL/GPU-compatible code. Inside the main kernel, call the subKernel directly.

import { GPU } from 'gpu.js';

const gpu = new GPU();

// 1. Define the subKernel functions
function calculateSquare(val) {
  return val * val;
}

function calculateCube(val) {
  return val * val * val;
}

// 2. Map and create the kernel
const multiKernel = gpu.createKernelMap(
  {
    squares: calculateSquare,
    cubes: calculateCube
  },
  function(data) {
    const value = data[this.thread.x];

    // Invoke subKernels inside the main kernel
    calculateSquare(value);
    calculateCube(value);

    // Return the primary kernel result
    return value * 2;
  }
).setOutput([5]);

Extracting Values from the Execution Output

When executed, a kernel created with createKernelMap returns a structured object rather than a single array.

The output contains:

  • result: The value returned by the main kernel function.
  • Named Keys: Arrays corresponding to the names specified in the subKernel definition object.

Execution and Destructuring

You can access the values directly by property name or via object destructuring:

const inputData = [1, 2, 3, 4, 5];

// Execute the kernel
const output = multiKernel(inputData);

// Extract the primary result and subKernel results
const { result, squares, cubes } = output;

console.log('Main Result (Doubled):', result);
// Output: Float32Array [2, 4, 6, 8, 10]

console.log('SubKernel (Squares):', squares);
// Output: Float32Array [1, 4, 9, 16, 25]

console.log('SubKernel (Cubes):', cubes);
// Output: Float32Array [1, 8, 27, 64, 125]

Key Considerations

  • Void Calling: You do not need to assign the subKernel calls to a variable inside the main kernel body. Simply invoking calculateSquare(value) triggers the GPU to write that subKernel's return value to its respective output buffer for that thread.
  • Array Map Alternative: If you pass an array of functions instead of an object (e.g., [calculateSquare, calculateCube]), the returned object will use the function names as keys. Providing an object literal ensures consistent naming even if your code is minified.
  • Output Dimensions: All subKernels share the same output dimensions defined by .setOutput().
