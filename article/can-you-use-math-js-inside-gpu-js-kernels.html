Can You Use Math.js Inside GPU.js Kernels?

This article explores whether external JavaScript math libraries, such as Math.js, can be executed directly inside a GPU.js kernel. It explains the architectural limitations of running third-party JavaScript libraries on the GPU, why standard CPU-bound code fails within shader environments, and the alternative approaches available for performing advanced mathematical computations using GPU.js.

The short answer is no. You cannot call external JavaScript libraries like Math.js inside a GPU.js kernel function.

To understand why, it is essential to look at how GPU.js operates. GPU.js works by taking a JavaScript function, parsing its Abstract Syntax Tree (AST), and transpiling that code into WebGL shader language (GLSL) or WebGPU code. This transpiled program runs directly on your graphics hardware.

Because the code is converted into low-level shader instructions, the kernel does not execute within the standard JavaScript engine (like V8 in Chrome or Node.js). It has no access to the Document Object Model (DOM), the standard window context, the Node.js runtime, or the CPU heap memory where external libraries reside. When GPU.js encounters external function calls or complex JavaScript objects—such as those provided by Math.js—it cannot translate them into valid GLSL, resulting in compilation errors.

GPU.js only supports a strict subset of JavaScript syntax. It supports basic primitive operations, loops, conditional statements, and a predefined selection of JavaScript's native Math methods that map cleanly to native GLSL functions. These supported methods include standard functions such as Math.sin(), Math.cos(), Math.sqrt(), Math.floor(), and Math.pow().

If your project requires advanced mathematical calculations, you can use the following alternatives:

1. Precompute on the CPU

Perform complex algebraic parsing, symbolic math, or data restructuring on the CPU using Math.js before invoking the GPU kernel. Once the data is processed into flat arrays or typed arrays, pass those values into the GPU.js kernel as arguments or input textures.

2. Use gpu.addFunction()

If you need custom mathematical functions that are not built into standard JavaScript, you can write pure functions using the supported GPU.js subset and register them using gpu.addFunction(). These custom functions are transpiled alongside the kernel and can be called directly inside the computation pipeline.

3. Recreate Formulas Manually

Translate complex mathematical logic into pure arithmetic and native Math functions directly within your kernel code. While this requires manual implementation of algorithms provided out-of-the-box by libraries like Math.js, it ensures full compatibility with the GPU compilation process.
