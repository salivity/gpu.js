Real-Time Audio Occlusion Masks with GPU.js

This article explains how to compute real-time ray-traced ambient sound occlusion masks for game engines using GPU.js. By translating JavaScript operations into WebGL compute shaders, developers can trace acoustic rays through scene geometry concurrently, generating frequency-dependent attenuation factors that feed directly into audio processing pipelines like the Web Audio API without blocking the main render loop.

Understanding Sound Occlusion Masks

In game audio, sound occlusion occurs when an obstacle fully or partially blocks the direct acoustic path between an audio emitter and the listener. Unlike light, lower-frequency sound waves diffract around edges, while high frequencies are heavily absorbed or scattered. A sound occlusion mask is a numerical factor—often a multi-band vector representing low, mid, and high frequencies—applied to audio filters (such as low-pass biquad filters and gain nodes) to dynamically muffle obstructed audio.

Ray-tracing sound involves casting vectors from an audio source toward the listener or an array of listening sample points, detecting intersections with geometric primitives, and tallying the material transmission properties of blocked paths.

1. Scene Geometry Representation for GPU.js

GPU.js cannot process complex JavaScript objects or scene graphs natively. Geometry must be flattened into typed arrays representing vertices, bounding volumes, or material densities.

To maintain real-time performance, represent obstacles as Axis-Aligned Bounding Boxes (AABB) or simplified triangle meshes:

// Flattened triangle vertices: [x1, y1, z1, x2, y2, z2, x3, y3, z3, ...]
const triangleVertices = new Float32Array([...]);

// Material absorption coefficients per triangle (0.0 = transparent, 1.0 = fully occluded)
const materialAbsorption = new Float32Array([...]);

2. Formulating the GPU.js Ray-Tracing Kernel

Using GPU.js, compile a WebGL-accelerated kernel that casts multiple rays per emitter. By distributing secondary rays within a small cone around the direct line-of-sight vector, the system can approximate edge diffraction and spatial leakage.

const { GPU } = require('gpu.js');
const gpu = new GPU();

// Kernel outputs an occlusion value between 0.0 (open) and 1.0 (occluded) per audio emitter
const calculateOcclusion = gpu.createKernel(function(emitters, listener, triangles, absorptions, triCount, raysPerEmitter) {
    let emitterIdx = this.thread.x;
    let originX = emitters[emitterIdx * 3];
    let originY = emitters[emitterIdx * 3 + 1];
    let originZ = emitters[emitterIdx * 3 + 2];

    let targetX = listener[0];
    let targetY = listener[1];
    let targetZ = listener[2];

    // Compute direct ray direction
    let dirX = targetX - originX;
    let dirY = targetY - originY;
    let dirZ = targetZ - originZ;
    let maxDist = Math.sqrt(dirX * dirX + dirY * dirY + dirZ * dirZ);

    dirX /= maxDist;
    dirY /= maxDist;
    dirZ /= maxDist;

    let totalOcclusion = 0.0;

    // Simple ray-triangle intersection test (Möller-Trumbore algorithm variant)
    for (let i = 0; i < triCount; i++) {
        let idx = i * 9;
        
        let v0x = triangles[idx],     v0y = triangles[idx + 1], v0z = triangles[idx + 2];
        let v1x = triangles[idx + 3], v1y = triangles[idx + 4], v1z = triangles[idx + 5];
        let v2x = triangles[idx + 6], v2y = triangles[idx + 7], v2z = triangles[idx + 8];

        let edge1X = v1x - v0x, edge1Y = v1y - v0y, edge1Z = v1z - v0z;
        let edge2X = v2x - v0x, edge2Y = v2y - v0y, edge2Z = v2z - v0z;

        let pvecX = dirY * edge2Z - dirZ * edge2Y;
        let pvecY = dirZ * edge2X - dirX * edge2Z;
        let pvecZ = dirX * edge2Y - dirY * edge2X;

        let det = edge1X * pvecX + edge1Y * pvecY + edge1Z * pvecZ;

        if (det > -0.00001 && det < 0.00001) continue;
        let invDet = 1.0 / det;

        let tvecX = originX - v0x;
        let tvecY = originY - v0y;
        let tvecZ = originZ - v0z;

        let u = (tvecX * pvecX + tvecY * pvecY + tvecZ * pvecZ) * invDet;
        if (u < 0.0 || u > 1.0) continue;

        let qvecX = tvecY * edge1Z - tvecZ * edge1Y;
        let qvecY = tvecZ * edge1X - tvecX * edge1Z;
        let qvecZ = tvecX * edge1Y - tvecY * edge1X;

        let v = (dirX * qvecX + dirY * qvecY + dirZ * qvecZ) * invDet;
        if (v < 0.0 || u + v > 1.0) continue;

        let t = (edge2X * qvecX + edge2Y * qvecY + edge2Z * qvecZ) * invDet;

        if (t > 0.0001 && t < maxDist) {
            totalOcclusion += absorptions[i];
        }
    }

    // Clamp occlusion factor to [0.0, 1.0]
    if (totalOcclusion > 1.0) {
        return 1.0;
    }
    return totalOcclusion;
})
.setOutput([numberOfEmitters])
.setPrecision('unsigned');

3. Mask Generation and Temporal Smoothing

Because WebGL computations on the GPU run asynchronously relative to the CPU game loop, values fetched from calculateOcclusion must be smoothed to avoid acoustic clicking or popping artifacts.

  1. Dispatch Kernel: Execute the kernel during the physics or spatial audio update step (typically 20–30 Hz, as audio spatialization requires lower update rates than graphics).
  2. Buffer Retrieval: Extract the resulting occlusion array.
  3. Low-Pass Filtering Over Time: Apply linear interpolation (lerp) to the output value per emitter:
currentOcclusion[i] += (targetOcclusion[i] - currentOcclusion[i]) * deltaSmoothing;

4. Applying the Mask to the Game Audio Engine

Map the calculated occlusion value directly to digital signal processing (DSP) nodes in the sound engine:

  • Direct Gain Attenuation: Scale down direct sound amplitude: \[\text{Gain} = 1.0 - (\text{Occlusion} \times \text{MaterialCutoff})\]
  • Frequency Filtering: Lower the cutoff frequency of a low-pass filter to emulate the absorption of high frequencies by structures: \[\text{CutoffFrequency} = \text{BaseFrequency} \times (1.0 - 0.8 \times \text{Occlusion})\]
  • Reverb Send Balancing: Increase indirect/reverberant audio mix relative to the direct path to model energy propagating through room reflections rather than line-of-sight.
