Calculate Polar Coordinates in GPU.js

Converting Cartesian grid indices to radial polar coordinates within GPU.js enables shaders, procedural textures, and circular math operations directly on the GPU. This guide details how to transform thread indices (this.thread.x and this.thread.y) into radial distance (\(r\)) and angular measurement (\(\theta\)) using built-in math functions supported by the GPU.js compiler.

The Transformation Logic

In GPU.js, each parallel thread represents a coordinate on a 2D grid accessed via this.thread.x and this.thread.y. By default, the origin (0, 0) is located at the bottom-left corner of the execution context.

To calculate polar coordinates relative to an arbitrary center (usually the middle of your output canvas or matrix), follow three steps:

  1. Translate the coordinates to center the origin.
  2. Calculate the radial distance (\(r\)) using the Pythagorean theorem.
  3. Calculate the angle (\(\theta\)) using the two-argument arctangent (Math.atan2).

Mathematical Formulas

Given an origin \((x_0, y_0)\):

  • Horizontal offset: \(\Delta x = \text{this.thread.x} - x_0\)
  • Vertical offset: \(\Delta y = \text{this.thread.y} - y_0\)
  • Radius (\(r\)): \(r = \sqrt{\Delta x^2 + \Delta y^2}\)
  • Angle (\(\theta\)): \(\theta = \text{atan2}(\Delta y, \Delta x)\)

Implementation Example

The following kernel computes both the radius and angle for every pixel on a 500x500 canvas and returns the computed polar values:

const { GPU } = require('gpu.js');
const gpu = new GPU();

const width = 500;
const height = 500;
const centerX = width / 2;
const centerY = height / 2;

const calculatePolar = gpu.createKernel(function(centerX, centerY) {
    // 1. Shift origin to center
    const dx = this.thread.x - centerX;
    const dy = this.thread.y - centerY;

    // 2. Compute radius (Euclidean distance)
    const radius = Math.sqrt(dx * dx + dy * dy);

    // 3. Compute angle in radians (-PI to PI)
    const angle = Math.atan2(dy, dx);

    // Example output: storing radius in index 0, angle in index 1
    // GPU.js supports returning arrays of numbers
    return radius;
}).setOutput([width, height]);

const result = calculatePolar(centerX, centerY);

Normalization and Considerations

  • Radius Normalization: To convert the radial distance into a normalized range from 0.0 to 1.0, divide radius by the maximum possible distance, which is typically Math.sqrt(centerX * centerX + centerY * centerY).
  • Angle Normalization: Math.atan2(dy, dx) yields values in radians between \(-\pi\) and \(\pi\). To map this to an interval from 0.0 to 1.0, use: 
    const normalizedAngle = (angle + Math.PI) / (2 * Math.PI);
  • Performance: If you only need relative radial comparisons (such as checking if a thread is within a circular boundary), avoid Math.sqrt and compare squared distances directly (dx * dx + dy * dy <= radius * radius) to reduce GPU instruction cycles.
