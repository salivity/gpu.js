Edge-Preserving Guided Filter in GPU.js

Guided image filtering is an edge-preserving smoothing technique that computes local linear coefficients between a guidance image and an input image, transferring structural edges without creating halo artifacts. This article outlines the mathematical pipeline of the guided filter and details how to implement each computation stage as hardware-accelerated kernels using GPU.js for real-time browser performance.

Mathematical Formulation

The guided filter assumes that the filtering output \(q\) is a local linear transformation of the guidance image \(I\) within a local window \(\omega_k\) centered at pixel \(k\):

\[q_i = a_k I_i + b_k, \quad \forall i \in \omega_k\]

When filtering an input image \(p\) guided by image \(I\), the coefficients \(a_k\) and \(b_k\) minimize the squared difference between \(q\) and \(p\) with a regularization parameter \(\epsilon\):

  1. Compute means via a box filter of radius \(r\): \[\mu_I = f_{\text{mean}}(I), \quad \mu_p = f_{\text{mean}}(p)\] \[\mu_{II} = f_{\text{mean}}(I \odot I), \quad \mu_{Ip} = f_{\text{mean}}(I \odot p)\]
  2. Compute variance and covariance: \[\sigma_I^2 = \mu_{II} - \mu_I^2\] \[\text{cov}_{Ip} = \mu_{Ip} - \mu_I \mu_p\]
  3. Compute the linear coefficients: \[a_k = \frac{\text{cov}_{Ip}}{\sigma_I^2 + \epsilon}, \quad b_k = \mu_p - a_k \mu_I\]
  4. Compute the average coefficients across overlapping windows: \[\bar{a} = f_{\text{mean}}(a), \quad \bar{b} = f_{\text{mean}}(b)\]
  5. Generate the final output: \[q = \bar{a} \odot I + \bar{b}\]

(For self-guided smoothing, \(I = p\).)

GPU.js Implementation Pipeline

Implementing this pipeline in GPU.js requires multiple rendering passes. Because GPU.js operates with WebGL textures, chained kernels should enable pipeline: true to avoid reading data back to the CPU between steps.

1. Box Filter Kernel

The box filter calculates the mean pixel value within a square window of radius \(r\):

const gpu = new GPU();

const createBoxFilter = (width, height, radius) => {
  return gpu.createKernel(function(image, r) {
    let sum = 0;
    let count = 0;
    const x = this.thread.x;
    const y = this.thread.y;

    for (let dy = -r; dy <= r; dy++) {
      for (let dx = -r; dx <= r; dx++) {
        const nx = x + dx;
        const ny = y + dy;

        if (nx >= 0 && nx < this.constants.width && ny >= 0 && ny < this.constants.height) {
          sum += image[ny][nx];
          count += 1;
        }
      }
    }
    return sum / count;
  }, {
    constants: { width, height },
    output: [width, height],
    pipeline: true
  });
};

2. Element-Wise Multiplier Kernel

Compute products such as \(I \odot I\) and \(I \odot p\):

const createMultiplyKernel = (width, height) => {
  return gpu.createKernel(function(a, b) {
    return a[this.thread.y][this.thread.x] * b[this.thread.y][this.thread.x];
  }, {
    output: [width, height],
    pipeline: true
  });
};

3. Linear Coefficients Kernel

Compute \(a_k\) and \(b_k\) using local variances and covariances:

const createCoefficientsKernel = (width, height) => {
  return gpu.createKernel(function(meanI, meanP, meanII, meanIp, eps) {
    const x = this.thread.x;
    const y = this.thread.y;

    const mI = meanI[y][x];
    const mP = meanP[y][x];
    const varI = meanII[y][x] - (mI * mI);
    const covIp = meanIp[y][x] - (mI * mP);

    const a = covIp / (varI + eps);
    const b = mP - (a * mI);

    // Channel 0: a, Channel 1: b
    this.color(a, b, 0, 1);
  }, {
    output: [width, height],
    pipeline: true
  });
};

4. Reconstruction Kernel

Apply the averaged coefficients \(\bar{a}\) and \(\bar{b}\) to the guidance image to yield the smoothed result:

const createReconstructKernel = (width, height) => {
  return gpu.createKernel(function(meanA, meanB, guidance) {
    const x = this.thread.x;
    const y = this.thread.y;
    return (meanA[y][x] * guidance[y][x]) + meanB[y][x];
  }, {
    output: [width, height]
  });
};

Executing the Filter

To execute edge-preserving smoothing on an image:

function runGuidedFilter(image, guidance, width, height, radius, eps) {
  const boxFilter = createBoxFilter(width, height, radius);
  const multiply = createMultiplyKernel(width, height);
  const computeCoeffs = createCoefficientsKernel(width, height);
  const reconstruct = createReconstructKernel(width, height);

  // Intermediate products
  const II = multiply(guidance, guidance);
  const Ip = multiply(guidance, image);

  // Mean components
  const meanI = boxFilter(guidance, radius);
  const meanP = boxFilter(image, radius);
  const meanII = boxFilter(II, radius);
  const meanIp = boxFilter(Ip, radius);

  // Calculate a and b
  const coeffs = computeCoeffs(meanI, meanP, meanII, meanIp, eps);

  // In GPU.js, extract passes or use a multi-channel box filter for a and b
  const meanA = boxFilter(coeffs, radius); 
  const meanB = boxFilter(coeffs, radius);

  // Final edge-preserved smoothed output
  return reconstruct(meanA, meanB, guidance);
}

Parameter Tuning

  • Radius (\(r\)): Controls the spatial window size. Larger values result in broader smoothing across flat regions while respecting major structural boundaries.
  • Epsilon (\(\epsilon\)): Controls edge preservation. A higher \(\epsilon\) treats low-contrast edges as noise and smooths over them, functioning closer to a standard box blur. A lower \(\epsilon\) preserves fine gradients and sharper transitions.
