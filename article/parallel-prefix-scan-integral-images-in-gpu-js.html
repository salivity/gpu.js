Parallel Prefix Scan Integral Images in GPU.js

Computing an integral image—also known as a summed-area table—enables constant-time area sum queries over 2D grids, making it invaluable for real-time computer vision and image processing tasks. In this article, you will learn how to implement an integral image generator on the GPU using gpu.js by breaking down the 2D scan into separable horizontal and vertical parallel prefix scans using the step-efficient Hillis-Steele algorithm.

Algorithmic Foundation

A 2D integral image calculates each pixel's value as the sum of all elements above and to the left of it:

\[I(x, y) = \sum_{x' \le x, y' \le y} A(x', y')\]

Because addition is associative and separable across dimensions, a 2D prefix scan can be computed in two independent phases:

  1. Horizontal Pass: Compute an inclusive prefix scan across every row independently.
  2. Vertical Pass: Compute an inclusive prefix scan across every column using the output of the horizontal pass.

On parallel architectures like GPUs, the Hillis-Steele scan is commonly chosen for ease of implementation. For an array of size \(N\), it executes in \(\lceil\log_2 N\rceil\) steps. At step \(k\) with an offset \(s = 2^k\), each thread at index \(i\) adds the value from index \(i - s\) to its current value if \(i \ge s\).

GPU.js Implementation

In gpu.js, multi-pass algorithms benefit from setting pipeline: true, which retains intermediate results in GPU memory as textures instead of reading them back to the CPU between steps.

Step 1: Kernels for Prefix Steps

Define two kernels: one for the horizontal pass and one for the vertical pass.

const { GPU } = require('gpu.js');
const gpu = new GPU();

// Horizontal scan step
const horizontalScanStep = gpu.createKernel(function(input, offset, width) {
    const x = this.thread.x;
    const y = this.thread.y;
    
    const currentVal = input[y][x];
    if (x >= offset) {
        return currentVal + input[y][x - offset];
    }
    return currentVal;
})
.setPipeline(true)
.setDynamicOutput(true);

// Vertical scan step
const verticalScanStep = gpu.createKernel(function(input, offset, height) {
    const x = this.thread.x;
    const y = this.thread.y;
    
    const currentVal = input[y][x];
    if (y >= offset) {
        return currentVal + input[y - offset][x];
    }
    return currentVal;
})
.setPipeline(true)
.setDynamicOutput(true);

Step 2: Running the Multi-Pass Computation

Execute \(\lceil\log_2(\text{width})\rceil\) steps horizontally, followed by \(\lceil\log_2(\text{height})\rceil\) steps vertically:

function computeSummedAreaTable(matrix, width, height) {
    horizontalScanStep.setOutput([width, height]);
    verticalScanStep.setOutput([width, height]);

    let currentTexture = matrix;

    // 1. Horizontal Prefix Scan across rows
    const numHorizontalSteps = Math.ceil(Math.log2(width));
    for (let k = 0; k < numHorizontalSteps; k++) {
        const offset = 1 << k; // 2^k
        currentTexture = horizontalScanStep(currentTexture, offset, width);
    }

    // 2. Vertical Prefix Scan across columns
    const numVerticalSteps = Math.ceil(Math.log2(height));
    for (let k = 0; k < numVerticalSteps; k++) {
        const offset = 1 << k; // 2^k
        currentTexture = verticalScanStep(currentTexture, offset, height);
    }

    // Read back final result from GPU memory to a flat or 2D array
    return currentTexture.toArray();
}

Performance and Precision Considerations

  • Floating-Point Precision: Summed-area tables accumulate values quickly. For standard 8-bit images, large inputs (\(2048 \times 2048\)) can exceed standard 32-bit floating-point precision limits (\(2^{24}\) exact integer range). If working with large matrices, normalize input values between 0.0 and 1.0 before scanning.
  • Pipeline Cleanup: Intermediate textures generated during the loop must be cleaned up if you loop over multiple frames in a real-time application to prevent GPU memory leaks. Use .delete() on intermediate texture handles when swapping buffers.
  • Memory Coalescing: Reading along rows in the horizontal pass offers optimal continuous memory access. The vertical pass accesses strided memory, but the SIMD execution model on modern hardware handles this efficiently up to standard texture sizes.
