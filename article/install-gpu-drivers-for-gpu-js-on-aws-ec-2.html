Install GPU Drivers for GPU.js on AWS EC2

Running GPU-accelerated JavaScript applications in the cloud requires specific hardware, proprietary drivers, and native OpenGL bindings. This guide outlines the exact process to configure an Amazon Web Services (AWS) EC2 GPU instance, install native NVIDIA graphics drivers and CUDA dependencies, configure headless rendering libraries, and verify that gpu.js runs directly on the GPU without falling back to the CPU in a Node.js environment.

1. Launch a Compatible AWS EC2 Instance

Select an instance type that includes a dedicated NVIDIA GPU. Recommended options include:

  • G4dn instances: Powered by NVIDIA T4 GPUs (cost-effective for general inference and compute).
  • G5 instances: Powered by NVIDIA A10G GPUs (higher compute performance).

Launch the instance using Ubuntu 22.04 LTS or Ubuntu 24.04 LTS, assign sufficient storage (at least 30 GB), and attach an appropriate security group.

2. Update System Packages and Install Compiler Essentials

Connect to your instance via SSH and update the package repository. Install the Linux kernel headers and standard build tools required to compile native Node.js modules and graphics bindings:

sudo apt update && sudo apt upgrade -y
sudo apt install -y build-essential linux-headers-$(uname -r) pkg-config

3. Install the NVIDIA Driver and CUDA Toolkit

Ensure the system detects the attached GPU by installing the proprietary NVIDIA drivers and utilities.

Add the official graphics drivers repository and install the recommended driver package:

sudo add-apt-repository ppa:graphics-drivers/ppa -y
sudo apt update
sudo apt install -y nvidia-driver-535 nvidia-utils-535

Once the installation completes, reboot the instance to apply kernel changes:

sudo reboot

After reconnecting via SSH, verify that the drivers are functioning properly:

nvidia-smi

The output should display your GPU model, driver version, and CUDA version.

4. Install Native Headless Graphics Libraries

In a headless cloud environment, gpu.js executes server-side via Node.js using headless-gl (gl). This native binding requires system-level OpenGL, GLEW, and X11 development libraries to compile:

sudo apt install -y \
  libxi-dev \
  libglu1-mesa-dev \
  libglew-dev \
  libx11-dev \
  mesa-utils \
  xvfb

5. Install Node.js and Project Dependencies

Install a current LTS version of Node.js using the NodeSource repository:

curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs

Create a new working directory and install gpu.js:

mkdir gpu-test && cd gpu-test
npm init -y
npm install gpu.js

During the npm install phase, npm compiles the native headless-gl binary against the graphics headers installed in the previous step.

6. Verify GPU Execution in gpu.js

Create a test script named test.js to ensure computations are executed on the physical GPU hardware:

const { GPU } = require('gpu.js');

const gpu = new GPU();

const kernel = gpu.createKernel(function() {
  return this.thread.x;
}).setOutput([5]);

const result = kernel();
console.log('Result:', result);
console.log('Execution Mode:', kernel.subKernelOutput ? 'Unknown' : gpu.mode);

Run the script:

node test.js

If the environment is configured correctly, the output will confirm:

Result: Float32Array(5) [ 0, 1, 2, 3, 4 ]
Execution Mode: gpu

If the mode reports cpu, verify your nvidia-smi output and ensure the headless-gl native build succeeded during package installation.
