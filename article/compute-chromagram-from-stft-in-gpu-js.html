Compute Chromagram from STFT in GPU.js

Computing chromagram pitch class profiles from Short-Time Fourier Transform (STFT) frames projects linear-frequency spectral energy into twelve discrete semitone bins representing musical pitch classes (C through B). By leveraging gpu.js, you can offload this matrix multiplication and binning pipeline to the GPU, allowing real-time or high-throughput audio analysis directly in JavaScript environments. This guide explains the mathematical transformation from STFT bins to chroma bins and provides a complete GPU-accelerated implementation using gpu.js.

The Chroma Transformation Pipeline

A chromagram condenses the \(N/2\) positive frequency bins of an STFT magnitude spectrum into 12 pitch classes. The transformation consists of three primary steps:

  1. Frequency Mapping: Map each STFT bin index \(k\) to its corresponding frequency in Hertz: \[f(k) = \frac{k \cdot f_s}{N}\] where \(f_s\) is the sample rate and \(N\) is the FFT window size.
  2. Pitch Class Assignment: Convert frequency into a fractional MIDI note number, then determine its pitch class via modulo arithmetic: \[p(f) = 12 \log_2\left(\frac{f}{440}\right) + 69\] \[\text{pitch\_class} = \lfloor p(f) \rceil \pmod{12}\]
  3. Filter Weighting: Apply Gaussian or triangular weighting centered around each pitch class to accumulate energy from the STFT magnitude or power spectrum into a \(12 \times 1\) vector per frame.

In gpu.js, this is most efficiently implemented as a matrix-matrix multiplication: multiplying a precomputed Chroma Filterbank matrix (\(12 \times K\), where \(K\) is the number of STFT bins) by the STFT matrix (\(K \times T\), where \(T\) is the number of time frames).

Step 1: Precomputing the Chroma Filterbank on the CPU

Before executing the GPU kernel, generate the \(12 \times K\) weight matrix on the CPU. This matrix specifies the contribution of each FFT bin to each of the 12 chromatic semitones.

function createChromaFilterbank(numBins, sampleRate, fftSize) {
  const filterbank = Array.from({ length: 12 }, () => new Float32Array(numBins));
  const A4_FREQ = 440.0;

  for (let bin = 1; bin < numBins; bin++) {
    const freq = (bin * sampleRate) / fftSize;
    if (freq < 27.5) continue; // Skip frequencies below A0

    // Fractional MIDI pitch
    const midiPitch = 12 * Math.log2(freq / A4_FREQ) + 69;
    const pitchClass = ((Math.round(midiPitch) % 12) + 12) % 12;

    // Apply Gaussian weighting centered at the nominal pitch
    const deviation = midiPitch - Math.round(midiPitch);
    const weight = Math.exp(-0.5 * Math.pow(deviation / 0.4, 2));

    filterbank[pitchClass][bin] += weight;
  }

  // Normalize each pitch class row
  for (let c = 0; c < 12; c++) {
    let sum = 0;
    for (let bin = 0; bin < numBins; bin++) {
      sum += filterbank[c][bin];
    }
    if (sum > 0) {
      for (let bin = 0; bin < numBins; bin++) {
        filterbank[c][bin] /= sum;
      }
    }
  }

  return filterbank;
}

Step 2: GPU.js Kernel Implementation

Using gpu.js, define a kernel that computes the dot product between the 12 chroma filter rows and the magnitude values of each STFT frame.

const { GPU } = require('gpu.js');
const gpu = new GPU();

/**
 * Multiplies the Chroma Filterbank [12 x K] by STFT Frames [K x T]
 * Output Dimensions: [T, 12] (Width: T frames, Height: 12 chroma bins)
 */
const computeChromagramKernel = gpu.createKernel(
  function (filterbank, stftFrames, numBins) {
    const chromaIdx = this.thread.y; // 0 to 11
    const frameIdx = this.thread.x;  // 0 to T - 1

    let sum = 0.0;
    for (let k = 0; k < numBins; k++) {
      sum += filterbank[chromaIdx][k] * stftFrames[k][frameIdx];
    }
    return sum;
  }
).setOutput([/* totalFrames */, 12]);

Step 3: Executing the Pipeline

Combine the filterbank and input STFT data, set the kernel output dimensions dynamically, and execute the kernel:

function computeChromagram(stftMagnitudes, sampleRate, fftSize) {
  const numBins = fftSize / 2;
  const numFrames = stftMagnitudes[0].length; // Assuming [numBins x numFrames]

  // 1. Generate Filterbank Matrix [12 x numBins]
  const filterbank = createChromaFilterbank(numBins, sampleRate, fftSize);

  // 2. Set dynamic kernel dimension
  computeChromagramKernel.setOutput([numFrames, 12]);

  // 3. Execute matrix projection on the GPU
  const chromagram = computeChromagramKernel(filterbank, stftMagnitudes, numBins);

  return chromagram;
}

Output Interpretation and Normalization

The resulting output is a 2D array of dimensions \(12 \times T\). The indices \(0\) through \(11\) correspond to:

  • 0: C
  • 1: C# / Db
  • 2: D
  • 3: D# / Eb
  • 4: E
  • 5: F
  • 6: F# / Gb
  • 7: G
  • 8: G# / Ab
  • 9: A
  • 10: A# / Bb
  • 11: B

To make the pitch profiles invariant to audio volume differences across time, apply an \(L_2\) or Euclidean norm across the 12 bins for every frame in a subsequent normalization pass.
