Attach Existing Canvas to a GPU.js Kernel

GPU.js allows developers to accelerate computations using WebGL, including rendering visual outputs directly to the screen via graphical kernels. By default, GPU.js creates its own hidden canvas element for graphical outputs, but you can explicitly bind an existing HTML5 canvas from your DOM instead. This article demonstrates how to attach a pre-existing <canvas> element to a GPU.js instance and configure a graphical kernel to render directly into it.

1. Define the Canvas in HTML

Ensure your HTML contains a <canvas> element with explicit dimensions or an ID for referencing in JavaScript:

<canvas id="my-canvas" width="512" height="512"></canvas>

2. Pass the Canvas to the GPU Instance

The most reliable way to attach an existing canvas element is to pass it directly into the GPU constructor options. When GPU.js initializes, it will use the WebGL context associated with this specific canvas rather than instantiating a new offscreen canvas.

const canvas = document.getElementById('my-canvas');

// Initialize GPU.js using the existing canvas
const gpu = new GPU({
  canvas: canvas,
  mode: 'webgl2' // Falls back to 'webgl' if webgl2 is unsupported
});

Note: Ensure that no 2D context (canvas.getContext('2d')) has been initialized on this canvas prior to passing it to GPU.js, as a canvas can only host one context type at a time.

3. Create a Graphical Kernel

When creating the kernel, set the graphical setting to true. This instructs the kernel to use the special this.color(r, g, b, a) function to set pixel colors instead of returning numerical values. The output dimensions must also match or scale to your target canvas.

const renderKernel = gpu.createKernel(function() {
  // Normalize pixel coordinates
  const x = this.thread.x / this.output.x;
  const y = this.thread.y / this.output.y;

  // Set color for each pixel: this.color(r, g, b, a)
  // Values must be floats between 0 and 1
  this.color(x, y, 0.5, 1.0);
}, {
  output: [512, 512],
  graphical: true
});

4. Execute the Kernel

Run the kernel function to perform the calculation and update the attached canvas:

renderKernel();

Once executed, GPU.js draws the resulting frame directly onto the attached #my-canvas element in the DOM without requiring manual buffer copying or canvas swaps. If you update kernel parameters and call renderKernel() repeatedly (for example, inside a requestAnimationFrame loop), the existing canvas will continuously update with hardware-accelerated visuals.
