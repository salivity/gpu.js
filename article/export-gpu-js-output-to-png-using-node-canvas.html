Export GPU.js Output to PNG Using Node-Canvas

GPU.js allows developers to run complex, parallel computations on the GPU using WebGL, but it lacks native file-system capabilities to export images directly to disk in a Node.js environment. However, you can achieve this by pairing GPU.js with node-canvas. By configuring a GPU.js graphical kernel, capturing the rendered pixel buffer, and feeding that data into a node-canvas instance, you can render computations on the GPU and immediately write the output as a PNG file using standard Node.js file system APIs.

How the Pipeline Works

GPU.js operates in Node.js by utilizing headless-gl under the hood. While it can compute values and render pixels in an off-screen WebGL context, it cannot generate file encodings like PNG or JPEG on its own.

The node-canvas package fills this gap by implementing an off-screen HTML5 Canvas API backed by Cairo. By transferring raw pixel arrays from the GPU.js context to a node-canvas 2D rendering context, you can leverage the canvas's .toBuffer() method to encode the raw byte array into a PNG and save it using Node's fs module.

Step-by-Step Implementation

  1. Install Dependencies: Ensure you have the required packages installed in your project:

    npm install gpu.js canvas

  2. Create a Graphical Kernel: Initialize GPU.js and create a kernel with the graphical: true option. Inside the kernel function, use this.color(r, g, b, a) to define the output pixel colors.

  3. Extract Pixel Data: Call the kernel, then use the internal canvas or kernel.getPixels() method to retrieve the raw Uint8Array or Uint8ClampedArray containing the RGBA color components.

  4. Transfer to Node-Canvas and Save: Create an instance of node-canvas matching your kernel's dimensions. Create an ImageData object, assign the pixel values from GPU.js, draw it to the 2D context, and write the generated PNG buffer to the disk.

Complete Example Code

const { GPU } = require('gpu.js');
const { createCanvas, createImageData } = require('canvas');
const fs = require('fs');

const width = 512;
const height = 512;

// Initialize GPU.js
const gpu = new GPU();

// Define a graphical kernel
const renderKernel = gpu.createKernel(function() {
  // Generate a simple gradient
  const r = this.thread.x / this.output.x;
  const g = this.thread.y / this.output.y;
  const b = 0.5;
  this.color(r, g, b, 1);
})
.setOutput([width, height])
.setGraphical(true);

// Run the kernel
renderKernel();

// Extract the raw RGBA pixels (Uint8Array)
const pixels = renderKernel.getPixels();

// Set up node-canvas
const canvas = createCanvas(width, height);
const ctx = canvas.getContext('2d');

// Create and populate ImageData
const imgData = createImageData(new Uint8ClampedArray(pixels.buffer), width, height);
ctx.putImageData(imgData, 0, 0);

// Export directly to disk as PNG
const buffer = canvas.toBuffer('image/png');
fs.writeFileSync('output.png', buffer);

// Clean up GPU memory
gpu.destroy();

Handling Coordinate Flips

WebGL's coordinate system originates at the bottom-left corner, whereas standard 2D canvases and image formats originate at the top-left corner. When using kernel.getPixels(), the vertical axis may appear inverted. To resolve this, you can invert the Y-index computation directly inside the kernel logic or flip the canvas vertically before drawing the image data:

// Flipping vertically using 2D context transformations
ctx.save();
ctx.scale(1, -1);
ctx.drawImage(canvas, 0, -height);
ctx.restore();

By combining the parallel rendering power of GPU.js with the file-encoding capabilities of node-canvas, you create a high-performance pipeline capable of outputting procedurally generated images, simulations, and data visualizations directly to PNG files in headless Node.js environments.
