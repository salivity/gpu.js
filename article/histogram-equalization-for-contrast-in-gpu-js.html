Histogram Equalization for Contrast in gpu.js

Histogram equalization is a digital image processing technique used to improve image contrast by redistributing the most frequent pixel intensity values evenly across the available spectrum. This article explains how to implement histogram equalization using gpu.js to leverage parallel hardware acceleration in the browser or Node.js. It details the core mathematical steps—calculating luminance, generating a Cumulative Distribution Function (CDF), and remapping pixel intensities through a WebGL compute kernel.

The Histogram Equalization Workflow

Equalizing an image's histogram involves four distinct stages:

  1. Luminance Extraction: Converting RGB pixel values to grayscale or extracting the lightness channel in color spaces like HSL.
  2. Histogram Computation: Counting the frequency of each intensity value (typically 0 to 255).
  3. Cumulative Distribution Function (CDF) Calculation: Computing the running total of the histogram frequencies to generate a mapping function.
  4. Intensity Remapping: Applying the normalized CDF as a lookup table (LUT) to transform the original image pixels.

While steps 2 and 3 involve reduction operations that run efficiently on the CPU or via multi-pass reduction shaders, steps 1 and 4 are massively parallel and gain significant performance advantages when run on the GPU using gpu.js.

Step 1: Extracting Luminance and Histogram

Because standard WebGL 1.0/2.0 contexts do not natively support atomic operations for arbitrary histogram bins without advanced extensions, the fastest approach in JavaScript typically combines a CPU histogram reduction with a GPU pixel remapping kernel.

First, extract the pixel data from an HTML <canvas> element and compute the 256-bin histogram:

function getHistogram(imageData) {
  const data = imageData.data;
  const histogram = new Uint32Array(256);
  
  for (let i = 0; i < data.length; i += 4) {
    // Perceived luminance calculation
    const luminance = Math.round(
      0.299 * data[i] + 0.587 * data[i + 1] + 0.114 * data[i + 2]
    );
    histogram[luminance]++;
  }
  return histogram;
}

Step 2: Calculating the Normalized CDF Lookup Table

The Cumulative Distribution Function accumulates the histogram frequencies to determine how intensities should be scaled:

function computeLookupTable(histogram, totalPixels) {
  const cdf = new Float32Array(256);
  let cumulativeSum = 0;

  for (let i = 0; i < 256; i++) {
    cumulativeSum += histogram[i];
    cdf[i] = cumulativeSum;
  }

  // Find the minimum non-zero cumulative value
  let cdfMin = 0;
  for (let i = 0; i < 256; i++) {
    if (cdf[i] > 0) {
      cdfMin = cdf[i];
      break;
    }
  }

  // Generate the normalized 0-255 lookup table
  const lut = new Float32Array(256);
  for (let i = 0; i < 256; i++) {
    lut[i] = Math.round(((cdf[i] - cdfMin) / (totalPixels - cdfMin)) * 255);
  }
  
  return lut;
}

Step 3: Implementing the GPU Remapping Kernel

With the lookup table ready, use gpu.js to apply the transformation across all pixels simultaneously. The kernel reads the original image data, converts each pixel to YCbCr or preserves color balance, applies the lookup table to scale the intensity, and outputs the equalized pixel.

import { GPU } from 'gpu.js';

const gpu = new GPU();

function createEqualizationKernel(width, height) {
  return gpu.createKernel(
    function (imagePixels, lut) {
      const x = this.thread.x;
      const y = this.thread.y;

      // Extract current pixel channels (normalized 0 to 1 in gpu.js textures)
      const r = imagePixels[y][x][0] * 255;
      const g = imagePixels[y][x][1] * 255;
      const b = imagePixels[y][x][2] * 255;
      const a = imagePixels[y][x][3];

      // Calculate original luminance
      const yVal = Math.floor(0.299 * r + 0.587 * g + 0.114 * b);

      // Fetch equalized luminance from the LUT
      const newY = lut[yVal];

      // Scale RGB channels to preserve hue and saturation
      const scale = yVal === 0 ? 0 : newY / yVal;
      
      const outR = Math.min(255, r * scale) / 255;
      const outG = Math.min(255, g * scale) / 255;
      const outB = Math.min(255, b * scale) / 255;

      this.color(outR, outG, outB, a);
    }
  )
  .setOutput([width, height])
  .setGraphical(true);
}

Step 4: Executing the Pipeline

To apply the enhancement:

  1. Render your source image to an offscreen canvas and retrieve its ImageData.
  2. Generate the histogram and CDF lookup table using the CPU functions.
  3. Pass the source image and the lookup table into the gpu.js kernel.
  4. Render the output canvas to the screen.

Using this hybrid approach ensures that pixel remapping processes in parallel via WebGL fragment shaders, allowing real-time histogram equalization even on high-resolution images or video streams.
