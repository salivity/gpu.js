Simulate Crystal Growth and Dendrites via GPU.js

This article explores whether crystal growth and dendritic solidification patterns can be simulated using gpu.js, an open-source JavaScript library for GPU-accelerated computing. It details the underlying mathematical frameworks—specifically Phase-Field models and Cellular Automata—and demonstrates how gpu.js translates these stencil-based physical simulations into high-performance WebGL shaders. By leveraging hardware acceleration directly in the browser or Node.js environment, developers and researchers can achieve real-time, interactive visualizations of complex metallurgical and physical phenomena.

Feasibility and Underlying Physics

Simulating dendritic solidification via gpu.js is entirely feasible. Dendrite formation in supercooled melts is governed by coupled partial differential equations that describe heat diffusion, phase transitions, and surface tension anisotropy.

The two most common approaches to modeling this behavior are:

  1. Phase-Field Models (e.g., the Kobayashi Model): These models use continuous order parameters to track the boundary between liquid and solid phases alongside the local temperature field. Calculating the evolution requires solving the Allen-Cahn equation coupled with thermal diffusion.
  2. Cellular Automata (CA): A discrete model where space is partitioned into a uniform lattice. State transitions occur based on local neighbor states, temperature, and stochastic rules that dictate crystallographic orientation.

Both methodologies rely on local, spatial neighbor updates (stencil operations), making them ideal for the Single Instruction, Multiple Data (SIMD) execution model that GPUs provide.

How GPU.js Executes Solidification Simulations

GPU.js works by transpiling JavaScript functions into WebGL shaders (GLSL). When computing a simulation grid, each pixel or cell is mapped to an independent GPU execution thread.

In a solidification model, every cell must calculate its next state based on its current state and the states of its adjacent neighbors (Moore or von Neumann neighborhoods):

  • Laplacian Computation: Heat dissipation and phase-order diffusion require calculating spatial derivatives using finite difference approximations (e.g., a 5-point or 9-point Laplacian stencil). In gpu.js, this is achieved by sampling adjacent coordinates (this.thread.x ± 1, this.thread.y ± 1) within the kernel.
  • Anisotropy Functions: Dendritic branching requires preferential growth along specific crystallographic axes (such as four-fold or six-fold symmetry). GPU.js evaluates trigonometric formulations of gradient angles inside the kernel per thread at full hardware speed.
  • Ping-Pong Texturing: Time-stepping requires reading from an input state at time \(t\) and writing to an output buffer at time \(t + \Delta t\). GPU.js handles this by rendering directly to textures and cycling the inputs and outputs across successive animation frames.

Practical Considerations and Performance

Simulating these dynamics via gpu.js offers distinct advantages alongside certain technical constraints:

  • Real-Time Visual Feedback: By compiling to WebGL, gpu.js avoids the overhead of passing large matrix arrays from CPU memory to the graphics card on every step. The simulation data remains in GPU memory and can be rendered directly to a canvas in real time.
  • Precision Constraints: Phase-field models can suffer from numerical instability if gradient steps are too large or floating-point precision is insufficient. WebGL 1.0 environments sometimes struggle with 32-bit floating-point precision textures; ensuring WebGL 2.0 support is essential for stable numerical integration.
  • Dimensionality: 2D simulations run seamlessly at high frame rates on standard consumer-grade hardware. While 3D simulations are possible in gpu.js by mapping volumetric coordinates to 2D texture atlases, memory bandwidth and WebGL texture size limits will constrain the resolution of large 3D domains.

GPU.js is a capable and accessible tool for simulating crystal growth. It provides researchers and developers with a simple JavaScript API that harnesses raw graphics hardware to model complex, computationally intensive dendritic patterns without needing native C++ or CUDA implementations.
