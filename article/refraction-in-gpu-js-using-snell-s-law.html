Refraction in GPU.js Using Snell's Law

This article explains how to simulate optical refraction through transparent spheres using Snell's Law inside a GPU.js shader. You will learn the core vector mathematics behind ray-sphere intersections, how to compute the refracted direction when entering and exiting a surface, and how to write a functional GPU.js kernel that renders transparent spherical geometry.

The Mathematics of Snell's Law

Refraction describes the change in direction of a wave passing from one medium to another. Snell's Law defines this relationship:

\[n_1 \sin(\theta_1) = n_2 \sin(\theta_2)\]

Where:

  • \(n_1\) is the refractive index of the initial medium (e.g., air \(\approx 1.0\)).
  • \(n_2\) is the refractive index of the second medium (e.g., glass \(\approx 1.5\), water \(\approx 1.33\)).
  • \(\theta_1\) is the angle of incidence.
  • \(\theta_2\) is the angle of refraction.

Vector Formulation of Refraction

To compute the refracted ray vector \(\vec{R}\) given an incident normalized ray \(\vec{I}\) and surface normal \(\vec{N}\):

  1. Calculate the ratio of refractive indices: \(\eta = \frac{n_1}{n_2}\).
  2. Compute the cosine of the incident angle: \(\cos(\theta_1) = -\vec{N} \cdot \vec{I}\).
  3. Calculate the discriminant for Total Internal Reflection (TIR): \[k = 1.0 - \eta^2 (1.0 - \cos^2(\theta_1))\]
  4. If \(k < 0\), total internal reflection occurs, meaning no light refracts through the surface.
  5. If \(k \ge 0\), the refracted ray direction is: \[\vec{R} = \eta \vec{I} + (\eta \cos(\theta_1) - \sqrt{k}) \vec{N}\]

Handling Ray-Sphere Intersection

A sphere is defined by a center point \(\vec{C}\) and radius \(r\). For a ray originating at \(\vec{O}\) with direction \(\vec{D}\):

  1. Vector from origin to center: \(\vec{L} = \vec{C} - \vec{O}\).
  2. Projection of \(\vec{L}\) onto \(\vec{D}\): \(t_{ca} = \vec{L} \cdot \vec{D}\).
  3. Perpendicular distance squared: \(d^2 = (\vec{L} \cdot \vec{L}) - t_{ca}^2\).
  4. If \(d^2 > r^2\), the ray misses the sphere.
  5. Half-chord distance squared: \(t_{hc} = \sqrt{r^2 - d^2}\).
  6. The two intersection distances are \(t_0 = t_{ca} - t_{hc}\) (entry) and \(t_1 = t_{ca} + t_{hc}\) (exit).

The Two Refraction Events

Rendering a transparent sphere requires computing two separate refractions:

  1. Entry: Ray travels from air (\(n_1 = 1.0\)) to sphere medium (\(n_2 = 1.5\)). The normal points outward from the sphere center.
  2. Exit: Ray travels through the interior from sphere medium (\(n_1 = 1.5\)) back to air (\(n_2 = 1.0\)). The normal at the exit point must be inverted (\(-\vec{N}\)) to point into the sphere opposite to the propagation direction.

Implementing in GPU.js

Because GPU.js converts JavaScript functions into WebGL fragment shaders, calculations should use primitive numbers rather than complex object abstractions for maximum performance.

const { GPU } = require('gpu.js');
const gpu = new GPU();

const renderKernel = gpu.createKernel(function(width, height) {
    // Thread pixel coordinates
    const px = this.thread.x;
    const py = this.thread.y;

    // Normalized Device Coordinates (-1 to 1)
    const u = (px / width) * 2.0 - 1.0;
    const v = (py / height) * 2.0 - 1.0;

    // Camera setup
    const rayOx = 0.0;
    const rayOy = 0.0;
    const rayOz = -3.0;

    // Ray direction (normalized)
    let rayDx = u;
    let rayDy = v;
    let rayDz = 1.5;
    const rayLen = Math.sqrt(rayDx * rayDx + rayDy * rayDy + rayDz * rayDz);
    rayDx /= rayLen;
    rayDy /= rayLen;
    rayDz /= rayLen;

    // Sphere attributes: center (0,0,0), radius 1.0
    const sphereCx = 0.0;
    const sphereCy = 0.0;
    const sphereCz = 0.0;
    const radius = 1.0;

    // Indices of refraction
    const nAir = 1.0;
    const nSphere = 1.5;

    // Ray-Sphere Intersection
    const lx = sphereCx - rayOx;
    const ly = sphereCy - rayOy;
    const lz = sphereCz - rayOz;

    const tca = lx * rayDx + ly * rayDy + lz * rayDz;
    const d2 = (lx * lx + ly * ly + lz * lz) - (tca * tca);

    if (d2 > radius * radius) {
        // Background color (gradient)
        this.color(0.1, 0.1, 0.2, 1.0);
        return;
    }

    const thc = Math.sqrt(radius * radius - d2);
    const t0 = tca - thc; // First intersection point (entry)

    // --- First Refraction: Entering Sphere ---
    const hit1X = rayOx + rayDx * t0;
    const hit1Y = rayOy + rayDy * t0;
    const hit1Z = rayOz + rayDz * t0;

    // Normal at entry
    const n1X = (hit1X - sphereCx) / radius;
    const n1Y = (hit1Y - sphereCy) / radius;
    const n1Z = (hit1Z - sphereCz) / radius;

    const eta1 = nAir / nSphere;
    const cosI1 = -(n1X * rayDx + n1Y * rayDy + n1Z * rayDz);
    const k1 = 1.0 - eta1 * eta1 * (1.0 - cosI1 * cosI1);

    if (k1 < 0.0) {
        // Total internal reflection at entry
        this.color(0.0, 0.0, 0.0, 1.0);
        return;
    }

    const sqrtK1 = Math.sqrt(k1);
    const refr1Dx = eta1 * rayDx + (eta1 * cosI1 - sqrtK1) * n1X;
    const refr1Dy = eta1 * rayDy + (eta1 * cosI1 - sqrtK1) * n1Y;
    const refr1Dz = eta1 * rayDz + (eta1 * cosI1 - sqrtK1) * n1Z;

    // --- Finding Exit Intersection Point ---
    // Ray originates inside sphere; find chord distance to exit
    const exitLDotD = (sphereCx - hit1X) * refr1Dx + (sphereCy - hit1Y) * refr1Dy + (sphereCz - hit1Z) * refr1Dz;
    const tExit = 2.0 * exitLDotD;

    const hit2X = hit1X + refr1Dx * tExit;
    const hit2Y = hit1Y + refr1Dy * tExit;
    const hit2Z = hit1Z + refr1Dz * tExit;

    // Normal at exit (inward-facing normal)
    const n2X = -(hit2X - sphereCx) / radius;
    const n2Y = -(hit2Y - sphereCy) / radius;
    const n2Z = -(hit2Z - sphereCz) / radius;

    // --- Second Refraction: Exiting Sphere ---
    const eta2 = nSphere / nAir;
    const cosI2 = -(n2X * refr1Dx + n2Y * refr1Dy + n2Z * refr1Dz);
    const k2 = 1.0 - eta2 * eta2 * (1.0 - cosI2 * cosI2);

    if (k2 < 0.0) {
        // Total internal reflection inside sphere
        this.color(1.0, 1.0, 1.0, 1.0);
        return;
    }

    const sqrtK2 = Math.sqrt(k2);
    const finalDx = eta2 * refr1Dx + (eta2 * cosI2 - sqrtK2) * n2X;
    const finalDy = eta2 * refr1Dy + (eta2 * cosI2 - sqrtK2) * n2Y;
    const finalDz = eta2 * refr1Dz + (eta2 * cosI2 - sqrtK2) * n2Z;

    // Sample background or environment pattern using final refracted ray
    const grid = (Math.floor((hit2X + finalDx * 4.0) * 2.0) + Math.floor((hit2Y + finalDy * 4.0) * 2.0)) % 2.0;
    if (grid === 0.0) {
        this.color(0.8, 0.4, 0.1, 1.0);
    } else {
        this.color(0.2, 0.6, 0.9, 1.0);
    }
}).setOutput([512, 512]).setGraphical(true);

renderKernel(512, 512);

Performance Considerations in GPU.js

  • Maintain Flat Arithmetic: Avoid instantiating custom JavaScript classes or Array objects inside the GPU kernel loops. The transpiler converts flat variable declarations directly into native WebGL registers.
  • Normalize Carefully: Ensure that both the initial camera ray direction and the surface normal vectors are unit-length. Neglecting normalization creates distorted refraction angles and inaccurate Total Internal Reflection thresholds.
  • Epsilon Offsets: When extending this approach to multiple objects, offset the origin of subsequent rays by an epsilon factor (e.g., \(10^{-4}\)) along the normal to prevent self-intersection artifacts known as surface acne.
